# 寿康宫回宫面太后，五连问一问一答（第56集第899幕）

局面类型：被试探 / 被当众发难（压力面）
对方：太后，后宫最高长辈，卧病，手里握着是否容得下甄嬛的最后一句话；眉庄在场，是太后喜欢的人，也是甄嬛的好姐妹。太后最在意的是后宫平衡、皇家颜面，以及不让皇帝身边再出一个狐媚的人。
甄嬛的处境：弱。刚回宫第二天，废妃重入宫，有孕在身；一进门先跪着，对方迟迟不叫起；四周没有自己带来的人。
她的目的：一场问话里不落任何一条罪名，让太后把“防备”降成“可以用”。她没有想赢这场对话，只想过关。

## 1. 人设和差异化

她在太后面前立的是收敛、惶恐、不争的人。

和前一天在景仁宫的样子比：给皇后请安时她说“恭祝娘娘凤体康健、千岁金安”（第56集第894幕），还主动奉上佛珠，进退从容；给太后请安只说“愿太后凤体康健、福泽万年”（第56集第899幕），每一句都留意太后的脸色。博主观点：同一个人，面对皇后冷静克制，面对太后察言观色、小心翼翼（BV1sWGwzZEA9，约02:15至02:29）。

和眉庄比：眉庄可以逗太后，可以说“越活越年轻”，甄嬛不能。两个人在同一个房间里分工明确，眉庄负责松，甄嬛负责守。博主观点：眉庄一直在看甄嬛的脸色和太后的脸色，随时准备兜底（约06:10至06:16、07:55至07:58）。

为什么对上太后的胃口：太后要的是一个认罪、认错、不炫耀的人。甄嬛每被追问一次，就多认一次小错，把自己放到“可以教导”的位置，太后的火就一点点退下去。

## 2. 读人

太后：
- 开场“回来了？永寿宫住得还习惯？”是寒暄的壳。永寿宫刚被皇帝花大钱重修过（第55集第879幕、第56集第892幕可见整修一事），这句话要看甄嬛会不会因宠而骄。博主观点：假如甄嬛回答装修得很好，太后就有借口发难（约03:16至03:48）。
- 甄嬛说了不安之后，太后立刻接“虽然奢华，皇帝要宠着你，也不算什么”，转头抱怨药苦。说明她要的试探结果已经拿到，发难的借口没了，于是换成发脾气。博主观点：太后失去借口后开始找事（约04:32至04:36）。
- “有身子的人还叫跪着？你来服侍哀家漱口。”嘴上是体恤，实际是让甄嬛站到她身边被近距离打量。博主观点：太后全程不看茶杯，只盯着甄嬛，等她手抖出错（约06:16至06:31）。
- 第二轮指责“服侍人的功夫见长，难怪去了甘露寺那么久，还叫皇帝念念不忘，倒真学会了狐媚惑主那一套”。博主观点：服侍得好和服侍得不好都会被抓住，这是只要领导想找茬就一定找得到的题（约06:48至07:13）。
- 第三问、第四问、第五问越问越近：先问为什么惶恐，再问是不是故意设计，最后问为什么撇下女儿又肯回头。博主按难度给了三到五星（约07:52、08:36、10:42）。
- 太后听到坦白之后的反应是“果真如此，倒是哀家错怪你了”，说明她要的是一个她能接受的说法，并不需要完整真相。
- 太后管得很严：眉庄刚想开口帮腔，被一句“哀家跟她说话，你插什么嘴？”挡回去。第36集第590幕太后问莞嫔“你可知罪”时，也用过同样的做法打断眉庄，说明太后每次问罪都要当事人自己回答。

眉庄：
- 太后叫甄嬛起来之后，转头怪眉庄“你怎么看着熹妃这样跪着，也不提醒哀家叫她起来”。眉庄回的话把甄嬛跪着说成“太后的孙儿跪着”，太后当场笑了。博主观点：太后是在给自己找台阶，眉庄的回答让这个台阶很舒服（约12:26至13:04）。

甄嬛看出来的细节：太后每个问题都是顺着她上一句话往下压，没有突然换题。所以她的回答只回应眼前这一句，不多加一个字，不给下一问留抓手。

## 3. 布局链条

目标：这一场只求平安过关，不求立功。
铺垫：
1. 回宫第二天上午先去景仁宫请安，送佛珠，把最容易出事的皇后一关先过了（第56集第894幕）。
2. 下午与眉庄同行。眉庄说“你昨儿才回宫，不如同我一起去向太后请安吧”（第56集第898幕），甄嬛借眉庄受宠的位置入场，没有单独面见。
3. 博主观点：眉庄去太后宫中从不带侍女，甄嬛这次也没带，是刻意收敛（BV1sWGwzZEA9，约00:50至01:03）。

借谁的手：眉庄。她负责逗笑、缓场、替甄嬛把“跪着”这件事讲成孙儿请安。

等什么时机：
- 第一问甄嬛当场答完，不拖。
- 第四问是全场风险最高的一问。博主观点：甄嬛脸上出现一丝慌乱，随后迅速镇定，选择不否认（约08:52至09:15）。

怎么收网：按太后每一问各接一个短答案。
1. 问住得习惯不习惯，答不安，不提装修好坏。
2. 被指狐媚惑主，只说惶恐，不替自己辩护。
3. 问为什么惶恐，答戴罪之身，把一切归给皇帝的旧情和怜悯。
4. 问是不是故意设计，先说不敢欺瞒，再交代一个能解释得通的经过，最后把过错揽到自己没有及时禀明。
5. 问为什么离宫又回头，答恨的是诬陷之人，不敢怨皇上，离宫是万念俱灰，回来是看到皇上对她有情。

留了什么后手：
- 太后叫她起身、赐座，局面从“面试”转成“训示”，这是下一张卡的内容（见局卡B12）。
- 她没有求任何东西，没有为自己或家人开口，所以太后找不到挑剔的地方。

## 4. 关键话术

- 第56集第899幕 甄嬛：“永寿宫太过奢华，臣妾很是不安。”
  为什么管用：先把自己和奢华分开，用不安替代享受，堵住恃宠而骄的指责。

- 第56集第899幕 甄嬛：“太后言重了，臣妾实在惶恐。”
  为什么管用：被骂狐媚惑主时，对内容不争一个字，只表态度。争内容就会落进狐媚这个话题里。

- 第56集第899幕 甄嬛：“臣妾乃戴罪之身，皇上顾念旧情来甘露寺探望，臣妾感激涕零，不想一朝有孕，皇上思虑皇儿是皇室血脉，不忍其流落在外，所以格外怜悯臣妾。”
  为什么管用：自称戴罪之身，把主动权都放在皇帝一边，自己只是被怜悯的人，太后找不到她邀宠的话柄。

- 第56集第899幕 甄嬛：“臣妾不敢欺瞒太后，皇上与臣妾并非偶遇，因为当时臣妾未出月而离宫，身子一直不好，所以迁居凌云峰长住，皇上来甘露寺时不见臣妾，以为臣妾还病着，故而到了凌云峰探望。”
  为什么管用：被问到最敏感的一问时，先把偶遇两个字推翻，让太后感觉到坦诚；再把事实里能说得通的那一半讲出来。博主观点：领导最讨厌下属睁着眼睛说瞎话，坦诚是最有效的沟通方式，但也不会什么都说（约09:23至09:34）。这一句的风险见雷区。

- 第56集第899幕 甄嬛：“是臣妾未及时向太后真明情由，臣妾有罪。”
  为什么管用：对方语气缓和之后，抢先认一个小错。博主观点：反正太后总是要发难的，不如自己先扣个罪名（约10:22至10:26）。认的是没有及时禀报，并没有认下设计回宫。

- 第56集第899幕 甄嬛：“皇上是一国之君，不是臣妾一人之君，朝堂之事臣妾虽为父亲伤心，却也只会恨诬陷之人，不敢怨恨皇上，臣妾当日执意离宫，是以为皇上对臣妾毫无情分，因而万念俱灰，可皇上来看臣妾，臣妾就知道皇上并非无情，今日侥幸回宫，臣妾只想安心侍奉皇上，弥补过错。”
  为什么管用：先表明立场（不怨皇上），再讲自己离开的原因，再讲回来的原因，最后落在做事。博主观点：这一段可以拆成三点，先表态度端正，再陈述离宫原因，再解释重修旧好（约11:07至12:05）。

- 第56集第899幕 眉庄：“太后，熹妃跪着，就是她肚子里太后的孙儿跪着，一家子都向太后请安行礼，难道臣妾还要去拦吗？”
  为什么管用：不顶撞太后，也不替甄嬛辩解，只把跪着换成孙儿请安，让太后顺着笑下来。

## 5. 换到职场

### 场合一：面试（二面或终面，面试官追问你为什么离开又为什么回来）

对应的局：你曾经离开一家公司或一个行业，现在又来应聘，面试官问“当初为什么走，现在为什么回头，是不是别处不顺”。
打法：
1. 先表一个态度：对原来的团队没有怨气。
2. 说离开的真实原因，只讲自己当时的判断，不甩锅。
3. 说现在选择这里的真实原因，落在具体的事上。
4. 对他可能担心的点（稳定性、动机），主动把你的安排说出来。
一句能直接说出口的话：“当时离开是因为（真实原因），这个决定我自己负责，对原来的团队没有怨气。现在选择这里，看中的是（具体的事），我想做的是（你准备落地的一件事）。”

### 场合二：老板 1on1（老板追问你拿到某个机会的过程）

对应的局：你得到了一个资源、项目或曝光机会，老板问“这件事是不是你自己运作的”，语气带着怀疑。
打法：
1. 先说老板关心的点，让他知道你听懂了。
2. 只讲属实的过程，按时间顺序说，不把运作的部分说成巧合。
3. 对没有提前同步这一点主动认错，认流程上的疏漏，不认莫须有的动机。
4. 说清楚接下来怎么同步，让他安心。
一句能直接说出口的话：“这件事我没有提前跟您同步，是我的疏漏。经过是这样的：（按时间说事实）。后面这类事我会在（具体时点）先跟您对一下。”

## 雷区

- 第四问的回答里，她讲的迁居凌云峰是真事，但省掉了自己的安排。第53集第848幕苏培盛说：“前两日正说起二月二龙抬头要敬香踏春的事情，奴才就尽力地劝皇上到甘露寺来敬香，到时候再引皇上到凌云峰来吧。”可见皇帝到凌云峰有人安排。我们自己的判断：这种说法只在对方已经决定不再深究时才有效。职场里面对关键事实的追问，只讲属实的内容，不要靠省略让对方形成一个假印象，一旦被核对出来，信用一次归零。
- 博主观点：甄嬛对着太后坦诚，是因为否认只会被拆穿，皇帝自己都知道甘露寺是设计的（约09:00至09:07）。这个判断依赖皇帝是否也清楚，职场里不要假设老板和他的老板一定不知道。
- 眉庄想插话被当场喝止。职场里替别人抢答，尤其在对方正在追问他的时候，往往让对方更被动。
- 认小错是为了换取台阶。认到自己没有做过的事上，之后会被反复拿来说。
- 太后的试探题（住得习惯吗）背后是一个陷阱。职场里领导随口问起最近环境还适应吗，先想他想听到什么，不要随口夸某个资源好。
