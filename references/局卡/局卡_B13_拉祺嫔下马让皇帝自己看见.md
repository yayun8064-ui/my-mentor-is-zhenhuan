# 拉祺嫔下马，让皇帝自己看见（第56至58集）

局面类型：被抢功陷害（遭暗算后的反制） / 立威管人
对方：祺嫔（瓜尔佳文鸳），皇后一系，爱撒娇争宠，一激就炸，皇帝一直当她是肤浅可爱。皇帝，纵容祺嫔，最在意自己不被怨怼、不被人糊弄。欣贵人，被祺嫔压着、抢宠，想要自己做一宫主位。苏培盛，皇帝身边最懂他的人，是甄嬛的自己人。
甄嬛的处境：官面上位高（熹妃），有孕，皇帝宠着；实际上敌人背后有皇后和瓜尔佳氏，皇帝对祺嫔的印象是纵容包庇。回宫第二天被人在轿辇路上做手脚，没有抓到证据。
她的目的：让祺嫔在皇帝心里从可爱变成恶习，最后由皇帝亲手降她的位分，自己不留下挟私报复的名声。

## 1. 人设和差异化

她在皇帝面前一直是体谅、识大体、肯为别人说话的人。轿辇出事那晚，皇帝要重罚，她拦着，请求皇上不要张扬此事（第57集第902幕）。这个人设让她后面的每一次开口，听起来都是为了后宫安宁，跟自己出气无关。

和其他人比：
- 祺嫔争宠靠撒娇、梦魇、半夜请皇帝，用了又用（第57集第911幕）。
- 欣贵人受了委屈，只会忍着，有苦说不出（第57集第909幕、第905幕）。
- 甄嬛把每次出手都放在皇帝能接受的话题上：积福、后宫不宁、体恤别人。

为什么对上皇帝的胃口：皇帝要的是一个不添乱、肯体谅的女人，同时又希望有人替他管后宫。她两样都给了。

## 2. 读人

皇帝：
- 纵容祺嫔：“她就是这样的性子，虽然肤浅张狂，倒也不失可爱。”（第57集第914幕）说明他对祺嫔的初始态度是宠。
- 同一幕里，她用“后宫众人以后都会群起效仿”换了说法，皇帝马上说“如你所说，朕是该对祺嫔略施薄惩，也要对欣贵人加以安慰”，说明他吃“后宫整体”这个理由。
- 他对被怨怼最敏感。第58集第922幕他列罪名时，最后一条是“因朕不来而迁怒旁人，实则是怨怼于朕”。博主观点：皇帝抓重点的能力收放自如，不想罚时装听不见，想罚时一个台阶就够了（BV1hgtczkEiA，约20:44至20:57）。
- 对他最管用的是旁观者的视角，当事人告状反而没用。博主观点：苏培盛把听到的议论讲给皇帝，皇帝自己气上心头（约11:51至11:57）。

祺嫔：
- 对宠爱的反应非常强。第57集第911幕皇帝翻了欣贵人的牌子，她半夜喊梦魇把皇帝请走。第57集第915幕她在园子里被甄嬛听见，骂熹妃“妖媚样子”。
- 沉不住气。第58集第922幕她以为皇帝没来，抄起鞭子骂：“谁说皇上不来瞧本宫的？都是你们这起子贱人调唆，一味地讨好永寿宫来作践本宫。”
- 博主观点：谁说皇上不来，这话很可能是有人故意刺激她（约15:19至15:30），剧本没有交代，这是博主的推测。

欣贵人：被压得久了，愿意站到甄嬛一边（第57集第905幕她自己来投靠）。

佩儿：被祺嫔打骂，过得不好，愿意帮甄嬛看着储秀宫（第57集第909幕）。这一步利用了一个被欺负的人，放到雷区。

苏培盛：愿意配合，并且会说话。博主观点：苏培盛和槿汐一直有暗线联系（约12:24至12:47）。剧本里第58集第919幕可见甄嬛问槿汐“你去见了苏培盛，他怎么说？”

## 3. 布局链条

目标：祺嫔降位，欣贵人上来，甄嬛自己不动手。
铺垫一，先把账记下。
1. 回宫路上轿辇滑脚，现场捡到的鹅卵石上有苔藓（第56集第900幕）。眉庄说“看来是有人存心了”。
2. 甄嬛让小允子找花匠查，说“不管是谁，既做得出来，就别怪我容不下她”（第57集第901幕）。
3. 晚上皇帝要重罚，她拦下，只说“若再有下次一并罚过”（第57集第902幕）。第二天她对浣碧说得更直白：“我到底没伤着，皇上去查出个人来也不会重罚，倒不如先按下不提，到时候一并发作才好。”（第57集第905幕）

铺垫二，收下欣贵人的投靠。
欣贵人上门诉苦，她不立刻答应，送一盆矮子松，借机点了一下苔藓的来历，说“连里面搁的鹅卵石都是精心挑过的”（第57集第905幕）。她让佩儿留在储秀宫看动静（第57集第909幕）。

铺垫三，借糙米薏仁汤，先改皇帝的看法。
第57集第911幕皇帝半夜被祺嫔从欣贵人那边请走，小允子回报后，她定下送一壶糙米薏仁汤，要当着皇帝的面（第57集第912幕）。随后她对皇帝说：“皇上以为不过纵容祺嫔几次，却不想后宫众人以后都会群起效仿……”皇帝自己说该薄惩祺嫔。博主观点：这是改变皇帝对祺嫔印象的第一步，把可爱换成恃宠而骄（约01:21至01:43）。第57集第915幕眉庄转述太后很欣慰，这一步同时兑现了局卡B12里太后的差事。

铺垫四，让苏培盛和皇帝一起把她推到前面。
第58集第920幕苏培盛端莲子汤，说熹妃闷闷不乐，再说皇帝“这么办，可没办到娘娘的心坎上”，引出让她见家人。博主观点：这一段一是把皇帝引到永寿宫，二是让皇帝带着亏欠的心情去面对后面的事（约03:53至04:14）。

借谁的手：苏培盛（递话、选项）、欣贵人（当场陈述）、佩儿（受害者）、皇帝（裁决者）。

等什么时机：第58集第921幕皇帝在永寿宫，苏培盛问翻不翻牌子，甄嬛劝他去别处，皇帝选了春禧殿；苏培盛提到路过储秀宫又要听祺嫔嘀咕，皇帝追问，才有后面一串。祺嫔在这个时间点刚好因为皇帝不来而发火。

怎么收网：
1. 甄嬛先替祺嫔说话（“不过是爱吃醋罢了”），皇帝反而更生气。
2. 储秀宫来人说祺嫔不痛快，皇帝挥手不去，甄嬛说“不如皇上去看看，臣妾陪着皇上走走，就当是消食了”（第58集第921幕）。博主观点：与其背后告状，不如让领导现场抓包（约14:52至15:00）。
3. 到了储秀宫，祺嫔正在抽打宫女，皇帝亲眼看到。
4. 欣贵人说明因果，佩儿答话，皇帝自己问出佩儿侍奉过熹妃，把前后事连起来。
5. 皇帝亲口列罪、降位、迁居交芦馆，储秀宫交给欣贵人（第58集第922幕）。甄嬛在这一幕没有台词，博主观点：她在场起监工威慑的作用（约16:47至16:58）。

留了什么后手：
- 欣贵人暂代储秀宫，成为她在后宫的一个支点。
- 她没有说过祺嫔一句坏话，所有结论都由皇帝自己说出。
- 隐患：祺嫔被放出后成了皇后手里的刀，第59集第948幕她对皇后说“臣妾万死不辞”。

## 4. 关键话术

- 第57集第902幕 甄嬛：“皇上就当为臣妾和腹中的孩子积福吧，也当给那个人一次回头的机会，若再有下次一并罚过。”
  为什么管用：把不罚说成积福，同时给下一次留了名正言顺的理由。

- 第57集第914幕 甄嬛：“皇上以为不过纵容祺嫔几次，却不想后宫众人以后都会群起效仿，欣贵人之流日久难免心生怨恨，而祺嫔之流则恃宠而骄，如此一宫不宁则后宫不宁，长久下去岂非酿成大祸？”
  为什么管用：不讲自己受了什么委屈，把一件小事放大成后宫格局问题，皇帝会想到整体，不会只盯着祺嫔一个人。

- 第58集第920幕 苏培盛：“皇上，您这么办，可没办到娘娘的心坎上，娘娘高兴不了。”
  为什么管用：只说老板的做法没达到目的，不告诉他该怎么做，让老板自己问出你想要的答案。

- 第58集第921幕 苏培盛：“皇上，敬事房的人刚才来问，皇上今晚是否还要翻牌子？”
  为什么管用：只给皇帝两个选项，翻或不翻。博主观点：这是封闭式问题，比让皇帝自己想去哪好控制得多（约09:00至09:36）。

- 第58集第921幕 甄嬛：“祺嫔的性子是要强了些，但也不轻易报病喊痛的，不如皇上去看看，臣妾陪着皇上走走，就当是消食了。”
  为什么管用：看似替祺嫔说话，实际把皇帝带到现场。让老板亲眼看，比你转述有力得多。

- 第58集第922幕 皇帝：“责打无罪宫女，毫无怜悯之心，忌妒熹妃有孕，以下犯上，又因朕不来而迁怒旁人，实则是怨怼于朕。”
  为什么管用：这是皇帝自己的总结，三条罪名都是他当场看到或刚刚听到的，没有一条出自甄嬛之口。

## 5. 换到职场

这一局里能带到职场的，只有借力、证据和时机这三类做法。

### 场合一：老板 1on1（同事长期出问题，老板一直当没看见）

对应的局：某个同事反复迟交、甩锅或者跨部门拖延，已经影响你的工作，老板每次都说“他就那样”。
打法：
1. 第一次出事只记录，不追究，把事实和影响写成文字，并说明下次再出现请老板一起看。
2. 先让老板对问题形成共识，说长期这样大家都会效仿这一类对整个团队的影响，不先谈这个人。
3. 把证据备好：时间线、数据、受影响的人，不用形容词。
4. 选老板心情平稳、时间宽裕的时候谈，或者放进已有的例会。
5. 给老板两个具体选项让他选，不替他做决定。
一句能直接说出口的话：“这类延误这个月出现了（次数）次，影响了（具体项目），时间线我整理在这里。您看是先在流程上加约束，还是直接和（相关负责人）当面对一下？”

### 场合二：聊投资（投资人对你们的某个说法有疑问）

对应的局：投资人对你们的口径或进展存疑，只听你讲，他很难判断。
打法：
1. 先问清他最怀疑哪一点，只回应这一点。
2. 主动给出可以核验的原始数据和可以访问的现场，不自己下结论。
3. 请对方挑一个他信得过的第三方（客户、老股东）直接去问，不预先统一口径。
4. 时机上选在你有新数据或新进展的时候，让事实自己说话。
一句能直接说出口的话：“您可以直接看我们的（原始数据）和（客户名单），挑您想聊的任何一位去问，我们不预先打招呼。”

## 雷区

- 利用佩儿：把一个被欺负的人留在敌人身边当眼线，对方的安全由你负责。职场里不能让弱势的同事替你收集信息，更不能让他承担风险。
- 苏培盛的暗示：皇帝问是不是时常议论，他回“倒也不是时常，只不过奴才偶尔听见过几次”，字面否认，实际坐实（博主观点，约10:48至11:09）。这是借别人的嘴挑拨，只在识别对手手法时有用，不能套用。
- 甄嬛对皇帝说“祺嫔不过是爱吃醋罢了”，表面替人说话，实际在引导皇帝往反方向想。同样不能套用。
- 当面羞辱：弘历说“记得要拿五个海碗那么大的壶，祺嫔的梦魇要紧，也不必煮熟了，滚了就拿过去吧”（第57集第912幕），甄嬛吩咐小允子当着皇帝的面送汤。第57集第915幕她又当面说“你有多厉害本宫不知道，本宫只知道隔墙有耳”。这样的做法让对方恨意更深。
- 对手一旦走投无路，会变成别人的刀（第59集第948幕）。把人逼到死角，后面会有反噬。
- 博主观点：新贵人（欣贵人）在现场刺激祺嫔发火，并且双方已经正式合作（约15:19至15:53）。剧本里没有证据，本卡不采用。
- 博主观点：单就责打宫女来说，降位关禁闭有点严重（约21:32至21:37）。职场里处罚要和问题大小匹配，否则旁观者会反过来同情被处罚的人。
