# 华妃遣周宁海送厚礼，甄嬛赏银打点、礼物入库不戴（第3集）

局面类型：被试探 / 拒绝（婉拒站队）
对方：周宁海，翊坤宫首领太监，替协理六宫、最得宠的华妃跑腿传话。他本人最在意差事办得有脸面、自己有油水；他背后的华妃最在意势力和面子，新人是拉拢还是敲打，她心里有数。
甄嬛的处境：弱。刚入宫的常在，位分低，没有靠山可以直接用。场合是自己的碎玉轩，看上去私下，实际上每句话每个动作都会被周宁海原样带回翊坤宫。
她的目的：华妃不能得罪，华妃的人也不能当。让周宁海回去只有好话可讲，同时不给皇后一边留下她已经站到华妃那边的口实。

## 1. 人设和差异化

她在华妃的人面前立的是懂规矩、有礼数、谢意到位，但一点没有攀附意思的新人。

和其他新人比：
- 夏冬春：皇后的人送来布料，她就当着周宁海的面抬皇后踩华妃（第3集第52幕，剧本舞台说明写周宁海听在耳里，悻然离去）。她把一次收赏变成了公开站队，而且站得很响。
- 沈眉庄：同一天赏领路太监一锭银子（第3集第45幕），那是对带路人的常规打点，对象和性质与甄嬛这一笔不同。
- 甄嬛：谢意说给周宁海听，银子递到周宁海手里，东西却不进自己的屋子。整个过程没有一句评价华妃或皇后。

为什么对上周宁海的胃口：他是跑腿的人，要的是体面和不空手。茶请了，银子给了，话也传得出去，他没有任何理由在华妃面前说她不好。

## 2. 读人

周宁海：
- 他拒了茶：“咱们娘娘规矩严，奴才呢还得给别的小主送赏去，所以也不敢多耽误了。”（第3集第51幕）说明他今天的任务是各宫逐一送赏，行程是华妃定的。甄嬛请茶给足面子，他也不勉强多坐。
- 他接了赏银，没有推辞。说明他把这份打点当作惯例，收下就是一笔人情。

华妃（通过身边人的话读出来）：
- 槿汐的判断：“小主，华妃与皇后分庭抗礼，小主千万不能怠慢。”（第3集第50幕）
- 浣碧的判断：“华妃娘娘这样厚赏，恐怕是看谁有来历，故意在拉拢吧。”（第3集第51幕）
- 流朱带回的信息：沈贵人的赏赐和甄嬛一样多，延禧宫只有富察贵人和夏常在有。（第3集第51幕）这说明华妃是按出身分档送礼，有来历的人才有份。

皇后一方：同一天，剪秋亲自带着江南织造局的料子去给夏冬春（第3集第52幕）。两边都在拉人。博主观点：领导们给谁送礼是拉拢信号，新人怎么收礼是站队信号（树懒小结界，BV1q2SEBqENg，约07:17至07:35）。

## 3. 布局链条

目标：把这次拉拢接下来，但接成一份礼貌，不接成一个立场。

铺垫：
1. 槿汐先给了方向，不能怠慢（第3集第50幕）。甄嬛一听“周公公在外边候着”，没有迟疑，说我即刻就来。
2. 同一天的入宫过程里，她已经在康禄海面前表过“更看重忠心二字”（第3集第48幕），这批下人今天都在碎玉轩里，她知道这一幕有人看着。

借谁的手：浣碧递赏银，槿汐登记入库。甄嬛自己只做三件事：说谢、请坐、点头。

等什么时机：周宁海当面开口说“华妃娘娘命奴才给您送些礼物来”之后。甄嬛的第一反应是把谢意转交给华妃本人，对礼物本身不置一词。

怎么收网：
1. 谢华妃，托周宁海转达谢意。
2. 请他坐下喝茶，给足面子。
3. 周宁海推辞后，示意浣碧送上赏银。
4. 周宁海走后，槿汐道喜，甄嬛说这些东西一时用不着，登记收入库房。
5. 流朱和浣碧开始议论拉拢，甄嬛只回了一个“嘘”的动作，把话头压住（第3集第51幕）。

留了什么后手：
- 礼物入库，没有穿戴。博主观点：一旦戴上就有了站队华妃的嫌疑，在局势没有明朗前保持中立（BV1q2SEBqENg，约04:11至04:19）。剧本里甄嬛说出口的理由只有“一时也用不着”，站队的顾虑属于博主的解读，她本人没有这样讲过。
- 第二天觐见皇后，她交代梳寻常发髻（第3集第56幕）。华妃在场时点评她“穿得简单了点，但是难掩姿色”（第3集第58幕），没有借题发挥。
- 当华妃抛出沈眉庄“国色天香”的话头时，甄嬛抢在皇后开口前把两边都夸了一遍（第3集第58幕）。
- 后续：华妃继续送东西（第7集第140幕送点心），甄嬛对着点心想到了夏冬春挨的一丈红，对槿汐说她很害怕。这说明单靠第一次的分寸并不能一劳永逸，只是先把门口守住。

## 4. 关键话术

- 第3集第50幕 槿汐：“小主，华妃与皇后分庭抗礼，小主千万不能怠慢。”
  为什么管用：提前给出基调，既不亲近也不怠慢，这一句决定了后面所有动作的力度。

- 第3集第51幕 甄嬛：“多谢娘娘美意，有劳公公向娘娘转达嫔妾的谢意。坐下喝杯茶吧。”
  为什么管用：谢意落在华妃身上，对周宁海只是请他传话和歇脚，两层都不碰礼物本身。

- 第3集第51幕 周宁海：“辜负莞常在盛情，咱们娘娘规矩严，奴才呢还得给别的小主送赏去，所以也不敢多耽误了。”
  为什么管用：对方自己把边界划清了，甄嬛顺势放他走，没有硬留。

- 第3集第51幕 甄嬛：“这些东西一时也用不着，先登记了收入库房吧。”
  为什么管用：不说不要，也不说戴，只说用不着，既不驳华妃的面子，又把礼物放到没有人看得见的地方。

- 第3集第51幕 浣碧：“华妃娘娘这样厚赏，恐怕是看谁有来历，故意在拉拢吧。”
  为什么管用：这句话本身是对的，但在周宁海刚走、院里人多的时候说出来有风险，甄嬛用动作止住了它。

- 第3集第58幕 甄嬛：“皇后娘娘母仪天下如明月光辉，华妃娘娘国色天香似明珠璀璨，臣妾等望尘莫及。”
  为什么管用：两边同等分量地夸，没有比较，也没有偏向，是前面“不站队”这条线在公开场合的落点。

## 5. 换到职场

### 场合一：聊投资（两家投资机构先后向你抛出意向，其中一家还附带了额外资源）

对应的局：一家机构主动递来明显偏厚的条件或资源，你知道另一家与它有竞争关系，你不想现在选边。
打法：
1. 谢意给到位，礼数不缺，让对方感觉被认真对待。
2. 不当场答应，也不当场拒绝，把节奏交给自己说了算。
3. 对方给的东西先收在手边，不拿出去给另一家看，也不拿来压价。
4. 对另一家同样保持礼数，让双方听到的话在分量上差不多。
一句能直接说出口的话：“谢谢（某机构）这份诚意，我们很重视。目前我们还在推进（某个阶段），等（具体节点）有明确安排，第一时间和您同步。”

### 场合二：老板 1on1（隔壁部门负责人主动向你示好，而他和你的直属老板有分歧）

对应的局：别的部门领导给你递来项目机会或资源，你的直属老板对此很敏感。
打法：
1. 当面说谢，不评价那位领导，也不评价你老板。
2. 机会先放着，不立刻动用，不在公开场合亮出来。
3. 在跟老板的常规 1on1 里，主动把这件事当作信息同步一句，让他从你这里听到，不从别人那里听到（这一步是我们补的，剧本里甄嬛没有做）。
一句能直接说出口的话：“（某部门负责人）上周提到一个合作机会，我先跟您汇报一下，想听听您觉得对我们现在的节奏有没有帮助。”

## 雷区

- 夏冬春：当着周宁海抬皇后、踩华妃（第3集第52幕）。后来华妃看着她穿皇后赏的料子，说“以为有皇后撑腰，就可以在这儿耀武扬威了吗”（第3集第59幕），一丈红随后落下。职场里对应：当着某一方的人夸另一方，话一定会传回去。
- 浣碧：在刚送走客人的院子里直接把局势说破。职场里对应：判断可以对，但说的地点和听的人要选好。
- 把礼物不用、只收着的做法，只能解决第一步。华妃的拉拢后来还在继续（第7集第140幕）。职场里对应：不选边只是缓冲，真正的位置需要靠后面的事一件件立起来。
- 银子数目：博主观点是这一笔和沈眉庄赏领路小太监的数额相同，是精心计算过的公关费，既不能太多显得巴结，也不能太少显得轻视（BV1q2SEBqENg，约03:14至03:34）。剧本第3集第45幕写眉庄一方给的是一锭银子，第3集第51幕只写“赏银”，没有写数额，两边是否相等待核，本卡不据此下结论。
