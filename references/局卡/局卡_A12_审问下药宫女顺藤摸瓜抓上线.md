# 审问下药宫女，顺藤摸瓜抓上线（第10集）

局面类型：立威管人 / 被抢功陷害（审问内鬼，追到幕后）
对方：花穗，新调来碎玉轩的宫女，原是余氏身边的人，被余氏赏了不少金银逼着办事；上线是余氏，递药的小印子是余氏手下的太监；剧本第10集第195幕还写到华妃、丽嫔、曹贵人在知道小印子被抓后商量对策，说明余氏背后有人。对方最在意的是保命和钱，嘴硬是因为怕招出主子。
甄嬛的处境：对等偏强。主子审奴婢，在自己宫里，私下，人证物证已经攥在手里（墙洞、罐盖、来历，见上一张卡）。但幕后在暗处，一旦走漏风声，上线会销毁线索。
她的目的：拿到口供，找出上线，当晚在现场人赃并获，同时留活口，对外不走漏消息。

## 1. 人设和差异化

她在花穗面前先立的是赏罚分明的好主子，翻脸之后立的是掌握了全部证据的人。

差异：
- 和流朱比：流朱一开口就是喝令花穗抬头，语气像要吃了人似的（第10集第192幕）。甄嬛先说别怕，我只是有几句话要问你，把场面压低。
- 博主观点：槿汐在团队里唱白脸，流朱唱黑脸，小允子是武力担当，甄嬛是主帅（树懒小结界，BV1j6bDzFEtz，约18:12至18:20）。这一场里黑白脸的配合很清楚：甄嬛先礼后兵，流朱出主意施压，槿汐补问细节。
- 博主观点：初期的甄嬛还能耐着性子和花穗周旋几句，后面的甄嬛都是单刀直入（约14:43至14:49）。

为什么对上花穗的胃口：花穗被钱收买，忠心有限。她需要一个能活下去的出口，甄嬛在她最怕的时候给了将功恕罪这条路。

## 2. 读人

花穗：
- 听到赏，立刻说分内应该的，是想把自己放在忠仆的位置上。
- 被问旧主时说“奴婢粗笨，从前跟不得什么好主”，在撇清和余氏的关系。甄嬛顺势接话，把余氏对她的好处直接亮出来。
- 两次答“实在不知”，说明她嘴硬，有底线，不会一击就垮。
- 被逼到临界点才开口，说明她对余氏有畏惧，同时更怕死。
- 她知道的信息很具体：墙洞、隔天一次、一更时分、两声布谷鸟叫、送药人是男人、右手掌心有疤（第10集第192幕）。甄嬛追问的就是这些能当场对上的细节。

甄嬛怎么读：先问来历，让她自己说出余氏；再用“恩惠”二字，直接把动机说在她前面，对方不可能再绕。

小印子：
- 剧本写他先是被甄嬛叙旧式地问话：“如今你在哪里当差呢？”（第10集第194幕）。他曾是甄嬛身边的旧人，后来被转给丽嫔，再转到余氏，说明他在宫里一路跟着风向走。
- 他说话滑头，“当奴才的只是跟着小主罢了，没的好坏”，直到被打才招。

余氏背后的人（第10集第195幕）：
- 丽嫔提出一了百了，曹贵人拦下，说动手反而引人注目，余氏想活，更想全家都活。说明背后的人也在读余氏。这是对手的读人，放进来是让用户看清对手在算什么。

## 3. 布局链条

目标：口供、上线、人赃并获。

铺垫：上一张卡里三条线已经齐了（墙洞、罐盖、来历），再动人。

借谁的手：
- 流朱：施压（黑脸）。
- 槿汐：补问传递方式、同党，当晚假扮花穗取药。
- 小允子：押人、守株待兔、动刑。
- 眉庄：夜里在场，认出小印子。
- 浣碧：把花穗叫进屋，剧本里写她对花穗说“小主知道你忠心，说待会要赏你呢”（第10集第193幕）。这一步是用假的好处骗人进屋，见雷区。

等什么时机：
- 流朱已经提前吩咐拿烧红的炭备着（第10集第192幕）。
- 花穗被叫进屋，先让她放下戒心，再一步步收紧。

怎么收网：
1. 放松。先夸她差事当得好，说要赏她，让她以为是好事。
2. 套话。问她从前在哪儿当差，让她自己说出余氏。
3. 亮牌。“可是她给你的恩惠也不小吧？否则你怎么敢在我宫里犯这种杀头的死罪！”
4. 对质。拿药罐盖子问她。
5. 给她一个表忠心的机会（握炭）。她退缩，说明心虚，随后跪下求饶。
6. 给出路。“这是你将功恕罪的机会”。
7. 追细节。时间、暗语、送药人的特征，全部是当晚抓人需要的信息。博主观点：这一步是关键，只抓住花穗不行，还要找出上线，再在案发现场人赃并获（BV1j6bDzFEtz，约17:17至17:23）。
8. 控制现场。花穗被捆去库房，防她自尽，对外说她被打发去了沈贵人那里；槿汐当晚假扮她去取药（第10集第192幕）。博主观点：要点有两个，留着人证活口，别打草惊蛇、统一口径（约17:46至18:08）。
9. 守株待兔。小允子带着几个太监埋伏，一抓一个准，抓到的是小印子（第10集第194幕）。
10. 审小印子：先叙旧，再问他夜里在做什么，他支吾，再用刑，他招认余氏指使（第10集第194幕）。

留了什么后手：
- 甄嬛当场定下：“这件事情，还是得向皇上皇后禀报。”（第10集第194幕）眉庄接话提醒，皇上若还念旧情就不好办。槿汐随即提到欺君之罪，这条线索指向余氏冒充除夕夜倚梅园中那个人，后面怎么用不在这一期视频的范围里，转写到19:55就结束，没有讲到。
- 对内：不告诉陵容，只告诉眉庄（第10集第192幕）。
- 对外：花穗不露面，口径是被打发去了沈贵人那里。

## 4. 关键话术

- 第10集第192幕 甄嬛：“槿汐说你差事当得不错，东西也管得井井有条，我很高兴，心里琢磨着该赏你些什么，也好叫别人知道我赏罚分明，做事更勤谨些。”
  为什么管用：把审问包在一次赏识里，花穗戒心降到最低，也等于告诉她，你的名字我已经记下了。

- 第10集第192幕 甄嬛：“余氏被降位，自然也算不得什么好主，可是她给你的恩惠也不小吧？否则你怎么敢在我宫里犯这种杀头的死罪！”
  为什么管用：先接对方的说法，再把动机说在她前面，她不用承认也被点穿了。

- 第10集第192幕 甄嬛：“你真的不懂我在说什么？那我那煎药的药罐盖子是怎么回事？”
  为什么管用：对方说了不知道之后，直接拿出一个只有做过的人才能解释的物证。

- 第10集第192幕 甄嬛：“那就好好说来，若有半句不尽不实的，立刻拖出去打死！”
  为什么管用：先划底线，再给出路。这一句是威胁，不能套用，见雷区。

- 第10集第192幕 甄嬛：“你只管说你的，这是你将功恕罪的机会，若有半分欺瞒，绝不饶你！”
  为什么管用：对方开口之后马上给一个明确的利益，让她继续往下说。

- 第10集第192幕 甄嬛：“那不就是今晚？拿药是什么时候，可有什么暗语？”
  为什么管用：对方说了一半，她没有停在“知道了”，马上追到了能用的细节。

- 第10集第192幕 甄嬛：“你有没有见过送药那人？”
  为什么管用：每问一个人，同时补一个能抓人的特征，线索从上线一路落到了具体的人。

- 第10集第192幕 甄嬛：“小允子，捆了她去库房，别叫她寻短见。若有人问起来，就说我打发她去了沈贵人那里。”
  为什么管用：保活口，也给外面一个统一的说法。

- 第10集第194幕 甄嬛：“虽然我们长久不见，但好歹也是主仆一场，我问你什么答就是了。”
  为什么管用：对旧人先说情分，再立规则，逼他自己选择是好好说还是挨打。

## 5. 换到职场

### 场合一：老板 1on1（团队里出了问题，你要先和涉事同事谈，再向老板汇报）

对应的局：交付延误、客户投诉或资料外泄，你怀疑是团队里某位同事的操作，需要先谈一次，再决定怎么向老板汇报。
打法：
1. 谈之前把证据整理好，至少三样：记录、时间点、对应的流程。不空手去。
2. 开场先肯定他做得好的部分，让谈话保持平和。
3. 让对方先把经过说一遍，你不先下结论。
4. 把你手里的事实一件件摆出来，请他解释差异，每一件只问一个问题。
5. 给他一个说清楚、补救的出路，并记下约定。
6. 向老板汇报时，只讲发生了什么、已经控制到哪里、下一步是什么。
一句能直接说出口的话：“这件事我想先听你自己说一遍。我手上有（具体记录）和（具体时间点），你把经过讲出来，后面怎么补救，我们一起想办法。”

### 场合二：面试（被问到怎么处理下属或合作方的违规）

对应的局：面试官问，你发现合作方或下属有违规，会怎么处理。
打法：
1. 先说止损：先控制影响，再追原因。
2. 再说核实：证据先齐，再约当事人单独谈。
3. 说怎么谈：让对方先讲，你对照事实，给他补救的空间。
4. 收在流程补漏上。
一句能直接说出口的话：“我会先把影响控制住，再找当事人单独谈。谈之前我先把记录整理好，开场先听他怎么说，再对照事实。结论出来之后，我更看重把流程补上，同样的口子不能再出现。”

## 雷区

- 烧红的炭、拖出去打死、对小印子动刑：剧情里是主子对奴婢，这些做法逼出来的口供，可信度靠事后对证。职场里不能用恐吓、体罚或威胁逼人招供，对方会为了脱身乱说，信任也毁了。
- 用赏识骗人进屋：浣碧对花穗说“小主知道你忠心，说待会要赏你呢”（第10集第193幕），这是设假前提。职场里不要用假好处把人叫过来再摊牌，一旦识破，对方和旁观者都会觉得你不可信。
- 对方一开始就嘴硬，两次说不知道。职场里被问到时嘴硬、绕开、反复说“忠心”，本身就成了线索。
- 结局：皇帝下旨杖毙了花穗和小印子（第10集第198幕），甄嬛事后说“我心里恨极了被人暗算，也恨极了花穗和小印子，可皇上真的下旨杀了他们，我这心里并不畅快。”（第10集第200幕）职场里对应：追查到人为止，处理结果由上面定，做调查的人也会有心理负担，先想清楚自己能不能承受。
- 博主观点：初期周旋、后期单刀直入（BV1j6bDzFEtz，约14:43至14:49）。职场里对应：谈话开场可以平和，但事实清楚之后不要继续绕圈，耽误的是别人的时间。
