# 永寿宫赐座苏培盛，把共同对手说开（第60集）

局面类型：投其所好 / 谈条件
对方：苏培盛，皇帝身边最亲近的首领太监，刚从慎刑司出来，刚被皇帝试探过一轮。最在意槿汐的安危、自己在皇帝面前的位置，其次是安全感。
甄嬛的处境：对等偏强。她是熹妃，位分高于他；但他是皇帝的人，不能被她直接使唤。私下，永寿宫，只有他和她的几个心腹。
她的目的：把苏培盛稳稳拉到自己这边，让他明白谁在保护他和槿汐、谁是共同的对手，同时不让他觉得自己背叛了皇帝。

## 1. 人设和差异化

她在苏培盛面前立的是体恤下属、坦率说话、不居功的主子。

和其他人比：
- 皇后用把柄压他，让他在慎刑司吃了几天苦头。
- 皇帝用另一种方式对他施压：先安抚，再试探他为什么没有主动汇报与槿汐往来（第60集第952幕），这里的信任出现了缝隙。
- 甄嬛一开始就是赐座、问身体，没有问罪，也没有施恩。

为什么对上他的胃口：他在宫里是个看透人情的聪明人，不喜欢绕圈子。她只说了几句实在话，又把事态的责任分给自己一部分，让他听完不觉得欠债。

## 2. 读人

苏培盛：
- 他开口先说自己：“奴才本以为自个儿的身子还挺强健的呢，没想到只到慎刑司数日，做了几天的粗活，身子就这么不济了，真是老了，不中用了。”（第60集第954幕）这是在示弱，也在暗示他受了委屈。
- 他说“奴才如今还是回到皇上的身边，倒也不敢有人说三道四的，只是槿汐那边？”（第60集第954幕）问的是槿汐，这就是他的软肋，也是他想要的承诺。
- 他不绕圈子，一句“奴才一时疏忽，没想到就连带皇后娘娘也上了心，奴才会谨记教训的”，把责任归在自己，不指名骂任何人。
- 博主观点：苏培盛从慎刑司出来后有三件事变了：不再完全中立，因为被皇后害过；与皇帝之间第一次出现信任危机；他明白皇帝可能会试探他，需要小心应对（树懒小结界，BV1MK16B6EeY，约12:37至13:25）。

甄嬛看出来的细节：他来这里表面是奉皇命送红枣雪蛤，实际也是来表态。博主观点：这是拜码头（BV1MK16B6EeY，约19:59至20:01）。

## 3. 布局链条

目标：苏培盛站在她这一边，对槿汐放心。

铺垫一，早在他被抓的时候就答应过要打点。
她在慎刑司对槿汐说“你放心，苏培盛那边我会打点好”（第59集第946幕）。后来也是她一路走到端妃那里去，第一个理由就是苏培盛在皇上身边服侍多年，是最清楚皇上脾性的（第59集第947幕）。

铺垫二，他被放出来之后，她让槿汐得以回来，并保证只罚一年月钱（第60集第951幕）。他心里清楚这是谁努力的结果。

借谁的手：皇帝。苏培盛是以送皇帝赏赐的名义来的，这样他不需要对皇帝隐瞒什么。

等什么时机：槿汐回永寿宫、苏培盛回养心殿之后。他刚回到岗位，最需要确认两件事：自己安不安全，槿汐安不安全。

怎么收网（第60集第954幕）：
1. 先赐座，再问他身体，把他当成一个值得尊重的人，不当下属使唤。
2. 先承认槿汐被议论的原因在于她在自己身边，把自己放进事情里。
3. 再提事情的起因：缨络是他不小心掉出来的。把话说开，也不责怪，只描述事实。
4. 说明自己已经尽了力，最终是皇上顾念旧情。她没有把功劳揽在自己身上。
5. 他说“谨记教训”，她接过去：“这个教训不仅公公要谨记，本宫也会牢牢记住。”
6. 他再问槿汐，她只回三个字：“你放心。”

留了什么后手：
- 他随后回家对槿汐说了那番话，问她是不是心甘情愿（第60集第955幕），槿汐的回答让两人更近。这一段是他们两人之间的事，不属于甄嬛的布局，但她为这一晚铺好了条件。
- 博主观点：这次谈话并不代表苏培盛背叛皇帝，事件最大的后果是苏培盛从不站队变成与熹妃同一阵线（BV1MK16B6EeY，约21:53至22:02，转写不清，待核）。
- 要注意的一点：博主转述的甄嬛原话是“你们能够毫发无伤地出来，可不是敌人仁慈，而是我方全力营救的结果”（BV1MK16B6EeY，约21:23至21:34，转写不清）。剧本里没有这句话，剧本里的甄嬛说的是“好在皇上顾念旧情”。以剧本为准。

## 4. 关键话术

- 第60集第954幕 甄嬛：“公公也辛苦了，浣碧，赐座。”
  为什么管用：先给体面和座位，对方的防备会下降一半。

- 第60集第954幕 甄嬛：“数日不见，公公清减了不少。”
  为什么管用：先关心他的身体，让他先谈自己的处境，不先谈事。

- 第60集第954幕 甄嬛：“公公心知肚明，槿汐会被人说三道四，也是因为她在本宫身边的缘故。”
  为什么管用：把外面的闲话归到自己头上，对方不会觉得被责怪。

- 第60集第954幕 甄嬛：“此次的事虽说是公公一不小心掉出了那枚缨络才闹出的事端，本宫一力想保住你们二人，却也无计可施，好在皇上顾念旧情。”
  为什么管用：既指出问题来自哪里，又说明自己出了力，同时把结果归功于皇帝，苏培盛听到的是一个知道进退的主子。

- 第60集第954幕 苏培盛：“是啊，奴才一时疏忽，没想到就连带皇后娘娘也上了心，奴才会谨记教训的。”
  为什么管用：这是对方的回答。他主动把这件事定性为疏忽，没有指责任何人，也留了余地。

- 第60集第954幕 甄嬛：“这个教训不仅公公要谨记，本宫也会牢牢记住。”
  为什么管用：把教训分成两份，一份是他的，一份是自己的。两个人被放在同一个位置上，他听出来的是同盟。

- 第60集第954幕 甄嬛：“你放心。”
  为什么管用：对方想要的只有一个承诺，她只说三个字。

- 第60集第954幕 苏培盛：“有娘娘这么一句话，奴才没有什么不放心的。”
  为什么管用：这是对方的确认，表示他接受了这个承诺，也接受了这条线。

## 5. 换到职场

### 场合一：老板 1on1（老板身边的得力助手刚因为一次失误挨了批评，你和他需要继续合作）

对应的局：老板的助理或项目负责人因为一次疏漏被点名，你作为相关方也被牵连。现在要和他恢复正常合作，又不想让他觉得你来问罪或来施恩。
打法：
1. 先关心人，别急着谈事。
2. 把外面的议论和你自己的位置说清楚，让他知道你没有置身事外。
3. 把事情的起因平实说一遍，不夸大他的责任，也不夸大你帮的忙。
4. 同意共同记住这次的教训，把你自己放进去。
5. 他最关心的那件事，你只给一个明确的态度，别说太多。
一句能直接说出口的话：“这几天辛苦了。这次的事我这边也有没做到位的地方，（具体哪一点）我记住了。后面（具体事项）我们提前对一下，你放心。”

### 场合二：大佬建联（需要通过大佬身边的助理或合伙人先建立信任）

对应的局：想联系的大佬身边有一位助理，所有联系都要经过他。你想让他知道你尊重他，没有打算只把他当成一条路。
打法：
1. 先把对方当作独立的人来对待，不要只当渠道。
2. 说明你理解他的工作节奏，不占用他太多时间。
3. 把你想请教的事简短说清，并问他怎么提最方便。
4. 给他一个明确的承诺，比如你不会在没有同步的情况下直接联系大佬。
一句能直接说出口的话：“我知道您这边日程很满，我只说一件事：（你想请教的具体问题）。您看怎么安排最不打扰，我都按您的节奏来。”

## 雷区

- 甄嬛在这里是把共同对手说开，但没有挑拨他与皇帝的关系。职场里要拉近一个关键人物，不要让他在上级和你之间选边，也不要请他替你向上级隐瞒什么。
- 把对方的软肋当作交换条件，是一条危险的线。苏培盛在意的是槿汐，甄嬛的“你放心”要建立在真实的救助上，她事先就做了事。职场里拿别人的私人牵挂做筹码，会失去长期信任。
- 她把功劳让给皇帝，不居功，让对方感觉到安全。职场里把功劳让给老板，只让一次，每次都说自己没出力会被看成虚伪。
- 共同对手的叙事有风险。两个人一起把第三个人定为敌人，容易从抱怨滑向结盟攻击。职场里背后议论上级或同事，最终往往会传到当事人耳朵里。
- 博主关于“拜码头”的解读比较简略，我们自己的判断：苏培盛是否真正倒向熹妃，剧本里没有明说，以后几集的行动可以验证，不要把它写成定论。
