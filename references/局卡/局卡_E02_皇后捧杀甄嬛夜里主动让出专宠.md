# 皇后捧杀，甄嬛夜里主动让出专宠（第8至9集第152至177幕）

局面类型：被捧杀（识别套路与防人）
对方：皇后宜修，加上当场的华妃、丽嫔、齐妃，最后是皇帝。皇后最在意的是保住贤良的名声，让后宫维持她压得住的局面，不让哪个新人坐大。皇帝最在意的是自己不被说成薄情寡义，前朝后宫都稳。
甄嬛的处境：弱。刚承宠就连宠七日，还得了椒房，位分只是贵人。白天一边是皇后当众抬举，一边是华妃、丽嫔当众酸她，夜里单独面对皇帝时她占上风，可这份上风正是别人瞄准的靶子。
她的目的：不接皇后递过来的高台，自己把“专宠”这个靶子摘下来，同时让皇帝觉得她是在替他着想，不在皇帝心里留下“有人欺负她”的印象，也不得罪任何人。

## 1. 人设和差异化

她在这一段里立的是受宠、但自己不敢独占的贤惠人。

和其他人比：
- 丽嫔当众说“狐媚东西，就知道纠缠皇上！”（第8集第163幕），后来又在景仁宫提四阿哥的生母，当场被皇后训斥（第8集第165幕）。嘴快的人先露了底。
- 眉庄给她的建议是“忍”，“与其以卵击石，不如静静等待”（第8集第157幕）。眉庄的忍是等，等别人先出手。甄嬛比她多走一步，自己动手把靶子拿下来。
- 华妃借“专宠”两个字想挑开她和眉庄（第8集第166幕）。甄嬛没有争辩，一句“娘娘用心良苦”把话原样还给华妃（第9集第166幕）。

为什么对上皇帝的胃口：皇帝当晚问她有没有心事，她给的理由全落在皇帝自己身上，是六宫安稳、子嗣福泽、皇帝的名声。没有一句在讲她自己委屈。

## 2. 读人

皇后：
- 汤泉宫之行，皇后临时称病不陪驾，原话是“皇上今日好兴致，本宫何不成全了皇上？”（第8集第146幕）。成全的人是她，这份情她自己先记上了。
- 甄嬛从行宫回来，单独去景仁宫补行请安礼，皇后一连串好话：“其实以妹妹你的才貌，这份恩宠早该有了”，“妹妹以后常来常往的就拿这儿当自己的家，不必拘束”（第8集第152幕）。话里没有一句提醒她收敛，反而一路往上抬。
- 后来有一天请安，皇后在众妃面前赐她开过光的万字福寿绵被，说“你盖着睡觉也好早日得个皇子”（第8集第165幕）。我们自己的判断：这句话把一个指标挂在她身上，当着华妃的面说，等于告诉所有人这个人要有孩子了。华妃马上接了一句“若来日诞下皇子，就能赶上齐妃了”（第8集第165幕），在场的人都听出了靶子的味道。
- 博主观点（脖子细哔哔叨，BV1ay2xB3E45）：皇后需要在六宫和甄嬛面前维持贤良形象，对甄嬛越大度，六宫越嫉恨她（约01:02）。皇后是在把甄嬛捧得高高的，让她松懈，有错可犯、有把柄可抓，这就是捧杀（约01:27至01:33）。赐被子的用意有几层：显得亲厚让甄嬛记她的好，给甄嬛在宫里树敌，让皇帝看见她的心意，同时提醒没有孩子的华妃甄嬛将来难对付（约03:34至03:57）。

华妃和丽嫔：
- 华妃在翊坤宫翻行房档，数着甄嬛连着几天的侍寝，丽嫔骂她缠着皇上，华妃一句“那是皇上喜欢她缠，别人想缠还缠不住”（第8集第163幕），说明华妃心里清楚根源在皇帝的偏爱，甄嬛本人没有错，她要的是让甄嬛难受。
- 博主观点：华妃不信后宫有姐妹情，借恩宠这件事想拆开甄嬛和眉庄（约07:21至07:42）。

眉庄：
- 眉庄被华妃点名抄《女论语》，又被问“怎的忘了专宠之余分一杯羹给自己的姐妹”。回来甄嬛私下问她“姐姐，你可怪我？”，眉庄答“若不是你，也会有旁人，若是旁人，我宁愿是你”（第9集第166幕）。甄嬛要的就是确认这一条没有裂。

皇帝：
- 夜里他先问“怎么醒了？”“睡不着，有心事？”，再问“怎么，有人难为你吗？”（第9集第167幕）。最后这句是递过来的口子：她只要点一个名字，皇帝就会替她出头。
- 博主观点：甄嬛不能说实话，说了像告黑状，皇帝真替她出头，她以后在后宫更难待（约10:13至10:19）。所以她换了说法，把理由从自己被针对转成劝皇帝为大局（约10:21至10:36）。

太后：
- 紧接着的下一幕，皇帝去寿康宫请安，太后提起“先帝在的时候他亲额娘舒妃专宠六宫众妃怨妒的事”（第9集第168幕）。博主观点：太后不好直说，借舒妃的旧事敲打皇帝，专宠会招来六宫怨妒（约14:19至14:30）。剧本里甄嬛说这番话在先、太后说在后，可见专宠已经是皇室里公开的忌讳，她赶在被人点名之前自己卸掉了。

## 3. 布局链条

目标：卸掉专宠这个靶子，同时保住皇帝的心。

铺垫：
1. 景仁宫单独补请安，皇后抬一句，她只接一句小话：“皇后娘娘母仪天下，若能日日见到皇后安好，便是六宫同被恩泽了。”“娘娘教诲，臣妾字字谨记在心。”（第8集第152幕）恩宠早该有了这类话，她一个字不接。
2. 在存菊堂听眉庄说“忍”，她追问“姐姐，你会生气吗？”（第8集第157幕），先把最亲近的人确认下来。
3. 景仁宫请安，当众被皇后抬，出来路上又被丽嫔和华妃酸，全部接下，不回击。对丽嫔只回一句“丽嫔娘娘侍奉圣驾已久，必然知道非礼勿言四字”（第8集第166幕），对华妃回“娘娘用心良苦”。
4. 私下对眉庄说清楚：“不论是否得宠，我与姐姐的情谊一如从前”（第8集第166幕）。

借谁的手：不借人，借的是理由。皇帝自己的名声（“男儿凉薄喜新忘旧”）、前朝后宫的牵连（“六宫妃嫔与前朝盘根错节，牵一发而动全身”），全是皇帝自己在乎的东西。

等什么时机：夜里雷雨，皇帝先开口问有没有心事，再问有没有人为难她。她等对方问完才说，并且先说“臣妾害怕”，把身段放软。

怎么收网：
1. 先示弱，只说怕，不说事。
2. 抛出一句话让皇帝自己去想：“皇上可否听过‘集宠于一身，亦是集怨于一身’？”
3. 皇帝问有没有人为难，她马上否认：“没有，没有人为难臣妾。”
4. 把请求落在制度上：“雨露均沾六宫祥和，才能延绵皇家子嗣与福泽，臣妾不敢专宠。”
5. 皇帝说“若是朕不肯呢？”，她不顶，抬一顶“皇上是明君”。
6. 皇帝还是不松口，她算一笔账：已经七日，皇帝前朝忙，后宫若成了怨气所钟之地，皇帝不能安心，而且旁人会议论皇帝凉薄。
7. 最后一句“臣妾不能让皇上烦心，臣妾不忍”，皇帝答“知道了”。

留了什么后手：
- 当晚皇帝翻了齐妃的牌子（第9集第172幕），甄嬛说“也好”。皇帝在齐妃那里坐不住，被嫌衣服颜色，说完就走（第9集第174幕）。
- 皇帝回程路过碎玉轩，听到《湘妃怨》，改了主意（第9集第176幕）。他说“那朕就明日再做明君，今夜且再做一回昏君”，她答“那臣妾明日再做贤妃，再去向齐妃姐姐请罪”（第9集第177幕）。
- 结果：专宠的名头没了，皇帝的心比之前更近。她还留了一句要去给齐妃赔罪，等于把让出去的那一份做成了明面上的人情。
- 代价：她自己并不轻松。“我自己也糊涂了，希望今日皇上不要来，可他真的不来，我却高兴不起来。”（第9集第172幕）

## 4. 关键话术

- 第9集第167幕 甄嬛：“皇上待臣妾这样好，皇上可否听过‘集宠于一身，亦是集怨于一身’？”
  为什么管用：先夸皇帝对她好，再抛一句旧话让皇帝自己去想。她没有说谁在怨，没有指名，皇帝没有被要求表态。

- 第9集第167幕 甄嬛：“没有，没有人为难臣妾。雨露均沾六宫祥和，才能延绵皇家子嗣与福泽，臣妾不敢专宠。”
  为什么管用：皇帝递来告状的口子，她先堵上，再把理由换成皇帝关心的子嗣和六宫。这样提出来是在为皇帝分忧，不会被理解成争宠失败后的抱怨。

- 第9集第167幕 甄嬛：“六宫妃嫔与前朝盘根错节，牵一发而动全身，皇上是明君。”
  为什么管用：皇帝刚说“若是朕不肯呢”，这句把后宫的事连到前朝，再顺手给皇帝戴一顶明君的帽子。皇帝再坚持就是不当明君。

- 第9集第167幕 甄嬛：“皇上若专宠臣妾而冷落其他嫔妃，旁人不免会议论皇上男儿凉薄喜新忘旧。臣妾不能让皇上烦心，臣妾不忍。”
  为什么管用：最后一击落在皇帝最怕的评价上，并且收尾回到“我不忍”，对方听到的是心疼，听不出要求。

- 第9集第166幕 甄嬛：“娘娘既让姐姐抄录女论语训示后宫众人，为的就是防止后宫争宠招惹事端，娘娘用心良苦，妹妹们一定谨遵。”
  为什么管用：对方想借专宠挑拨，她把对方自己定的规矩还给对方，句句是恭敬，没有一句可以被抓住。

- 第9集第177幕 甄嬛：“那臣妾明日再做贤妃，再去向齐妃姐姐请罪。”
  为什么管用：让出去的位置要有人承接，她当场把后续的人情安排好，皇帝看到的是她懂事，看不出赌气。

## 5. 换到职场

### 场合一：职场（部门例会上，总监当众把你捧成部门的顶梁柱，同组同事的脸色已经变了）

对应的局：你刚做成一个亮眼的项目，上级在全组面前反复夸你，还说“以后这块就靠你了”。夸奖里带着期限和指标，旁边的人开始阴阳怪气。
打法：
1. 当场只接一句小话，不接“顶梁柱”这类大词，别让夸奖在会上越抬越高。
2. 会后单独找上级，把功劳拆开讲：哪几块是谁做的，写出具体名字和具体动作。
3. 提出下一个出彩的机会让给一位同事牵头，你来配合，并说清自己能提供什么。
4. 不提任何人对你说过什么难听的话，只说怕这样下去大家心里别扭，影响配合。
一句能直接说出口的话：“这次能做成，（同事A）的（具体一块）和（同事B）的（具体一块）是关键。下一个（项目名）我想请（同事A）牵头，我这边配合，您看行吗？”

### 场合二：日常（亲戚聚会上，长辈当众把你夸成全家的榜样，表哥在旁边一直没说话）

对应的局：过年聚餐，一位长辈连着几次说“全家就数你最有出息、最孝顺”，还半开玩笑地说“明年给我们带个对象回来”。夸奖挂着任务，同辈的人已经不太自在。
打法：
1. 当场接话只接一半，笑着把夸奖分出去一份，别照单全收。
2. 事后单独给被比下去的那位发一句话，说清你知道他做了什么，把他的付出说成具体的事。
3. 对长辈挂上来的任务不顶，也不答应，改成一个眼前能做的小事。
一句能直接说出口的话：“舅妈您别这么夸我，这几年家里（具体事）都是（表哥）在跑，我就是占了个顺手的光。对象的事等有消息了我第一个告诉您。”

## 雷区

- 皇后的手法要认得：夸奖当着第三个人说，夸奖里挂一个必须兑现的指标（“早日得个皇子”），夸奖的同时没有一句提醒你收敛（第8集第152幕、第165幕）。职场里碰到有人连着公开夸你、给你加担子、又从不提醒你边界在哪，先假设对方有别的用意，再核实。
- 丽嫔：当众骂人，把华妃也带了进去，当场被皇后训。职场里替你出头的人嘴越快，越容易把你拖进一场你不想打的架。
- 华妃借“专宠”挑拨甄嬛和眉庄（第8集第166幕）。职场里有人在你得意时特意提你和某位亲近同事的关系，多半是要拆你们的搭档。
- 甄嬛对皇帝没有说有人为难她。我们自己的判断：向上告状之前，先算对方出头之后你还有没有退路，皇帝出头，她在后宫更孤立。职场里老板问有没有人给你使绊子时，每次都点名并不稳妥，先想清楚老板出头之后你还剩什么退路。
- 让出去的位置要有人接得住。齐妃接了牌子，皇帝在她那儿坐不住，被嫌衣服颜色、嫌她老（第9集第174幕）。我们自己的判断：对方接不住时，让出去的东西会回到你身上，职场里让机会之前，先想好谁接，接不住你要不要兜底。
- 让出去不等于没有代价。甄嬛当晚自己也说高兴不起来（第9集第172幕）。职场里主动让出的东西，要先接受自己会难受一阵。
- 集宠于一身亦是集怨于一身这类意思，对老板直接说成我不想太突出，会被听成不上进。她能说，是因为皇帝先问了有没有心事，并且理由全落在皇帝利益上。
