# 端妃出面劝皇帝放人（第59集第947至949幕，结果见第60集第950至952幕）

局面类型：求人办事 / 被试探（皇帝问端妃的态度）
对方：端妃，久病隐居，不站队，皇帝敬她不爱管闲事（博主观点：除皇后外她的话语权最高，约17:45至17:52）；皇帝，多疑，最怕后宫有人串通起来糊弄他，嘴上说要给皇后面子，心里想要回苏培盛；皇后，另一边几乎同时行动，放出祺贵人当刀（博主观点，约12:06至12:12）。
甄嬛的处境：对等偏弱。私下，延庆殿，两个人没有深交；时间紧，槿汐和苏培盛还在慎刑司。博主观点：她刻意等到晚上才去，是为了掩人耳目（BV1YmsGzKECJ，约08:50至08:54）。剧本只写了延庆殿，没有交代时辰。
她的目的：请端妃在皇帝面前替人说话，把案子的分量降下来，同时不让皇帝觉得她和端妃串通。

## 1. 人设和差异化

甄嬛对端妃立的是请教的平等姐妹，称“姐姐”，说“着急见姐姐，也不知姐姐肯不肯帮我”。博主观点：她用词里透着一丝不确定，是在试探端妃是否还愿意结盟（约11:03至11:44）。

她请求的理由落在皇帝身上，没有讲自己：“我是一心想救槿汐和苏培盛，自然也是为了皇上，苏培盛在皇上跟前服侍多年，是最清楚皇上脾性的，如今乍然被拘，一则损伤皇上颜面，二则皇上身边也没有会服侍的人，处处不得顺心遂意。”（第59集第947幕）博主观点：她求端妃的思路是帮皇上救苏培盛，没有讲救自己人（约11:52至12:06）。

端妃在皇帝面前立的人设是不管闲事、不说闲话的读书人：“臣妾是不愿管别人的闲事，更不爱说别人的闲话。”（第59集第949幕）皇帝接着说：“没错，朕觉得这是你最大的好处。”

和其他人比：皇后主张严惩，敬妃持中不言，甄嬛不便开口，这三种声音皇帝都听过（皇帝在第59集第949幕自己点出）。端妃是唯一一个有分量又和这件事没有利害的人。

## 2. 读人

皇帝：
- 他开口就把三方站位摆出来：“如今宫中纷传着崔槿汐和苏培盛之事，皇后主张严惩，敬妃持中不言，熹妃不便说话，你怎么看？”这是在等第四个声音。
- 他先警觉：“你最近见过什么人、听过什么话吗？”博主观点：皇帝一向多疑，最担心后宫有人串通起来忽悠他（约17:05至17:09）。
- 他此前刚削过皇后的权：“你的身子从来没有好利索过，后宫的事自然有端妃和敬妃为你担着。”（第58集第932幕）可见他对端妃的话有分量上的期待。
- 他吃“人情”这一套：“这样的事朝朝代代都有……论起来他们都是饮食男女，太监虽算不得男人，也总是有人的情意，朕又何必如此灭人欲？”（第60集第950幕，皇帝对甄嬛说的话，已经是端妃这套说法的回声）。

皇后：
- 在交芦馆用两句话试祺贵人：“你就这么想出去吗？”“很快就到中秋了，本宫会去劝皇上把你放出去，你也应该知道要怎么去回报本宫的恩情吧。”祺贵人立刻答：“臣妾万死不辞，即便不为了皇后，臣妾也知道是谁陷害了臣妾。”（第59集第948幕）博主观点：这是服从性测试，明明自己要用人，偏要对方先表忠心（约12:23至12:38）。
- 博主观点：皇后挑这个时间放人，是算准甄嬛快生了，需要有人唱对台戏，祺贵人一点就炸，关得越久放出来越疯，正好当刀使（约13:49至14:02）。

端妃：
- 剧本里她是在翻《孟子》等着皇帝来。博主观点：说明她料到甄嬛会来求她，已经在想办法（约10:51至10:58）。书摆在桌上最显眼的位置、皇帝习惯坐右边，这些细节是博主的推测，剧本没有写（约14:08至14:55）。待核。
- 她知道在是否有罪上纠缠会落进皇后的规则。博主观点：所以她把话题抬到治国哲学和帝王心术的层面，改变游戏规则（约19:00至19:10）。

甄嬛看出来的细节：这件事皇后有宫规，有物证，只靠辩护赢不了。必须换赛道，有人替皇帝找一个体面的说法，让他自己放得下。

## 3. 布局链条

目标：在皇帝面前拿到一个“缓一缓、不杀”的口子。
铺垫：
1. 前一步是局卡B14：不向皇帝求情，稳住槿汐。
2. 博主观点：甄嬛登门的时点很讲究，她没有一回宫就去示好，等收拾了祺嫔、赢得太后的支持、在后宫立住之后才来（约09:27至09:38）。
3. 称呼的变化。博主观点：昔日的婉嫔叫端妃“娘娘”，现在叫“端姐姐”，端妃也改口叫“妹妹”，重新界定了平等结盟的关系（约09:49至10:48）。

借谁的手：端妃。皇帝会听她的话，因为她不爱管闲事。

等什么时机：皇后刚刚放出祺贵人（第59集第948幕），皇帝正在想各方意见，这时来端妃这里，是专门听一个不站队的人说话。

怎么收网：端妃的六步（第59集第949幕）。
1. 先拆皇后的理论依据。她讲朱熹曲解孔孟，把存天理灭人欲说成“实在大大地不通”，并把话引到宫里：“如果按照朱夫子所说，那么后妃怎么能够为皇上绵延子嗣呢”。博主观点：这是釜底抽薪，把皇后严惩的理论依据掀了（约16:36至16:42）。
2. 皇帝警觉时撇清：“臣妾是不愿管别人的闲事，更不爱说别人的闲话。”
3. 被问怎么看，换说法：各花入各眼，是非只在人心，把对食重新定性为宫女太监的慰借。博主观点：她不说违纪，说慰借，一件政治案件变成了人情冷暖的故事（约18:53至18:57）。
4. 给可落地的方案：法不责众加容人之量，大事化小小事化了。
5. 留台阶：自己是为了熹妃和惠嫔怀着身孕，听不得打打杀杀。博主观点：她把自己的立场藏起来，让皇帝觉得她识大体、顾大局（约20:26至20:40）。
6. 走前补一句关心：天凉了，茶里兑点菊花，嘴角起皮了。

留了什么后手：
- 结果在第60集第950幕：皇帝对甄嬛说“端妃有句话说得很是，宫中现在有两位嫔妃有孕，哪里能见得这样生死打杀的东西？即便要罚，也该缓一缓”。
- 槿汐回来，只罚一年月钱（第60集第951幕）。
- 皇帝对苏培盛说：“永寿宫没事，崔槿汐也没事。朕罚了你们一年的月银小惩大戒，这样不体面的事朕不能不顾及皇后的道理，得表个态度出来。”（第60集第952幕）
- 同一幕里甄嬛还有另一手，她向皇帝提起纯元皇后，这一步在博主下一期视频里讲（约23:21至23:36），本卡不展开。

## 4. 关键话术

- 第59集第947幕 甄嬛：“着急见姐姐，也不知姐姐肯不肯帮我。”
  为什么管用：开口先问对方肯不肯，把选择权交给对方，不预设她一定会帮。

- 第59集第947幕 甄嬛：“我是一心想救槿汐和苏培盛，自然也是为了皇上，苏培盛在皇上跟前服侍多年，是最清楚皇上脾性的，如今乍然被拘，一则损伤皇上颜面，二则皇上身边也没有会服侍的人，处处不得顺心遂意。”
  为什么管用：先说自己的目的，再说这件事对对方真正要服务的人有利，让请求变成顺着对方本来就要做的事。

- 第59集第949幕 端妃：“宫中也是如此啊，如果按照朱夫子所说，那么后妃怎么能够为皇上绵延子嗣呢？所以臣妾认为说这样话的人必定是一个无情之人，与皇家的宽厚之德背道而驰。”
  为什么管用：用对方绕不开的现实拆掉皇后的大道理，同时不点名。博主观点：这句话就差直接贴脸骂皇后刻薄了（约16:52至16:56）。

- 第59集第949幕 端妃：“皇上，且不说臣妾的身子不适不能出去，即便是能出去，皇上也是知道的，臣妾是不愿管别人的闲事，更不爱说别人的闲话。”
  为什么管用：被问你是不是串通了，不直接保证，只把自己一贯的做派摆出来，让对方自己得出结论。

- 第59集第949幕 端妃：“宫中美女如花，可无人能说哪枝最好，就比如说桃花吧，喜爱者称为宜室宜家，不爱者弃之逐水飘零，其实各花入各眼，是非只在人心罢了。今日之事，皇后认为是关系到宫中的风纪规矩，臣妾不以为然，他们并没有祸乱后宫，只是宫女太监们相互的慰借罢了，奴才们一进宫便孤身劳作到死，难免的凄凉寂寞，只是想寻个伴，以己度人，想想也觉得可怜得很。”
  为什么管用：先用审美讲不同意见都成立，让对方松动，再把性质换掉，从违纪换成慰借。

- 第59集第949幕 端妃：“何况是宫女太监们对食之事，皇上要是不信，到每个宫去查一下，保不定都有，难道个个都要杀之而后快吗？皇上乃一国之君、天下之王，责任之重大何止是一个家翁，大可端出一副容人之量来，大事化小小事化了。许是臣妾见熹妃和惠嫔都怀有身孕，实在听不得这些打打杀杀的事。”
  为什么管用：先让对方想到大家都有，再把他抬到更高的位置，最后给他一个无法拒绝的台阶。博主观点：端妃没有说求你别杀人，她把自己的立场换成了保护皇嗣（约20:26至20:35）。

- 第59集第949幕 端妃：“天凉了，让伺候您的奴才在您的茶里兑一点菊花，臣妾见您的嘴角都起皮了。”
  为什么管用：办完正事再补一句私人关心。博主观点：这句话顺带突出了苏培盛的功劳，也让皇后只顾权力的印象更明显（约21:24至21:49）。

## 5. 换到职场

### 场合一：大佬建联（请一位有分量又不站队的前辈，在关键场合替你的团队说句话）

对应的局：你的团队卷进一件事，决策人在犹豫，你认识一位决策人尊重、本身没有利害关系的前辈。
打法：
1. 时点选在你已经做出一些成绩、有东西可以拿得出手的时候，不要一遇到事就上门。
2. 以请教的口气开口，先问对方愿不愿意，不预设一定帮。
3. 把请求说成对决策人有利的事，别只讲自己的难处。
4. 只给事实和背景，不教前辈该怎么说。
5. 事后回报一个具体结果。
一句能直接说出口的话：“我这边遇到了（一件具体的事），想请教您怎么看。这件事如果处理不好，对（决策人或行业共同关心的事）也不利，所以想听听您的判断。”

### 场合二：老板 1on1（替被追责的同事争取较轻的处理）

对应的局：同事犯了规，流程上确实有问题，处罚方案偏重，你想争取较轻的处理，但不想被看成包庇。
打法：
1. 不否认规则和事实，先说疏漏确实存在。
2. 把问题从有没有错，换成怎么处理对整体最好。
3. 给一个可以落地的较轻方案，并写明会补上哪些流程。
4. 台阶留给老板：处理轻一点，对项目和团队更稳。
一句能直接说出口的话：“这件事规则上确实有疏漏，我建议按（较轻的处理方式）处理，同时补上（流程），既能给各方一个交代，也不影响（项目）进度，您看可以吗？”

## 雷区

- 皇后的手法：用我给你机会你要懂得感恩的方式试人，再把情绪不稳的人当刀使（第59集第948幕）。职场里遇到先要你表忠心再办事的人，要识别。
- 端妃把全后宫拉下水：“到每个宫去查一下，保不定都有”。这对皇帝有效，是因为他自己也清楚。职场里把大家都这样当成唯一理由，容易被反问一句那为什么偏偏是你。
- 端妃暗指皇后无情。背后评价同事的人格，一旦传回去，会变成明面的敌意。
- 皇帝问“你最近见过什么人”这一句，暴露了串通口径是最容易被问穿的东西。职场里事先对好口径，不如各说各的事实。
- 博主观点：皇帝想起婉嫔当年被害，端妃没有出来求情，所以认为两人不熟，放下疑心（约17:14至17:22）。我们自己核对剧本：第59集第949幕里没有这一段内心活动，本卡不采用。
- 博主转述端妃保证“查不到我和熹妃见面的证据”（约17:10至17:14），剧本里的原话是撇清不爱管闲事，两者有出入。
