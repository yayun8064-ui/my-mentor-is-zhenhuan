# 康禄海带头跳槽，当众发银子放人（第4至5集第86幕，前情见第3集第48幕）

局面类型：立威管人 / 谈条件（放人的条件）
对方：碎玉轩首领太监康禄海，带着徒弟小印子、小荷子，准备投奔丽嫔。他最在意的是前程和靠山，他的判断是主子久病、没有前途。在场的还有槿汐、佩儿、小允子，他们在看甄嬛怎么处理背叛者。
甄嬛的处境：弱。入宫两个月，一直在养病（剧本第5集第87幕交代，这场病由她自己用药拖着，身体其实没有那么重），内务府克扣用度，下人开始议论。场合是整个宫里的人都在的院子里，等于当众。
她的目的：体面放人，不让失势变成笑话传出去；稳住留下来的人；顺手看清每个人的心思。

## 1. 人设和差异化

她立的是有分寸、赏罚分明、好聚好散的主子。

和旁边的人比：
- 流朱：气愤，当场点破康禄海虚情假意，还要他们去辞了丽嫔，并威胁过了今天再想走就拉去慎刑司（第5集第86幕）。流朱说的话痛快，但会把场面推向撕破脸。
- 康禄海：假哭，嘴上说舍不得，实际上早就决定要走。
- 甄嬛：在流朱开口后拦下来，说康公公忠心大着呢，伺候谁都是一样的，然后叫人给银子。她把一次背叛处理成了一次普通的调动。

为什么对上这群人的胃口：留下来的人看到的是，走的人得到了体面，留的人以后不会亏待。想走的和想留的都有台阶。

## 2. 读人

康禄海：
- 私下说“不行，咱们不能跟她葬在这儿”（第4集第84幕），又说“倒是该筹谋着上哪儿找位新小主了”。（第4集第84幕）说明他早就想走，来辞行只是找时机。
- 他编的说法是“丽嫔娘娘指名让奴才过去伺候”（第5集第86幕），把背叛包装成身不由己。
- 甄嬛听得出这是演，没有当场揭穿。

流朱：忠心，但情绪压过了判断。后来她又当众威胁，这对想留下的人也是压力。

小允子：他哥哥病了，甄嬛请温太医去看（第5集第86幕小允子自己说出来）。恩情是真的，所以他的忠心不用查。

佩儿：之前拖延、和流朱吵过嘴，但留下来表了态。博主观点：她是求安稳、随大流的普通打工人，算不上小人（树懒小结界，BV1q2SEBqENg，约15:49至16:07）。

## 3. 布局链条

目标：放走想走的，留住该留的，同时不被人看轻。

铺垫一，入宫当天先立规矩。
第3集第48幕，甄嬛对新分来的人说：“今后你们便是我的人了，在我名下当差伶俐自然是好，但我更看重忠心二字，你们可记牢了？”接着让浣碧赏了银子。博主观点是忠心比能力更重要，管理者更需要可靠的自己人（BV1q2SEBqENg，约00:55至01:20），而且光画饼不够，要发真金白银（约01:24至01:39）。

铺垫二，她在最不显眼的人身上用了心。
第4集第82幕，夜里小允子在廊下哭，说哥哥在四执库病了一个多月。甄嬛让他这两天去照顾哥哥，之后还请温太医去医治（小允子在第5集第86幕交代）。这一笔对她当时的处境没有任何回报。

铺垫三，康禄海师徒私下商量（第4集第84至85幕）。这一段甄嬛不在场，让观众知道，辞行早有预谋，临时起意的成分很小。

借谁的手：浣碧发银子，流朱做坏人的角色（虽然甄嬛并没有安排）。

等什么时机：康禄海当众跪下假哭开口之后。她没有问缘由，直接说“知道了”。

怎么收网：
1. 先接下康禄海的说辞，祝他去了好地方，让他收拾东西即刻走。
2. 叫浣碧把宫里的人都唤进来。
3. 对所有人宣布一个统一的条件：这一病快两个月，不需要这么多人，想走的去浣碧那里领一锭银子。
4. 流朱当场呛康禄海，她拦下，说他忠心大着呢，叫浣碧给银子。
5. 留下的人一个个表态，她回应，最后一句总承诺。

留了什么后手：
- 对留下的人：“你们跟着我这个久病失宠的小主，从没享过一天的福，却还如此待我，我无以为报，只要有我在一日，我绝不让你们受委屈。”（第5集第86幕）
- 给小允子加一条厚被子，因为他在廊下上夜受冻。
- 第5集第87幕，她对眉庄总结：“奴才不在于多，只在于忠心与否。”
- 第7集第135幕，皇帝要给碎玉轩派首领太监，槿汐说康禄海两个月前被丽嫔叫走了。甄嬛提议先让小允子顶上，皇帝答应。当初留下的人，这时成了自己提拔的第一批人。

## 4. 关键话术

- 第3集第48幕 甄嬛：“今后你们便是我的人了，在我名下当差伶俐自然是好，但我更看重忠心二字，你们可记牢了？”
  为什么管用：先把价值观立好，后面每一次人事变化都可以回到这一条。

- 第5集第86幕 甄嬛：“知道了。丽嫔娘娘那儿也是个好去处，能去也是你的造化，收拾了东西即刻就去吧。”
  为什么管用：对方想要台阶，她给了一个体面的。同时没有追问，也不挽留，语气像送一个正常调动的人。

- 第5集第86幕 甄嬛：“我这一病，快两个月了。病中怕吵闹，也实在无需这么多人来伺候，所以今儿找你们来只问一句话：若谁有意离开碎玉轩，去浣碧那里领一锭银子便可走人。”
  为什么管用：用我不需要这么多人来说明放人，不指向任何一个人，谁都不用承认自己想走。这一句同时是筛选。

- 第5集第86幕 甄嬛：“流朱！康公公忠心大着呢，伺候谁都是一样的。浣碧，给银子。”
  为什么管用：拦住流朱的同时用反话收口，场面立刻往下走，没有留下扯皮的空间。

- 第5集第86幕 甄嬛：“只要有我在一日，我绝不让你们受委屈。”
  为什么管用：对留下的人，把承诺说成一个具体的时间范围，不空泛。

- 第5集第87幕 甄嬛：“奴才不在于多，只在于忠心与否。”
  为什么管用：对眉庄说的话，给这件事定性，也是在给眉庄提醒她自己宫里该留意什么。

## 5. 换到职场

### 场合一：面试（面试官问：你带的团队里有人提出离职，你怎么处理？）

对应的局：压力或行为面，考察你带人的底线和格局。
打法：
1. 先接住，不当场质问动机，也不当场挽留。
2. 给全员一个统一的规则，想走的现在提，交接和补偿按公司规定办，想留的我们一起把目标做完。
3. 对留下的人，事后逐一确认，并说清楚你能为他们做什么。
4. 不对走的人说坏话，不在背后评价。
一句能直接说出口的话：“我会先听他把话说完，不当场挽留也不指责。之后我会跟全组说清楚：想走的可以现在提，交接我们按流程来；想留的，我们一起把（目标）做出来。”

### 场合二：老板 1on1（团队里一位关键同事被挖走，你向老板汇报）

对应的局：老板得知消息后找你谈，想知道团队还稳不稳。
打法：
1. 只讲事实：谁走，什么时候走，交接怎么排。
2. 同步你已经和剩下的人逐个聊过，哪几位明确想留。
3. 请老板在资源上给你一个具体的支持，来稳住节奏。
一句能直接说出口的话：“（某同事）已经确定离开，交接计划是（日期）前完成。剩下的几位我都单独聊过，（几位）明确想留。我需要您帮我争取（具体资源），这样接下来的（节奏）能稳住。”

## 雷区

- 流朱：当众威胁，“若过了今日再想走，小主立刻回了皇后，拉去慎刑司做苦役”（第5集第86幕）。职场里对应：用威胁留人，留下来的多半是怕你的人，真心信你的人反而更容易寒心离开。
- 放人的理由：我病了，不需要这么多人。这个理由只有在你确实不想追究时才好用。流朱当场反驳“牛不喝水强按头”（第5集第86幕），说明局内人一眼能看穿。职场里对应：不要拿编出来的处境当作放人的理由，被看穿时信用会受损。
- 这场病本身是甄嬛自己用药拖出来的（第5集第87幕：“这药只是不让我的病好得那么快罢了”）。她对下属说的我病了，是半真半假。职场里不能照搬，对团队的话要么真，要么不说。
- 博主观点：发银子是在筛选忠诚，让不忠诚的人主动现形（BV1q2SEBqENg，约15:16至15:30）。我们的判断：这个做法有前提，你付得起银子，也有后续兑现承诺的能力。甄嬛后来真的提拔了小允子（第7集第135幕）。没有兑现，这个筛选就成了空话。
