# 对食案发，先稳槿汐再找路（第59集第943至946幕）

局面类型：被当众发难 / 认错善后
对方：皇后，带着端妃、敬妃上永寿宫当面发难，借宫规立威，顺带收回被削掉的协理权；皇帝，多疑，爱面子，自己也离不开苏培盛；槿汐，被关进慎刑司，心灰意冷，一心求死。皇后最在意的是借这件事把甄嬛身边的人拔掉，同时显得自己秉公。
甄嬛的处境：官面上位高有孕，实际被动。对方有物证（缨络、搜出的匣子）、有宫规，当众被夺走处置权。她不能硬顶，也不能被扣上包庇的名头。
她的目的：先保住槿汐和苏培盛的命，不让槿汐想不开，不被皇后抓到串通勾结的证据。

## 1. 人设和差异化

她在这件事里先后立了三种姿态：
- 对皇后：顺从、尊重规矩、请求秉公。两次请求自己处置被拒之后，第三句话把皇后架到秉公的位置上。
- 对皇帝：认管教不严，不替人求情。
- 对槿汐：平等的自己人，说“总是我对不住你”，不摆主子的架子。

和旁边的人比：
- 浣碧第一反应是怕，担心清誉，劝她别管（第59集第943幕）。
- 槿汐第一反应是认命，劝她自保，求她舍掉自己（第59集第946幕）。
- 苏培盛在慎刑司扛下了拷打，没有供出槿汐（第59集第946幕槿汐转述）。
- 甄嬛的做法是分三步：先防自己不被拖下水，再稳住人，最后才去找路。

为什么这样立：皇后拿的是宫规，宫规面前讲情分讲不过，只能把对方放到她自己说过的话里。

## 2. 读人

皇后：
- 带着端妃、敬妃一起来。她的话是：“熹妃，照理说你的宫里本宫是可以不来的，只是因为你是胧月公主的生母，又怀着身孕，有些事情不能不顾着你的颜面，所以本宫只好叫了端妃和敬妃一起过来走一趟。”让两位妃子当见证，也让这件事变成后宫共同的事。
- 先用缨络把事情坐实，再搜房间，搜出东西之后一句“当真是秽乱后宫”，把性质定下来。
- 引用大道理压人：“在宫中服侍的人必须自身检点，存天理灭人欲，才能安心侍主”。这句话端妃后来专门拆掉，见局卡B15。
- 夺走处置权的借口很体面：“你有了身孕，怎么好做这样的事，再说熹妃你也要避嫌才好啊。”博主观点：皇后利用办公室恋情挑起皇上对甄嬛的疑心，皇上最怕别人勾结起来忽悠自己（BV1YmsGzKECJ，约03:32至03:38）。

皇帝：
- 从“皇后已经跟朕说了”可以读出，他先听了皇后的版本。博主观点：皇帝默许皇后带走二人，目的是借皇后的手查清楚，自己两头不得罪（约03:38至03:46）。
- 他一边抱怨茶凉，一边说“苏培盛不在，这帮人都失了规矩，没有一件事能做好的”，说明他离不开苏培盛。博主观点：皇帝是在想苏培盛（约01:49至02:04）。
- 他最后一句“你若是真舍不得崔槿汐，朕叫内务府再给你挑个更好的”，意思是他不打算放人。博主观点：这句话说明皇帝根本没有打算饶恕他们（约04:16至04:26）。

槿汐：
- 求死。她说“不如就让奴婢在此自生自灭吧”（第59集第946幕）。
- 她对苏培盛有了新的看法：“谁知道那日在慎刑司，他竟怎么拷打也不说出奴婢来，奴婢倒多出几分真心来。”这说明两个人都没有供出对方，对食之外没有别的证据。博主观点：正因为没有拿到二人勾结的证据，罪名才只剩对食，给了甄嬛周旋的空间（约04:31至04:36）。

甄嬛看出来的细节：皇后这次有备而来，物证、规矩、见证都齐了，皇帝又站在观望位置。这时候谁去求情，谁就是下一个被查的人。

## 3. 布局链条

目标：这一天只做三件事，不被拖下水，稳住人，看清皇帝的态度。
铺垫：
1. 皇后一进门，甄嬛先认出缨络，轻轻说一句“单凭一个缨络也说明不了什么，许是槿汐丢了，正好叫苏培盛给捡着了，还打算日后还给她呢”，把最小的物证先压到最小（第59集第943幕）。
2. 皇后坚持搜房，她说“槿汐是臣妾身边的人，这事就不劳皇后娘娘动手了，臣妾来做就是”，被皇后以避嫌为由拒绝（第59集第943幕）。
3. 搜出东西后，她再一次请求自己处置，被皇后用“存天理灭人欲”挡回。

借谁的手：这一天不借人。端妃是第二天的事（见局卡B15）。

等什么时机：
- 皇后走后她才说“皇后果然耐不住了”，当着皇后不露任何情绪。
- 去养心殿不求情，先看皇帝的态度。
- 出来之后才去慎刑司。

怎么收网：这一局到稳住人为止。
1. 对皇后：把对方推到公正的位置上，让她以后重罚都有违自己的话。
2. 对皇帝：只讲苏培盛的价值，和自己的管教不严。
3. 对槿汐：当面给定心丸。博主观点：甄嬛到慎刑司有三个理由，稳住槿汐的求生意志，保住自己团队的威信，也保住后面静妃（敬妃）的态度（约05:19至07:21）。博主认为她没有封口的打算（约04:52至05:09）。

留了什么后手：
- 对槿汐留的话：“苏培盛那边我会打点好”。
- 对皇帝留的是一个印象：她没有求情，没有辩护，只在认错，没有显出急着救人的样子。
- 对皇后留的是公开的一句话：既保住皇家颜面，又能清肃后宫。

## 4. 关键话术

- 第59集第943幕 甄嬛：“臣妾冒昧恳求皇后娘娘，槿汐是臣妾身边的人，不如就交由臣妾来处置吧。”
  为什么管用：先走正当程序提一次要求，被拒也留下自己主动担责的记录。

- 第59集第943幕 甄嬛：“娘娘是太后、皇上眼中的贤后，又为后宫众人所敬仰，想必娘娘一定会秉公处置，既保住皇家颜面，又能清肃后宫。”
  为什么管用：把对方的公开身份当约束，把清肃后宫和保住颜面并列，皇后后面想要重罚就得先说服自己。

- 第59集第943幕 甄嬛：“怕？我若是害怕，由着她拉下槿汐，下一个就是你，再就是我自己，一个都跑不了。”
  为什么管用：对身边人讲清利害，把怕转成不能退。

- 第59集第944幕 甄嬛：“一群好马也得有识途的老马带着才能走得平稳顺畅，何况是他们这些向来听吩咐做事的人？现下苏培盛犯了事被拘着，他们自然像无头苍蝇一般乱转了。”
  为什么管用：不替人求情，只讲这个人对皇帝有多重要。博主观点：这是敲边鼓，强化皇帝的需求（约02:13至02:25）。

- 第59集第944幕 甄嬛：“臣妾没有约束好宫人，是臣妾的不是。”
  为什么管用：先认管教的责任，给自己留出不被追究包庇的余地。

- 第59集第945幕 甄嬛：“皇后有备而来，切切实实拿住了把柄，又有宫规压着，皇上也不能说什么，若本宫去求，皇后正好请君入瓮，治本宫一个庇护纵容之罪。”
  为什么管用：这是她回答浣碧为什么不开口求情。读人和算账都在这一句里。

- 第59集第946幕 甄嬛：“死是最容易的事情，一脖子吊上去就完了，可是你这样做是亲者痛、仇者快，不值得，以我们多年的情分，你信我，我一定会救你出去的。”
  为什么管用：对想放弃的人，先把放弃的代价讲透，再给一个“你信我”的承诺。因为有多年情分在，这种话才有分量。

## 5. 换到职场

### 场合一：老板 1on1（你带的人出了事，被别的部门或合规点名）

对应的局：你的下属被合规、审计或者别的部门点名，处理通知已经发到老板那里，你来找老板，没有直接要求从轻。
打法：
1. 不急着替人求情，先弄清规则和证据，别让人觉得你在包庇。
2. 主动认自己的管理责任。
3. 用事实说明这个人对团队的价值，只讲事实，不动感情。
4. 先稳住当事人，再找能影响决定的人，每一步都看老板的态度。
一句能直接说出口的话：“这件事我作为负责人有管理上的责任，我先把经过了解清楚，今天下班前把情况和我的处理建议报给您。”

### 场合二：聊投资（团队出了舆情或事故，投资人听说了）

对应的局：团队出了一件会被外界议论的事，投资人问到你，你想控制影响。
打法：
1. 先稳住核心成员，避免人心散掉。博主观点：创业公司遇到公关危机，能迅速摆平大家反而更看好你，被打趴下威望清零（约06:34至06:45）。
2. 主动同步事实和进展，讲清边界。
3. 给出处理时间表。
4. 不替当事人辩护，也不甩锅给当事人。
一句能直接说出口的话：“这件事（简述）我们昨天已经处理到（进展），核心团队都在岗，接下来（时间点）会给您一份完整说明。”

## 雷区

- 苏培盛把槿汐的信物贴身带着，结果在公开场合掉出，敬妃当场说：“宫女的东西是不能被太监贴身收着的。”（第59集第943幕）职场里私人关系和私人物品不要带进公开场合，对手只需要一个抓手。
- 皇后的手法值得识别：以关心为名上门，夺走处置权，先搜证据后审问。职场里对方以关心和避嫌为理由要你交出处理权的时候，往往是在拿走你的话语权。
- 博主观点：甄嬛去慎刑司没有封口的打算（约04:52至05:09）。我们自己核对剧本：她在第59集第946幕只给槿汐打气、承诺救人，没有要求保密。职场里稳住当事人不等于封口，也不要借稳人的机会统一口径。
- “亲者痛、仇者快”这类话对多年的老搭档有效，对不熟的人会显得在施压。
- 没有证据时靠一时的沉默撑过去。博主观点：两人都没有供出对方，对食之外没有别的罪名（约04:31至04:36）。职场里不要假设对方不会开口。
- 博主观点：皇帝对甄嬛起了疑心，把权力交还给皇后，增加了对付甄嬛的筹码（约03:46至03:57）。职场里老板在一件事上偏向别人，说明你的位置也在变。
