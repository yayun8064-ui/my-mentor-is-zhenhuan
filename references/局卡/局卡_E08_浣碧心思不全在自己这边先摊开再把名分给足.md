# 浣碧心思不全在自己这边，甄嬛先摊开，再把名分一次给足（第2集至第65集）

局面类型：谈条件（替人在上位者面前争名分） / 立威管人（对心思不全在自己这边的亲人）
对方：浣碧，甄嬛同父异母的妹妹，母亲是罪臣之女，一直以婢女的身份跟着甄嬛；心气高，想要名分，也有自己喜欢的人。夜宴当场还有皇帝（做主赐婚）、宁嫔澜依（把浣碧往低处安排）、果郡王允礼（浣碧心上人，也是甄嬛的旧情人）。
甄嬛的处境：身世这一层，浣碧是随时会连累全家的把柄（第19集第321幕：“父亲私纳罪臣之女的罪名就足以让他流放宁古塔”）。夜宴那一场，当众，被动，一张小像差点牵出她自己和允礼的事。
她的目的：先把浣碧的心思摆到明处，不让她继续往外找靠山；再在夜宴上把一场危机转成一桩喜事，把浣碧的名分、母亲的牌位、嫁妆一次办全，让她和自己站在同一条线上。

## 1. 人设和差异化

她在浣碧面前立的是长姐。第19集第321幕她说：“你还要叫我小主吗？该叫我一声长姐才是。”这句话把主仆关系改成了姐妹关系，才有后面所有的安排。

和一般的管人方式比：甄嬛没有用赏赐加敲打，她先讲清楚浣碧为什么不甘，再给一条能走的路。

和皇后比（我们自己的分析）：皇后对“庶出”二字又恨又怕，一生都在为这个身份争（第41集第674幕、第72集第1118幕）。甄嬛面对浣碧的庶出身份，选的是补：改族谱、改身份、把母亲的牌位请进祠堂。

为什么对上浣碧的胃口：浣碧最在意的是名分，赏赐排在后面。第18集第308幕她对着亡母烧纸，说“为什么我和小主都是爹的女儿，姐姐可以获宠，为娘家带来荣耀，而我却不能呢”。甄嬛给的正好是这个。

## 2. 读人

浣碧：
- 心结：母亲一辈子为奴为婢，自己也只能为奴为婢（第18集第308幕）。
- 想靠别人出头：“我若没有人举荐，又怎么能够出头呢？”（第19集第321幕）当时她就是为此接近了曹贵人和华妃。
- 心气高：第47集第767幕，甄嬛想替她找婆家，她听出话里的意思，反问允礼“究竟是方便我们姐妹相见呢，还是方便王爷与小姐相见”，又说“我若喜欢一个人，即使嫁给他做妾也是心甘情愿的”。
- 在意出身有来由。博主观点：浣碧前半生一直为出身挣扎，想要更好的出身是她的权利，要求本该是二小姐却做了多年婢女的人毫不在乎出身，不现实（BV1TYN76GEvm，约13:40至14:32）。
- 对皇帝：被问要不要侍奉，她答“奴婢有罪，奴婢已经有心上人了”（第65集第1013幕）。这是她第一次在皇帝面前把自己的心思说出口。
- 夜宴上主动认下小像：“请皇上恕奴婢死罪，此物是奴婢的小像。”（第65集第1016幕）这一步既替甄嬛解了围，也替她自己抢到了位置。博主观点：小像掉出来并没有浣碧安排的痕迹。理由是荷包是允礼自己站起来、自己解腰带时掉出来的，浣碧只是倒酒和擦拭，而且允礼常翻看小像，真被动过手脚他早就发现了（脖子细哔哔叨，BV1nvM86gEAa，约03:38至05:38）。博主还认为，浣碧是听了澜依先前把小像说成像二小姐的话，才意识到自己也可以把这件事揽下来（约10:52至10:57），并且事先看过荷包里的东西，说出来的细节才可信（约12:21至12:36）。
- 甄嬛早就知道她的心思：夜宴后在园中对允礼说“浣碧一直喜欢你，她对你的情意并不比我对你少，我很早就知道”（第65集第1016幕）。所以席上那句“臣妾竟是个傻子，这丫头瞒得臣妾好苦”，我们自己的判断是给皇帝听的。

皇帝：想把浣碧赐给允礼，理由是“你一直在熹贵妃的身边小心谨慎，你，朕很放心”（第65集第1016幕）。他看重的是浣碧在甄嬛身边的位置，对名分没有兴趣。

澜依：博主观点：她不喜欢浣碧，但分得清轻重，提起杜鹃和杜若，是在替浣碧打圆场，保的是允礼（BV1nvM86gEAa，约13:26至13:54）。她提议“做个侍妾也算抬举了”，又问“难不成浣碧作为福晋要与咱们平起平坐吗”（第65集第1016幕）。她在替皇帝和后宫维持上下尊卑。后来她点破：“那张小像怎么会无故轻易掉出来呢？王爷不是那么不谨慎的人。”（第69集第1087幕）

允礼：不肯给福晋，因为“在臣弟心里她才是唯一的妻子”（第65集第1016幕）。甄嬛要给浣碧的名分，卡在这里。

## 3. 布局链条

目标：浣碧以钮祜禄家二小姐的身份嫁给允礼，母亲的牌位入祠堂，嫁妆和排场不输别家。

铺垫（跨集）：
1. 第2集第29幕：甄远道在入宫前夜告诉甄嬛浣碧的身世，甄嬛回：“浣碧的身世，将来若有机会，我一定给她指个好人家。”
2. 第19集第321幕：浣碧私下接触曹贵人被甄嬛识破。甄嬛摊牌，同时给出路：让她认父亲为义父，从甄府出嫁，母亲的牌位进祠堂，名字入族谱。这一幕的完整经过见局卡A13。
3. 第47集第766至767幕：甘露寺里，甄嬛当着太妃和允礼提出给浣碧找人家，被浣碧顶回去，甄嬛立刻收：“浣碧的婚事匆匆说定也不好，不如以后从长计议。”事后她对允礼解释：“浣碧一向心气高。”承诺没有丢，也没有硬推。
4. 第65集第1013幕：皇帝想让浣碧侍奉，甄嬛替她挡：“浣碧臣妾要留着，哪日亲自给她指婚才算完呢。”

借谁的手：皇帝做主，敬妃主婚（第65集第1018幕），内务府拟名字，甄远道出面认亲。

等什么时机：夜宴上小像掉出，皇帝先怀疑甄嬛，浣碧站出来认下。皇帝问“嬛嬛，她的心思你可知道吗”，甄嬛接住这个台阶。博主观点：浣碧两次说“身份低微”，是在提醒甄嬛兑现先前答应过的事，第二次还转头看向甄嬛（BV1nvM86gEAa，约15:09至15:23、15:43至15:47）。

怎么收网（第65集第1016幕）：
1. 先接话稳住场面：“臣妾竟是个傻子，这丫头瞒得臣妾好苦。”
2. 皇帝要把人赐给允礼，澜依提侍妾。甄嬛不争当不当赐，只问身份：“那她进了王府，身份是侍妾、侧福晋还是福晋呢？”
3. 第一口开高价：“臣妾想收浣碧为义妹，名入族谱，以钮祜禄家二小姐的身份风风光光嫁入果郡王府为福晋。”
4. 浣碧自己说“根本都不在乎名分”，甄嬛继续劝：“你若这样无名无分进了王府，来日别人议论起来……连私通这种话都会说出来。”理由落在浣碧和王爷的名声上。
5. 允礼拒绝福晋，甄嬛不再顶，退到：“皇上做主吧，只别委屈了浣碧就好。”皇帝定下：以钮祜禄家二小姐的身份嫁为侧福晋。
6. 之后允礼自己向皇帝请旨：“终身不再另娶，还要浣碧入府主持家事”（第65集第1017幕），实际管家权落到浣碧手里。

收尾（第65集第1018至1020幕）：取名玉隐；永寿宫按内务府嫁妆的三倍再添一份；父母入宫相见；婚前一夜叮嘱。

留了什么后手：母亲入宗庙的事也一起办了（第65集第1018幕“你娘入宗庙的事情要紧”）。浣碧的亲娘有了名分，以后浣碧要护的也是这份体面，与甄嬛的利益连在一起。

## 4. 关键话术

- 第2集第29幕 甄嬛：“浣碧的身世，将来若有机会，我一定给她指个好人家。”
  为什么管用：听到敏感的事，第一句先表态不会亏待她，对方日后知道时，这句话就是凭据。

- 第19集第321幕 甄嬛：“你还要叫我小主吗？该叫我一声长姐才是。”
  为什么管用：当面把称呼改回来，主仆关系变成姐妹关系。

- 第19集第321幕 甄嬛：“父亲心里是有你的，我这个长姐心里也是有你的。”
  为什么管用：先讲对方心里的不甘，再讲你的在意，对方才听得进后面的利害。

- 第65集第1013幕 甄嬛：“浣碧臣妾要留着，哪日亲自给她指婚才算完呢。”
  为什么管用：不否定皇帝的兴趣，只说这个人我自己安排，把人从对方手里留下来。

- 第65集第1016幕 甄嬛：“那她进了王府，身份是侍妾、侧福晋还是福晋呢？”
  为什么管用：对方要给，你不接也不推，先问名分。名分这个词一出来，对方就得当着众人的面给个说法。

- 第65集第1016幕 甄嬛：“浣碧，你不知道人多口杂，你若这样无名无分进了王府，来日别人议论起来……”
  为什么管用：对方说不要名分时，把理由换成对方在意的名声。

- 第65集第1020幕 甄嬛：“路是自己选的，就没有回头的余地了，在这宫里活下去太难了，我没有时间也没有心思去后悔。”
  为什么管用：对方问你后不后悔，你不接情绪，只讲现实。

- 第65集第1020幕 甄嬛：“你只要记住以后你我的肩上都挑着甄氏一族的担子，记住你是王爷的侧福晋。”
  为什么管用：把共同的责任说出口，让对方的新身份和你的家族绑在一起。

- 第69集第1087幕 甄嬛：“她虽是私心，却也无可厚非。”
  为什么管用：旁人拿小像的事挑拨时，不否认浣碧有算盘，也不追责，承认这是一场各取所需。

## 5. 换到职场

### 场合一：职场（团队里身份特殊的核心成员，想要职级或名分，私下在找别的靠山）

对应的局：你组里有一位外包转岗、借调或试用期长期延后的核心成员，一直没拿到应有的职级，你发现她私下和别的部门负责人走动频繁。
打法：
1. 先私下摊开，不当众点破。说你已经知道她在做什么，也知道她想要什么。
2. 把她想要的东西说在她前面：职级、头衔或转正。
3. 给出走正路的具体办法和时间，比如这个季度的评审。
4. 去上面争的时候，第一口开到她心里想要的位置，让上级自己往下压，别一开始就报最低价。
5. 兑现后讲明白：这个位置带着责任，你们现在是一条线。
一句能直接说出口的话：“你想要的是（职级或转正），这件事我清楚，你最近和（部门）走得近我也知道。这条路不用绕，我去跟（老板）争，（时间点）之前给你一个结果。”

### 场合二：日常（姐妹或亲戚之间：身份上总被排在后面的那个人，心里有怨，私下在找别的靠山）

对应的局：你家里有一个长期被当作自家人使唤、却没有真正名分的妹妹、表妹或堂姐妹，在家族的重要场合总被排在后面，她对你有怨气，也开始和别的亲戚走得近。
打法：
1. 找一个只有你们两个人的时候，先承认她的委屈，把她心里的话替她说出来。
2. 再讲清楚她现在走的那条路有什么后果，比如牵连到全家。
3. 给她一个看得见的补偿，比如在亲戚面前正式介绍她的位置、给她该有的排面。
4. 到了重要场合，当着长辈的面一次把话说全，别分几次给。
5. 事后告诉她，这个位置带着一份责任，你们要一起扛。
一句能直接说出口的话：“你心里有委屈，我知道，不用说。这次（场合）我当着（长辈）的面把你的位置讲清楚，该有的体面，一样不会少。以后家里的事，我们俩一起扛。”

## 雷区

- 浣碧前期的算盘：她曾经找曹贵人和华妃借势（第19集第321幕）。身边人有自己的盘算，压是压不住的，只能给她一条她肯走的正路。
- 采蘋事件：浣碧后来替甄嬛办玉娆婚事的差事，找的人是自己王府的旧人，理由是给王府多一重保障（第66集第1030幕，详见局卡E09）。给了名分之后，她做事仍然先顾着自己。
- 解围只解了一半。博主观点：皇帝对浣碧的说法半信半疑，酒醒之后派人盯着允礼夫妇，观察出两人不合，和浣碧所说的“王爷钟情七年”对不上，才转去查甄嬛（BV1nvM86gEAa，约16:21至19:46）。职场里对应：危机当场被化解，不代表对方真的信了，后续还要继续补。
- 小像的交换：浣碧认下小像，既替甄嬛解了围，自己也拿到了侧福晋的位置。澜依后来说“人不为己天诛地灭，玉福晋别诛灭了自己的良心才好”（第69集第1087幕）。职场里对应：对方在你危机时替你出头，同时拿到好处，这是交换。你默认了，就要把这个交换当作交换，别再要求对方只为情义。
- 名分买不来全心：后来浣碧在允礼面前说“她哪里是为了保全你，她是为了保全她自己”，又说“长姐她虽然是我的亲姐姐，她虽然有恩于我，但是你是我的夫君哪”（第73集第1129幕）。职场里对应：给了位置，也别指望对方在所有事上都站你这一边。
- 甄嬛自己付的代价：把心上人让给了妹妹，“从前只有我，往后便只有浣碧了”（第65集第1016幕）。有些成全需要当事人付出实打实的代价，别随口答应。
- 身世的风险没有消失：甄嬛一直守着身世这件事，对外只说义妹（第65集第1016幕），对允礼才说出“浣碧并非我义妹，而是我亲妹妹”。职场里对应：别人的敏感信息，只给必须知道的人。
