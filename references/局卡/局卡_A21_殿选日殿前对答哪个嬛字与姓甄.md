# 殿选日殿前对答，哪个嬛字与姓甄（第1至2集第20幕，后续见第2集第23幕）

局面类型：被试探 / 被当众发难（太后挑姓氏）
对方：皇帝，新帝，亲自在殿上问话，对有学问又好看的人有兴趣。太后，皇帝的生母，坐在一旁，管着殿选的分寸，最在意规矩和后宫的平衡。
甄嬛的处境：弱。殿前当众，旁边是太监和一排秀女，没有一个人替她说话；她自己并不想被选中（第1集第15幕）。
她的目的：把问话答完整，不给甄家丢脸，也不去抢风头；姓氏被挑出来时，让它不变成污点。

## 1. 人设和差异化

她立的人设是有家学、守规矩、被问什么答什么的大理寺少卿之女。

同一个殿上，几个秀女的路数各不相同：
- 沈眉庄被问读没读过四书，答“臣女不曾读过”，皇帝略失望，太后接了一句“你能识字就很好了”（第1集第20幕）。她靠的是端庄和老实。
- 安陵容被撂牌子后仍然恭谨地谢恩，太后说“你倒懂规矩”（第1集第18幕）。她靠的是懂规矩，再加一只落在头上的蝴蝶。
- 甄嬛的特点是每一个回答都带着出处：名字说诗句，姓氏说先帝的评语。别人答的是自己，她答的是有来历的东西，皇帝和太后都没法当场驳回。

为什么对上皇帝的胃口：博主观点是皇上喜欢有文化的，但不喜欢只有文化的，所以他还要看甄嬛长得好不好看（树懒小结界，BV1dG8Mz3EEt，约17:26至17:47）。甄嬛一句诗把学问交出来，抬头一看，样貌也交出来了。

## 2. 读人

皇帝：
- 他先问“哪个嬛字”，再追问“是蔡伸的词？”，说明他是真的在辨学问。（第1集第20幕）
- 学问过关后，他的话马上转到人：“只是不知你是否担得起这个名字，抬起头来。”（第1集第20幕）可见他要看人。
- 博主观点：甄嬛抬头后，太后瞳孔地震，皇上立刻往前探身，眼睛都瞪大了一圈，太后回头看他，发现皇上已经看愣了（BV1dG8Mz3EEt，约17:50至18:19）。
- 太后挑姓氏时，他是第一个接话的人，站在甄嬛这边：“先帝的意思朕明白。”（第2集第20幕）
- 博主观点：皇帝对这场选秀本来就不情愿，脸拉得很长，和甄嬛想到一块去了（瑞脑消教授，BV1DNjR6LEpb，约16:46至16:53）。博主给的原因有两层。一层是太监报名字时家世官职在前、名字在后，选秀看的是背后的势力（约17:25至17:45）。另一层是第一批被撂牌子的几位秀女，背后要么连着隆科多，要么连着年羹尧，两边还互相勾连，皇帝本能地厌恶往后宫塞人（约21:54至22:10，转写里人名有错字）。博主还认为选秀是前朝政治的延续，皇帝重用甄远道这类汉臣，所以才特意强调要从汉军旗里多选一些人（约07:15至07:27）。对照剧本：第1集第3幕皇帝确实对太后提过想多从汉军旗里选几个秀女，说法是满汉一家，但剧本没有把这件事和重用甄远道连在一起，这半句是博主的推断，本卡只当参考。

太后：
- 她挑的是一个有规矩依据的毛病：“秀女姓甄，犯了皇帝名讳。”（第2集第20幕）这类话不能当场硬顶。
- 博主观点：太后喜欢有规矩体统的人，因为她自己是从后宫厮杀里走过来的，而且眼下后宫已经有一个跋扈的华妃，嫔妃入宫后个个像华妃就不得了（瑞脑消教授，BV1DNjR6LEpb，约31:56至32:15）。这段话讲的是太后为什么留下安陵容（第1集第18幕）。我们只借它说明太后看重规矩，不把它直接当成太后挑姓氏的动机。
- 博主观点：太后希望后宫平分春色，不希望再来一个宠冠后宫的人，所以赶紧找理由打发甄嬛（BV1dG8Mz3EEt，约18:19至18:26）。剧本只写了太后的话，没有写她的心思，这条是博主的读法。
- 博主观点：太后不死心，要加大考试难度（约19:48）。这一段见局卡A22。

甄嬛没有明说的判断（我们的读法）：能压住“犯名讳”这类问题的，只有比提问的人更高、而且所有人都绕不过的权威。她选的是先帝，也就是皇帝的父亲。她没有拿自己的才华来辩，也没有道歉，因为道歉等于认了犯讳。

## 3. 布局链条

目标：把姓氏的问题化解掉，不让它变成选秀时的把柄。
铺垫：
1. 殿选之前，她对眉庄说“我倒巴不得没选上”（第1集第15幕），所以她没有准备要表演什么。点名时她还笑着看眉庄，太监连喊两遍她才反应过来（第1集第20幕舞台说明）。博主也说她真没把选秀放心上，居然公然开小差（BV1dG8Mz3EEt，约16:50至16:57）。瑞脑消教授同样指出，甄嬛独自靠在台子上，和举止端庄的眉庄形成对比，到这时为止她的所有举动都在表示不想入宫，不要再说她是故意装样子的（BV1DNjR6LEpb，约12:28至12:46）。
2. 因为没有刻意准备，她的回答全部来自平时的家学，所以每一句都经得起追问。博主的说法是后宫状元的被动技能被触发了，立刻引了一句诗（约17:21至17:24）。
3. 博主解释她为什么没有故意答砸：选秀的每个细节都会传出去，因负面原因落选，甄家会丢脸；她又见过世面，性格坚定，太后也不能随便给人扣帽子（约18:45至19:05）。

借谁的手：先帝的评语，以及皇帝本人。
等什么时机：太后把“犯了皇帝名讳”说完之后才开口，没有抢在前面替自己解释姓氏。
怎么收网：
1. 先称“禀太后”，把话递给提问的人，不越过太后去跟皇帝说。
2. 只讲一件事：父亲当年为官，先帝看了姓名，说姓甄好，听着像忠贞之士。一个犯讳的毛病，被讲成了先帝给的勉励。
3. 讲完就停。皇帝接过去，连引甄宓，把话题带到“甄氏出美人”（第2集第20幕）。甄嬛这里没有台词。

留了什么后手：
- 第2集第23幕，皇帝独自看排单，嘴里念的是“嬛嬛一袅楚宫腰”，随后给她起封号，理由是“朕觉得甄氏莞尔一笑的样子，甚美”。一句对答变成了皇帝记住她的钩子。
- 代价也在同一幕：皇后借汉军旗已有两位贵人为由，提醒“这样做会不会太过显眼了”，皇帝把她的位分压成了常在。风头出得多，位分上会被扣一点。

## 4. 关键话术

- 第1集第20幕 甄嬛：“嬛嬛一袅楚宫腰”，正是臣女闺名。
  为什么管用：问的是哪个字，她用一句诗把字、出处和寓意一次交代，又正好接住皇帝爱诗词的口味。她没有解释笔画，没有炫耀读过多少书。

- 第1集第20幕 皇帝：是蔡伸的词？ 甄嬛：是。
  为什么管用：皇帝追问出处，她只答一个字。第二问不加料，节奏留给皇帝。

- 第2集第20幕 甄嬛：“禀太后，当年臣女父亲为官，圣祖康熙看见父亲姓名，说姓甄好，听着像忠贞之士，以此作为勉励。”
  为什么管用：被挑毛病时不辩解、不认错，换一个更高的评价标准。话递给提问的太后，内容里没有一个字夸自己，全是在说别人对甄家的评价。

- 第2集第20幕 皇帝：“先帝的意思朕明白。”
  为什么管用：这是效果。她的回答给了皇帝一个站队的理由，一句话把太后的质疑接了过去。

- 第2集第20幕 皇帝：“江南有二乔，河北甄宓俏”，甄氏出美人。
  为什么管用：她自己没有再说话，姓甄反而被皇帝说成了加分项。得到肯定时少说话，比再补一句更稳。

## 5. 换到职场

### 场合一：面试（面试官指出你简历上的一个硬伤）

对应的局：面试官说“你的专业和这个岗位不太对口吧”，旁边还有第二位面试官在看。
打法：
1. 属实的部分直接认，不辩解，不道歉到底。
2. 换一个对方也认可的评价标准，比如别人对你这段经历的评价，必须是真的、能被核对的。
3. 话递给提出问题的那位面试官，不转头去讨好另一位。
4. 说完就停，让面试官自己决定要不要追问。
一句能直接说出口的话：“您说得对，我的专业确实跟这个岗位不对口。（你之前的上级或客户）在（具体项目）里对我这一块的评价是（原话），所以我想把这段经验放到这个岗位上继续做。”

### 场合二：大佬建联（行业活动上被大佬当场问一句出处）

对应的局：你在交流环节提到一个观点，大佬追问“这是（某人）的框架吧？”，周围有人听着。
打法：
1. 对出处类的追问，直接答是或者否，不抢着展示你读过多少。
2. 补一句来源和你自己怎么用的，保持简短。
3. 把后面的话让给对方，对方想聊就会接。
一句能直接说出口的话：“是的，出处是（作者或报告），我在做（你负责的那一块）的时候用到了它。”

## 雷区

- 甄嬛在点名时走神，太监连喊两遍才反应（第1集第20幕，博主也点评了，约16:50至16:57）。职场里对应：轮到自己发言时还没进入状态，第一印象会被拖低，好在这次没出事。
- 她引的是先帝的话，现场没法验证。剧本里这句话没有被追问。职场里对应：只引能被核对的第三方评价，编造一句领导说过的话，被追问一次信用就没了。
- 她能过关，靠的是皇帝当场站在她这边。职场里对应：不要把希望放在有人替你接话上，要准备一个没有人帮你时也能说完的版本。
- 一场好的对答也会招来对手的警惕：太后随后加试，皇后随后压位分（第2集第20幕、第23幕）。职场里对应：在老板面前表现得太亮，同级和旁观的人会开始盯你，要预留应对。
- 我们自己的判断：这一局里甄嬛没有任何对别人不利的手段，但回答的底气来自家学和日常积累，临场学是学不来的。
