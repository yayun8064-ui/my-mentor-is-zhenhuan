# 册封日辇后随行，并在景仁宫替皇帝压住皇后（第61集，前情见第8集）

局面类型：立威管人 / 被试探（皇帝想偏宠，皇后想拖延）
对方：皇帝，权力最高，今天想表达对她的偏爱；皇后，正在失去六宫之权，最在意的是体面和手里最后一点实权。
甄嬛的处境：强，但当众。皇帝站在她这一边，前朝后宫都盯着看，任何一个小动作都可能变成别人的把柄。
她的目的：稳稳接下协理六宫之权，不让皇帝的偏爱变成她的靶子，不给皇后留新把柄，也让皇帝和太后相信她得势之后不会飘。

## 1. 人设和差异化

她在这一天立的是守规矩、懂分寸、不抢风头的熹贵妃，对皇后恭敬，对皇帝讲规矩，对姐姐们请教。

和其他人比：
- 皇帝想把偏宠放在明面上，他到永寿宫来等不及，要与她同乘辇去景仁宫（第61集第967幕）。
- 皇后拿身体和孩子找借口，不想放权（第61集第968幕）。
- 甄嬛既不顺着皇帝的偏宠走，也不与皇后针锋相对。她先拒绝特殊待遇，再在皇后受阻时替皇帝说话，形式上全是谦让。

为什么对上皇帝的胃口：他在七年前就见识过她这一套。汤泉宫里皇帝走到池边试水，她回的是：“皇上要学汉成帝吗？臣妾可万万不敢做赵合德。”（第8集第147幕）当时她还把话头转到了班婕妤的贤德上。今天她又一次拒绝了同乘，勾起的正是这段记忆。

## 2. 读人

皇帝：
- 等不及见她，直接来永寿宫，是怕景仁宫又出变故。博主观点：三年前晚贵人进封时，皇帝在景仁宫等，结果出了事，这次他亲自来永寿宫是怕重演（树懒小结界，BV1UmqaBcEna，约20:19至20:40）。这条属于博主的推断，剧本里皇帝只说“朕等不及要见你，与其在景仁宫苦等，不如和你一起同去”（第61集第967幕）。
- 喜欢听她说规矩，说自己“永志不忘”。旧事被勾起来，他会觉得自己当年的眼光得到了印证，没有任何被说服的感觉。
- 权力早就决定好了。博主观点：交权的圣旨在双生子落地那天就传遍六宫，现在只是象征性问皇后意见（BV1UmqaBcEna，约23:57至24:02）。

皇后：
- 找借口拖。第一个借口是熹贵妃要照料孩子，还有胧月要接回永寿宫；第二个借口是头次料理后宫，这些事说多不多、说小也不小（第61集第968幕）。
- 博主观点：皇后显然第一次听到胧月不接回永寿宫的消息，说明六宫的核心信息只在皇帝和熹贵妃之间流转，皇后已经被排除在外（BV1UmqaBcEna，约24:29至24:39）。

甄嬛读到的风险（博主归纳）：同乘会引来嫉妒，会给皇后新把柄，也会削弱她在皇帝和太后心中谨慎的形象（BV1UmqaBcEna，约22:38至23:11）。

## 3. 布局链条

目标：把交权这件事办得干净，不留尾巴。

铺垫一，先和皇帝说好胧月的归属。
皇后的第一个借口，是胧月要接回永寿宫。皇帝回答得很快：“朕和熹贵妃商量过了，觉得胧月由敬妃抚养甚好，不必再挪动了”（第61集第968幕）。这个借口在皇后开口前已经被甄嬛堵死，前提是她在此之前已经和敬妃谈好了（见局卡 B22）。

铺垫二，用一个旧典故先立住贤德的形象。
七年前汤泉宫拒绝皇帝试水（第8集第147幕），今天拒绝同乘，两次拒绝前后相连。博主观点：她用这句话在皇帝心里植入一种感觉，当年那个讲道理的晚贵人，如今真的配得上却辇之德（BV1UmqaBcEna，约22:18至22:30）。

借谁的手：皇帝的决定，加上端妃和敬妃两位老资格。
她抢在皇帝不耐烦之前开口，把皇后能用的两位老人，说成是自己愿意讨教的对象。

等什么时机：皇后的第二个借口说出口之后。她没有在第一个借口出现时就争，等皇后把理由都亮出来，再一次性处理。博主观点：皇上在旁听得不耐烦，但又不方便当场发作（BV1UmqaBcEna，约24:51至25:11）。

怎么收网（第61集第967至968幕）：
1. 先拒绝同乘：“皇上请上轿辇，臣妾随行就是。”
2. 受册时对皇后恭敬：“承教于皇后，不胜欣喜。”
3. 皇帝提出交权，皇后第一个借口被皇帝顶回去。
4. 皇后第二个借口刚说到不如这两个字，甄嬛立刻接话，先认下皇后说的“所言极是”，再说自己年轻，要向端妃和敬妃请教。
5. 皇后只能回一句“你肯如此想就最好了”。
6. 最后甄嬛补一句“臣妾是皇后一手调教，绝不辜负皇后期望”，把皇后放在师长的位置上，让她体面收场。

留了什么后手：
- 当晚重华宫宴席上，皇后以阴阳祝酒词反击，甄嬛没有回应，反而在后面的安排里把侍寝权让给了敬妃（见局卡 B24）。
- 博主观点：皇帝对她的主动配合十分欣赏，从这一刻起皇后正式被架空（BV1UmqaBcEna，约25:23至25:42）。

## 4. 关键话术

- 第61集第967幕 甄嬛：“今日盛礼，愈发不能失了礼数，皇上请上轿辇，臣妾随行就是。”
  为什么管用：不说我不要你的偏爱，只说今天这个场合需要守礼。皇帝没有被拒绝的难堪，旁观的人也挑不出她的错。

- 第61集第967幕 甄嬛：“从前不敢忘的，如今更不敢忘。”
  为什么管用：一句话把过去和现在连起来，对方自己去回忆，不需要她再解释典故。

- 第61集第968幕 甄嬛：“承教于皇后，不胜欣喜。”
  为什么管用：对即将被取代的人先给足礼数，对方发难的余地少了一半。

- 第61集第968幕 甄嬛：“皇后娘娘所言极是，臣妾到底年轻，不如诸位姐姐阅历丰富，端妃姐姐最早入宫，敬妃姐姐曾协助皇后料理后宫多年，臣妾很愿意向两位姐姐讨教问询。”
  为什么管用：先同意对方，再把对方的担心转化成一个自己主动承担的动作。两位被点名的老人也因此成了自己的人。

- 第61集第968幕 甄嬛：“臣妾是皇后一手调教，绝不辜负皇后期望。”
  为什么管用：给对方一个师长的位置，对方失去权力的同时保住了面子，没有理由继续纠缠。

- 第61集第968幕 皇后：“你肯如此想就最好了。”
  为什么管用：这是皇后的反应，说明这一招让她无话可说，只能顺着台阶下。

## 5. 换到职场

### 场合一：老板 1on1（你被安排接手一个原来由资深同事负责的职责，对方有些不情愿）

对应的局：老板决定把某块职责交给你，原负责人找理由说时机不对、你经验不足，老板脸上有些不耐烦。
打法：
1. 事前先和老板对齐，把对方可能用的借口提前问清楚、提前有答案。
2. 会上先不谈权，先谈尊重：认同对方提出的担忧，说明你的经验确实不如他。
3. 把对方的经验放在你要请教的位置，邀请他在交接期继续带你。
4. 在老板失去耐心之前抢话，不让老板替你出头，也不让他为难。
5. 结束时留给对方体面，让他知道你会按他的节奏交接。
一句能直接说出口的话：“（原负责人）说得对，这块他的积累比我深。交接这段时间我想先按他的节奏走，也想请他把（具体事项）带我过一遍，您看这样可以吗？”

### 场合二：面试（被问到空降到成熟团队后如何服众）

对应的局：面试官问，如果你加入后团队里有比你资历深的人，你怎么开展工作。
打法：
1. 先讲你的原则：前两周以听为主，不动现有的东西。
2. 把资深同事放在老师的位置上，具体说你会向谁请教什么。
3. 讲一件你真实做过的类似交接，说明你如何拿到信任。
4. 补一句边界：该有的决策权你会向上级确认清楚，不会自己硬抢。
一句能直接说出口的话：“我会先花两周时间听团队里资深同事讲清楚现有做法，哪些要保留我先问他们，改动之前会先和他们过一遍。我之前在（你真实的经历）里就是这么接手的。”

## 雷区

- 这一局的前提是皇帝已经表态站在她这一边，交权圣旨早已传出。职场里没有上级事先背书，不要上来就按这一套演。
- 请教要做真。被请教的人若发现你只是做样子，会觉得被利用。我们自己的判断：甄嬛请教端妃和敬妃，有后面的合作基础，职场里同样需要真的合作作为支撑。
- 抢话替上级打圆场，要看准上级真的在不耐烦。上级没有这个意思时抢话，会被认为越权。
- 拒绝偏爱本身也是表演的一种。博主指出这一场处处是逻辑闭环（BV1UmqaBcEna，约20:05至20:07），但职场里谦让太过会被看成作秀，要保持一致。
- 对失势的人给体面，不等于对方不记仇。皇后当晚就在祝酒词里反击。职场里留给对手台阶，也要准备好对方的下一招。
