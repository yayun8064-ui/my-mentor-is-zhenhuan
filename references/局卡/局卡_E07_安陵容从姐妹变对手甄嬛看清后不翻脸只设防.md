# 安陵容从姐妹变成对手，甄嬛看清后不翻脸、不传话、只设防（第44集至第68集）

局面类型：识别套路与防人 / 被试探
对方：安陵容（后来的安嫔、鹂妃），曾经一同入宫的姐妹，现在是皇后阵营的人，宠爱和嗓子都不稳，最在意的是不被人踩下去，对甄嬛又羡慕又怨恨。
甄嬛的处境：回宫后有孕，怕再被暗算；对方一边示好一边带话，没有别人在场，没法当面翻脸，也没法拿出证据。
她的目的：不撕破脸，不被对方借成传话的人，对方送来的话和东西有用的收下，没用的不接，把核实的活交给自己人。

## 1. 人设和差异化

她对陵容立的是念旧情、但不再交底的姐姐。第57集第918幕她说“咱们到底也是这么多年的姐妹了”，到了第61集第978幕说“本宫自然记得妹妹对本宫是何等姐妹情深，必然滴水之恩涌泉相报，绝不辜负”。两句字面都是姐妹情深，听的人心里各有一本账。

和眉庄比：眉庄先觉出不对。第11集第203幕她对甄嬛说“我总还觉得这不像我日日面对的那个陵容”，甄嬛当时还替陵容说话（“陵容毕竟也是为了咱们”）。甄嬛是后来被事实推着看清的，没有靠直觉抢先下判断。

和皇后比：皇后对陵容说“不中用的人留在宫里，除了死没有其他出路”（第66集第1028幕）。甄嬛对陵容留着面子上的礼数，同时在事上一点一点收紧，没有把话说绝。

为什么对上陵容的胃口：陵容要的是甄嬛继续把她当妹妹，才能一次次靠近。甄嬛给了称呼，没给信任。

## 2. 读人

陵容靠近的几种办法（读人用，不当作打法）：
- 自损来证明忠心。第37集第603幕，她端来用自己的血入药的补汤，说“因为姐姐是唯一肯帮我的人，若姐姐都不肯信我，在这后宫之中还有谁能信呢”。甄嬛当场把药倒了，对流朱说：“是否有心，不在这些东西上，她是否真的割肉都不要紧，我只盼她还有些姐妹真心。”
- 事先瞒着不说。第32集第514幕，陵容靠皇后安排接近皇帝，没告诉甄嬛，咳疾好了也没说。甄嬛点了一句：“陵容，你的咳疾好了也该告诉我一声，叫我担心，也叫我意外。”
- 把你的私事递给你的对手。第43集第695幕，当着皇后的面，陵容把皇帝叫甄嬛“莞莞”这个小名说了出来。
- 把“对不起”变成一道题。第57集第918幕，她先说“昔日之错已经铸成，陵容只希望在今日能稍稍弥补”，被甄嬛反问之后立刻接“姐姐这话便是不肯原谅陵容了”。你要是怕背上不原谅的名声，就会顺着她往下走。
- 先扎一下痛处，再给情报。同一幕里她先问“自己的亲生女儿竟成了别人的孩子，姐姐感觉如何”，后面才拿出欣贵人的事。
- 借刀。她说“储秀宫中谁与姐姐积怨已久啊”，要把滑轿的账记到欣贵人头上，临走又拿出一个说是欣贵人送的香囊。香囊里装的是什么，剧本里浣碧只说了半句（第58集第919幕“她那香囊里分明就是——”），没有点名。博主观点：香囊里大概放的就是麝香一类害人的东西，用来提醒甄嬛“这个香囊我可以说是欣贵人送的”，和她把滑轿的事往祺嫔身上引是同一个思路（脖子细哔哔叨，BV1rRE76PEVQ，约08:33至08:59）。

看清的节点：第44集第719幕，温实初告诉甄嬛，舒痕胶里有分量不轻的麝香，“目的就是遮掩住麝香的气味，若非懂得香料之人，是调不出来的”，也说“其实也未必是安小主所为”。甄嬛答：“人更叫我恶心。”她还叮嘱温实初先别让眉庄知道，让眉庄不要得罪皇后与安陵容。第720幕槿汐劝她：“如果以前她还是个暗敌的话，那么她现在就算是个明敌了，我们岂不是更好防范了？”甄嬛回：“不管是不是她愿意，是她做的就是她做的。”

陵容来的目的：博主观点：她当时还没到走投无路的程度，投诚没有必要，主要是借甄嬛的手去压祺嫔，等于把甄嬛当枪使，所以她面对甄嬛的挖苦也不肯忍着（BV1rRE76PEVQ，约04:10至04:53）。博主还认为滑轿路上的石子就是陵容事先放的，理由是只有她在甄嬛没说起之前就备好了香囊（约09:05至11:56）。这是博主的推断，剧本里没有直接交代，只作参考。

陵容的处境：第58集第919幕，槿汐从苏培盛那里问回来，“祺嫔和安嫔现如今都是皇后身边的人，不过二人一直面和心不和，近来皇后偏看重祺嫔，安嫔难免有些失意了”。陵容这时来示好，是失意时找靠山，甄嬛看到了这一层。

## 3. 布局链条

目标：对方每一次靠近，都不让她拿到想要的东西，同时把她带来的有用消息变成自己的。

铺垫：
1. 第37集第603幕：倒药，开始分辨真心和表演。
2. 第44集第719至720幕：确认麝香，暗敌变明敌，当晚没有发作，也没有告诉眉庄。
3. 第57集第907幕：回宫后欣贵人来说了一堆话，甄嬛对浣碧说“五分信，五分不信”。她对谁的话都只信一半，所以陵容这一次的话，她同样只信一半。

借谁的手：槿汐去问苏培盛查陵容的处境；浣碧传话给佩儿再转欣贵人；太医在后面当众验东西时出场。

等什么时机：陵容拦她，当街就接；复盘等到回永寿宫、屏退左右之后。

怎么收网（第57集第918幕到第58集第919幕）：
1. 路上被拦，不躲，不热络，先把话递回去：“许久不见，妹妹当真是贵人了。”
2. 她拿亲生女儿刺你，不辩解，只说“做人有得亦有失”，并把话带到对方身上：“比起有些人用尽心机却尽失人心，只怕到头来是竹篮打水一场空呢。”
3. 她要你相信欣贵人是真凶，你不接这个结论，也不替她传话：“她是皇后跟前的红人，妹妹怎敢在背后说这种无凭无据的话呢？”
4. 她忏悔，你不安慰，也不替她定罪，把话递回去让她自己说：“怎么，妹妹从前也做过什么见不得人的错事？”
5. 她递香囊，你只表态不接受：“你的心意我明白了，我自会小心。”
6. 回宫立刻复盘。浣碧急着说香囊，甄嬛说：“她今日所说的话未必全都是谎话，倒也有几分可信。”博主观点：未必全是谎话指的是陵容和祺嫔不合这条信息，和滑轿那件事无关（BV1rRE76PEVQ，约14:41至15:00）。接着让槿汐汇报，再判断陵容与皇后“是一路性子的人”，最后一句定方案：“安陵容特来告诉我此事，我倒不妨坦然接受。”让浣碧转告欣贵人，把消息交给另一个相关的人。

留了什么后手：
- 数月后第61集第978幕街头再遇，陵容嗓子已坏。甄嬛点出“人心不足，机关算尽，往往过分自强便成了自戕”。浣碧提出趁她失势了结她，甄嬛不同意：“在宫中，死是最好的解脱，她深受皇宠多年又性子要强，如今她失宠受辱，当真比死还叫她难受百倍。”博主观点：这一场陵容是来投诚，做利益交换，那句“有了姐姐，我还怕什么呢”暗指皇后拿纯元做文章，意思是她知道皇后的事，能给甄嬛提供价值；在外面人多的地方不敢说透，是怕甄嬛反过来拿这件事挑拨她和皇后（脖子细哔哔叨，BV1no7p65ENm，约04:09至05:48、06:43至07:08）。博主认为甄嬛用那句“滴水之恩涌泉相报”回绝了投诚（约06:27至06:35，转写不清，意思待核）。
- 陵容怀孕后，第67集第1058幕甄嬛上门，把检查所有东西说成对陵容的保护：“我这么做，正是为了咱们的姐妹情分，万一有人要动什么手脚，也不至于有下手之机呀。”两位太医当面验了一遍，没有查出问题，她再请卫临多诊一次脉，小允子跟着陵容的宫女去取香料。
- 终局在第68集第1076幕，不放进这张卡。

## 4. 关键话术

- 第44集第720幕 甄嬛：“不管是不是她愿意，是她做的就是她做的。”
  为什么管用：对一个人的苦衷和责任分开记账。理解她的难处，不代表后面不设防。

- 第57集第918幕 甄嬛：“比起有些人用尽心机却尽失人心，只怕到头来是竹篮打水一场空呢。”
  为什么管用：对方刺你的痛处时，不说我不痛，把同一个话头原样还回去。

- 第57集第918幕 甄嬛：“她是皇后跟前的红人，妹妹怎敢在背后说这种无凭无据的话呢？”
  为什么管用：对方想让你对第三个人下结论，你用对方自己的立场把话挡回去，既不否认也不认同。

- 第57集第918幕 甄嬛：“妹妹这话我就不知从何听起了，皇上眼中的妹妹是最温顺安静的，怎么，妹妹从前也做过什么见不得人的错事？”
  为什么管用：对方想用忏悔换你的原谅，你装作听不懂，让她把话讲完整，不替她承担定性。

- 第57集第918幕 甄嬛：“你的心意我明白了，我自会小心。”
  为什么管用：收下消息，不收下人情。这句话对外是谢意，对内是我知道你想干什么。

- 第58集第919幕 甄嬛：“她今日所说的话未必全都是谎话，倒也有几分可信。”
  为什么管用：对方的话不整块相信，也不整块丢掉，拆开来逐项核对。

- 第61集第978幕 甄嬛：“本宫自然记得妹妹对本宫是何等姐妹情深，必然滴水之恩涌泉相报，绝不辜负。”
  为什么管用：没有一个字是狠话，对方听了会明白你都记着。

- 第67集第1058幕 甄嬛：“我这么做，正是为了咱们的姐妹情分，万一有人要动什么手脚，也不至于有下手之机呀。”
  为什么管用：把检查说成为对方好，对方想拒绝就要先说出拒绝的理由。

## 5. 换到职场

### 场合一：职场（曾经被你提携过的同事，换了阵营，突然跑来示好，还带来别人的坏话）

对应的局：以前和你一起做项目的同事，如今在另一个部门，忽然来找你，说某位同事在背后讲你，还送你一份资料或方案“供你参考”。
打法：
1. 不翻旧账，也不表现出信任。称呼和礼数照旧。
2. 把他说的话拆成几块：哪些能查，哪些只是评价。能查的交给自己人去核实。
3. 他要你对第三个人表态，不替他传话，也不给结论。
4. 他给的资料和方案，按流程过一遍：交给（法务、风控或第三方评审）看，说成对大家都稳妥。
5. 重要的事不再交给他，信息也只给必须知道的部分。
一句能直接说出口的话：“你说的这些我先记下了，我这边也去核一下。你给的（资料名称）我按流程走一遍（审核或评审）再用，这样对咱们俩都稳妥。”

### 场合二：日常（闺蜜在背后捅过刀，现在忽然亲热起来，还来提醒你另一个朋友的坏话）

对应的局：多年的好友，你最近发现她在背后说你、抢了你的机会，隔几天她又来找你，说她替你着急，提醒你要提防另一位朋友，还塞给你一个她说是别人送的东西。
打法：
1. 先找第三方确认事实，别只凭一个人的转述下结论。
2. 当面保持礼数，不翻脸，也不接受她的忏悔或指控。
3. 她要你对第三个人表态，不接，把话收回去。
4. 她给的东西和介绍的人，自己去核实后再决定用不用。
5. 你的计划、私事、真实的想法，从这一刻起不再告诉她。
一句能直接说出口的话：“你这么惦记我，我记着。你说的这些我自己去问问，没弄清楚之前，我对谁都不会说什么。”

## 雷区

- 甄嬛自己的前期：她替陵容解过围，给过陵容舒痕胶的用处（第26集第439幕陵容送药、第29集第482幕她主动再要），对陵容的信任一直延续到第44集。职场里对应：帮过的人，不要因为旧情在关键物品和关键信息上放松检查。
- 陵容的话术清单，职场里需要识别：①用自损或自责证明忠心；②你不原谅我这类道德绑架；③先扎痛处，再给情报，让你情绪不稳时听话；④把别人的坏话带给你，却让你代她出面；⑤送你一件来历不清的东西。
- 陵容的话有真有假。甄嬛说“未必全都是谎话”，意思是她没有因为讨厌陵容就把对方带来的有用消息一起丢掉。丢掉是另一种被对方牵着走。
- 当众验东西有成本。第67集第1058幕两位太医验完，“并没有半点损伤胎气的东西”，什么也没查出来。验货可能落空，落空时要有台阶，甄嬛是用“如此，我和安妹妹都能安心了”收的场。没有台阶，就会被说成无端猜疑。
- 对手阵营里失意的人，会换一个靠山再来。陵容失意时找甄嬛，是因为皇后偏看重祺嫔。职场里对应：对方突然示好，先问他在原来的阵营里出了什么事。
- 甄嬛不动杀心。浣碧提议趁陵容失势了结她，甄嬛没有接。博主观点：甄嬛从来没有追求过你死我活，恨归恨，也许忘不了当年的好姐妹时光（BV1no7p65ENm，约08:02至08:15）。
- 甄嬛自己的原则：不翻脸，也不原谅。第68集第1078幕她对陵容说“我不会恨你，也不想原谅你，因为太不值了”。职场里对应：不原谅不等于追着不放，把精力留给自己的事。
