# 凌云峰重逢，让皇帝主动提回宫（第53集，前情见第47至52集）

局面类型：求人办事 / 谈条件
对方：皇帝（雍正），权力远高于甄嬛，疑心重，爱面子，不肯先低头；苏培盛，皇帝身边最懂他的人，每天有人排队求他办事。
甄嬛的处境：弱。废妃之身，人在宫外，已有身孕，没有任何可以直接动用的东西。私下操作，局的前半段全在暗处。
她的目的：让皇帝自己心甘情愿提出接她回宫。她不能先开口。博主的判断是“对方不提，自己就绝对不能提”（树懒小结界，BV1bJECzPEmC，约39:46至40:12），剧本里的做法与此一致：她全程没有说过“接我回去”。

## 1. 人设和差异化

她在皇帝面前立的人设是病着、想念他、什么都不求的人，和宫里天天争宠的嫔妃反着来。

差异在三处：
- 穿着：苏培盛给她备了华服，她没穿，说“皇上在宫里，浓艳素雅都看得多了，我便是要这样洁净到底”。（第53集第853幕）
- 要求：她不要名分，反过来替后宫着想，说“实在不愿宫中的诸位嫔妃因为今日之事再起争端”。（第53集第853幕）
- 姿态：见面时先认错，话里全是“只要四郎在这里”。

为什么对上皇帝的胃口：他在宫里见够了争宠的人。博主观点：皇帝对穿搭审美考究，宫中嫔妃大多浓妆艳抹，甄嬛另辟蹊径做简约淡然路线，但素雅不等于摆烂，病容是画出来的，头发上有茉莉香（BV1bJECzPEmC，约26:44至27:18）。

## 2. 读人

苏培盛：
- 槿汐的判断：收买他不能靠金帛和利益，他是身子残缺的人，“不能娶妻生子才是他一辈子最大的苦楚”。（第53集第846幕）这是读他的软肋，也是这一局里最容易伤人的一步，所以放在这里和雷区，不放进打法。
- 他自己的话：“这件事奴才既是帮娘娘，也是帮奴才自己。”（第53集第848幕）说明他要的是一个对他自己也有好处的理由，光讲情分他不会动。
- 博主观点：对苏培盛这样的人不要绕圈子，他一眼能看破，所以槿汐全程坦诚，但坦诚不等于没有技巧（BV1bJECzPEmC，约09:26至09:34）。

皇帝：
- 苏培盛原话：“以皇上天子之威，是绝不可能低头来就范娘娘的。”（第53集第848幕）读出来的是他爱面子，不会先低头。
- 苏培盛透露皇帝病重时唤的是她，说明他心里有她。（第53集第848幕）
- 博主观点：皇帝其实看得出这是一场戏，他“不介意嫔妃们演戏，只要他们肯为自己用心”（BV1bJECzPEmC，约29:33至29:47）；他害怕甄嬛对他还有心结，在禅房门口停了一下才进去（约28:31至28:43）。
- 皇帝仍在掌控的口气：“若非当初你这般任性、意气用事，朕又怎么会舍得让你出宫？”（第53集第853幕）说明他要的是对方认错回头。

温实初：老实人，会照她的话去办，但她不让他知道回宫的事（第53集第843幕）。这是在利用他的信任，放在雷区。

## 3. 布局链条

目标：让皇帝亲口说出接她回宫。这一场只走了第一步。博主说回宫整整用了三个月、剧中用了三集（BV1bJECzPEmC，约42:16至42:26）。

铺垫一，先把自己状态调好。
找温实初要益气补血的药和“神仙玉女粉”，说“我讨厌看到自己这样病恹恹的样子”。同时交代槿汐“我要回宫的事先别叫他知道”。（第53集第843幕）

铺垫二，找到能把话递到皇帝面前的人。
槿汐提出苏培盛是唯一能在皇帝面前说上话的人，也是最了解皇帝的人。（第53集第846幕）

借谁的手：槿汐去苏培盛私宅。槿汐的话是：“难不难的，谋事在人，成事在天，尽力就好。若是皇上有一天能和莞嫔重新在一起，那你我岂不是也顺理成章地在一块了？”（第53集第847幕）苏培盛答应来见甄嬛。

苏培盛面试甄嬛。
他来禅房先道贺，再试探甄嬛的态度。甄嬛的回答都没有提回宫享福，只说想念皇上和公主，“若此生还有机会再见皇上和公主一面，那我便死也瞑目了”。（第53集第848幕）博主的看法是这场对话是苏培盛的面试，他要确认的是甄嬛的态度够不够坚定（BV1bJECzPEmC，约11:40至11:45、16:11至16:17）。

等什么时机：苏培盛在御花园利用二月二这个日子。他先抛两个错误选项：宝华殿祈福、花神庙赶庙会，让皇帝自己否掉；再让眉庄顺势说出去凌云峰赏春、再去甘露寺祈福；最后给皇帝一条退路，“咱们只是到那儿去敬香嘛，又不见她”。（第53集第849幕）博主点出这是先排除错误选项，免得有刻意引导的嫌疑（约20:21至20:28）。

怎么收网：
1. 皇帝到甘露寺先问莞嫔，住持静岸支支吾吾，静白把虐待说成莞嫔“自请为寺里的老弱姑子浣洗衣物、砍柴挑水”（第53集第852幕），皇帝自己去了凌云峰。
2. 皇帝进门后，苏培盛当着他的面装作也是头一回来，称呼先说“莫愁师太”再改口“莞嫔”，撇清自己事先串通的嫌疑（第53集第853幕，博主观点见约30:07至30:25）。
3. 槿汐替甄嬛说病根和惦记：“娘子自出宫之后就一直惦记着皇上和公主，神情恍惚，夜夜睡不好，才拖着一直没有痊愈。”
4. 甄嬛自己只说“皇上？皇上怎么会来这儿。”，整场开头一个字都没有求。

留了什么后手：
- 她提的要求是替别人考虑：“实在不愿宫中的诸位嫔妃因为今日之事再起争端。”（第53集第853幕）皇帝因此答应连皇后面前都不提，生活起居由苏培盛安排，这条线就此走通。
- 皇帝的承诺是“朕就下令甘露寺每月举行一次祝祷，朕亲自上香就是”，没有说接她回宫。（第53集第853幕）这一步留下了每月一次的见面机会。
- 苏培盛清场、封口：“今天的事谁要是说出去，就是不要自个儿的脑袋了。”（第53集第853幕）

## 4. 关键话术

- 第53集第843幕 甄嬛：“我有着身孕，气血不足对孩子不好，劳烦你开些益气补血的药给我，还有，从前的神仙玉女粉还在吗？”
  为什么管用：用孩子作理由，对方不会追问；一次提出药和粉两样东西，把目的藏在日常照顾里。

- 第53集第847幕 槿汐：“难不难的，谋事在人，成事在天，尽力就好。若是皇上有一天能和莞嫔重新在一起，那你我岂不是也顺理成章地在一块了？”
  为什么管用：把别人的难处接过来，替对方把这件事对你自己有好处的理由说出口。

- 第53集第848幕 甄嬛：“我当年任性离宫，然而我家中得罪，我又有何脸目再侍奉皇上？离宫这几年我也十分想念皇上，种种情由还请公公代为转达。”
  为什么管用：先认错再表思念，话是说给要转达的人听的，字句现成，苏培盛可以原样复述给皇帝。

- 第53集第848幕 甄嬛：“其实日子苦些怕什么，只怕心里更不安乐，我若此生还有机会再见皇上和公主一面，那我便死也瞑目了。”
  为什么管用：被问是不是受不了苦想回宫时，答案只落在见到人这一件事上，绝口不提享福。

- 第53集第849幕 苏培盛：“奴才知道甘露寺有皇上不想见的人，反正咱们只是到那儿去敬香嘛，又不见她，再加上如今出宫正好可以为太后的病情祈福，更显得诚意些，要是时辰早，奴才再陪皇上去凌云峰踏春去。”
  为什么管用：先给皇帝一个体面的理由，再把真正的目标放在“顺路”里，不用皇帝承认自己想见她。

- 第53集第851幕 甄嬛：“苏培盛的意思我知道，他是希望我盛装一举赢得皇上的心，只是这样未免落了刻意。”
  为什么管用：对方好心给的办法如果会显得刻意，宁可不用。

- 第53集第853幕 槿汐：“娘子自出宫之后就一直惦记着皇上和公主，神情恍惚，夜夜睡不好，才拖着一直没有痊愈。”
  为什么管用：让别人说，比自己说可信，也让她自己不用开口求。

- 第53集第853幕 甄嬛：“实在不愿宫中的诸位嫔妃因为今日之事再起争端。”
  为什么管用：不要名分、替别人着想，显得无所求；同时让皇帝顺势把保密和照顾都安排好。

- 第53集第853幕 甄嬛：“只要四郎心中有嬛嬛，嬛嬛哪怕从此一生在此孤苦修行也是甘之如饴。”
  为什么管用：把退路说给对方听。博主观点是以退为进，让皇帝自己舍不得（BV1bJECzPEmC，约41:16至41:40）。

## 5. 换到职场

### 场合一：老板 1on1（想要资源或晋升，又不想直接开口）

对应的局：你想争取一个更大的项目、编制或者晋升，但老板爱面子，你直接提会让他为难，他也没有现成的理由给你。
打法：
1. 先把自己的状态和准备做好：你要的东西需要什么成果支撑，先摆在老板看得见的地方。
2. 找一个最懂老板的人（老板的搭档、助理或者跨部门的老同事）摸清他的节奏，只和对方说一个对他自己也有好处的理由。
3. 不要硬约一场“谈晋升”的会，借一个常规场合，比如季度复盘、项目评审，让话题自然走到你想要的地方。
4. 面对面时先讲你做了什么、遇到什么难处，让老板自己说出那你想要什么。
5. 要求提得小，替他想好台阶，比如“不用现在定”先让我试一个季度。
一句能直接说出口的话：“这块我不想给您添难处，您看哪些现在就能定，哪些我先自己扛着往前做？”

### 场合二：大佬建联（通过熟人搭线之后的第一次交流）

对应的局：展会上通过共同朋友加到大佬微信，第一次交流，你想有后续，但直接提合作或请教会显得刻意。
打法：
1. 搭线的人只传一件事：你对他做的事真有了解。
2. 第一次交流不提要求，只让对方看到你做了功课，并给他留一个不用马上答应的台阶。
3. 要的是下一次见面的理由，不要当场要承诺。
一句能直接说出口的话：“我先不占您太多时间，等（具体的事）做出一个能看的版本，我再来请您看一眼，您看可以吗？”

## 雷区

- 槿汐用对食的感情去换苏培盛的帮忙，博主评论捶腿这个动作是先给点甜头，再给功利的目的套上一层浪漫的外衣（BV1bJECzPEmC，约08:57至09:06）。我们自己的判断：这一招要靠牺牲槿汐本人，职场里不要拿私人关系做交换，谁都承担不起。
- 做戏依赖皇帝愿意不拆穿。博主观点是皇帝其实看得出（约29:33至29:47）。职场里不要指望老板看不穿，装偶遇、装可怜一旦被识破，信用就没了。
- 瞒着温实初，让他按要求办事却不告诉他真正的目的。职场里用人不交底，这个人日后知道会寒心。
- 静岸、静白在皇帝面前互相甩锅，被皇帝追问时静岸答不上来，静白把虐待美化成“自请”（第53集第852幕）。博主观点是皇帝没有深究，是因为这趟另有目的（约25:19至25:30）。职场里对应：被上级追问时推诿或美化，上级暂时不追，不代表信了。
- 这一局只走了第一步。皇帝的承诺是每月来上香，没有接她回宫。职场里对应：一次谈话不要想拿下所有结果，先拿到一个可以继续的约定。
