# 景仁宫修宫殿的提议，被皇帝将计就计赐姓抬旗（第55集）

本卡从宜修一侧写，目的是看清对手的舆论招数怎么被反用，以及甄嬛愿意付出什么代价。

局面类型：被试探 / 谈条件（宜修在和皇帝过招，甄嬛不在场）
对方：皇后宜修，想用舆论拖住甄嬛回宫的节奏，同时保住自己手里的掌控权；对面是皇帝，已经决定迎回甄嬛，要的是回宫的过程体面且不留把柄。
甄嬛的处境：弱，但是局势在向她倾斜。废妃之身，人在凌云峰，怀着孕。她这一局不出手，接受皇帝安排的全部代价，包括改姓、加岁数、担任四阿哥的生母（第55集第880幕）。
她的目的：回宫，并拥有足以对抗皇后的身份。

## 1. 人设和差异化

这一局各方立的人设：
- 皇后：表面大度的中宫，替皇帝考虑安置事宜，实际在铺陷阱。
- 皇帝：被大臣反对逼得想办法的君主，一边说生气，一边把难题变成自己的主动牌。
- 甄嬛一侧：不争不抢，皇帝说什么她接什么，接受的态度是“这些都是小事”。

和其他人比：皇后一向用大局、舆论、制度给别人设限。皇帝这一次没有按她的节奏走，反而把她提出的“赐姓”变成自己的大动作。

## 2. 读人

皇后：
- 表面支持，实际鼓动对立。博主观点：修建宫殿是皇后提出来的，现在西南有水灾，为一个妃子大兴土木，甄嬛没回宫就先遭舆论攻击，这是她当年对付华妃的老办法（树懒小结界，BV1euM3zsEwG，约14:50至15:09）。
- 她的话术看上去为皇帝着想，其实在推他和大臣对立：“大臣们向来如此，总是小题大做，皇上自己拿主意便是了。”（第55集第879幕）博主观点：皇帝越是一意孤行，大臣就越觉得甄嬛祸水（BV1euM3zsEwG，约15:44至16:09）。
- 她很在意一个细节：钮祜禄是满族最古老的姓氏之一，一旦赐给甄嬛，甄嬛的出身会高过自己（BV1euM3zsEwG，约18:05至18:16）。所以她赶紧给出折中方案，在“甄”字后面加一个“佳”字。
- 博主观点：这个折中方案也带着小心机，加“佳”字是后来的汉军旗得宠后才有的做法，等于让人一看就知道出身（BV1euM3zsEwG，约18:19至18:56）。

皇帝：
- 他不傻。博主观点：皇帝听到大臣集体反对，会联想到背后有人。皇后一直不同意接甄嬛回宫，怎么会突然这么好心要修宫殿，他看似不经意的抱怨其实在敲打皇后（BV1euM3zsEwG，约15:30至15:44）。
- 博主观点：他来的时候已经想好了解决方案，今晚拉扯是要点皇后，让她不要再搞小动作（BV1euM3zsEwG，约19:05至19:11）。
- 博主观点：他全程像个恋爱脑，实际在搞政治平衡，让甄嬛拥有可以对抗皇后的力量（BV1euM3zsEwG，约23:36至24:03）。
- 他对舆论有一套：“人言何所畏惧，他们愿意议论也好，不愿意也罢，朕已决意要给嬛嬛妃位。”（第55集第879幕）

甄嬛：
- 她听到苏培盛转述安排后只说“这些都是小事，皇上做主自然是好的”。博主观点：她现在需要的只是对付皇后的武器，过去自尊那么强的人，愿意放弃出身和父母去做别人的女儿（BV1euM3zsEwG，约25:26至25:41）。

## 3. 布局链条

目标（宜修）：拖慢甄嬛回宫，至少让她背着骂名回来。
目标（皇帝）：风平浪静迎回甄嬛，同时给甄嬛一个能压住皇后的身份。

铺垫一，皇后先抛出修宫殿的提议，让皇帝去前朝试水。她前一天说过要为莞嫔新建宫殿（第55集第879幕），而博主观点是这个提议是个坑（BV1euM3zsEwG，约14:50至15:09）。

铺垫二，大臣反对。皇帝回来抱怨：“今日朕在前朝把此事一提，这众大臣就跟商量好了似的，全都跳出来反对”，理由是水灾国库吃紧（第55集第879幕）。

借谁的手：大臣与舆论。这是皇后的拿手工具。

等什么时机：寿康宫刚刚败下阵来，太后已经把迎回的决定权交给皇帝。皇后既然无法正面拦，就转成拖。

怎么收网（皇帝一方，第55集第879幕）：
1. 皇帝先退一步：“朕已经想好了，让内务府把永寿宫整修出来，谅他们也不好再说什么。”
2. 再进一步：“不过让他们这么一提，朕倒觉得此事还得再下点别的功夫。”
3. 皇帝顺着大臣的理由逐条补强：出身不够，就抬旗赐姓；没有皇子，就给四阿哥配一个有身份的额娘；年龄差不够，就加十岁。
4. 皇后每一步都想拦，每一步都被他用一句话堵回去。
5. 最后皇帝抛出封号：把莞字改成熹字，“来日之路光明灿烂”。皇后只能说“极好”。

留了什么后手：
- 之后皇后在景仁宫对陵容说：“回宫有什么不好，虽然率土之滨莫非王土，但后宫踏踏实实在本宫掌握之中，她要回来就回来吧。”祺嫔被要求让父亲在朝中咬住甄嬛回宫的事，陵容要把握甄嬛的个性（第55集第889幕）。
- 博主观点：熹字取“光明灿烂”之意，皇帝想表达甄嬛过去所有的不幸都已过去；在皇后眼里，这一连串安排是送给甄嬛的超级大礼包（BV1euM3zsEwG，约24:25至25:22）。

## 4. 关键话术

- 第55集第879幕 皇后：“大臣们向来如此，总是小题大做，皇上自己拿主意便是了。”
  为什么管用：对手这句话看上去站在皇帝一边，实际在鼓励皇帝与舆论对立。听别人说“你自己做主”时，要想一想做主之后谁承担后果。

- 第55集第879幕 皇帝：“朕已经想好了，让内务府把永寿宫整修出来，谅他们也不好再说什么。”
  为什么管用：被反对时不硬顶，用一个更小的方案先化解阻力。

- 第55集第879幕 皇帝：“不过让他们这么一提，朕倒觉得此事还得再下点别的功夫。”
  为什么管用：把对方的反对意见当成需求清单，逐条补上。

- 第55集第879幕 皇后：“此事皇上可要三思啊，皇上若要赏甄氏脸面，要赐姓，可以在甄姓的后面加一佳字，抬为甄佳氏即可呀。”
  为什么管用：这是对手的折中方案。表面是退让，实际限制了对方的升幅。遇到别人提出看似公平的折中时，要看它缩小了谁的空间。

- 第55集第879幕 皇后：“可是莞嫔才二十二岁，跟四阿哥他只差了七岁，怎么能做四阿哥的额娘呢？”
  为什么管用：对手在无法反驳大方向时，开始在细节里找漏洞。

- 第55集第879幕 皇后：“皇上执意如此，臣妾也无法了，只是怕堵不住那悠悠之口。”
  为什么管用：认输之后还想再留一句风险提示，给将来出了问题留一个“我早说过”的记录。

- 第55集第880幕 甄嬛：“这些都是小事，皇上做主自然是好的。”
  为什么管用：对方给的代价很大，她只回一句接受。真正在意的是结果，不在意称呼。

## 5. 换到职场

### 场合一：面试（对方给你的是较低的头衔，换来更大的权限）

对应的局：新公司愿意给你一个比你期望略低的职级，但实际授权很大。你要判断这个交换划不划算。
打法：
1. 先问清楚授权范围、汇报线和资源，看实际权限有多大。
2. 把头衔看成次要项，不要在这个点上纠缠，让对方觉得你好说话。
3. 接受之前，把授权范围和考核方式写进沟通纪要或邮件。
4. 约定一个复盘时间点，到时按结果调整职级。
一句能直接说出口的话：“头衔我可以先按（职级）走，但希望（具体权限和汇报线）能在入职文件里写清楚。三个月后我们按（具体指标）复盘一次，您看可以吗？”

### 场合二：聊投资（对方提出看似折中的条款，实际限制你的空间）

对应的局：投资人说愿意投，但提出一个“折中”条款，比如更严格的对赌或董事会席位。你要分辨它缩小了谁的空间。
打法：
1. 把折中条款拆开，一条一条看它限制了什么。
2. 先说认同对方担心的点，再提出替代方案。
3. 不当场接受，也不当场拒绝，留出回去核对的时间。
一句能直接说出口的话：“您这个安排我理解，担心的是（对方的顾虑）。不过（条款）会让我们在（具体方面）受限，能不能换成（替代方案），同样能保障您这边的（顾虑）？”

## 雷区

- 皇后利用舆论、安排大臣联合上书、让祺嫔“泼尽脏水”（第55集第889幕），属于操纵舆论去伤人，只能识别，不能使用。职场里遇到总有人在你背后放大家都这么说的风声，要留意源头。
- 皇帝给甄嬛改姓、假称生母、加十岁，是伪造身份。职场里伪造履历、包装身份不可套用，一旦被查，后果远比甄嬛的处境严重。
- 甄嬛愿意付出的代价极大，博主观点是她只需要对付皇后的武器（BV1euM3zsEwG，约25:26至25:41）。职场里接受代价之前，要想清楚底线，代价可以付，原则不能丢。
- 我们自己的判断：皇帝的“恋爱脑”和“政治平衡”哪个占主导，剧本没有明说，博主的判断是后者。职场里别把上级的热情当作长期支持。
- 皇后把加“佳”字当成留一手，被皇帝一句话堵回。职场里做小动作，被识破后会损失信用。
