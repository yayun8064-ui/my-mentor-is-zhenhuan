# 认下弘历，三条规矩一次讲明白（第56集第893幕）

局面类型：谈条件 / 立威管人
对方：弘历（四阿哥），年少的皇子，生母出身微贱，在宫里一直没有靠山。最在意的是被承认和安全感，其次是不被人看不起。
甄嬛的处境：对等偏强。她是熹妃，对外是弘历的生母；但这个身份是皇帝设的，要靠弘历在人前配合才能立住，所以她需要他，不能只靠压。私下，永寿宫，没有旁人。
她的目的：把对外的母子关系变成真实的同盟；同时把规矩讲清楚，不让他自怨自艾，也不让他出错牵连自己。

## 1. 人设和差异化

她在弘历面前立的是疼他的额娘，同时是把话讲在前面的人。

前因：皇帝在第55集第879幕宣布，从今往后四阿哥的生母是钮祜禄甄嬛，让她以生了四阿哥才离宫祈福的名义回来，岁数也添上十岁（第55集第880幕苏培盛转述）。所以她对弘历说“人前人后我都是你的生母”，是这个身份的使用说明，是在交代这个身份怎么用。

和宫里其他人比：
- 皇后一方对弘历下过手。她先在三阿哥面前说弘历用心、难保他日不成大器（第54集第873幕），随后弘历的嬷嬷喝了他的绿豆汤中毒身亡（第54集第874幕）。太后的判断是宫里最在乎四阿哥存在的人就是皇后（第54集第875幕），皇后得知死的是嬷嬷，骂了一句“无能！”（第54集第876幕）。
- 眉庄救了他，请太后留他在寿康宫（第54集第875幕）。眉庄给的是庇护。
- 甄嬛给的是身份。她没有再提同情，直接给出一个他可以挺直腰的位置：爱新觉罗氏和钮祜禄氏的儿子，和其他阿哥一样。

## 2. 读人

弘历：
- 自卑很重。他在第54集第874幕说：“我能住回宫来已经是万幸，皇阿玛每次见我也只问我读书的事，若我连书也读不好，就更没有人瞧得起我了。”第875幕又说：“孙儿自知卑微，不讨人喜欢”。
- 博主观点：他是主动求见，没有等甄嬛召唤，对未来的谋划积极主动（树懒小结界，BV1MoKbzbEnm，约14:04至14:09、18:39至18:43）。
- 开口第一句用的是别人的话：“惠嫔娘娘告诉我，只要有额娘在，我就不再是没有额娘的野孩子。”博主观点：这是借惠嫔之口试探甄嬛的态度，他担心自己在养母心中的分量，因为甄嬛肚子里又有了孩子（BV1MoKbzbEnm，约16:51至17:23）。
- 博主观点：弘历之前几次出手，在岁玉轩门口蹭甄嬛的流量，在皇后面前表现，一路都很努力，目标是找到有权有势的养母，摆脱出身（BV1MoKbzbEnm，约15:54至16:34）。剧本里这些具体情节本卡未逐一核对。

甄嬛看出来的细节：他要的是一句确认，礼物给不到这个。所以她先回他“有弘历，额娘也不是孤身一人了”，让他知道他对她也有价值，再往下说规矩。

## 3. 布局链条

目标：把母子名分变成对外一致的口径、对内互相扶持的关系。

铺垫：
1. 皇帝抬旗赐姓，给了甄嬛一个新的出身和一个儿子（第55集第879幕）。
2. 弘历被毒、被眉庄和太后保护（第54集第874至875幕），他知道谁在乎他、谁想害他。
3. 弘历进门就转述惠嫔的话，说明眉庄在这之前已经和他谈过（第56集第893幕）。

借谁的手：惠嫔（眉庄）作为中间人，已经替她铺了一层；皇帝的旨意提供了名分。

等什么时机：回宫当天。博主观点：她还没拜见皇后，最好的姐妹还没来，先见了弘历（BV1MoKbzbEnm，约18:33至18:43）。同一天，刚验完香、温实初刚走，弘历就来求见（第56集第893幕）。

怎么收网：
1. 先接住他的不安，让他放心：额娘疼他，她也有了依靠。
2. 再用“有几句话额娘还是要告诉你”把话收紧，进入规矩。
3. 第一条：无论生母是谁、多想她，人前人后都是我的生母。
4. 第二条：不许自怨自艾，因为他是爱新觉罗氏和钮祜禄氏的儿子，荣辱一体。
5. 第三条：流言当没听到，只记住自己是皇上的儿子，和其他阿哥一样。
6. 对方回答“是，儿子明白”“是，儿子都记住了”，完成确认。

留了什么后手：
- 把关系说成荣辱一体，实际上让他也有了自保的动力。博主观点：这是命运共同体，她失势他回到落魄皇子的处境，他行为不端也会连累她（BV1MoKbzbEnm，约18:16至18:28）。
- 她没有承诺他任何具体的东西，只给了身份，之后怎么用要看他自己的表现。
- 她允许他对外叫额娘，也没有强迫他内心改变，给他留了自己想念生母的空间：“无论你的生母是谁、你有多想她”。

## 4. 关键话术

- 第56集第893幕 弘历：“惠嫔娘娘告诉我，只要有额娘在，我就不再是没有额娘的野孩子。”
  为什么管用：对方说出来的是他最担心的事。读出这一句，才知道她接下来该说什么。

- 第56集第893幕 甄嬛：“有弘历，额娘也不是孤身一人了。”
  为什么管用：先让对方知道他对你有价值，再说别的。博主观点：这是在告诉弘历，我们的关系你依靠我，我也依靠你（BV1MoKbzbEnm，约17:27至17:31）。

- 第56集第893幕 甄嬛：“弘历，你虽然知道额娘疼你，但有几句话额娘还是要告诉你。”
  为什么管用：先确认感情，再转入规则，提前打好预防针，避免对方觉得是责备。

- 第56集第893幕 甄嬛：“无论你的生母是谁、你有多想她，人前人后我都是你的生母。”
  为什么管用：对外口径一致，对内留出余地。承认他有想念的权利，要求的只是人前人后一致。

- 第56集第893幕 甄嬛：“你不能自怨自艾，因为你是爱新觉罗氏和钮祜禄氏的儿子，额娘的荣辱和你的荣辱是一体的。”
  为什么管用：先给理由再下禁令。理由讲的是他的身份，没有拿她的权威压人；再把利益绑在一起，对方会更主动遵守。

- 第56集第893幕 甄嬛：“额娘回宫，宫里的流言不少，你听到了就当没听到，你只要记住你是皇上的儿子，尊贵的皇子，和其他阿哥都是一样的。”
  为什么管用：不展开讲流言的内容，给对方一个可以站稳的立足点。

- 第56集第893幕 弘历：“儿子知道宫里面只有额娘最疼我。”
  为什么管用：对方主动表态，说明这一次确认见效了。

## 5. 换到职场

### 场合一：老板 1on1（老板把一位资历浅、没有靠山的新同事交给你带）

对应的局：老板安排了一个新人跟你，你希望他成为盟友，免得他变成眼线，也不希望他的问题连累你。
打法：
1. 先接住他的不安，让他知道他在这个组的位置是老板定的，与他从哪里来没有关系。
2. 把对外口径说清楚：对外我们保持一致，有分歧先私下说。
3. 讲清利益绑定：他做好了，我在汇报里会写明是他做的；他出问题，我也要出面。
4. 给他一个往上想的资格，不要只让他做执行。
一句能直接说出口的话：“你在这个组的位置是老板定的，跟你是谁带来的没有关系。对外我们口径一致，有不同意见先私下说。你做的东西，我汇报时会写明是你做的；你这边出问题，我们一起处理。”

### 场合二：大佬建联（对方比你资深，你想长期保持往来）

对应的局：你想让一位资深前辈愿意持续指点你，但你们之间没有上下级关系，对方没有义务。
打法：
1. 让对方知道他对你有用，也让你对他有用，建立双向。
2. 一开始就讲清往来的方式，比如多久同步一次，用什么形式。
3. 不要只索取，给对方他缺的东西，比如一线的真实反馈。
一句能直接说出口的话：“我这边在（一线做的事）上能拿到比较新的反馈，您要是想看，我每月整理一份给您。您方便的时候，也想请您点拨我一下。”

## 雷区

- 靠一个名分绑定的关系，基础是双方都有用。博主观点：弘历担心的是自己在养母心中的分量（BV1MoKbzbEnm，约17:16至17:23）。职场里一旦让下属觉得自己只是工具，他会开始找别的靠山。
- 编造出身：甄嬛的生母身份是皇帝设的假称（第55集第880幕苏培盛说“假称为四阿哥的生母”）。职场里不能用假履历、假经历做人设。
- 荣辱一体既是绑定，也是风险：她失势，弘历也失势。职场里把别人的前途绑在自己身上之前，要先想清楚你能不能兜得住。
- 把话说满：规矩里“人前人后”都要做到，实际很难监督。职场里可以要求对外一致，但无法要求对方内心无芥蒂。
- 弘历在博主视频里被描述得很有谋划，博主评价他“能够达成目标全都是靠她自己”（BV1MoKbzbEnm，约16:31至16:36）。职场里对这类下属，要防止他把你当成跳板。
