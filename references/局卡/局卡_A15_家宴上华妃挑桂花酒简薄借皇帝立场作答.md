# 家宴上华妃挑桂花酒简薄，借皇帝立场作答（第21集，前情见第20集）

局面类型：被当众发难 / 投其所好（顺着上位者的立场答）
对方：华妃（年世兰），家宴上刚被太后和皇后连着绕着弯子损了一轮，满肚子火，最在意面子和皇上对甄嬛的亲近；富察贵人，华妃一边的跟班，后面补了一刀；在场的还有皇帝、果郡王等亲贵和后宫众人。
甄嬛的处境：对等偏强，当众。位分是贵人，不高；但皇帝刚刚当众说了酒是他和她一起酿的，她站在皇帝身边。眉庄被禁足，华妃又盯得紧（第21集第353幕）。
她的目的：把华妃嫌酒简薄的发难化解掉，不让皇帝的脸面受损，也不给自己留下被抓住的话头。

## 1. 人设和差异化

她在这场里立的是替皇帝说话的明白人，不为自己辩护，只讲皇帝的立场。

和别人比：
- 华妃讲排场和天家风范，要拿宫中珍藏的好酒待客。
- 富察贵人讲甄嬛自己有一双奢华的蜀锦玉鞋，说她提倡节俭站不住脚。
- 淳儿帮腔，说那是皇上喜欢才赐的。
- 甄嬛讲的是战事、节俭、共进退，一句都没有说自己。

为什么对上皇帝的胃口：博主观点，边关战事不断，皇上天天向皇后示意后宫要节俭开销，后宫嫔妃全都省吃俭用（树懒小结界，BV1MH8BzmETe，约01:07至01:15）。甄嬛的话刚好替皇帝把想传达又不好自己讲的意思讲了出来。博主观点：皇上不方便开口，于是甄嬛替他维护尊严、传达节俭度日的规定（约05:56至06:02）。

## 2. 读人

华妃：
- 家宴上王爷在座，她特意提到这一点，是想借场面挑刺（第21集第354幕）。
- 她前面已经被太后和皇后连着损过：太后夸衣服，皇后点出绢花价值不菲，皇帝也说“年羹尧就你这么一个妹妹，自然是朕赏赐他什么他都贴补给你了”（第21集第354幕）。博主观点：太后记恨她抢走自己的步摇，故意当众阴阳她（BV1MH8BzmETe，约01:17至01:23）。
- 博主观点：华妃没有听出皇帝解释桂花酒的用意，只顾着嫉妒皇上和甄嬛亲密（约05:08至05:15）。
- 她话里的漏洞：她说酒简薄，等于说皇帝亲手做的酒简薄。博主观点：这话同时打了皇上的脸，翻译过来是皇上小气，拿小作坊的酒招待亲贵（约05:37至05:46）。
- 博主观点：华妃表面奢侈无度，背后是嫌弃皇后提拔的人不善管理内务府，弄不出好东西（格格說剧，BV1seQ2BTEav，约00:35至00:43）。该期讲的是家宴之后的清音阁看戏，这里只借来印证她讲排场的习惯。她嫌酒简薄、要拿宫中珍藏的酒，与这个习惯一脉相承（我们的判断）。

皇帝：
- 第21集第344幕，甄嬛私下说下雨雪点蜡烛气味不好也太费，皇帝回“你倒肯节俭”，还说要把这个巧宗告诉皇后，后宫的银子能省便省。甄嬛接着说，若能省下银子办个粥厂赈济贫民倒也是积德。
- 博主观点：节俭的要求在家宴之后仍在往下压，清音阁看戏时连皇后都出面带头讲节流，博主因此调侃皇帝在用度上抠门（枇杷树下等李子熟，BV1Uptc6WEWU，约29:28至29:33）。对应剧本第22集第368幕，皇后劝众姐妹开源不成也要节流。
- 家宴上他把桂花酒说成是自己和莞贵人一起采摘酿的，这是一次公开的示范。博主观点：皇上这是向众人明确传达自己节俭度日的准则（约05:00至05:08）。

富察贵人：
- 说话前半句顺着甄嬛，后半句翻出她那双蜀锦玉鞋，是抓双标的路数（第21集第354幕）。
- 博主观点：她没看懂前朝后宫的局势，不懂皇上的心意所向，以为自己在贬甄嬛，其实贬的是皇上的外交发言人（约06:38至07:05）。

淳儿：
- 单纯但口齿伶俐，看得清局势，关键时刻能接话（博主观点，约07:21至07:29）。

## 3. 布局链条

目标：把挑刺化解，且不得罪皇帝。

铺垫：
1. 第20集第327幕，皇帝赐给她一双用蜀锦、蓝田玉、合浦明珠做的鞋。这份赏赐后来成了富察贵人抓她的话柄。
2. 第21集第344幕，私下和皇帝聊省蜡烛、省银子、办粥厂，把节俭这一条先对齐。
3. 太后和皇后连着损华妃，华妃的火气已经积到了顶。

借谁的手：皇帝的节俭意愿；太后和皇帝的名义（“自太后皇上起都节俭用度”）；淳儿（第二轮）；皇帝（收口）。

等什么时机：华妃把话说完，皇帝还没有开口，甄嬛抢在他前面接下来。皇帝自己回应华妃会变成家宴上的争执，甄嬛替他讲，皇帝不用开口。

怎么收网：
1. 不回应简薄这个评价，直接讲背景：西北战事初平。
2. 把节俭拉到太后和皇帝头上，后宫与他们共进退。
3. 把桂花酒定性为皇上亲手所制，变成一件不能被否定的东西。
4. 落点：这杯酒体现皇帝的节俭之心，也显出皇室内部亲密无间，对在座亲贵讲的是亲近，没有讲寒酸。
5. 富察贵人翻出玉鞋，她不再接话，由淳儿用一句话把玉鞋归给皇帝的喜欢；皇帝用“朕最喜欢你有什么便说什么”收口（第21集第354幕）。

留了什么后手：
- 全程没有与华妃正面顶嘴，也没有为玉鞋辩白。博主观点：这一局之后，表面最风光的是华妃，实际上最受宠的是甄嬛和淳儿（约08:02至08:08）。
- 华妃没有服气：回宫后她对颂芝说，皇上虽说要节俭，可是也不能太不顾脸面，转头想着凑一笔银子给太后送重礼（第22集第355幕）。这是后一局的起点。
- 博主观点：腊八那天太后召见甄嬛，是要核实华妃此前告状说甄嬛奢侈的话，看到甄嬛没有穿得张扬便满意，并抬举甄嬛；博主还提到华妃自己两个月的用度比皇后宫中高出三倍（格格說剧，BV1seQ2BTEav，约12:18至13:33）。用度高出三倍，剧本第22集第362幕有写。太后点头抬举的细节，我们只核到第22集第370幕太后开场，余下只作博主观点。

## 4. 关键话术

- 第21集第344幕 甄嬛：“况且一下雨雪动不动就要点蜡烛，气味不好不说，也太费了。”
  为什么管用：这是私下对皇帝说的，用生活里的小事先把节俭的态度立起来，到了公开场合，她再说同样的立场，皇帝只会觉得一致。

- 第21集第354幕 华妃：“家宴之上，众位王爷在座，桂花酒甜醉，但却略显简薄，若是以宫中珍藏的美酒待客，岂不更显天家风范？”
  为什么管用：这是对手的话，放在这里是让用户看对手怎么借场面压人，借众人在场、借天家风范，把一句挑刺说得冠冕堂皇。

- 第21集第354幕 甄嬛：“西北战事初平，自太后皇上起都节俭用度，后宫理当与太后皇上共进退。以皇上亲手所制的桂花酒代替名贵酒种遍示亲贵，不仅是皇上节俭用度之心，更显皇室亲密无间。”
  为什么管用：不反驳简薄，把评价标准换成大局。先讲战事，再讲太后皇上带头，再讲后宫跟随，最后把酒说成皇帝的亲手之物，对方再批评就是批评皇帝。

- 第21集第354幕 富察贵人：“莞贵人提倡节俭那自然是很好的，可是听闻贵人有一双蜀锦绣成的玉鞋，奢华无比，不知道姐姐我是否有幸可以一观呢？”
  为什么管用：这是对手的第二刀，先捧后翻旧账，借别人的话把你的标准用回你自己身上。放在这里是让用户认出这种套路。

- 第21集第354幕 淳儿：“那是皇上喜欢莞姐姐才赐给她的，自然是越贵重越奢华越好喽，既然皇上喜欢又有什么不可以呢？皇上您说是不是？”
  为什么管用：把争议的东西归到皇帝的喜好上，再把问题抛回给皇帝，让他自己表态。

- 第21集第354幕 皇帝：“朕最喜欢你有什么便说什么。”
  为什么管用：上位者一句话定调，之后没有人再追。

## 5. 换到职场

### 场合一：聊投资（路演或饭局上有人挑你们太简单、太克制）

对应的局：投资人或同场的人当着其他人的面说：你们这个版本是不是太简单了，团队是不是太小了。
打法：
1. 不否认他看到的事实。
2. 把他挑的这一点，说成当前阶段的选择，并且和对方关心的目标绑在一起。
3. 讲你们现在集中在哪一件事，要验证什么，什么时候能看到结果。
4. 对方继续追问，把话递还给对方：您更看重的是哪一项。
一句能直接说出口的话：“您说得对，这个版本确实做得克制。现阶段我们把资源集中在（核心验证点），这样能最快验证（具体指标）。规模上来以后，该补的我们会补。”

### 场合二：老板 1on1（有同事拿你的主张反过来质疑你）

对应的局：你在团队里提倡过一个标准，比如控制成本、统一流程，同事在老板面前翻出你自己的例外，来质疑你说一套做一套。
打法：
1. 先认下事实：这一项确实有例外。
2. 说清楚例外的原因，原因要和老板定的目标一致。
3. 把话题放回整体目标上，不去争谁对谁错。
4. 以后自己的例外提前报备，减少被抓住的机会。
一句能直接说出口的话：“这个标准我自己也要对照，（具体一项）确实有例外，原因是（具体原因）。整体上我们还是按（老板定的目标）在走，后面类似的情况我会提前跟您报备。”

## 雷区

- 甄嬛自己有短板：她倡导节俭，脚上却有蜀锦玉鞋（第20集第327幕），被富察贵人当众翻出来。职场里对应：在公开场合给自己立高标准之前，先看自己有没有例外。
- 华妃此前就在太后面前提过甄嬛的蜀锦鞋子（第20集第331幕），玉鞋这个话柄一直在对手手里，博主也提到华妃告状这件事（格格說剧，BV1seQ2BTEav，约13:18至13:25）。富察贵人在家宴上再翻一次，说明一场家宴压不掉它。职场里对应：已经被人记下的短板，要提前自己补上。
- 华妃当众否定一件皇帝参与的东西，变成了打皇帝的脸。博主观点：华妃只顾着骂莞贵人，忘了皇上也有份做这个酒（BV1MH8BzmETe，约06:27至06:31）。职场里对应：批评一个项目之前，先看看它背后是谁拍板。
- 富察贵人翻旧账，忘了东西是谁赏的。职场里对应：翻旧账之前，先确认这件事是谁批的。
- 淳儿接话很痛快，但博主觉得可以收一收，留三分薄面（BV1MH8BzmETe，约07:43至07:49）。职场里对应：替人挡刀的时候，不要把对方逼到没有台阶。
- 甄嬛替皇帝说话，靠的是第21集第344幕私下确认过他的态度。职场里对应：替上级发言之前，要先确认他真的是这个立场，否则会说错。
- 华妃没有被说服，回去想着送太后重礼（第22集第355幕）。职场里对应：当众把对方压住，对方私下不一定服气，后续还会有动作。
