# 安比槐案，皇后和华妃意见相反，甄嬛先守规矩再借古喻今（第14集第260至267幕）

局面类型：被试探（被上位者问“你怎么看”）
对方：皇帝。这一天已经先后被皇后和华妃各见了一次，两人为同一个人（安比槐）说的话相反。他最在意的是后宫不插手朝政，西北军情和年羹尧都压在眼前，还有自己不要被任何一边牵着走。
甄嬛的处境：对等偏弱。私下，勤政殿里只有两个人，皇帝小憩刚醒。她是新近得宠的莞贵人，安答应的父亲是她要救的人，但她开口求情就是后宫干政。
她的目的：让皇帝自己决定重新查安比槐，保住安陵容的父亲，同时自己不留下干政的痕迹，也不让华妃觉得是她在跟年家作对。

## 1. 人设和差异化

她在这一场里立的是懂规矩、爱读书、只提问的人。

和另外几个人比：
- 皇后抢在前面去见皇帝，求情求在人情上。回来后对安陵容说“已经尽力了”，再顺手向甄嬛要一句“分劳解忧”（第14集第264幕）。皇后要的是安家记她的人情。
- 华妃要的是从严。曹贵人在清凉殿提醒她，年将军在外征战，后方却连军粮都办不妥当，难怪皇上生气；华妃自己说，换作她治理后宫，“必定铁腕铁拳铁石心肠”（第14集第264幕），随后去了勤政殿。
- 眉庄想先去探口风，被苏培盛一句“您这一开口，不等于是跟华妃过不去了吗？”劝回（第14集第261幕）。
- 甄嬛既不求情，也不表态站队。她只说两位娘娘的意见相反，“还是这件事情本就值得再细细推敲”，把一个二选一的题目换成一个要查的题目。

为什么对上皇帝的胃口：皇帝当天已经听了两次站队的话，最想要的是一个不站队、又让他能下台的人。甄嬛给的是史书里的道理，皇帝还夸她“句句不涉朝政，却句句以史明政”。

## 2. 读人

皇帝：
- 不喜欢后宫问政。苏培盛对眉庄说得很直：“皇上一向不喜欢后宫过问政事的，尤其这是军情大事，事关年羹尧西北的军情大事”（第14集第261幕）。所以这个局里直接求情是死路。
- 被夹在中间的烦。他自己说“皇后前脚刚走，华妃就来了，都是为了同一个人”（第14集第267幕），可见他心里清楚是两头来游说。
- 喜欢被读懂。甄嬛靠扇子上的胭脂香味，说出华妃来过，他当场夸“你倒是见微知著啊”，又说“什么都瞒不过你”（第14集第267幕）。先把气氛调到他放松，再谈正事。
- 想听的是史书里的做法。甄嬛特意提“皇上一向仰慕唐宗宋祖风范”，投其所好之后才开口讲责其首宽其从。

皇后：
- 剪秋在桃花坞说“娘娘去勤政殿见皇上了”，陵容说“皇后娘娘好快的消息，算准了我和姐姐要来求她，就先去见皇上了”（第14集第263幕）。皇后抢在求情的人开口之前出手，求情的人情就归她。
- 皇后回来后对甄嬛说：“莞贵人善解人意，如能知本宫心之所向，自然能为本宫分劳解忧。”（第14集第264幕）这句话在要甄嬛表忠，是在人情之外再提一个条件。甄嬛当场把茶倒进香炉，答“能为皇后娘娘分忧解劳是臣妾等分内之事”，没有答应任何具体的事。

华妃：
- 槿汐的判断是“想必是与皇后反其道而行之，想请皇上从严处置安比槐吧”（第14集第266幕）。后来皇帝自己说：“安比槐的事朕没有听华妃的，华妃就使了两天小性子，朕也要好好安抚一下她。”（第15集第269幕）

甄嬛自己对局势的判断（第14集第266幕）：“此时没有比华妃娘娘更关心皇后娘娘的人了。”“多谢她如此卖力，如此一来，我可省心多了。”我们自己的判断：两边的力量在皇帝那里互相顶住，她只需要在中间递一句“值得再推敲”，就足以让皇帝顺势选第三条路。

博主观点（脖子细哔哔叨，用了两期。BV1ZftE6XEKf 是 p32，讲勤政殿之前的铺垫；BV1iKBxBZERm 是 p33，讲勤政殿这一场）：
- 甄嬛听完陵容的话，先问的是安比槐有没有参与其中，博主说救不救的前提是他到底有没有罪，不弄清真相不能冒然出头（p32，约01:38至01:58）。
- 苏培盛劝眉庄的原因，博主归纳为两条：一来背负后宫干政的罪名，二来得罪华妃（p32，约06:23至06:27）。
- 皇后抢先出手，博主认为是在买人心，要买的对象是甄嬛，陵容只是由头（p32，约13:20至13:31）。博主说甄嬛欠了人情又被华妃盯着，只能先投诚，她没有真心要辅佐皇后，在她心里树只有一棵，就是皇上（p32，约14:20至14:57）。
- 甄嬛求皇后的目的是把水搅混。皇后一出马，华妃大概率也会干预，两位高位者为一个小官出面，皇帝要考虑的就变成自己支持哪一方势力，这时才是甄嬛出手的时机，自己第一个出手是枪打出头鸟（p33，约00:42至01:29）。
- 进门先开玩笑、借扇子聊华妃，是因为皇帝累了，直接挑明来意只会让他烦上加烦（p33，约02:14至02:20）。扇子上的小心思皇帝很受用，给后面的谈话开了好头（p33，约03:20至03:26）。
- 博主把那段话拆成三点：后宫不得干政是摆立场，只为帮皇上排忧解难；两位娘娘意见相左，是把皇帝的注意力从押送粮草转到后宫，让他做决断时把后宫的因素也算进去；以史明政，把皇帝捧成唐宗宋祖，再说外有战事内有刑狱二者清则社稷明（p33，约05:03至05:43）。
- 博主认为皇帝一早可能已有定论，三个女人的出场只是让他更坚定，真正的决定权永远在皇帝手里（p33，约07:52至08:09）。甄嬛这番筹谋的作用，是把战场拉大，让皇帝同时考虑后宫的影响（p33，约08:14至08:27）。
- 博主对“不敢僭越”那一段的看法：所谓干政与否，在于皇帝的心意，皇帝愿意就多说无妨，不愿意就是干政（p33，约09:17至09:24）。
- 博主还看到剪秋把功劳都揽给皇后，又顺口提起甄嬛和眉庄，是在挑拨陵容和眉庄（p33，约09:54至10:28）。

## 3. 布局链条

目标：让皇帝自己说出“重新明查”，又不让人看出这是甄嬛的主意。

铺垫：
1. 陵容来求。甄嬛一开口就点出限制：“朝政上的事情咱们未必插得上嘴啊。”（第14集第260幕）从这时起，她就没打算走直接求情这条路。
2. 眉庄去试口风，被苏培盛劝回（第14集第261幕）。她从眉庄的遭遇确认了直接求情走不通。
3. 求皇后。皇后抢先见了皇帝，回来说已经尽力（第14集第264幕）。甄嬛把皇后的人情收下，却把答应的内容压到最小。
4. 与槿汐推算华妃的动向（第14集第266幕），确认两边的力量会互相顶住。

借谁的手：
- 皇后和华妃这两个对立面，各自把话递给了皇帝，甄嬛拿他们的对立做问题：两位娘娘为什么意见相反。
- 史书里的明君做法。皇帝爱听的典故，是她借来的另一只手。

等什么时机：皇帝自己连问两遍“那么你呢”之后。第一遍她只猜两位娘娘各自的立场，没有给自己的看法。第二遍才开口。

怎么收网：
1. 进门先聊闲话，不提正事。扇子上的香味、华妃来过，让皇帝觉得她是来陪他的。
2. 自降一格：“嬛嬛本就不如华妃娘娘善体君心，只会惹四郎生气。”
3. 皇帝说出“都是为了同一个人”，她只问一句“可是为了安答应的父亲安比槐一事？”，名字由她点出，内容和立场一个字不加。
4. 皇帝第一次问“那么你呢？你又是为何？”，她替两位娘娘各说一句，不评对错。
5. 皇帝第二次问“那么你呢”，她先声明“后宫不得干政，嬛嬛铭记于心”，随后只提一个问题：是不是两位娘娘真的意见相左，还是这件事本就值得再细细推敲。
6. 皇帝问“什么推敲”，她借古喻今，讲责其首宽其从，最后落在“外有战事内有刑狱，二者清则社稷明”。
7. 皇帝自己说出结论：“安比槐一事朕会派人重新明查，必不使一人含冤。”
8. 她马上再退一步，请皇帝勿怪自己放肆。皇帝给她台阶：“莞贵人甄氏不敢，甄嬛无妨。”她接一句“对四郎必定知无不言”，把“臣”和“妻”的界线留给皇帝自己划。

留了什么后手：
- 她没有给任何处置建议，也没有替安家求情，所有话都是提问和史书。以后有人追究，说不出她干政的话。
- 次日剪秋告诉陵容：“今儿一早皇上命济州协领沈自山重审安大人牵涉运送军粮一案，安大人活命有望了。”（第14集第268幕）功劳被说成皇后的。剧本里甄嬛没有出来纠正，也没有要这份功劳。
- 皇帝随后对她说“朕待你不同旁人，你是知道的”（第15集第269幕），又一次表示对她与别人不同。她接着说心惊余氏与丽嫔之事，没有借机要位分。

## 4. 关键话术

- 第14集第267幕 甄嬛：“嬛嬛本就不如华妃娘娘善体君心，只会惹四郎生气。”
  为什么管用：当天华妃刚来过，她先把自己放到“不会讨好”的位置，皇帝反而放松，觉得她没有目的。

- 第14集第267幕 甄嬛：“让嬛嬛来猜上一猜。皇后娘娘仁善，必定是为安答应求情的，华妃娘娘刚直不阿，想必是要四郎执法严明不徇私情。”
  为什么管用：替两位各说一句好话，不选边。皇帝发现她把两边的立场都说准了，又没有偏向。

- 第14集第267幕 甄嬛：“后宫不得干政，嬛嬛铭记于心，嬛嬛只是奇怪，皇后娘娘与华妃娘娘同为安比槐一事面见皇上，不知真的是两位娘娘意见相左，还是这件事情本就值得再细细推敲？”
  为什么管用：先自己说出规矩，对方就没法拿规矩压她；再用一个问题把二选一改成一个待查的事，皇帝想追问就得往下接。

- 第14集第267幕 甄嬛：“臣妾幼时观史，见圣主明君责罚臣民时，往往责其首而宽其从，恩威并济，使臣民敬畏之外更感激天恩浩荡。”
  为什么管用：用史书里的做法替皇帝想好台阶，既免了从严的压力，又给了施恩的名声。

- 第14集第267幕 甄嬛：“皇上一向仰慕唐宗宋祖风范，皇上亦是明君仁主。臣妾愚昧，认为外有战事内有刑狱，二者清则社稷明。”
  为什么管用：先夸皇帝爱听的人设，再把军情和刑狱并排，让皇帝自己去想这两件事哪个更要紧，不替他得出结论。

- 第14集第267幕 甄嬛：“臣妾一介女流，在皇上面前放肆，还请皇上勿要见怪才好。”
  为什么管用：皇帝已经表态后，她马上退一步，把刚才的话放回“闲谈”里。

- 第14集第267幕 甄嬛：“是，嬛嬛在皇上面前不敢僭越，可是对四郎必定知无不言。”
  为什么管用：皇帝给了台阶说“莞贵人甄氏不敢，甄嬛无妨”，她不顺势多说，只把一个称呼的差别接住，让皇帝觉得她既守规矩，也对他坦诚。

## 5. 换到职场

### 场合一：职场（两位副总先后找老板，一个要砍预算，一个要加预算，老板私下问你怎么看）

对应的局：老板在周五下午和你单独聊，说“（A总）和（B总）今天都来找过我，意见正好相反，你怎么看？”老板其实在看你站不站队，也在找一个能下台的办法。
打法：
1. 先聊一点老板关心的背景，让他觉得你来陪他想事情，没有带着表态的任务。
2. 老板问第一遍，你只复述两位各自的立场和理由，不评对错。
3. 老板追问时，先把边界讲出来：这件事该怎么定在老板那儿，你不替哪边表态。
4. 然后只提一个问题：两位的分歧，是对（某个指标）的判断不同，还是手里的数据口径不同。
5. 老板问你什么意思时，拿公司或行业里一个类似的先例讲，让老板自己得出结论。
6. 老板拿了主意之后，退一步，别抢功劳。
一句能直接说出口的话：“这件事怎么定在您那儿，我不替哪一边表态。我就是有个疑问：（A总）看的是（口径一），（B总）看的是（口径二），两边看的是同一个数吗？要是口径不一样，先对齐再谈砍还是加，可能就不用二选一了。”

### 场合二：日常（爸妈为同一件事意见相反，各自先跟你说过，妈妈最后问你“那你呢”）

对应的局：家里要决定（具体事，比如要不要给弟弟出一笔钱），爸爸和妈妈各自先找过你，说法相反。吃饭的时候妈妈看着你问：“那你呢？”
打法：
1. 不当场选边，先把两个人各自担心的点复述一遍，让两边都觉得被听懂。
2. 声明这件事怎么定是爸妈的事，你不替任何一方说话。
3. 只提一个问题：你们担心的是同一件事吗。如果爸怕的是（具体顾虑一），妈怕的是（具体顾虑二），把这两条都解决，是不是就不用二选一。
4. 讲一个他们都认识的人遇到过的类似情况，让他们自己往下想。
一句能直接说出口的话：“这个钱怎么出是你们两位的事，我不替谁说话。我就想问一句：爸担心的是（具体顾虑一），妈担心的是（具体顾虑二），如果这两条都能解决，是不是就不用二选一了？”

## 雷区

- 眉庄的直接求情：苏培盛说得很明白，开口就是跟华妃过不去，万一被人小题大做，眉庄父亲的前程也受牵连（第14集第261幕）。职场里替人说情，先问清楚会得罪谁，对你自己的位置有什么影响。
- 皇后的手法要认得：抢在别人开口之前出手，把人情记在自己名下，再顺势提一个条件（第14集第264幕）。职场里有人帮你办事的同时暗示你要懂他的意思，先问清楚他要什么，别当场答应不明确的事。
- 华妃的做法：精心打扮去见皇帝，主张从严（第14集第267幕里，甄嬛从扇子上的胭脂香推出来的）。结果皇帝没有听她的，事后只花两天哄她（第15集第269幕）。职场里靠情绪和姿态逼老板表态的上级，老板可能表面安抚，但并不采纳。
- 剪秋把甄嬛说成也去求情（第14集第268幕）。她在皇帝面前守住的“不干政”，到了皇后一方的嘴里变成了“也去求情”。职场里你在老板面前守的边界，传到别人嘴里可能被改写，重要的话要留有后续的证据。
- 把结果全算在自己的话上。博主观点：皇帝可能一早就有定论，皇后、华妃和甄嬛只是让他更坚定（p33，约07:52至08:09）。我们自己的判断：职场里老板采纳了你的意见，也别当成是你说服了他，不要事后去提醒老板是你的功劳。
- 借古喻今对皇帝有用，因为皇帝爱听唐宗宋祖。我们自己的判断：对不爱听典故的老板，这一招会变成说教。先看老板平时爱用哪类类比，再决定举什么例子。
- 皇帝说“妻子在夫君面前畅所欲言谈史论政，有何不可？”（第14集第267幕），这是对方主动给的口子。她仍回“臣妾不敢”。职场里老板说“你随便说”，也先退一步，再看他是不是真想听。
