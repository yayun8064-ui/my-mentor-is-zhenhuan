# 请温实初担欺君的风险，先交底再给退路（第54集第857至860幕）

局面类型：求人办事 / 谈条件
对方：温实初，太医，从小认识的世交，对甄嬛有情，也一直想护着她。最在意她的安危，其次是自己能不能真的帮上忙。
甄嬛的处境：弱。人在宫外，要求的事会让对方担上杀头的罪名；但对方有情，会听她的。私下，凌云峰禅房。
她的目的：让温实初在皇帝面前把孕期说成“一个月”，并且在后面的日子里配合安胎、让皇帝少亲近，把月份的真相藏住。

## 1. 人设和差异化

她在温实初面前立的是没有退路的人，也是不勉强人的人。

和她对苏培盛的做法比（见局卡B01）：对苏培盛，她只露一半，让对方以为怀孕是偶然；对温实初，她交全底，月份、孩子是谁的、自己要什么，一次说清。博主观点：整件事最关键的一步是太医必须是自己人，苏培盛只是合作关系，所以甄嬛要严格划定他能知道的范围，温实初才是可以交底的人（树懒小结界，BV1gvJqzXEwz，约09:43至10:19）。

和温实初自己的立场比：他一进门质问的是“你父亲已经回京医治了”背后是谁安排的，关心的是她怎么拿到的这个结果。她不绕，第一句就承认他已经知道了。

## 2. 读人

温实初：
- 进门先质问父亲回京：“苏培盛是御前的人，他怎么会突然接你父亲回京呢？”（第54集第859幕）说明他消息灵通，自己拼出了不对劲，也说明她不用再编借口。
- 他最怕的是她回宫走旧路：“那条路太苦了。”（第54集第859幕）
- 他自己提过会照顾她们母子一生一世（第54集第859幕），这是他能给的全部。甄嬛要他看到的是，这些不够解决她要面对的事。
- 他最终说的是：“这世上我拿你最没办法，除了帮你，除了听你的，我也没有其他帮助你的法子。”（第54集第859幕）说明他没有被说服，只是已经没有别的路可走。
- 博主观点：温实初早就知道甄父病重却没有行动，被甄嬛多次拒绝也不冤枉（BV1gvJqzXEwz，约14:37至14:56）。这是博主的评价，本卡只用来看他的行动力有限这一点。

苏培盛传话时对他说的是：“这件事可是皇上特谕交代的，容不得第三人知晓，能明白我的意思吗？”（第54集第858幕）苏培盛没有在这里提月份，月份的真相只有甄嬛当面告诉他。

## 3. 布局链条

目标：温实初在皇帝面前说出“有喜已有一月”，之后配合瞒住月份。

铺垫：
1. 槿汐当着苏培盛的面提议请温实初安胎，理由是太医院里只有他与娘娘有交情，身份未明更怕张扬（第54集第857幕）。苏培盛答应并向皇帝禀告，所以温实初是以皇帝钦点的身份来的，后面的事有了官面理由。
2. 苏培盛到太医院传话，没有讲月份，只说皇上钦点他为一位小主请脉安胎（第54集第858幕）。

借谁的手：槿汐出主意，苏培盛传皇命，温实初本人。

等什么时机：温实初冲进来质问之后。他已经猜到了，所以她直接把事说完，没有再铺垫。

怎么收网：
1. 先把前提说清：这个孩子的月份只有一个多月，与他所知道的两个多月不同。
2. 说出结论：我遇见了皇上，这个孩子是皇上的。要紧的是皇上认定这一点。
3. 他喊欺君之罪，她拿出一个对方不可能选的选项：万一，就是你不肯帮我，你去告诉皇上月份不对。他回答“你明明知道我不会”。
4. 对比他的照顾一生一世与她要面对的三件事：接回父亲、保全家人、查明允礼的死因。他自己说出“说来说去终究是我无能，我不能帮你”。
5. 退一步，把选择权交给他：他肯帮就帮，不能帮她也不勉强。
6. 讲处境：留在宫外是坐以待毙，宫里斗得再久也比在外面被人无声无息害死强。
7. 他说出“我便拼命保全你就是”。

留了什么后手：
- 温实初到皇帝面前说“只是娘娘的胎象略有不稳，需要好好静养，为保万全恐怕不能与之过分亲近”（第54集第860幕），皇帝因此不会靠近，月份不容易被看出来。她随后束腹，对浣碧说“只要皇上不与我亲近，便可瞒天过海”（第54集第863幕）。
- 温实初转头把消息传给眉庄，请她在太后面前帮着说话（第54集第864幕）。他从被动配合变成主动帮她联络。

## 4. 关键话术

- 第54集第859幕 甄嬛：“你既然已经知道了，又何必要费口舌来问我这些呢？”
  为什么管用：对方已经看懂一半，就不再装，直接把没说的部分补齐，节省了双方猜来猜去的时间。

- 第54集第859幕 甄嬛：“是谁的都不要紧，要紧的是皇上认定这个孩子是他的，认定了我腹中的孩子只有一个多月。”
  为什么管用：把对方纠结的真相放下，只讲这件事需要他做的那一点。

- 第54集第859幕 甄嬛：“你能照顾我和孩子一生一世，可是你能帮我把我病重的父亲从宁古塔接回来好好医治吗？你能保全我的家人不再为人所害吗？你能帮我查明允礼的死因为他报仇吗？”
  为什么管用：把对方的好意和现实需求并排放，让他自己看出差距。这三问用的是他对她的感情，见雷区。

- 第54集第859幕 甄嬛：“如今你肯帮我就帮，不能帮我我也不会勉强你。”
  为什么管用：给出退出的口，对方反而更愿意留下。

- 第54集第859幕 甄嬛：“我在宫外无依无靠，不过是坐以待毙罢了，宫里的日子哪怕是斗得无穷无尽，总比在这里斗也不斗就被人害死的好。”
  为什么管用：对方担心的是路太苦，她用对比回答，苦的路至少有出路。

- 第54集第859幕 温实初：“可是我如果这么保着你走下去，只能保着你回宫踏上旧路，嬛儿，那条路太苦了。”
  为什么管用：对方的真实顾虑是对你的担心，听清这一句，才知道该回应什么。

- 第54集第860幕 温实初：“回皇上，莞嫔娘娘有喜已有一月，只是……”
  为什么管用：执行的人把关键口径说了出来，后半句再补上需要静养、不宜亲近，堵住了漏洞。

## 5. 换到职场

### 场合一：老板 1on1（请老板为一个有争议的决定背书）

对应的局：你要推一个有风险的方案，需要老板在更高一层面前表态支持，一旦出事他要承担连带责任。
打法：
1. 先交底，把你已经知道的最坏情况全部说清楚，包括数据中的短板。
2. 说明你需要他做的具体动作只有一个，比如在周会上点头同意，或者替你向上级说一句。
3. 讲清楚你自己兜住哪一部分，让他看到风险没有全压在他身上。
4. 把退出的口留给他，并且让他知道说不也没关系。
一句能直接说出口的话：“这件事有风险，我先把最坏的情况讲清楚：（最坏情形）。我需要您做的只有（一个具体动作），其余的我来扛。您要是觉得不合适，直接说，我再想别的办法。”

### 场合二：面试（请前上司做推荐人）

对应的局：新公司要做背景调查，你需要前领导为你说话，而你们离开时有些不愉快的地方。
打法：
1. 先说清你为什么换工作、新岗位是什么，让他知道自己要回答什么。
2. 把他可能被问到的问题提前告诉他，让他没有被突然袭击的感觉。
3. 明确说他不方便也没关系，你有备选。
4. 对方答应之后，再补充一两件你们共同做过的事，方便他回忆。
一句能直接说出口的话：“新公司会做一次背景核实，可能会问到（我们一起做过的那个项目）。我先把情况同您说一下，您看是否方便帮我回答，不方便也完全没问题，我另外安排。”

## 雷区

- 利用感情：整局的关键一句“你去告诉皇上”是拿一个对方绝不会选的选项来逼他，又拿他承诺的照顾一生一世去对比三件他做不到的事，让他自觉无能。这是利用对方的感情换帮助，职场里不能用，对方日后想明白，只会寒心。
- 带人担死罪：让温实初在皇帝面前作假，是把他拉进一个九族的风险（博主观点，BV1gvJqzXEwz，约10:15至10:19）。职场里不要把合规、法务上有重大风险的事交给别人去做。
- 一个环节被拆就是连锁：月份靠温实初、苏培盛、束腹、少亲近几个环节同时成立，任何一个出错全线崩盘。
- 不让苏培盛知道月份的真相，同时让温实初全知道：两人各自知道不同的版本，温实初的表态要与苏培盛的转述对上，稍有不同就会露馅。
- 对方答应不等于对方放下顾虑：温实初的原话还是那条路太苦。职场里对方说“好”之后，也要记得回头问一句他真正担心的是什么。
