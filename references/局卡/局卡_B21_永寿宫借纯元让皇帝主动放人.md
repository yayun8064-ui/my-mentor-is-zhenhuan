# 永寿宫借纯元，让皇帝主动放人（第59至60集）

局面类型：求人办事 / 谈条件（全程不开口求）
对方：皇帝（雍正），权力远高于甄嬛，疑心重，爱面子，自认宽仁；幕后对手是皇后宜修，她以宫规拿住了槿汐和苏培盛，主张严惩。场外还有端妃，前一晚已经替甄嬛在皇帝面前打过底。
甄嬛的处境：弱。槿汐和苏培盛被皇后抓住缨络把柄，人证物证俱全（第59集第943幕）；她自己怀着双生胎，直接求情会被皇后扣上庇护纵容的帽子（第59集第945幕）。私下，在永寿宫，对面只有皇帝。
她的目的：让皇帝自己说出“即便要罚，也该缓一缓”，把死罪降成罚月钱，同时不让自己出面求情，也不与皇后撕破脸。

## 1. 人设和差异化

她在皇帝面前立的是体恤圣意、替皇后说话、委屈只往自己身上揽的熹妃。

和其他人比：
- 皇后讲宫规，说“存天理灭人欲”（第59集第943幕），皇帝听到的是冷冰冰的惩罚。
- 端妃讲孟子和朱熹，只给了皇帝一套能用的道理，自己并不替任何人求情（第59集第949幕）。
- 浣碧在旁边心疼主子，一开口就是诉苦。
- 甄嬛从头到尾没有替槿汐辩护，只夸皇帝宽仁，替皇后留余地，让皇帝自己去替她抱不平。

为什么对上皇帝的胃口：他刚听完端妃的劝，已经倾向有孕的嫔妃在宫里时，不要喊打喊杀。甄嬛进来前他心里是松动的，她需要的是让他觉得这个决定是自己想出来的，而且比皇后更体面。

## 2. 读人

皇帝：
- 爱听自己宽仁的评价。甄嬛一句“皇上素来宽仁待下”，把他放在一个他想守住的形象里。（第60集第950幕）
- 对纯元有执念，也对皇后失去信任。他听完“若纯元还在”，第一反应是“宜修如何能与纯元相提并论？”（第60集第950幕）
- 他早就被传言烦到：宫里纷传甄嬛腹中孩子的来路有问题，“旁人便罢了，竟然连皇后也要朕留心”（第60集第950幕）。这是他对皇后的新火气。
- 看到眼下乌青会心疼，一心疼就替她出头，不用她开口。
- 博主观点：皇帝来永寿宫的目的是试探甄嬛对这件事的态度，所以先聊闲话，谁先露底牌谁就失了先机（树懒小结界，BV1MK16B6EeY，约01:31至02:34）。

皇后：
- 她要扮演秉公办事的六宫之主，不能公开违背先皇后的仁厚名声。甄嬛正是利用这一点，在第59集第943幕早早把她放到“秉公处置”的位置上。

端妃：
- 话不多，说话有分量，皇帝觉得她“不愿管别人的闲事，更不爱说别人的闲话”（第59集第949幕）。让这种人先开口，可信度比甄嬛自己说高得多。

甄嬛没有把握的地方：她不知道端妃那晚的效果。博主观点是这一场对甄嬛是开盲盒（BV1MK16B6EeY，约00:54至01:07），剧本里浣碧问“小主放心得过端妃吗？”，甄嬛答“用人不疑，疑人不用。”（第60集第950幕）

## 3. 布局链条

目标：让皇帝自己决定从轻发落。

铺垫一，先让皇后站在“秉公”的位置上，也让自己站在“可以商量”的位置上。
皇后搜出槿汐的东西时，甄嬛先淡化（单凭缨络说明不了什么），被拒后再要求自己处置，最后给皇后戴一顶“贤后”的高帽：“娘娘是太后、皇上眼中的贤后，又为后宫众人所敬仰，想必娘娘一定会秉公处置，既保住皇家颜面，又能清肃后宫。”（第59集第943幕）这句话后面用得上：皇后一旦下狠手，就是不配这个“贤后”。

铺垫二，判断自己不能求。
她去养心殿，皇帝先说“你若是真舍不得崔槿汐，朕叫内务府再给你挑个更好的”（第59集第944幕）。她没有顺势求情，出门后向浣碧说明：“皇后有备而来，切切实实拿住了把柄，又有宫规压着，皇上也不能说什么，若本宫去求，皇后正好请君入瓮，治本宫一个庇护纵容之罪。”（第59集第945幕）

铺垫三，稳住槿汐，也稳住苏培盛那一头。
她怀着身孕去慎刑司，对槿汐说“死是最容易的事情，一脖子吊上去就完了，可是你这样做是亲者痛、仇者快，不值得”（第59集第946幕），又说苏培盛那边她会打点。

借谁的手：端妃。
她去延庆殿，把理由讲成“为了皇上”：苏培盛被拘，皇上身边没有会服侍的人（第59集第947幕）。端妃当晚在皇帝面前用孟子反驳朱熹的“存天理灭人欲”，再用“不痴不聋，不做家翁”劝皇帝端出容人之量，最后补一句熹妃和惠嫔都怀有身孕，听不得打打杀杀（第59集第949幕）。

等什么时机：第二天皇帝下朝后顺路来永寿宫。他心情好，来之前已经在端妃那里把“该缓一缓”的念头放进脑子里。

怎么收网（第60集第950幕）：
1. 先不谈案子。问皇帝为什么高兴，让他自己说。他说起端妃，等于把话头递到她手里。
2. 夸皇帝宽仁，把“宽仁”立成标准。
3. 抛出纯元，让皇帝回忆。她先称赞纯元治理王府，再借槿汐的口说纯元施惠上下。
4. 问一个假设：若纯元还在，槿汐与苏培盛会如何处置。她没有说该怎么处置，问题本身就带答案。
5. 把皇后绑在两个标准上：纯元的亲妹妹性情一路，且不会与皇上的宽仁相悖。皇帝自己得出结论：宜修比不上纯元。
6. 皇帝亲口说出端妃教的话：“即便要罚，也该缓一缓。”
7. 浣碧说出她睡不好，甄嬛当场拦住。皇帝看到乌青，反过来说她委曲求全。
8. 她继续顺从，还劝皇帝“切勿因此迁怒了皇后娘娘”。皇帝于是越发替她出头，说出“朕又何必如此灭人欲”。
9. 最后再补两刀软的：家丑要遮掩，不要让臣民笑话；苏培盛与皇帝朝夕相处，功过相抵。最后以一句玩笑结束，皇帝一句“朕哪里舍得”，气氛回到夫妻之间。

留了什么后手：
- 结果：槿汐回来，甄嬛说“皇上说了，只罚一年的月钱算是惩罚”（第60集第951幕），皇帝对苏培盛说的也是“朕罚了你们一年的月银小惩大戒”（第60集第952幕）。
- 对皇后：没有任何一句话攻击她，皇帝却已经对她有火气。后面皇帝在永寿宫说皇后“耳根子软”（第60集第963幕）。
- 博主观点：浣碧那句话还有一层深意，引导皇帝联想到皇后刺激嫔妃早产的旧事，把“整顿纪律”变成“想害有孕的人”（BV1MK16B6EeY，约08:02至08:36）。这是博主的推测，剧本里没有写明。

## 4. 关键话术

- 第59集第943幕 甄嬛：“娘娘是太后、皇上眼中的贤后，又为后宫众人所敬仰，想必娘娘一定会秉公处置，既保住皇家颜面，又能清肃后宫。”
  为什么管用：当面夸对手一顶大帽子，既堵住她明目张胆下狠手，也给自己留了将来说“您不够仁慈”的口子。

- 第60集第950幕 甄嬛：“皇上方才进来时仿佛很高兴，有什么高兴事也告诉臣妾，也好叫臣妾一同乐一乐。”
  为什么管用：对方带着目的来，她先不接目的，把话题交给他自己。他一开口谈高兴的事，就卸掉了防备。

- 第60集第950幕 甄嬛：“端妃娘娘久在宫中见识深远，而皇上素来宽仁待下，对内对外都是英明睿智，才得今日百业昌盛、百姓安定的局面。”
  为什么管用：先夸盟友，再把“宽仁”两个字安到皇帝头上，他之后做出宽仁的决定，就顺理成章。

- 第60集第950幕 甄嬛：“说句犯上冒昧的话，若是今日纯元皇后还在，那槿汐与苏培盛之事又会如何处置呢？”
  为什么管用：用一个假设句代替请求，对方的答案由他自己说出口，她不用担任何求情的责任。

- 第60集第950幕 甄嬛：“臣妾想，当今皇后是纯元皇后的亲妹妹，彼此性情自然是一路的，皇后娘娘虽说要以槿汐与苏培盛之事惩戒后宫，大约也不会真要了他们的性命吧？”
  为什么管用：看上去替皇后说好话，实际把皇后的做法放到对方心中最高的标准下，让标准替她发言。

- 第60集第950幕 甄嬛：“皇后娘娘也只是关心后宫之事罢了。”
  为什么管用：皇帝刚说出对皇后的不满，她立刻替皇后圆场。越不踩对手，越显得公允，皇帝的火气得不到出口，只能自己继续消化。

- 第60集第950幕 甄嬛：“多嘴！谁让你在皇上面前嚼舌根的？皇上，您别听浣碧乱说，臣妾没事，睡得很好。”
  为什么管用：自己说苦不可信，别人说出来再由自己拦，对方会以为自己看穿了真相。博主称这是一套绿茶连招（BV1MK16B6EeY，约07:50至07:55）。

- 第60集第950幕 甄嬛：“皇上切勿因此迁怒了皇后娘娘，皇上要怪就怪臣妾没有管教好宫人。”
  为什么管用：把责任揽到自己身上，对方越无处发火，越心疼她。

- 第60集第950幕 甄嬛：“嬛嬛是女子，肚子里的是小人儿，皇上既觉得难养，那就不养也罢了。”
  为什么管用：对方用玩笑话指责时，借他的话把玩笑接住，气氛从政治回到私人，让这一局不留痕迹地收尾。

## 5. 换到职场

### 场合一：老板 1on1（你的方案被另一位同事用制度压住，你不方便直接向老板求情）

对应的局：另一个部门以流程规范为由要叫停你的项目，老板也没有表态。你直接求他保项目，等于让他在两边之间选边站。
打法：
1. 先做自己能做的：把项目里可能被抓的缺口补好，别让对方的指控有实据。
2. 找一个老板信任、说话有分量的人，把你要讲的事实讲清楚，只讲事实，不替你求情。
3. 见老板时先问他最近在忙什么好消息，让他自己开口，再顺着他说的话接到你的事。
4. 用他自己说过的原则或公司公开的标准提问，不直接要结果，比如问他按咱们一直强调的（原则），这个项目应该怎么走比较稳妥。
5. 对那位同事只讲对事不对人，替对方留体面，让老板觉得你顾全大局。
一句能直接说出口的话：“您之前说过（老板自己的原则）。按这个标准，（那个项目）是不是可以先（缩小范围或延后一步）做？流程上的问题我这周补齐。”

### 场合二：大佬建联（第一次见面，对方带着自己的目的来）

对应的局：行业活动上你想和一位前辈建立联系，对方礼貌但警惕，你一开口就谈合作会被当成有求而来。
打法：
1. 开口先问他最近有什么高兴的事或值得关注的动向，让他先谈自己。
2. 从他的话里抓一个具体点，说出你自己的真实了解，别空夸。
3. 把你的请求变成一个他能给意见的问题，别变成一个需要他答应的要求。
4. 结束前给对方留一个轻的台阶，下次再聊。
一句能直接说出口的话：“您刚才提到（他说的那件事），我之前在（你真实的相关经历）里碰到过类似的情况，不知道您当时是怎么判断的？”

## 雷区

- 甄嬛搬出纯元，是利用皇帝对亡妻的感情，并让皇后在“比不上姐姐”的标准下显得苛刻。这一招拿到职场里，等于拿已经离开的人或对方的旧情当筹码，必须避开。可以借用的只有用对方自己认可的公开标准提问这一点。
- 浣碧替她说话再被她拦下，这套配合依赖皇帝愿意相信、不拆穿。我们自己的判断：这套做法依赖皇帝愿意相信、不去追问，博主对此没有明说，剧本里也没有交代他是否看穿。职场里不要指望上级看不穿，演苦情被识破，信用会一次清零。
- 这一局的成败压在端妃前一晚的铺垫上。端妃那晚说服的结果甄嬛当时并不知道，是赌。职场里自己的人情账户里有没有存量，要先查，别在没铺垫的情况下直接开演。
- 皇帝最后同意的只是罚月钱，槿汐和苏培盛的关系仍然是“不体面的事”（第60集第952幕）。职场里也一样，一次说服换到的是从轻处理，没有改变规则。
- 我们自己的判断：这一局皇后没有当场吃亏，却在皇帝心里掉了分。职场里把对方挤到没台阶下，对方下一轮往往会加倍还回来。
