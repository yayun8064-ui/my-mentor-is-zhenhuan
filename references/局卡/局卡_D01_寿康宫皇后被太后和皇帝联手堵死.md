# 寿康宫里皇后被太后和皇帝联手堵死（第54至55集）

本卡从宜修一侧写，目的是看清对手被怎样堵死，以及甄嬛在场外做了什么。

局面类型：被当众发难（宜修是被发难的一方）/ 谈条件（甄嬛一侧要的是回宫）
对方：皇后宜修，六宫之主，擅长用天象、制度、舆论把皇帝架在道德高地上，拦住甄嬛回宫；正面对阵她的是太后和皇帝，场外替甄嬛说话的是惠嫔（眉庄）。最在意的是中宫的权威，其次是不让甄嬛带着孩子回宫。
甄嬛的处境：弱。废妃之身，人在凌云峰，怀着身孕，回宫被天象卡住（第54集第871幕）。她自己的判断是：“我早就知道回宫没那么容易，也好，见招拆招总比不知道她们要做什么的好。”（第54集第872幕）全程不在场。
她的目的：让太后开口，让皇帝有台阶，让皇后无法反对，顺利回宫。

## 1. 人设和差异化

这一场里各方立的人设：
- 太后：护皇嗣、护孙辈的老祖宗，立在谁也不能越过的最高处。
- 皇帝：孝顺儿子，一心迎回有孕的嫔妃，不得不迁就皇嗣。
- 皇后：本来立的是为太后、皇帝身体着想的中宫，被太后一句话变成了不得不表态的当事人。
- 甄嬛一侧：通过眉庄立的是被天象连累、处处替太后皇后着想的孕妇。

和其他人比：皇后的招数一向是把大义放在前面，让对方无法反驳。这一次太后用同样的方式，把大义改成了皇嗣：“有什么事比你的皇嗣更重要呢”（第55集第877幕）。皇后自己找的天象，最后被别人用来反问她。

## 2. 读人

皇后：
- 博主观点：危月燕冲月听起来有点迷信，但厉害在于把皇帝架到道德高地，接甄嬛回宫就等于不顾皇后太后的身体安康（树懒小结界，BV1euM3zsEwG，约03:38至03:52）。
- 她擅长在不同场合找不同的借口：天象、祖制、言官、年龄。每一个借口都不单独致命，叠在一起才有力。
- 反应很快：虽然局面无力回天，她还是迅速抓住了三个弱点，疯狂攻击。博主归纳为：暗示孩子来路不明，制造舆论压力，用制度压人（BV1euM3zsEwG，约05:34至06:30）。

太后：
- 对皇后连续对嫔妃下手已经忍无可忍。第54集第875幕她问竹息：“宫里除了她还有谁更在乎四阿哥的存在呢？”又说：“皇后真是越来越肆无忌惮了，宫中竟连一个压制她的人都没有，长此下去，只怕皇帝要后嗣凋零了。”
- 博主观点：太后开口的称呼有意为之，在向皇帝暗示自己的态度（BV1euM3zsEwG，约02:51至03:14，转写不清，具体称呼待核）。她在皇帝面前点名四阿哥遇险，等于报出了皇后的身份（约05:24至05:30）。
- 博主观点：太后要的是平衡。甄嬛要能抗衡皇后，又不能越过中宫（BV1euM3zsEwG，约08:31至08:52）。

皇帝：
- 博主观点：他在等皇后表态，因为冲月冲的不仅是太后，还有皇后（BV1euM3zsEwG，约04:05至04:11）。
- 对皇后态度厌恶，全程不看她一眼（BV1euM3zsEwG，约06:35至06:38）。

甄嬛一侧的判断（来自剧本）：她明白要先让太后松口，所以让苏培盛转告眉庄：“一切的事要她劝得动太后才好。”（第54集第872幕）

## 3. 布局链条

目标：太后表态，皇帝即刻迎回，皇后无法公开反对。

铺垫一，对手出招。
皇后借钦天监的说法，让皇帝担心有孕女子靠近会危害太后和皇后，皇帝于是吩咐苏培盛“莞嫔回宫的事你先缓办吧”（第54集第871幕）。

铺垫二，甄嬛一侧不硬碰，转去找太后。
甄嬛让苏培盛告诉眉庄去劝太后（第54集第872幕）。

铺垫三，一个意外的契机：四阿哥遇险。
四阿哥的嬷嬷误食他的绿豆汤，当场毒发身亡。四阿哥奔出，撞见眉庄，眉庄把他带到寿康宫（第54集第874至875幕）。这场下毒是皇后手笔，她事后吩咐“立即撤手，撤得干干净净”（第54集第876幕）。剧本没有写眉庄是否早知道这件事会发生，博主也没有给出结论，我们不做判断。

借谁的手：眉庄、太后、皇帝，三个人各说一句话，没有一个人需要替甄嬛直接求情。眉庄在太后面前说：“为了危月燕冲月的天象影响太后跟皇后，莞嫔有了身孕也不能迎回宫中，只能长留在外，长此下去，皇嗣受损，真不知道是冲月还是冲了皇嗣。”（第54集第875幕）

等什么时机：太后听完四阿哥的事后说“竹息，明日请皇上来一趟”（第54集第875幕）。第二天皇后正在寿康宫给太后喂药，皇帝同时到场。博主观点：这是太后特意把两人放在一起，当着大家的面敲定甄嬛回宫（BV1euM3zsEwG，约00:43至00:54）。

怎么收网（第55集第877幕）：
1. 皇帝请安时说自己担心太后的身体，太后回他：“皇额娘年纪大了，身子不好，有什么事比你的皇嗣更重要呢？皇后你说是吗？”皇后只能答“是”。
2. 太后把天象降级成“不是要紧事”，同时抛出四阿哥遇险，说“若是莞嫔的孩子再有什么差错，哀家和皇帝容不得她”。这句话把皇后放在嫌疑人的位置，逼她以后只能演好人。
3. 皇后抓住三个弱点反扑：暗示孩子来路，抬出言官议论，抬出祖制没有废妃回宫的先例。
4. 皇帝逐一拆掉：“位分可废便可封”，“莞嫔怀的是皇家子嗣，总不能让她在荒山野地里晾着”。
5. 太后把权力交给皇帝，同时留下两个任务：给四阿哥找养母，以及不能过于宠爱莞嫔。
6. 皇后只能表态：“甄妹妹可以回宫自然是好啊，臣妾也怪想她的。”

留了什么后手：
- 太后要皇帝为四阿哥安排养母，博主观点：这等于暗示甄嬛回宫后接手保护四阿哥，增加了她对抗皇后的筹码（BV1euM3zsEwG，约07:49至08:12）。
- 皇后转头去找陵容，说“皇上一定要让她回宫，本宫让她回宫便是”（第55集第878幕），改走舆论路线，下一步是景仁宫里的修宫殿（见局卡 D02）。

## 4. 关键话术

- 第54集第872幕 甄嬛：“我早就知道回宫没那么容易，也好，见招拆招总比不知道她们要做什么的好。”
  为什么管用：被卡住时先接受现状，把对方的招数当作信息，不急着反扑。

- 第54集第875幕 眉庄：“太后说得是，为了危月燕冲月的天象影响太后跟皇后，莞嫔有了身孕也不能迎回宫中，只能长留在外，长此下去，皇嗣受损，真不知道是冲月还是冲了皇嗣。”
  为什么管用：用对方的前提推出对方不想要的后果，一句话把天象和皇嗣放到天平的两头。

- 第55集第877幕 太后：“皇额娘年纪大了，身子不好，有什么事比你的皇嗣更重要呢？皇后你说是吗？”
  为什么管用：自己先把受害者的理由拿掉，再让当事人表态，对方无法反对。

- 第55集第877幕 太后：“若是莞嫔的孩子再有什么差错，哀家和皇帝容不得她。”
  为什么管用：不点名也等于点名，用后果警告对方，同时给对方留一个不被追究的出口。

- 第55集第877幕 皇帝：“位分可废便可封，如此，朕重新册封予她便是。”
  为什么管用：对方抛出制度障碍时，直接给出一个制度内的做法，把先例问题拆成程序问题。

- 第55集第877幕 太后：“如何迎回、何时迎回，你是皇帝，你做主便是了，只是哀家自知病重，不能照顾四阿哥太久，希望皇帝替他安排一位养母，别让这孩子孤苦无依如惊弓之鸟。”
  为什么管用：同意之外加一个附带条件，既交出了决定权，也让自己的关切有了落点。

- 第55集第877幕 皇后：“甄妹妹可以回宫自然是好啊，臣妾也怪想她的。”
  为什么管用：这是对手认输的话术。局面已经无法扭转，退到一个听上去温和的位置，不留明显的反对记录。博主观点：称呼从“甄氏”改成“甄妹妹”，但绝口不提“莞嫔”，说明她还没有死心（BV1euM3zsEwG，约09:01至09:21）。

## 5. 换到职场

### 场合一：老板 1on1（你的方案被同事以风险或先例为由卡住，老板迟迟不表态）

对应的局：另一个部门说“没有先例、风险大”，老板顾及各方，没有明确支持。
打法：
1. 先判断对方的理由是真风险还是借口，真风险就补方案，借口就找更高层的标准。
2. 找一位在老板面前说话有分量、和你没有直接利益的人，先把背景讲清楚。
3. 把争议点换成老板最在意的目标，比如客户、营收或安全，让他自己权衡。
4. 给老板一个现成的台阶，比如分阶段试点、先小范围验证。
5. 他同意之后，把负责人和时间点一并定下来。
一句能直接说出口的话：“这个方案卡在（具体顾虑），我想了一个办法：先在（小范围）跑（时间），看（具体指标），达不到就停。您看这样风险是不是可控？”

### 场合二：聊投资（投资人说“这个方向没有先例”或“政策不明确”）

对应的局：路演问答，投资人用先例缺失或监管不明挡你。
打法：
1. 先认下事实，别争辩。
2. 找出相邻的先例，说明虽然事情略有差别，逻辑相通。
3. 把先例缺失这个问题，换成风险上限多大的问题，请他看你如何控制底线。
4. 给他一个小范围、可验证的方案，别让他一次性押注。
一句能直接说出口的话：“您说的先例确实没有，最接近的是（相邻的案例）。我们把风险控制在（具体上限），第一阶段只做（小范围），（时间点）你可以直接看到结果。”

## 雷区

- 下毒、栽赃、用天象这类编造的说法去压人，是皇后的做法，只能识别，不能使用。第54集第876幕她吩咐撤手，说明这条线有人在背后指挥。职场里遇到有人反复用“外部原因”卡你，也要想一想是不是有人在背后推。
- 皇后的招数一个接一个，但每一个都依赖一个更大的权威不介入。太后一旦站出来，所有借口同时失效。职场里靠单一借口卡人，被更高层一问就破。
- 太后是在多方平衡中让甄嬛回来，同时要求不能过于宠爱。甄嬛赢的是回宫，没有赢的是自由。职场里争取到一个位置，同时也要接受它附带的约束。
- 我们自己的判断：眉庄那番话的效果取决于四阿哥遇险这个恰好出现的契机。职场里不要把别人的意外当作自己的计划，也不要依赖运气。
- 皇后最后的表态温和但没有放下，说明认输只是暂时的。职场里对手让步时，不要放松，准备她的下一招。
