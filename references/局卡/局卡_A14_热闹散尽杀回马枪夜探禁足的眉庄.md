# 热闹散尽杀回马枪，夜探禁足的眉庄（第19集，前情见第18集）

局面类型：求人办事（借芳若的手办一件有禁令的事） / 闲谈社交（探望处在低谷的盟友）
对方：芳若，皇帝御前的掌事宫女，奉旨看守闲月阁，暗中照应眉庄，是这一局里唯一替她开门的人；眉庄，被禁足的沈答应，心灰意冷，仍然最挂念甄嬛；守卫，分两队，看门的人，最在意赏钱和差事不出岔子。
甄嬛的处境：弱。皇帝明令非朕的旨意任何人不许探视（第19集第313幕），一旦被发现就是欺君；身份还是借用浣碧的，私下，时间窗口只有守卫交班的一小段。
她的目的：见眉庄一面，问清当日假孕的来龙去脉，稳住她的心，并让芳若继续照应；不留痕迹，不被任何人发现。

## 1. 人设和差异化

她对每个人立的是不同的样子：
- 对守卫：没出现，由芳若出面，说是莞贵人给的赏钱、敬嫔娘娘备下的茶点。
- 对芳若：恭敬、托付，不空讲谢，说话是“姐姐就托与你照顾了，万望姑姑周全”。
- 对眉庄：当好姐妹。不谈自己的风光，开口先问手凉不凉，再说自己很好，只担心她。

差异：同样在局里的敬嫔和芳若，一个出面请皇帝撤守卫，一个出面调开守卫，各做各的那一块，甄嬛自己不在前台。她只在最后一步出现，把别人铺好的路走完。

## 2. 读人

芳若：
- 眉庄的话：“若不是芳若暗中周全，我连今日也挨不到了。”（第19集第319幕）说明她平日一直在帮眉庄传话和照应。
- 她一出手就很稳：先用赏钱拿走一队守卫，再用茶点留住另一队，最后在交班时给茶点加料，让剩下的人犯困（第19集第316幕、第319幕）。她为什么愿意冒这个险，剧本这里没有交代，待核。
- 博主观点：芳若把两队守卫的待遇做出差别，一队有钱，一队没有，没拿到的那一队自己心里不乐意，再给他们茶点和空头承诺，两队人就被分开吊走了（树懒小结界，BV1M1hwzJEzn，约00:57至01:47）。

守卫：
- 一队拿了钱就走，另一队先问“那我们呢”，听到茶点和日后美言才答应（第19集第316幕）。说明他们对赏钱、前途都很敏感。

眉庄：
- 状态：“这里早已不是昔日的闲月阁了。”“心都够暗了，再不见些亮光可不是黑透了吗？”（第19集第319幕）。
- 她最担心的是甄嬛有没有被牵连，也在想陵容能不能帮上，自己的处境排在后面。（第19集第319幕）
- 她对皇帝已经凉透了：“君恩，不过如是。”还提前说明这些话你听着会很刺心。
- 博主观点：眉庄经过一段时间的沉淀，脸上多了几分从容和看透规则的冷漠（约08:41至08:49），听到皇上已经没有反应（约08:55）。转写后面几句不清，待核。
- 博主观点：史馆思答夫，BV1aevPzuErL，约11:16至12:28：假孕案当晚，眉庄请求去请护胎的刘太医，反而让皇帝觉得她和刘畚有牵连，于是改请院判；博主认为眉庄察觉到了皇帝的疑心，再想起皇帝刚进门时的态度，对比十分鲜明。我们的对照：剧本第15集第271幕里，眉庄提刘太医，皇帝回的是无妨，都一样是太医，前后态度可以核对。我们的判断是眉庄在本局里对皇帝的冷淡，起点之一就是这一晚。

## 3. 布局链条

目标：见到眉庄，问清事情，稳住人心，原路退出。

铺垫：
1. 平时的通路。芳若一直在传话，眉庄说“芳若传话进来总说你很好，我还不相信”（第19集第319幕），说明甄嬛和眉庄之间一直有一条靠芳若维持的消息线。
2. 提前打点。第18集第310幕她说“那边我已经打点好了”。第19集第316幕，芳若拿出的赏钱就是莞贵人给的。
3. 借同一晚的另一件事制造窗口。华妃擅闯闲月阁那一局（见上一张卡《局卡_A13_借浣碧通风报信引华妃撞进闲月阁》）里，敬嫔当着皇帝请求撤去一半守卫，皇帝同意（第19集第313幕）。守卫减半，这是后面能走进门的前提。
4. 回去换装。第19集第317幕，小允子等在先前换衣服的屋子，说船已经停在荷丛深处，回来时不会让人注意。

借谁的手：芳若（调开守卫、守门、催时间）；敬嫔（撤守卫的名义）；小允子（船）；槿汐（护送，后来先回去）。

等什么时机：
- 华妃被斥回宫、皇帝刚走、闲月阁刚刚热闹过又冷下来。博主观点：这一招是整个闲月阁计谋的精华，刚经历闹剧，从最热闹变成最安静、最安全，所有人心里都最懈怠，此时去见眉庄是最佳时机（BV1M1hwzJEzn，约06:08至06:23）。
- 守卫交班的时候，剩下的人本来就松懈（第19集第319幕）。

怎么收网：
1. 先走位：芳若调开守卫（第19集第316幕）。
2. 芳若在门口告诉甄嬛：门虚掩，陪你进去（第19集第319幕）。
3. 进门第一句是看人：“你手这样凉。”
4. 先让眉庄放心：“我很好，就是担心你不好。”
5. 把外面的事讲给她听，让她知道有人替她出了气。
6. 问事：当日怎么回事，随后一起推：江太医给方子，刘畚来侍奉，都是有人安排的。
7. 给出路：一定会求皇上早日放你出来；家里全力追刘畚。
8. 限时：芳若在外面催，从速（第19集第319幕）。
9. 托付：出门后立刻拜托芳若周全。

补充（博主观点）：史馆思答夫，BV1aevPzuErL，约05:46至07:52、约09:23至09:40，讲的是甄嬛问事时想弄清的当晚经过：茯苓被侍卫揪出后一直喊自己是会贵人宫里的，曹贵人当场指认并亲自翻出血衣，华妃顺着往谋财害命上引，博主认为华妃和曹贵人在这几处一看就是知情人；眉庄当场急着和茯苓划清界限，博主认为就算她替茯苓求情，结果也一样，只会说成包庇毁灭证据。我们的对照：这个顺序在剧本第15集第271幕里都能对上。博主关于假设她求情的那一段是推测。

留了什么后手：
- 芳若的回答：“小主放心，今天这一闹总得安生两天，眉庄小主的日子也会好过些。”（第19集第319幕）说明这一局还给眉庄换来了几天安生日子。
- 回去路上偶遇果郡王，要求他保密：“都不要对人说起曾与我相遇一事，就如今晚一样。”（第19集第320幕）这一幕是另一个局，本卡不展开。
- 博主观点：甄嬛支开槿汐、独自走回去，才有后面的偶遇（约06:38至06:44，转写不清，待核）。

## 4. 关键话术

- 第19集第316幕 芳若：“你们也别恼，敬嫔娘娘体贴你们的辛苦，连茶点都备下了。”
  为什么管用：对没拿到赏钱的人，不否认差别，直接给另一份好处，把不满转成感谢。

- 第19集第316幕 芳若：“那有什么？你们在这儿怎么辛苦敬嫔娘娘都是看见的，往后你们差事当得好，敬嫔娘娘在皇上面前美言几句也是有的。”
  为什么管用：对方推辞时，再加一个对前途有用的承诺，让他们觉得接受反倒体面。

- 第19集第319幕 芳若：“现在正是侍卫交班的时候，刚才撤走了一半的侍卫，剩下的人也都懈怠了许多”
  为什么管用：把窗口的条件讲明，让甄嬛知道这一小段时间有多值钱。

- 第19集第319幕 甄嬛：“你手这样凉。”
  为什么管用：一句话先关心身体，不谈事情，对方马上知道你是为她来的。

- 第19集第319幕 甄嬛：“我很好，就是担心你不好。”
  为什么管用：对方最担心的是你，就先告诉她你没事，再说你担心她。

- 第19集第319幕 甄嬛：“方才外面的动静你可听到了？也总算是为你出了口气。”
  为什么管用：安慰之外，给她一个具体的好消息，让她知道有人在为她做事。

- 第19集第319幕 甄嬛：“我已经告诉你我家人全力追捕刘畚，等真相水落石出那一天，皇上必定会补偿你还你清白的。”
  为什么管用：只讲自己能做的和已经做了的事，不空许诺。眉庄回了一句“补偿？我这些天的苦痛岂是他能补偿我的？”，她没有再争。

- 第19集第319幕 甄嬛：“姑姑，姐姐就托与你照顾了，万望姑姑周全。”
  为什么管用：离开之前，当面把人托付给最有条件照应的那一位，对方会把它当作一份责任。

## 5. 换到职场

### 场合一：老板 1on1（大场合争议散了之后，单独补一次）

对应的局：季度复盘会上关于你的项目有争议，会后大家松了一口气，你要在老板不被打扰的时候单独补一次沟通。
打法：
1. 等公开场合的热度退下去，选一个对方压力最小的时间窗口。
2. 先问对方的状态和关心的事，再谈你的事。
3. 带一个具体可做的进展，不空谈承诺。
4. 说完就收，把时长控制在对方愿意给的范围里。
一句能直接说出口的话：“刚才会上我没展开，我单独补一下：（那件事）我这边的进展是（具体进展），接下来我会（具体动作），需要您支持的只有（一件事）。”

### 场合二：大佬建联（行业会议上人散了之后单独打招呼）

对应的局：行业会议上，大佬被很多人围着，你不挤，等人散了再单独打招呼。
打法：
1. 不在拥挤的时候塞名片，等人散了、会后茶歇再靠近。
2. 先说你听了他讲的哪一点，再说你有什么一个小发现，不要求对方当场回应。
3. 留一个下次联系的理由，不提合作。
一句能直接说出口的话：“刚才人多没来得及打招呼。我是（姓名），最近在做（你负责的那一块），您讲到的（具体观点）对我很有启发，我有一个小发现想改天跟您分享一句。”

## 雷区

- 违抗明令去探视：流朱在第18集第310幕提醒过，万一被发现可是欺君的大罪。职场里对应：明确不许做的事不要因为有机会就去做，想见一个人，先走正规渠道。
- 给守卫的茶点加蒙汗药（第19集第319幕）。这是害人手段，只能当作剧情了解，不可套用。
- 借用浣碧的身份混进去（第18集第310幕）。职场里对应：不要冒用别人的身份或权限办事。
- 芳若替眉庄担着风险：一旦出事，她先受罚。职场里对应：不要把别人拖进违规的事里。
- 眉庄说“君恩，不过如是”，甄嬛回的是“皇上他总是会眷顾你的”（第19集第319幕）。我们自己的判断：这句话在眉庄听来有些空，甄嬛后面补的是追查刘畚这样的具体动作。职场里对应：安慰低谷中的人，具体动作比一句总会好的更有用。
- 博主的说法在剧本里无法对上，本卡不采用：少女张六花，BV1L34y1d7ph，约01:43至02:19，认为刘畚能留在眉庄身边是因为皇后默许院判章弥调动，眉庄是被华妃和皇后两方联手设计的。剧本里刘畚被追捕后华妃明说刘畚知道她们太多事情（第15集第274幕），指向的是华妃一方，没有皇后默许的交代；甄嬛在第19集第319幕也只说有人一手安排。博主这一条属于推断，本局不引用。
- 这个窗口依赖前面那一局的成功。如果华妃没有撞进来，皇帝没有同意撤守卫，这个窗口就不会有。职场里对应：这类时机选择靠前一步的结果，不能事先假设。
