# 有孕之后借苏培盛传话，让皇帝自己说接回宫（第54集第855至861幕）

局面类型：求人办事 / 谈条件
对方：苏培盛，御前总管，皇帝最信任的人，自己也有算盘，不肯蹚过深的浑水；皇帝（雍正），疑心重，爱面子，在后宫待得烦闷。最在意的是安全感和利益（苏培盛），面子和情绪（皇帝）。
甄嬛的处境：弱。废妃之身，人在凌云峰，已有身孕，身边只有槿汐、浣碧。私下，全程在凌云峰禅房。前情是第53集凌云峰重逢（见样卡B），那一场只拿到了皇帝每月来上香，这一场要把它推到接回宫。
她的目的：让皇帝亲口说“随朕回宫”，姿态是她什么都不求；同时把有孕的消息限制在皇帝一个人知道，不让皇后提前布置。

## 1. 人设和差异化

她在苏培盛和皇帝面前立的是只想平安生下孩子的人，退到最低：先说不敢回宫，再说连名分都不要，答应的身份也行。

和宫里其他人比：
- 皇后一方听说有孕，反应是“千防万防，还是防不住那个狐媚子的肚子”（文鸳，第54集第862幕），想的是困住她。甄嬛反着来，主动把位置放低，让对方没有可打的靶子。
- 同样是靠怀孕争位置，她不拿孩子当筹码去讨价，把孩子说成皇家血脉，由别人说出“怎能不归入宗室玉牒”。

为什么对上这两个人的胃口：苏培盛要一个对自己有好处又没有风险的差事，她给了他“替皇上办一件体面事”的位置；皇帝在后宫没有可以说话的人，她表现得连等他来都不敢要求，却在他来的时候流泪、谈长相思。博主观点：这段戏表面上演给苏培盛看，真正的观众是皇帝，苏培盛只是传话筒（树懒小结界，BV1gvJqzXEwz，约11:04至11:12）。

## 2. 读人

苏培盛：
- 他的话：“这件事若是由娘娘亲自开口，就会让皇上觉得上回相会之事是娘娘有所图谋的，所以奴才已经寻了个机会提起来”（第54集第855幕）。他明白甄嬛不能自己开口，已经替她做了。博主观点：他知道甄嬛回宫有所图，但只要事情对各方都有利就行，不去管别人图什么（BV1gvJqzXEwz，约03:31至03:46）。
- 他推托谢礼，甄嬛接一句以她现在的地位，对方开口要什么她也未必给得起（第54集第855幕）。读出来的是他暂时不收报酬，因为报酬现在不能明说，欠着人情更稳。
- 博主观点：甄嬛严格限定苏培盛介入的程度，哪些能说哪些不能说。回宫不碰皇帝和苏培盛的核心利益，混淆皇室血脉却是诛九族的大罪，所以必须让苏培盛相信怀孕只是一个偶然（BV1gvJqzXEwz，约09:58至10:29）。

皇帝：
- 第一反应是高兴：“苏培盛告诉朕你有了身孕，朕欢喜得很”（第54集第861幕）。
- 博主观点：他生性多疑，知道凌云峰重逢是设计的，所以先召见温实初问月份，听清楚之后才放下奏折，对她的态度才转为真正的重视（BV1gvJqzXEwz，约19:38至20:38）。剧本里他召见温实初的幕是第54集第860幕，温实初答的是“有喜已有一月”。
- 他在后宫待得不舒服：“若非你有了身孕，宫里的事这样多，朕真没个高兴得所在了”（第54集第861幕）。博主观点：他话里话外全是对后宫嫔妃的不满（约21:53至21:59）。

皇后一方：
- 皇后已经知道皇帝去的是凌云峰：“听说皇上每回去甘露寺祈福，都要去甄嬛如今所住的凌云峰。到底是咱们失于防范了。”（第54集第856幕）但她没有出手。博主观点：她还停留在甄嬛是洗衣砍柴的底层形象，也觉得为一件捕风捉影的事得罪皇上不值（BV1gvJqzXEwz，约06:44至07:10）。甄嬛因此有了一段可以暗中动作的窗口。

## 3. 布局链条

目标：皇帝亲口说接她回宫，而且这件事看上去是皇帝自己的主意。

铺垫一，先让苏培盛把父亲的事办了。
第54集第855幕，甄嬛问“那我父亲的事？”，苏培盛答已经寻机会向皇帝提起，皇帝派人从宁古塔送老大人回京医治。博主观点：父亲的事对皇帝只是心情问题，她只要认错服软就行，不需要动用怀孕这张牌（BV1gvJqzXEwz，约04:04至04:21）。

铺垫二，让苏培盛自己发现有孕。
甄嬛没有直接宣布，在苏培盛面前上茶时干呕，槿汐接话说娘子这几日一直作呕。她再说一句“这除了槿汐和浣碧，公公是头一个知道的”（第54集第857幕）。槿汐只给事实：一个多月。结论由苏培盛自己推出来：“那可不正是皇上头一次来凌云峰的时候吗？”

借谁的手：苏培盛传话；槿汐出面推荐温实初（见局卡B02）；眉庄在太后那一头使力（温实初转告眉庄，第54集第864幕）。

等什么时机：苏培盛说了回宫“顺理成章”之后，她才开始一步步往下退：
1. 先要保密：皇后身子欠佳，不必惊动。
2. 再说不敢回宫，只想安静待产，苏培盛劝她，说皇上怎能让娘娘在这儿待产。
3. 再退一步，连名分都不要，答应身份回宫也行。苏培盛主动答应想法子和皇上说。

怎么收网：苏培盛回去后，皇帝在第54集第861幕亲自来凌云峰。甄嬛睡着，没有出去迎，醒来第一句还是埋怨“何必要巴巴赶过来”。皇帝先说“随朕回宫吧”，甄嬛答自己是废妃、不祥之身，不敢妄想；皇帝改口“既是废妃就重新再册”。她再问太后会不会不允，皇帝说子嗣在，太后不会阻拦，朕为你安排好。博主观点：至此甄嬛让皇帝心甘情愿说出接她回宫（BV1gvJqzXEwz，约23:13至23:18）。

留了什么后手：
- 保密：只皇上知道就行，由温实初安胎，防住皇后线。
- 太后一关：温实初转告眉庄，回宫之事皇帝一个人说了不算，需要太后点头（第54集第864幕）。
- 她自己已经预料到下一步：“皇后未必阻拦得了，只怕她顺水推舟来个请君入瓮”（第54集第865幕）。
- 这一局没有一次到位。随后钦天监说危月燕冲月，皇帝吩咐“莞嫔回宫的事你先缓办吧”（第54集第871幕）。博主在本期结尾预告下一期讲皇后为什么没能拦住（BV1gvJqzXEwz，约28:24至28:30）。

## 4. 关键话术

- 第54集第855幕 甄嬛：“有劳公公了，如何帮皇上瞒住宫里那就得看公公的本事了。”
  为什么管用：自己的诉求是保密，却说成替皇上办事，让苏培盛的差事有了体面的理由。博主观点：这句美化了苏培盛做这件事的出发点（BV1gvJqzXEwz，约03:01至03:07）。

- 第54集第857幕 甄嬛：“这除了槿汐和浣碧，公公是头一个知道的。”
  为什么管用：让对方成为第一个知道的外人，他会觉得自己被信任，也有了替她守住消息的责任感。

- 第54集第857幕 槿汐：“不前不后刚刚一个月多上一点。”
  为什么管用：只给事实，不下结论。结论由苏培盛自己算出来，他会更相信。

- 第54集第857幕 甄嬛：“皇上知道我有了身孕难免会欢喜过头，还得请公公在皇上身边提点着。”
  为什么管用：把请他做的事说成帮皇上控制欢喜，听上去全是在替皇帝考虑，没有一句在替自己要东西。

- 第54集第857幕 甄嬛：“皇后身子欠佳，宫中诸事烦扰，我的身孕实在不必惊动他人。”
  为什么管用：用体恤皇后的理由把保密说出来，没有一个字露出防备。

- 第54集第857幕 甄嬛：“我既是废妃出宫，哪里有再回宫的道理，我只盼这孩子能够平安长大就好了。”
  为什么管用：先把自己放到最低，对方会反过来说该回去。

- 第54集第857幕 甄嬛：“皇上如今能这般待我，已是我最大的福分了，我哪里还敢再奢求什么，若是皇上能给我腹中的孩子有个名分，即便是以答应身份回宫，我也感激涕零了。”
  为什么管用：要求提到最小，只要孩子的名分，自己的位分让给对方来加。博主观点：甄嬛知道皇帝吃软不吃硬，越不要越没有僭越之心，皇帝给权利地位时就越放心（BV1gvJqzXEwz，约12:57至13:04）。

- 第54集第861幕 甄嬛：“皇上也真是的，欢喜便欢喜吧，不拘哪一日来都行，今儿外头下着雨，山路又不好走，何必要巴巴赶过来呢？”
  为什么管用：嘴上埋怨，意思是心疼他。不要求他来，他反而更想来。

- 第54集第861幕 甄嬛：“嬛嬛是废妃，还是不祥之身，即便身怀龙裔，也不敢再妄想能够再回宫廷了。”
  为什么管用：皇帝说“随朕回宫”之后，她仍然先拒绝，让他把话说得更完整，说出重新册封。

## 5. 换到职场

### 场合一：老板 1on1（想换到更大的项目，但你不能先开口）

对应的局：你想调去一个更核心的项目，需要现在的老板放人，也需要对方负责人点头。你直接提会让老板觉得你有所图。
打法：
1. 先找一个老板信任、也和你说得上话的人（老板的搭档、老同事），只讲事实，比如你现在做到哪里、哪块你已经做完，结论让他自己得出。
2. 请他在合适的场合替你带一句话，内容是对老板有好处的理由，不要加你的要求。
3. 面对老板时，把要求压到最小：先不谈职级和名额，只说想把某一块做完整，让老板主动加码。
4. 保密范围先只到老板一个人，不要提前在群里或同事中放消息。
一句能直接说出口的话：“我先不谈职级和名额，只想把（你负责的那一块）做完整，您看是现在就放我试一个季度，还是等（某个节点）之后再定？”

### 场合二：聊投资（见投资人之前，先通过投资人身边的人摸清他关心什么）

对应的局：路演前你想让投资人先对你有一个准确的印象，又不想直接托人求见面。
打法：
1. 通过投后、助理或共同的朋友，只传递可核对的事实，比如你已经验证的数据。
2. 让对方自己判断这些数据意味着什么，你不替他下结论。
3. 见面时先退一步：这一轮不急着谈额度，先把下一个里程碑做出来给他看。
一句能直接说出口的话：“这一轮我们不急着谈额度，想先把（具体里程碑）做出来给您看，您觉得哪一点最值得先验证？”

## 雷区

- 欺君：整套布局建立在皇帝误以为孩子只有一个多月之上。第54集第863幕里甄嬛束腹，对浣碧说“只要皇上不与我亲近，便可瞒天过海”。这是欺骗皇帝，不可套用。职场里不要给上级、投资人一个失真的时间线或数据。
- 对苏培盛只露一半：博主观点是严格划定对方能知道的范围（BV1gvJqzXEwz，约10:04至10:29）。职场里可以只让对方做他担得起的事，但不要让他在不知情的情况下替你担风险。
- 做戏依赖对方不查。博主观点：皇帝生性多疑，先召见温实初确认月份（BV1gvJqzXEwz，约19:41至20:20）。职场里老板会交叉验证，任何靠对方不核对才成立的说法都撑不久。
- 把消息当作只有自己人知道：皇后一方很快就知道了，江福海看到温实初在太医院配安胎药，就推断出凌云峰有孕（第54集第862幕）。职场里自以为保密的事，往往有人早就听到风声。
- 一次谈话不要拿全部结果：这一局之后，回宫被天象拖住（第54集第871幕）。要留好下一步。我们自己的判断：她早就想到皇后会顺水推舟，所以每一步都留着后手。
