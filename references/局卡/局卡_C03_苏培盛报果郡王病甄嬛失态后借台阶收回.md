# 苏培盛报果郡王病，甄嬛失态后借台阶收回（第62集第991幕）

局面类型：认错善后 / 闲谈社交
对方：苏培盛，皇帝身边的总管太监，已经看出甄嬛与果郡王之间的私情，站在她这边。最在意的是不让这件事在皇帝面前炸开，也不让自己卷进去。
甄嬛的处境：位高，私下，周围是温实初、槿汐、玉娆这些自己人，属于强势但有真实软肋的时刻。
她的目的：刚刚情绪外露，要在最短时间里把失态收回来，给在场的人一个可以对外讲的说法，不留话柄。

## 1. 人设和差异化

她在这场里立的是统管六宫、对王府的事也自然关心的贵妃。

和苏培盛比：
- 苏培盛先说“碧姑娘不在？幸好，否则她听了可要心疼了”，把果郡王的病挂在浣碧身上，用浣碧做幌子。博主观点：这是教科书级别的情报输送，让甄嬛有了一个合法关心的理由（BV1nGcMz3EMn，约15:28至15:37）。
- 甄嬛自己的第一反应没有绕，直接问出口，那一刻只有惊，没有计算，计算在后一步。博主观点：甄嬛十分罕见地慌乱，说的理由不怎么令人信服（约15:47至16:14）。

和温实初比：
- 温实初缩手：博主观点，他与惠嫔之间的关系让他一直处于惊恐里，一惊一乍的本能反应暴露给了斐雯（约14:17至14:45）。
- 甄嬛在这场里没有缩手，也没有解释，在失态后用现成的台阶往下走。

## 2. 读人

- 苏培盛：博主观点，他此行有两层意思。第一，提前打预防针。果郡王昨夜起了高热，王府的事归皇后管，甄嬛现在处于信息盲区，午后她要同皇帝一起去阿哥所，万一皇帝谈到，以她现在的心理状态，大概率会当场失态（约16:42至17:07）。第二，确认一次。他此前经手过果郡王送合欢花的事，那件事只让他起疑，今天甄嬛的反应直接坐实了（约17:10至17:25）。剧本里那次他转述的话是：“只把凝晖堂内所有的合欢花都赠与娘娘”（第61集第976幕）。
- 苏培盛的下一步：博主观点，他是带着这层认知去参加滴血验亲的，解读他在景仁宫的每一个举动，要放在这个基础上（约17:25至17:37）。剧本里他后来在景仁宫替浣碧、槿汐挡刑，并劝皇帝此事尚未定论，不宜外扬（第63集第996幕）。
- 甄嬛的软肋：果郡王的病与她有关。博主观点，当年她高热，是果郡王为她卧雪退烧落下的病根（约15:40至15:45）。这是她控制不住的原因。
- 斐雯：温实初缩手那一下被她看到。博主观点，这成为日后皇后手里的一块拼图（约14:40至14:45）。甄嬛在这一场没有察觉。

## 3. 布局链条

目标：把失态变成关心下属的常规反应，让在场的人不再追问。

铺垫：
1. 苏培盛先传皇帝的话，说午后请娘娘一同去阿哥所探视六阿哥，再顺势说出果郡王的病，用浣碧做挂钩（第62集第991幕）。
2. 此前果郡王赠合欢花，苏培盛已经起疑（第61集第976幕），所以今天他的措辞很小心，每一句都留了台阶。

借谁的手：
- 苏培盛的两个台阶：一是“娘娘忙于理会六宫之事”，二是“就算娘娘自个儿不上心，也得为了碧姑娘过问一二嘛”。第一次她接过去并补上自己的说法，第二次直接收尾。

等什么时机：
- 失态后立刻给出一个自己的理由，不等别人追问。

怎么收网：
1. 失态：问出口“怎么没人来告诉本宫”。
2. 苏培盛第一次递台阶：先说她忙于六宫，再提到王府归皇后打理，给出不告知的合理理由。
3. 甄嬛接住，给出自己的说法：想着皇后身子才好，还要照顾太后，才多嘴问一句。
4. 苏培盛第二次递台阶：说她德惠六宫，也该为浣碧过问一二。
5. 甄嬛不再解释，一句“你赶紧去吧”结束话题。

留了什么后手：
- 浣碧此时已经在果郡王府照料，永寿宫少了一个能打探的人，皇后又把槿汐派去教新宫女规矩，切断了甄嬛的耳目（第62集第991幕、第62集第994幕）。博主观点：这是先屏蔽信号塔再动手（约25:38至25:52）。这件事与这次失态没有因果关系，只是同期的背景，说明甄嬛进景仁宫之前信息是盲的。

## 4. 关键话术

- 第62集第991幕 甄嬛：“这么大的事情，怎么没人来告诉本宫一声呢？！”
  为什么管用：这一句属于失误，放进来作为反面样本。它说明在自己人面前也会露底，后面所有动作都围绕收回这一句。

- 第62集第991幕 苏培盛：“娘娘忙于理会六宫之事，这种事怎么好来惊扰娘娘呢？何况王府之事自有皇后娘娘打理呢。”
  为什么管用：先替对方的疏漏找出合理的原因，把没人通知变成体谅她，同时点出这件事归谁管。

- 第62集第991幕 甄嬛：“是，本宫是想着皇后娘娘身子才好，还要照顾太后那边，所以才多嘴问了一句。”
  为什么管用：接过台阶，把关心的对象转成皇后与太后，姿态是替人分担。博主观点：这个理由不怎么令人信服，靠的是现场都是自己人（约16:12至16:14）。

- 第62集第991幕 苏培盛：“娘娘德惠六宫，自然也关心王府的事，就算娘娘自个儿不上心，也得为了碧姑娘过问一二嘛。”
  为什么管用：再给一个更稳的理由，把关心落到浣碧这个公开的身份上，让后面任何人复述这件事，都能说得通。

- 第62集第991幕 甄嬛：“你赶紧去吧。”
  为什么管用：台阶接住之后不再多说一句，越短越不留话柄。

## 5. 换到职场

### 场合一：老板1on1（听到一个出乎意料的坏消息，当场反应过大）

对应的局：老板说出一个你没有预料到的调整，比如项目被砍或者人事变动，你脱口追问并带着情绪。
打法：
1. 反应已经出来，不要想着撤回。承认这个消息来得突然。
2. 给自己一个与职责相关、可以核对的原因，比如你要跟进这个项目，需要知道影响。
3. 接住老板给的台阶，之后不再追加解释，回到下一步要做什么。
一句能直接说出口的话：“这个消息我确实没有料到，所以问得急了。我这边负责（你负责的那一块），想先知道对（具体事项）的影响，您看我下午先做什么？”

### 场合二：聊投资（投资人说出一个对你不利的消息，比如竞品融资）

对应的局：投资人说“（某家公司）刚拿了一笔大的”，你的表情或回答流露出紧张。
打法：
1. 不否认自己的反应，也不假装不在意。
2. 说一个真实的关注点，比如这会怎样影响你们的获客或估值逻辑。
3. 接着给出你们的差异点，把话题拉回自己。
一句能直接说出口的话：“这个消息我之前没有看到，我先确认一下细节。就我们现在的（具体业务）看，他们进入的是（某个方向），我们的（差异点）还是有空间的。”

## 雷区

- 靠对方的台阶收场，前提是对方站在你这边。苏培盛两次递台阶，是因为他已经站队。在职场里，对不熟的人流露情绪，对方未必接你的话。
- 理由要经得起核对。博主观点：甄嬛当时的理由不怎么令人信服，只是因为现场都是自己人才过得去。职场里如果理由牵强，对方一旦去核实，反而多一层信任损失。
- 她收回的失态背后，是一件需要保密的私事。职场里不要用解释去遮盖对工作有实质影响的事，比如利益关系或者真实的风险。
- 同场的任何人都会记住细节。温实初缩手被斐雯看到，成为之后的证词素材（博主观点，约14:40至14:45）。职场里在场的同事可能记下你的小动作，别以为没人看见。
- 同一场里，甄嬛随后请温实初替她去探望果郡王，借的是对方的情分（第62集第991幕）。这一段本卡不展开，也不适合在职场里套用：不要拿别人对你的好感去换你要的事。
