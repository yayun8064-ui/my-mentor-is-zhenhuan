# 满月宴上，把皇帝的偏宠转给敬妃（第61集，前例见第26集）

局面类型：投其所好 / 谈条件（当众）
对方：皇帝，当众说想去她宫里；敬妃，这一次的受益者，最需要陪伴；皇后，刚刚在酒席上说完一段话里有话的祝酒词，正被晾在一边；在座的所有妃嫔，都是观众。
甄嬛的处境：强，当众。她刚被册封熹贵妃，刚拿到协理六宫之权，皇帝站在她这一边。风险在于，一个不小心就会被看成恃宠生娇，或者抢了皇后最后一点体面。
她的目的：礼貌而不扫兴地拒绝皇帝当晚的邀约，把这份福利转给敬妃，让上午谈妥的同盟落到实处，同时不接皇后的话头。

## 1. 人设和差异化

她立的是有福先分给队友、一心为孩子着想的贵妃。

和其他人比：
- 皇后在酒席一开场敬酒：“臣妾但愿皇上待熹贵妃之心亦如丝柔无断绝，且请皇上饮尽此杯。”（第61集第969幕）话里有话，皇帝听出了被指责喜新厌旧。
- 过去的甄嬛遇到皇帝要留宿的场景，会劝皇帝去皇后宫里，借此表示贤德。第26集第435幕，她说“皇上不该陪着臣妾而误了与娘娘的月圆之夜”，又说“可是皇后待臣妾不薄，臣妾不愿让皇后娘娘伤心”。
- 今天她没有再把皇后放在这个位置，换成了一个收益更大的去处。

为什么对上这几个人的胃口：皇帝要的是体面，不愿意被人拒绝，又恰好要弥补对胧月的亏欠；敬妃要的是被看到；皇后无话可说，因为理由是孩子，没有人能反驳。

## 2. 读人

皇帝：
- 刚刚被皇后的祝酒词刺了一下，转头就迫不及待说“朕今晚去你宫里”。（第61集第969幕）
- 他十分重视孩子，听到“怕胧月吃醋”这类理由会接受。他自己的回答是：“总不能叫胧月觉得有了弟妹朕就冷落了她。”（第61集第969幕）
- 博主观点：他假装不记得这一天是皇后的日子，既是惩罚皇后刚才的发言，也是真的偏爱甄嬛（树懒小结界，BV1UmqaBcEna，约29:08至29:17）。

敬妃：
- 前一场深谈里她说得很清楚：“我宫里一共有三百二十六块砖石”（第61集第966幕）。甄嬛从那一刻起知道，她最缺的是陪伴。
- 博主观点：这份福利直接送到了敬妃的心坎上（BV1UmqaBcEna，约29:54至30:04）。

皇后：
- 博主观点：每月初一十五是皇后法定的侍寝日，今天恰好是满月日，这是她制度内最后一点保障，被皇帝在众人面前打了脸（BV1UmqaBcEna，约28:41至29:08）。这条日期推算属于博主的解读，剧本里只有一处旁证，皇后说“今儿个也不是初一十五的大日子”（第56集第894幕）。

## 3. 布局链条

目标：不让皇帝当晚留在永寿宫，并让他去敬妃那里。

铺垫一，上午刚完成的深谈和安排。
她在永寿宫与敬妃谈过，敬妃继续养胧月（第61集第966幕）；皇帝也被说通了胧月留在敬妃处（第61集第968幕）。这两步让“去敬妃宫里”成为一个合理的去处。

铺垫二，她有一套被验证过的拒绝方式。
第26集第435幕她已经用过类似的话，让皇帝去皇后处。今天换了对象，句式没有变，皇帝习惯于她这样说话。

借谁的手：皇帝对胧月的亏欠。
她把理由放在胧月身上，让皇帝自己觉得去敬妃宫里是在补偿孩子，感觉不到是在听从她的安排。

等什么时机：皇帝当众说“朕今晚去你宫里”的下一句。晚一句，他会在众人面前下不来台。

怎么收网（第61集第969幕）：
1. 先给出理由：今天是弘曕、灵犀的满月。
2. 理由里放进胧月：怕她这个做姐姐的吃醋。
3. 给出一个解决方案：请皇上替我去敬妃姐姐宫里陪胧月。
4. 补一句保证：胧月一定高兴。
皇帝回答：“也好，总不能叫胧月觉得有了弟妹朕就冷落了她。”

留了什么后手：
- 当晚她对浣碧说“左右皇上今晚宿在敬妃那儿，眉姐姐身子不舒服，咱们去看看她吧”（第61集第970幕），利用这段空档去看眉庄，同样是经营盟友。
- 博主观点：这一招同时向所有人展示，侍寝的安排从今以后由她来决定（BV1UmqaBcEna，约30:14至30:21）。

## 4. 关键话术

- 第61集第969幕 甄嬛：“今日是弘曕、灵犀满月，臣妾怕胧月这个做姐姐的会吃醋，不如皇上替臣妾去敬妃姐姐宫里陪胧月，胧月一定高兴。”
  为什么管用：拒绝没有用拒绝的字眼，直接给皇帝一个更体面的去处，并且理由是孩子，谁也挑不出毛病。

- 第61集第969幕 皇帝：“也好，总不能叫胧月觉得有了弟妹朕就冷落了她。”
  为什么管用：这是对方的回答。他自己找到了为什么要去的理由，等于接受了这个安排。

- 第26集第435幕 甄嬛：“皇上不该陪着臣妾而误了与娘娘的月圆之夜。”
  为什么管用：前例。过去她用同样的句式推皇帝去皇后宫里，立住贤德。

- 第26集第435幕 甄嬛：“可是皇后待臣妾不薄，臣妾不愿让皇后娘娘伤心。”
  为什么管用：前例的另一半，把拒绝说成为别人着想。今天的变化在于，她不再用这套话去照顾皇后。

- 第61集第969幕 皇后：“臣妾但愿皇上待熹贵妃之心亦如丝柔无断绝，且请皇上饮尽此杯。”
  为什么管用：这是对手的话术，值得看明白。表面是祝福，里面是暗示皇帝会喜新厌旧、暗示甄嬛对皇帝变了心，博主逐层拆解过（BV1UmqaBcEna，约26:19至27:53）。甄嬛没有接话，反而在后面的安排里把她晾在原地。

## 5. 换到职场

### 场合一：老板 1on1（老板想把一个露脸机会单给你，你想把一部分让给另一位更合适的同事）

对应的局：老板说这次高层汇报让你来讲，你知道其中一块是同事做的，而且他很久没有被看到。
打法：
1. 先谢老板，再把理由说成对事情最有利。
2. 把同事的名字和贡献说具体，别空夸。
3. 让老板自己决定这样安排，不要替他定。
4. 你仍然留一个位置：负责整体，别让老板觉得你在躲事。
一句能直接说出口的话：“这次汇报我想请（同事）来讲（他负责的那部分），这块他最清楚，我在旁边补充整体。您看这样安排可以吗？”

### 场合二：大佬建联（前辈给你一个名额，你想带上自己的搭档）

对应的局：行业前辈邀请你去一个小范围的交流会，你知道你的合作伙伴同样在做这件事，而且更需要这个场合。
打法：
1. 先真诚感谢，不要先推辞。
2. 讲一个对前辈同样有利的理由，比如你们两个人的内容互补。
3. 问一句能不能多带一位，不要擅自带人。
一句能直接说出口的话：“谢谢您想到我。（搭档）这块做得比我深，他也很想听听您的看法，不知道方不方便我们一起过去？”

## 雷区

- 甄嬛把皇帝的偏宠当众转给敬妃，同时当众折了皇后的面子。博主的说法是“展示实力”（BV1UmqaBcEna，约30:14）。职场里当众分配老板的好意，可能让老板觉得被越权安排。要先私下与老板对齐。
- 理由必须真实。这里的理由是胧月，她确实惦记孩子。职场里编一个理由去推掉机会，被识破会失去信任。
- 她没有给皇后任何台阶，与她过去的做法有很大不同。我们自己的判断：对失势的对手一点台阶不给，会让对方走向极端，后面滴血验亲那一局可以看到皇后加快了动作（博主观点，BV1UmqaBcEna，约30:48至30:56）。
- 皇后的祝酒词是一种识别样本：祝福的外壳下面藏着刺。职场里遇到当众的恭喜加提醒，要想一想它是在对谁说话。
