# 药里被动手脚，先不声张查内鬼（第10集）

局面类型：被抢功陷害（暗中被人下手） / 立威管人
对方：暗处的下药人。剧情后面查明，动手的是余莺儿（余氏，已被降位迁出钟粹宫，整日咒怨甄嬛），经手的是新调来碎玉轩的宫女花穗。明面上对手没有露脸，甄嬛手里只有一碗味道变酸的药。对方最在意的是报复，也要让甄嬛慢慢神智失常，查不出来。
甄嬛的处境：强弱混合。圣眷正好（第10集第186幕流朱说皇上疼小主谁都看得出来），但敌人在暗处，身边有内鬼；私下，对外不能露一点风声。
她的目的：先确认自己中了什么招，再把人和上线一起抓住，人赃并获。过程中不惊动对方，也不寒了自己人的心。

## 1. 人设和差异化

她在这件事里立的是冷静的主事人：自己是受害者，却先稳住身边每一个人，再安排大家各干一块。

和别人比：
- 温实初的第一反应是自责和防范：“微臣以后一定要格外加小心，从抓药到熬制，直到小主服下，微臣都会亲力亲为，不让他人插手。”（第10集第187幕）这只能防，抓不到人。
- 流朱的第一反应是借力：之前余氏咒怨不停，她想去禀报皇后让皇后做主（第10集第186幕）。甄嬛回绝了，说“得饶人处且饶人”，这是这一局之前的退让，见雷区。
- 甄嬛的做法是把防范放到第二位，先把找人排第一。博主观点：甄嬛知道有人害她，既没有惴惴不安，也没有暴跳如雷，立刻将计就计（树懒小结界，BV1j6bDzFEtz，约01:42至01:49）。

为什么对上团队的胃口：出事之后，手下最怕被追责。甄嬛先不追责，反过来替他们找理由，大家才会把线索一件件拿出来。

## 2. 读人

甄嬛自己：
- 先发现异常的是她，她闻到药“似乎酸得很”，又连着犯困（第10集第186幕）。
- 她没有直接下判断，先问浣碧“我是从什么时候开始贪睡的”，让身边人把时间线说出来，三五日前、一天睡五六个时辰。证据来自别人嘴里的描述，她自己没有下判断。

下药的人：
- 温实初的判断：“用药的人很是谨慎，加的药量很少，所以即便微臣每日给小主请脉，也很难发现。”（第10集第187幕）这个对手有耐心，懂药量，敢慢慢来。
- 药罐盖子用药水泡过，煮药时再把药性带进去（槿汐的推演，第10集第190幕）。说明对方的手法是改器具，避开盯人这一关。

花穗：
- 小允子假装嫌药罐破旧要换，她立刻拦下，说这类东西不必名贵，要用久的，轻易还换不得（第10集第191幕）。我们自己的判断：这句回答正好把有问题的盖子保住了，对方反应很快，大概有人教过。
- 来历：原是余氏身边的宫女，余氏降位后被遣出来，又被指到碎玉轩（第10集第192幕）。

团队成员（博主观点，BV1j6bDzFEtz）：
- 槿汐作为掌事，出了漏洞先认错，流朱看到槿汐跪下，自己也跟着跪（约08:17至08:25）。
- 浣碧对自己职责范围里的漏洞没有表态，站得离人群比较远，领导叫她反应也慢半拍（约08:26至08:35、11:38至11:46）。博主认为，甄嬛虽然脸上没表现出来，但把倒药的活换给小允子，说明她觉得浣碧不好使（约11:46至11:53）。这是博主的解读，剧本里没有明说。
- 小允子领了一句话，会把后面二三四步想全再汇报，所以不光去打听花穗，还顺路试探了她（约12:45至12:53）。

## 3. 布局链条

目标：把下药的人和上线都抓出来，人赃并获；整个过程不让对方起疑。

铺垫：
1. 先确认。药酸、犯困，请温实初来“把平安脉”，实际上用合谷穴扎针验毒，针上有淡淡的青色，说明药被动过（第10集第187幕）。
2. 定性。药里没有毒药，有人把本来分量较轻的药加重了。长期吃，半年内会神智失常（第10集第187幕）。
3. 排优先级。博主的说法是防范重要但不紧急，找出凶手才是重要且紧急（约02:06至02:10）。甄嬛的原话是“防范虽要紧，但如今当务之急，是要把那个下毒害我的人给找出来”。
4. 缩小范围。药在碎玉轩里熬，能下药的必定是身边人；温实初补一句，月前刚来了几个宫女太监，药是他们来了之后才出问题的（第10集第187幕）。
5. 演一场戏。她提高声音，让屋外的人听到“大人说我没事，我就放心了”，温实初也顺着说春困贪睡是寻常事（第10集第187幕）。
6. 槿汐发现宫墙底下有个新开的小洞，甄嬛把它接成第二条线，安排槿汐和小允子明日煎药时留神，务必人赃并获（第10集第188幕）。

借谁的手：
- 温实初：从医学上验证，也提供时间线。
- 槿汐：发现墙洞，推演药罐盖子的机关。
- 小允子：盯煎药，发现可疑的器具，当面试探花穗，打听来历。
- 不借外人。她没有去禀报皇后，也没有惊动内务府。

等什么时机：
- 第二天煎药时分，小允子和槿汐守着，仍然下了药，药从罐盖里混进来，没有人接近药罐（第10集第190幕）。她说“这件事情必有古怪”，随后才发现罐盖颜色比罐身深。

怎么收网（这一张卡只写到锁定嫌疑人，抓人和审问见下一张卡）：
1. 嫌疑人锁定。罐盖的证据加上保管人是新来的花穗（浣碧交代，第10集第190幕）。
2. 不动证据。“把药倒了，再把药罐子放回去，别叫人起了疑心”，药倒掉保安全，罐子放回去当诱饵。
3. 让小允子当面试探花穗，再打听来历（第10集第191幕、第192幕）。
4. 来历查实是余氏旧人，三条线（墙洞、罐盖、来历）全部指向同一个人，才动手。

留了什么后手：
- 对外口径统一：温太医说小主没事、药罐子原样放回去、没有一个人被点名。
- 同一幕里她定下今日的事要告诉眉庄，不告诉陵容，理由是陵容胆子小（第10集第192幕）。

## 4. 关键话术

- 第10集第186幕 甄嬛：“别惊动了人，就说请温大人来把平安脉。”
  为什么管用：要查人先找一个对外说得通的由头，名义是例行请脉，不会引起议论。

- 第10集第187幕 甄嬛：“防范虽要紧，但如今当务之急，是要把那个下毒害我的人给找出来。”
  为什么管用：把话题从我们怎么防，拉到我们要抓的是谁，让温实初从自责里出来，一起做事。

- 第10集第187幕 甄嬛：“那就请温大人与嬛儿同演一出戏，装作如无其事，免得打草惊蛇。”
  为什么管用：请对方配合一场演出，先说清目的是不惊动对手，对方才会放心照做。

- 第10集第188幕 甄嬛：“你只装作不知道，明天煎药时分让小允子和你一道留神着，务必人赃并获，杀他个措手不及。”
  为什么管用：线索由槿汐给出，甄嬛不抢，只把它排进计划里，明确两个人分工，时间也定死。

- 第10集第190幕 甄嬛：“也不能全怪你们，能在你们几个人眼皮子底下把药下进去还不被人发现，而且中间并没有人接近药罐，这件事情必有古怪。”
  为什么管用：先替手下开脱，再把问题引向没有人接近药罐这个矛盾点，大家才会往器具上想。博主观点：追责排不到第一位，这一句既让大家宽了心，也肯定了他们的工作能力（BV1j6bDzFEtz，约09:04至09:09）。

- 第10集第190幕 甄嬛：“小允子，把药倒了，再把药罐子放回去，别叫人起了疑心。再把花穗的来历给我打听清楚。”
  为什么管用：证据原地保留，对方看不到任何变化；同时把下一步的查证交给最适合的人。

- 第10集第191幕 花穗：“公公有所不知，这熬药的东西不必名贵，且要用久的才好，否则伤了药性，轻易还换不得呢。”
  为什么管用：这是对方的话，放在这里是让用户看对手怎么自保，一个现成的理由随时拿得出来，往往说明事先练过。

## 5. 换到职场

### 场合一：老板 1on1（发现自己负责的东西被人动过）

对应的局：你负责的数据、共享文档或客户资料出现被改动的迹象，你还不知道是谁、为什么，要向老板汇报。
打法：
1. 先自己核实，用能验证的办法，比如对比修改记录，不凭感觉。
2. 先稳住，不在群里点名，也不让可能相关的人察觉你在查。
3. 汇报时先讲影响范围和止损，再讲你准备怎么查，请老板给你几天时间，并请他暂时别在会上提。
4. 小范围拉两三个信得过的人，各查一条线，比如记录、权限、来源，三条线都指向同一处，再去找具体的人。
5. 汇报节奏：证据没齐，只汇报进展，不汇报结论。
一句能直接说出口的话：“老板，有件事想先跟您单独说一下。（某份数据）有被改动的迹象，我已经核对了（具体记录），影响范围目前看是（范围）。我想先不声张，给我（几天）把来源查清楚，查清之前请您也先别在会上提。”

### 场合二：面试（行为面试题：项目出了问题，你怎么处理）

对应的局：面试官问“团队里有人出了错或者项目出了异常，你当时怎么做的”。
打法：
1. 先说你怎么稳住人心：先不追责，先把线索收齐。
2. 再说排优先级：止损先于防范，防范先于复盘。
3. 说你怎么分工：谁查哪一条线，你负责哪一块。
4. 收在结果和流程补漏上。
一句能直接说出口的话：“当时我先做的是止损，没有急着追究是谁的问题，因为先查清楚发生了什么，团队才愿意把线索都拿出来。三天后我们定位到（原因），我负责的是（你负责的那一块），后面我们补上了（具体流程），同样的口子没有再出现。”

## 雷区

- 此前一直退让：流朱想告状，甄嬛说“不必对这种人费事了，得饶人处且饶人，她失宠难免心有不平，过段时间就好了”（第10集第186幕）。后来才发现对方一直没收手。流朱在审完花穗后说“小主这回一定要拿定主意，不能再忍让了”（第10集第192幕）。职场里对应：对一个明显怀恨的人，不处理不等于对方放下了。
- 只盯人，漏看器具：煎药有人盯，仍然被下药，因为手法在药罐盖子上（第10集第190幕）。职场里对应：查事故别只查人，也要查工具、权限、模板、共享文件。
- 温实初的亲力亲为只能防，抓不到人。职场里对应：单纯加强防范不会让问题自己消失，需要有人去找来源。
- 博主观点：出了问题不管责任在不在自己，都应该站出来表态；浣碧对自己职责范围里的漏洞无动于衷，和槿汐、流朱形成对比（BV1j6bDzFEtz，约08:26至08:45）。职场里对应：即使错不在你，也要表态，不然会被归到不好使的那一类。
- 剧里的将计就计是对着一个确定会害人的对手。职场里不要拿同样办法去试探普通同事，没证据之前，先小范围核实，不假装无事去套话。
