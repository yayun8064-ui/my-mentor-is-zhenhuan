# 汤泉宫之行皇后称病不陪驾，回宫请安甄嬛接招（第8集第146至152幕，前因见第7集第136幕）

局面类型：被试探 / 闲谈社交
对方：皇后，后宫之主，管着请安和礼数，最在意的是贤德的名声和与皇帝之间的体面；剪秋，皇后的心腹；齐妃，旁观并附和的人。
甄嬛的处境：弱。贵人，刚得宠，没有根基。皇后称病那一幕她不在场；次日回宫补请安是在景仁宫，对方的地盘，身边只有槿汐。
她的目的：补上侍寝后的请安礼数，不得罪皇后，不炫耀，不接对方抛来的话头。

这一局的主角其实是皇后。甄嬛不在场的那一幕是对手怎么出牌，次日的请安才是甄嬛的回应。用户用这张卡，主要是学会读懂“让一步”背后的东西，其次才是学甄嬛怎么接。

## 1. 人设和差异化

皇后立的人设是宽厚体贴、成人之美的中宫。

同一件事，不同人的反应：
- 皇后：听说皇帝赐莞贵人去汤泉宫，称病，不陪驾。她对齐妃说的是“本宫何不成全了皇上”。（第8集第146幕）
- 齐妃：当场夸皇后“当真贤德”，并且拿华妃做对比（第8集第146幕）。
- 华妃：独自在翊坤宫，泪眼朦胧，念叨“把她当杨贵妃宠着吗”（第8集第149幕），后来还翻行房档（第8集第163幕）。她的醋意写在脸上。

皇后的做法让她在同一件事上赢了华妃，没有摆出任何争的姿态。

甄嬛立的人设则是守礼、谦恭、不居功。次日请安时，她从头到尾没有提汤泉宫里发生过什么，也没有问起皇后称病的事，剧本里这一幕只有礼数和客气话。

## 2. 读人

皇后：
- 她原本打算同行。她问剪秋：“都准备妥当了吗？皇上何时启程啊？”（第8集第146幕）
- 听到“皇上赐莞贵人汤泉宫沐浴”，她先应了一声“噢”，然后才说称病（第8集第146幕）。我们的读法：改主意发生在听到具体的人之后。
- 齐妃替她宽心，说莞贵人只能在嫔妃们用的汤池，冲撞不到皇后（第8集第146幕）。她没有接这个理由，回的是“成全”。我们的读法：她要的是成全这个名义，不在乎汤池会不会冲撞。
- 她对两个人讲了两套话。对传话的剪秋，说的是身体不舒服；对在场的齐妃，说的是成全皇上。身体是给皇帝的理由，成全是留给旁人传出去的口碑。这条是读剧本得到的，两句话的原文在下面关键话术里。
- 同一个皇后在第7集第136幕面对莞贵人越级晋封，说的是：“宫规是老祖宗规定的，祖宗就是天子，天子就是皇上。她非池中之物，迟早的事。”剪秋提醒她该劝一劝，她没有去劝。这与汤泉宫那次一脉相承：皇帝偏爱谁，她不去正面拦。
- 博主观点：同一场里，皇后听到莞贵人晋封的消息，先是无语了三秒钟，然后撅嘴生气，再阴险地笑了一下（树懒小结界，BV1LV8MzrEjD，约01:09至01:28，转写里“晚贵人”是莞贵人）。这条说明皇后心里并不舒服，只是不在脸上和嘴上露出来。
- 博主观点：皇后不跟去有两层原因（脖子细哔哔叨，BV1wWSvBtECw，p12，约05:31至05:48）。第一层，她知道皇上这趟是为了甄嬛，去了只是讨没趣，不去反而能在皇上那里讨个好，还能在后宫落一个贤德的名声。第二层，她不去就变成皇上单独带甄嬛，这份荣宠没有第二个人享受过，等于把甄嬛推到风口浪尖，引来华妃等人的针对。对照剧本：第一层和第8集第146幕里皇后说的成全、齐妃夸的贤德对得上。第二层剧本里皇后没有说过，是博主的推测，本卡只当成一种可能的读法，不当结论。
- 博主观点：皇后在第7集第136幕练字时，表面不在意甄嬛获宠，转手就把字交给剪秋，表示不要这幅字了，博主认为这说明甄嬛获宠让皇后不高兴（BV1iBhP6QEmZ，p11，约04:16至04:41）。对照剧本：第7集第136幕只写了皇后与剪秋的对话，没有写递字这个动作，所以这一条来自博主对画面的观察，剧本里核对不到。
- 次日景仁宫不用请安，眉庄是这么说的：“本想去给皇后请安，谁想皇后身子不适，不用请安了，所以就来看看你。”（第8集第151幕）称病的说法被延续了下来，前后一致。

齐妃：把皇后的做法直接解读为美德，并顺手踩华妃（第8集第146幕）。她是皇后口碑的第一个传播者，看起来也没有意识到。

华妃（博主观点为主）：博主认为皇后的安排奏效了，对华妃来说单是宠爱并不可怕，独一份的偏爱才让她不安（BV1wWSvBtECw，p12，约09:28至09:55）。博主另一期还说，皇上平时对新人赏赐大方，多数后妃只当他又看上一个新人，华妃等人起初会静观其变，不会立刻针对（BV1iBhP6QEmZ，p11，约06:03至06:18）。对照剧本：第8集第149幕华妃的话重点落在赐浴汤泉宫、只带她一个人去，和博主说的独一份一致。

剪秋：次日替皇后补话。“自打莞贵人病了以后，娘娘三番五次地想要去看您，可无奈小主患的正是时疾，怕伤了娘娘的凤体，只好作罢。”（第8集第152幕）这是皇后第二次用身体当作不去的理由。我们的读法：这个理由别人没法核对，用起来很方便。

## 3. 布局链条

目标（皇后）：保住贤德的名声，不让皇帝觉得她在管他，同时不与新宠起正面冲突。
铺垫：
1. 第7集第136幕，她已经对莞贵人晋封定了调：不拦，迟早的事。
2. 她本来准备陪驾（第8集第146幕），所以称病时是在“原本要去”的基础上放弃，显得是主动让出，没有人会以为她没被邀请。

借谁的手：剪秋去向皇帝传话；齐妃在场，当场把它说成贤德。
等什么时机：听到消息就立刻，不拖到启程之后。皇上午后出发，她赶在那之前说完。
怎么收网：先让出行程，再让次日的请安也免掉（第8集第151幕），把称病这件事做成一个整体。
博主观点补充：博主认为不陪驾这一步同时有两个收益，讨皇上的好加贤德名声，以及让甄嬛一个人承受荣宠（BV1wWSvBtECw，p12，约05:31至05:48）。前一个收益有剧本支撑，后一个只是博主推测，见雷区。
留了什么后手：
- 次日甄嬛回宫补请安，皇后先体谅再提规矩，再给亲近，再布置任务（见下）。
- 第8集第165幕，皇后在众妃面前送甄嬛一件福寿绵被：“本宫给你留了一件，你盖着睡觉也好早日得个皇子。”华妃立刻接话：“可不是吗？若来日诞下皇子，就能赶上齐妃了。”礼物当众送，后面的话由别人来说。

甄嬛的接法（第8集第152幕）：
1. 进门行参拜大礼，不等皇后说，先认补请安迟了：“臣妾本该侍寝之后就来行礼参拜的，只因身在行宫才延迟至今，是臣妾的不是。”
2. 皇后说“只要皇上高兴，本宫也自然万安”，这是在提她承宠的事。甄嬛没有顺着往下说，把话题转到皇后身上：“皇后娘娘母仪天下，若能日日见到皇后安好，便是六宫同被恩泽了。”
3. 皇后说“拿这儿当自己的家，不必拘束”，她只答“是”，接着夸宫里的果香，说闻着格外舒心，话题落在眼前的东西上。
4. 皇后给她布置“养好身体、承子嗣”的任务，她答“娘娘教诲，臣妾字字谨记在心”。

这一幕里她没有要任何东西，也没有借机表态。我们的判断：此时甄嬛还没有看穿皇后。几幕之后她对眉庄说“皇后娘娘那样和蔼的人，怎么提到他们就生气了呢”（第8集第166幕）。所以这一局要学的是认出皇后的打法，甄嬛的接法只能学她的礼数部分。

## 4. 关键话术

- 第8集第146幕 皇后：“噢——剪秋，你去跟皇上说，本宫今天有点不舒服，今天不能陪皇上去行宫了。”
  为什么管用（对皇后）：理由是身体，别人无法反驳，也不会让皇帝觉得她在吃醋。

- 第8集第146幕 皇后：“皇上今日好兴致，本宫何不成全了皇上？”
  为什么管用（对皇后）：把退让说成成全，给自己留下贤德的口碑。

- 第8集第146幕 齐妃：“哎呀，娘娘当真贤德。若这事要换了华妃呀，不知道她又该怎么小心眼了。”
  为什么管用：旁人的夸奖比自己说更有分量，皇后什么都不用多讲。

- 第8集第152幕 皇后：“你身子方好，又刚回宫，便要你行这种大礼，真是难为你了。只是祖宗规矩，侍寝次日便要到中宫来行礼，不能不遵。”
  为什么管用（对皇后）：先体谅，再引规矩。体谅放在前面，规矩的分量就由皇后说了算。

- 第8集第152幕 甄嬛：“臣妾本该侍寝之后就来行礼参拜的，只因身在行宫才延迟至今，是臣妾的不是。”
  为什么管用：先认礼数的疏漏，同时说清楚迟到的原因是在皇帝身边，不展开，也不辩解。

- 第8集第152幕 甄嬛：“皇后娘娘母仪天下，若能日日见到皇后安好，便是六宫同被恩泽了。”
  为什么管用：对方一提“皇上高兴”，她把话题交还给皇后，不领功，不炫耀。

- 第8集第152幕 甄嬛：“娘娘教诲，臣妾字字谨记在心。”
  为什么管用：对一个长辈式的叮嘱，用最稳的话回应。但这类回答也可能被对方当成承诺，见雷区。

## 5. 换到职场

### 场合一：老板1on1（同事主动让出一个机会，你接下后见到对方）

对应的局：老板点了你去见一个重要客户，原本要去的资深同事听说后说“这次我就不去了，成全你”。你们之后在会上碰面。
打法：
1. 把对方的让出当成一次人情，先认礼数：没有提前打招呼是你的疏忽。
2. 对方一提你的机会，不顺着聊，把话题交还给对方。
3. 不追问对方为什么让，也不猜对方心里怎么想。
4. 给一个小而具体的后续动作，让对方有参与感。
一句能直接说出口的话：“这次安排我自己也没想到，没提前跟您打招呼是我的疏忽。（那件事）回来我先给您过一遍，您觉得哪里不妥，我马上改。”

### 场合二：大佬建联（第一次吃饭，大佬说以后常联系，别拘束）

对应的局：展会饭局，大佬很客气地说以后常来常往、当自己人。
打法：
1. 只接礼貌，不当承诺，也不趁热打铁提需求。
2. 回应要短，把话落在眼前能聊的东西上，比如对方公司最近做的一件事。
3. 把请教放到下一次，并且给出一个你先做的动作。
一句能直接说出口的话：“您这句话我记下了。我不急着麻烦您，等我把（具体的事）理出头绪，再约您半小时请教，可以吗？”

## 雷区

- 称病是一个说法，没人能核对。剧本没有写皇后是否真的不舒服。职场里借身体不舒服当理由躲开某件事，次数多了会被识破，信用受损，不要套用。这里写出来是为了识别：有人反复用一个没法核对的理由缺席，往往另有安排。
- 皇后先体谅，再引规矩（第8集第152幕）。职场里对应：先说理解你，紧接着一句只是制度规定，后一句才是真正的意思。
- 甄嬛答“字字谨记在心”，对方可以把它当成你接下了任务。职场里对应：对要好好养身体、早点出成绩这类叮嘱，回答别太满。我们的判断，剧本里这句话后来没有被追究。
- 第8集第165幕：当众送礼，话由别人接。职场里对应：被当众点名奖励时，要留意旁边谁在接话，接的话会把你放到更高的期待上。
- 博主说皇后不去还有把甄嬛推到风口浪尖的用意（BV1wWSvBtECw，p12，约05:31至05:48），剧本没有写皇后有这个想法，皇后明说的只有身体不适和成全皇上。读人时可以把它当成一种可能，没有证据就不要当成已经确认的事去判断别人。博主说皇后把字转手交给剪秋表示不要（BV1iBhP6QEmZ，p11，约04:16至04:41），剧本同样没有这个动作，核对不到。
- 华妃的反应是醋意写在脸上，还去翻档案（第8集第149幕、第163幕）。职场里对应：情绪外露，就让对手有了抓手。
- 甄嬛在这一幕里把皇后读成和蔼的人（第8集第166幕），说明她那时没有看穿。读人时不要只看对方说的话，要把同一个人在不同场合的做法连起来看。
