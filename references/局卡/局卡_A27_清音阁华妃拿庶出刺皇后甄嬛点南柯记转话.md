# 清音阁看戏，华妃拿庶出刺皇后，甄嬛点《南柯记》转话（第22集第368幕，前情见第22集第362至367幕）

局面类型：被当众发难（旁观者出面解围） / 闲谈社交
对方：华妃（年世兰），这场看戏的请客人，一路抢戏抢话，在炫耀哥哥年羹尧的同时借戏文攻击皇后；皇后（宜修），中宫，被当众拿出身说事，最在意的是中宫的体面；还有齐妃被刺中三阿哥的事、安常在（陵容）被抓住话柄、曹贵人在一旁捧华妃、淳常在天真插话。
甄嬛的处境：对等偏弱。位分是贵人，当众，在场的人都在看皇后怎么接；她本人没有被攻击，但华妃与她有仇，皇后也是她要防的人。
她的目的：在皇后被逼到沉默时递一个台阶，把话题从嫡庶拉走，不得罪华妃，也不让自己被卷进去；陵容失言后再补一刀圆回，不让场面升级。

## 1. 人设和差异化

她在清音阁立的是爱看戏、读书多、说戏不说人的人。

和在场其他人比：
- 皇后：被华妃连续刺中后，回话是“做得正妻就要有容人的雅量，夫君再宠爱妾室也好，正妻就是正妻”，是正面讲道理，被华妃追问到“庶出”之后沉默。
- 齐妃：被说三阿哥孝心太重不如读书，气得把手炉掷在桌上，情绪外露（第22集第368幕）。
- 曹贵人：华妃点薛丁山，她立刻夸华妃兄长战功赫赫，站队明显。
- 陵容：说“凡事最重要的是两心相悦最要紧”，被华妃抓住公开说“脸皮厚”。
- 甄嬛：全程只对淳儿低声说一句“这出戏热闹，你喜欢看”，等到最关键的一刻才开口，开口只谈戏。

为什么对上现场人的胃口：华妃要的是赢；皇后要的是不丢中宫的脸；甄嬛给的是一个都不用认输的出口，戏里的道理，谁也没被点名。

博主观点：甄嬛的话术胜过华妃和皇后。要打击一个人的信心，就要打在她安身立命的根上；华妃的底气来自权势滔天的哥哥年羹尧，甄嬛的戏文正好落在这个根基上（格格說剧，BV1seQ2BTEav，约06:57至07:17）。这是博主的解读，我们自己的分析在第3部分。

## 2. 读人

华妃：
- 这一场她是请客人，从一开始就抢戏本、抢话，说“本宫记得有一出极好的《鼎峙春秋》”，不等皇后先点。她已经把座位和话语权都放在皇后之前。
- 她开口攻击的顺序是：先点戏炫耀哥哥，再扎齐妃，再夸自己的衣裳是哥哥在外面赶做的，再提皇后在皇上跟前告状，最后拿樊梨花说皇后。每一轮的对象都比上一轮更大。
- 她知道皇后在皇帝那里提过翊坤宫的开销：“听说皇后前些日子因为臣妾宫中开销大，在皇上那儿告了一状”（第22集第368幕）。第22集第362幕皇后确实对皇帝提过账单。所以这场是报复。
- 博主观点：华妃表面奢侈，实际是看不上内务府和皇后提拔的人，嫌他们管不好、弄不出好东西（格格說剧，BV1seQ2BTEav，约00:35至00:43）。这和第22集第368幕她说哥哥托珍宝斋赶做的首饰只比内务府的好那么一丁点相合。
- 博主观点：华妃被皇后用正妻的口吻训诫节流，输了一个回合，于是提起樊梨花来扳回面子，拿嫡庶去戳皇后的软肋（格格說剧，BV1seQ2BTEav，约03:41至03:48）。这个先后顺序与第22集第368幕对得上。
- 博主观点：华妃知道皇后告状，是皇帝有意透露的，既敲打华妃，又让两边互相消耗（格格說剧，BV1seQ2BTEav，约01:49至02:08）。剧本只写了华妃自己说听说此事（第22集第368幕），没有交代消息怎么传到她那里，这一条是博主推测，我们不采用。

皇后：
- 第22集第367幕她前一晚才对皇帝说“明儿华妃约了六宫一同到清音阁看戏”，对华妃的邀约心里有数。
- 她被说“庶出”之后选择不回。剧本写“皇后不言”“皇后继续沉默”，说明这是最痛的一点，不适合再争。
- 博主观点：庶出是皇后最痛的一处，她始终认为皇帝是因为自己庶出才违背约定，改娶了嫡出的纯元（格格說剧，BV1seQ2BTEav，约04:48至05:26）。剧本里皇后自己说过类似的话，见第14集第257幕、第72集第1118幕，博主这一条有剧本支撑。
- 博主观点：皇后明知华妃不怀好意还答应赴约，本来可以稳坐看戏，却偏要在别人的戏台上唱自己的戏（枇杷树下等李子熟，BV1Uptc6WEWU，约28:00至28:20）。剧本里皇后前一晚就知道这场戏（第22集第367幕），她是有备而来还是被动入局，剧本没有明说。
- 博主观点：甄嬛和华妃斗得越凶，皇后越高兴，脸上的笑意藏不住（格格說剧，BV1seQ2BTEav，约09:09至09:22）。这是博主对表情的读法，剧本只写了皇后最后顺势收场。
- 她最后接甄嬛那句话时说“同是看戏，莞贵人便多有心得，难怪皇上这么喜欢和你说话”。我们的判断是她接了台阶，同时在提醒甄嬛她被看见了。

淳儿：天真，直接说出“这出戏闹了半天只为做个梦，多没趣啊”（第22集第368幕）。这个插话反而给了甄嬛一个往下讲的口子。

陵容：这一场她的话被华妃抓住。我们的判断是她被第22集第363至366幕的寝衣、玉钗那些事压着情绪（她在第22集第366幕私下说“我算什么啊”），所以才会在公开场合说出两心相悦。剧本没有直接写这一层，待核。
- 博主观点：陵容这句话虽然是说给皇后听的，多少带着自己的处境。她觉得自己熬到云开就能见月明，但皇帝和皇后之间做不到两心相悦，和她也不会有（格格說剧，BV1seQ2BTEav，约08:00至08:14）。
- 博主观点：陵容对甄嬛的不满是寝衣、玉钗这些事一件件叠出来的，甄嬛明知她因为淳儿的话不开心，却没有制止淳儿，也没有当面沟通（枇杷树下等李子熟，BV1Uptc6WEWU，约17:15至18:06，18:42至19:34）。这两条是博主对她心理的解读，剧本没有直接写，上面的待核照旧。

## 3. 布局链条

目标：打断华妃对皇后的攻击，让场面回到看戏，同时不得罪人。

铺垫：
1. 第22集第368幕前半，她一直沉默，只对淳儿说一句“这出戏热闹，你喜欢看”，回应淳儿低声问华妃怎么抢在皇后前头。她把自己放在不评论的位置。

借谁的手：借戏本身。点《南柯记》是把话题移进戏文里；借皇后的位置，用请示的口吻问皇后好不好；借淳儿一句话往下讲。

等什么时机：华妃问出“您说是不是啊，娘娘？”，皇后继续沉默，全场都在等一个结果的时候。这是皇后最难受、别人也最不好插话的一刻。

怎么收网：
1. 以请示的口气开口：皇后娘娘，咱们再点一出《南柯记》好不好？把点戏权给皇后，等于把台面交还给中宫。
2. 淳儿插话说没趣，她就地接话，讲看戏的道理：高楼起、高楼塌，越显赫越容易跌重，人去楼空，嫡庶贵贱、钱财权势，都不过是一场梦。这段话同时消解了嫡庶这件事，也对华妃的炫耀有一点提醒，但没有点任何人。
3. 皇后接话夸她，她回“臣妾不过是就事论事罢了”，不接这份夸奖，也不留话柄。
4. 陵容被华妃抓住后，她用《牡丹亭》的戏文把话拉回来，说安妹妹不过是就戏论戏。
5. 皇后顺势收场：既然就戏论戏，那就好好看戏。

博主观点：博主认为甄嬛点《南柯记》除了解围，矛头也对着华妃，面对甄嬛，华妃连动口的次数都很少（枇杷树下等李子熟，BV1Uptc6WEWU，约29:51至30:13，30:21至30:36）。另一位博主认为这段话也在提醒甄嬛自己，她住的碎玉轩有一座旧戏台，当年热闹后来废弃，甄家也逃不过高楼塌（格格說剧，BV1seQ2BTEav，约07:18至07:36）。碎玉轩有旧戏台，剧本第2集第38幕有写。剧本里甄嬛没有点任何人的名，对华妃的暗刺只是博主和我们各自的判断，卡里按剧本，不把它当成甄嬛明说的意图。

留了什么后手：她没有为皇后与华妃的冲突表态，也没有让华妃抓到把柄。之后腊八朝见太后那天，槿汐劝她挑温婉谦卑的大氅，说“阖宫朝见的日子实在不需要穿得太出挑”（第22集第369幕），她照做了，继续收着。

博主观点：腊八这天太后召见，是想核实华妃之前说甄嬛奢侈的话，看到甄嬛打扮得不出格，满意地点了头（格格說剧，BV1seQ2BTEav，约12:18至12:28）。剧本第22集第370幕我们只核到太后开场的第一句，太后点头这一段只作博主观点。

## 4. 关键话术

- 第22集第368幕 甄嬛：“这出戏热闹，你喜欢看。”
  为什么管用：对天真的人，不评论华妃的行为，只回应对方的喜好，不留话柄。

- 第22集第368幕 甄嬛：“皇后娘娘，咱们再点一出《南柯记》好不好？”
  为什么管用：用请示的口吻插话，把决定权给到最需要面子的人，也给了皇后一个换话题的借口。

- 第22集第368幕 甄嬛：“眼看他高楼起，眼看他高楼塌，越是显赫就越容易登高跌重，人去楼空，谁还管嫡庶贵贱，谁还分钱财权势，不过是南柯一梦而已。”
  为什么管用：借戏文把嫡庶这个刺人的话题降级为一场梦，对谁都不指名，但每个人都听得懂。

- 第22集第368幕 甄嬛：“臣妾不过是就事论事罢了。”
  为什么管用：被位高的人夸奖时，把话收回去，不让夸奖变成别人攻击你的由头。

- 第22集第368幕 甄嬛：“安妹妹不过是就戏论戏罢了。”
  为什么管用：同伴说错话被抓住时，不替她辩解内容，只改变这句话的性质，说它是在谈戏。

- 第22集第368幕 皇后：“既然就戏论戏，那就好好看戏吧。”
  为什么管用：这是对方顺着台阶落下来的话，说明解围被接住了。

## 5. 换到职场

### 场合一：和行业大佬建联（饭局上两位前辈当众互相拆台）

对应的局：饭局上，大佬A当着大家的面拿大佬B的出身、融资或公司规模说笑，B明显不舒服，在座的人都在等B怎么回。
打法：
1. 不站队，不评价谁对谁错。
2. 在对方沉默的一刻，用请示的口气把话题交给更资深的那一位。
3. 把话题移到一个无关个人的话题，比如行业周期、一个案例，用一个故事把大家的注意力拉走。
4. 别人夸你时轻轻收回。
一句能直接说出口的话：“两位前辈都是做过（某个周期）的，我想借这个机会请教一下，您当时怎么看（某个行业问题）？”

### 场合二：聊投资（两位投资人当着你的面互相抬杠）

对应的局：路演或交流会上，两位投资人在你面前争起来，一个质疑另一个的判断，场面僵住，所有人看着你。
打法：
1. 不替任何一方说话。
2. 把争论拉回到项目本身，用一个具体问题请他们给意见。
3. 用一句话把两个人的观点都放进你的计划里，说明你会参考。
一句能直接说出口的话：“两位的看法其实都指向同一个问题，就是（具体问题）。我们现在的打算是（具体做法），也想听听两位的建议。”

## 雷区

- 华妃：一场里连续点名攻击齐妃、皇后、安常在，每个人都得罪了一遍。职场里赢了一场争论却树了一圈对手。
- 齐妃把手炉掷在桌上，情绪压过了判断。
- 曹贵人那句“华妃娘娘的兄长战功赫赫，恰如唐朝大将薛丁山征西成功扬名千古。”是典型的捧场话，站队明显，职场里对强势的人一味捧，会让别人对你的立场有判断。
- 陵容在公开场合讲两心相悦，被抓住“脸皮厚”。职场里公开场合谈私人感受或攀比，容易被人拿来做文章。
- 博主观点：陵容被解围后并没有感激甄嬛，心里想的是甄嬛样样都会，还要踩着自己的窘迫出风头（格格說剧，BV1seQ2BTEav，约09:00至09:07）。剧本没有写陵容的心理，这是博主对表情的读法。替同伴圆场之后，对方的面子可能比你以为的更挂不住。
- 博主观点：华妃本可以抓住甄嬛谈《牡丹亭》这个话柄，结果皇后反倒夸甄嬛饱读诗书，博主还称《牡丹亭》是大清的禁书（枇杷树下等李子熟，BV1Uptc6WEWU，约30:43至30:56）。剧本没有提禁书，禁书一说我们不采用。引戏文时被人抓话柄的风险，仍然要想到。
- 甄嬛这一局解围成功，但皇后的回话是“难怪皇上这么喜欢和你说话”，带着提醒。替位高者解围，对方未必感激，反而可能对你留意。
- 戏文里“越是显赫就越容易登高跌重”对华妃也是一句暗刺，华妃没有当场反驳，但这样的话说多了，容易被人觉得你在影射。职场里解围的话不要让人能对号入座。
