# 养心殿被问朋党，甄嬛借欧阳修作答（第22集第358幕，前情见第22集第356至357幕）

局面类型：被试探 / 闲谈社交（陪上位者聊敏感话题）
对方：皇帝，刚见完年羹尧，不痛快，在找一个能说得出口的道理；年羹尧，功高，在殿外对她放话，言下之意是谁得罪华妃他不会袖手旁观。皇帝最在意的是权力平衡，不能被功臣压过；年羹尧最在意的是妹妹的地位和自己的体面。
甄嬛的处境：对等偏弱。私下，只有皇帝和她；问题关乎朝政，答错就是干政；年羹尧刚在门口威胁过她，她手里没有任何能压他的东西。
她的目的：回答皇帝的问题，但不评年羹尧，不替皇帝表态，不涉及任何具体的人和事；让皇帝心里松一些，也让自己留在他身边。

## 1. 人设和差异化

她在这一场立的是读书多、不碰政事、只管让皇帝宽心的人。

和皇后比：之后皇后在养心殿对皇帝查账，追问华妃这些开销若出在年羹尧府中，皇上可曾赏过他那么多，若没有赏，银子又从哪里来（第22集第362幕）。她直接指向年家的钱。皇帝回“这些朕多少知道，不必说了”，把话堵回去。甄嬛一个字也没碰年家。

和年羹尧比：他在殿外说“否则即便皇上不管，本将军也不会袖手旁观”，把威胁说在明面上。甄嬛回“兄妹情深，向来如此”，把威胁听成亲情话。

为什么对上皇帝的胃口：他自己给了框，“无妨，朕只和你谈论史书”，她就在这个框里答。他要的是一个能让自己心里有底的说法，不要一个结论。

## 2. 读人

年羹尧：
- 第22集第356幕，他在殿外被请坐，苏培盛连劝三次他才坐下；允礼出来，他坐着请安，说足疾发作不起身。我们的判断是他不把亲王放在眼里。
- 第22集第357幕，他请求皇帝重新起用赵之垣，皇帝说“朕听你的便是”。这件事的背景是华妃收了赵之垣的银子（第22集第355幕、第359幕），甄嬛没有参与，也没有证据显示她知道。
- 第22集第358幕他在门口对甄嬛说：“皇上虽有疼爱之心，怕只怕有些不知深浅不分尊卑之人恃宠生娇得罪娘娘。”这是对她的敲打。

皇帝：
- 第22集第358幕他问苏培盛“年羹尧出去的时候神色如何？”，再问“他是坐等的？”。他在核对年羹尧的无礼，没有当场发作。
- 苏培盛说“奴才失言”，他回“你是实话，未必是失言”，等于允许这类话被说出来。
- 他问甄嬛朋党，是把心里压着的事换成史书来聊。他在殿里已经对着年羹尧点头，要找人听他消气。
- “你惯会口头上哄朕高兴”是他看得很清楚的一句话，他知道她在哄，也愿意被哄。

苏培盛：进殿前提醒她“年大将军刚才来过，皇上不是很痛快，小主可得小心应对呀”，是递给她的信号。

## 3. 布局链条

目标：在不碰政事的前提下，让皇帝心里舒服一些。

铺垫：
1. 第22集第358幕，年羹尧在门口对她说那番话，她没有顶，也没有告状。
2. 苏培盛提前提示，她进殿先看皇帝的状态。

借谁的手：借欧阳修的《朋党论》，一段现成的古人观点，她没有给出自己的意见。

等什么时机：皇帝主动问之后，而且给了“只谈史书”的安全框，她才开口。

怎么收网：
1. 进门先替他着想：问自己来得是否赶上时候，皇上刚与年大将军议完国事，定然疲累。不问国事内容。
2. 皇帝问朋党，她先退一步：不敢妄言政事。
3. 皇帝说只谈史书，她才接：深宫里的人哪知道这些，只是读欧阳修时觉得有一段有理。
4. 引文只用一小段：小人同利暂相党引，见利争先、利尽交疏则互相贼害。这段话只讲以利相聚会因利而散，没有一个字在点人。
5. 让皇帝自己总结：他说“以利相聚，必然会为争利而散”。
6. 落点是宽慰：所以任何烦心事都不足以成为皇上的烦心事。
7. 皇帝要她写下来，她先推一下说自己的字像鬼画符，皇帝坚持，她才说恭敬不如从命。

留了什么后手：皇帝要她把《朋党论》写下来，等他烦心时看，这次对话因此有了落点，她不用再表态，他也不用再追问。后续她有没有写完，该幕之后剧本没有交代，待核。

## 4. 关键话术

- 第22集第358幕 甄嬛：“想来无人敢无事生非吧。”
  为什么管用：对方放狠话时，不接威胁，只把话说得轻，保留不卷入的位置。

- 第22集第358幕 甄嬛：“兄妹情深，向来如此。”
  为什么管用：把别人的威胁解读成亲情，对方没法继续往下说，也留不下任何把柄。

- 第22集第358幕 甄嬛：“臣妾是不是来的不是时候？皇上刚与年大将军议完国事，定然觉得疲累了。”
  为什么管用：进门先照顾对方的状态，同时表明自己没有打听国事的意思。

- 第22集第358幕 甄嬛：“臣妾不敢妄言政事。”
  为什么管用：越界的话题，先退一步，把选择权留给对方。

- 第22集第358幕 皇帝：“无妨，朕只和你谈论史书。”
  为什么管用：这是对方给出的安全框，说明先退一步是对的。

- 第22集第358幕 甄嬛：“欧阳公说，小人同利之时暂相党引成为朋党，等到见利而争先或利尽而交疏时则互相贼害。”
  为什么管用：引一段通用的古人观点，讲规律，不讲具体的人，听的人自己对号。

- 第22集第358幕 甄嬛：“所以任何烦心事都不足以成为皇上的烦心事。”
  为什么管用：把落点放在宽慰对方上，没有去判断谁对谁错。

- 第22集第358幕 甄嬛：“那臣妾就恭敬不如从命了。”
  为什么管用：推辞一次，对方坚持后再接，既守了分寸，也满足了对方的要求。

## 5. 换到职场

### 场合一：老板1on1（老板刚被一个强势下属或客户弄得不痛快，来问你的看法）

对应的局：老板刚开完一场不愉快的会，找你聊，问你对团队里拉帮结派、小圈子的看法，其实是想听你对某个具体的人的评价。
打法：
1. 先照顾他的状态，不打听细节。
2. 他问宽泛的问题时，先退一步，说不方便评价具体的人。
3. 他表示只是聊聊，你再用一个通用的观点回答，不点名。
4. 落点放在宽慰和怎么做事上。
一句能直接说出口的话：“具体的人我不方便评价。我之前看到过一种说法，因为利益聚在一起的小圈子，利益一变就容易散，所以这事不用太放在心上。您如果想聊怎么处理，我听您安排。”

### 场合二：面试（面试官问你怎么看团队里的小团体）

对应的局：面试官问“如果团队里有几个人形成小圈子，你怎么处理”，其实是想看你有没有立场、会不会评论别人。
打法：
1. 先说你不会评价具体的人。
2. 讲一个通用的原则，比如以事情为中心，对每一方按事情本身沟通。
3. 讲你的做法，落在能落地的动作上。
一句能直接说出口的话：“我不会去评价具体某一个人。对我来说，因为利益聚起来的圈子，利益一变就会散，我更愿意把精力放在（具体工作）上，跟每一方都按事情本身沟通。”

## 雷区

- 年羹尧当面威胁，甄嬛没有顶，也没有向皇帝提起。这一局的收益来自她没有在皇帝面前告状。职场里被威胁之后马上向上汇报，可能让对方立刻成为你的敌人，也可能保护你自己，取决于对方的位置和你手里有没有证据。
- 皇后的说法太直：点名年家的钱，皇帝直接堵回。职场里向上汇报涉及某位功臣或大客户，直接点名容易被压回。
- 她引欧阳修的话，皇帝听到的是对年羹尧的暗示（我们的判断）。如果她是有意把这个暗示递给皇帝，借他的手去处理另一个人，这个做法不可套用。职场里一般性的观点要真的当作观点来讲，不要拿来当暗箭。
- 皇帝说“你惯会口头上哄朕高兴”，他知道她在哄。上位者看得清，哄要有度，要有内容。
- 她只引了《朋党论》里讲小人之朋的那一段，没有提别的部分。职场里引用别人的观点只引一半，被人查证时容易被反问。
