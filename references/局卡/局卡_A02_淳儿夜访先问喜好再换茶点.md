# 淳儿夜访，先问喜好再换茶点（第3集第53幕，后续见第6集）

局面类型：闲谈社交 / 投其所好
对方：淳常在（淳儿），十四岁，同住碎玉轩东配殿，位分和甄嬛平级。性格直率，爱吃甜食，刚入宫四天，最在意的是被接纳、不被当小孩、不孤单。博主观点：她出身满军旗，家世不低于甄嬛（树懒小结界，BV1q2SEBqENg，约08:01至08:07）。
甄嬛的处境：对等，私下，同一屋檐下的邻居。当天赏赐最多，皇上特别喜欢她的消息已经传开。
她的目的：和邻居搭上信任关系；让对方在自己这里放松；赏赐太多容易招嫉妒，顺手把这层压力化掉。

## 1. 人设和差异化

她在淳儿面前立的是细心、不摆架子、愿意为你调整的姐姐。

和其他场景比：
- 夏冬春对待同批新人的方式是先比出身，再嘲讽（第3集第47幕、第54幕）。甄嬛同一天对邻居是反过来的，先问对方喝不喝得惯，再看对方想要什么。
- 淳儿自己的开场很周到：“莞姐姐忙了一日，我现在才敢过来，不算打扰吧？”（第3集第53幕）博主观点是这个时间点挑得很准，白天忙的时候不打扰，晚饭后气氛放松，又主动来拉近关系（BV1q2SEBqENg，约08:17至08:37）。甄嬛没有摆资历受着，马上回一句本来也想去看她。

为什么对上淳儿的胃口：她要的是舒服。甄嬛每一步都在让她更舒服一点，没有一步在评价她或打听她。

## 2. 读人

淳儿：
- 盯着桌上的点心（第3集第53幕舞台提示），说明晚饭没吃饱，也说明她不爱喝普洱，只是不好意思直说。
- 听到“看着妹妹年纪还小”，马上回“不啊，我都十四了”，说明她在意被当成小孩。甄嬛没有道歉也没有解释，直接把年龄换成口味：觉着妹妹不爱喝普洱，换杯牛乳茶。
- 被问到晚饭为什么没吃饱，说出了想爹娘、想家里的糟鹅。读出来的是：她需要的是一个能说话的人，点心只是入口。
- 她恭维甄嬛时，聊的是皇上喜欢姐姐，没有说别人坏话。博主观点是这也是一种高情商，并且很可能有家里安排的嬷嬷在背后指点（BV1q2SEBqENg，约11:06至12:26）。后一半是博主的推测，剧本里没有写。
- 她拒绝宫花的方式是把话落回点心：“不用了，我还是比较喜欢姐姐这儿的点心。”博主观点是这等于说好意心领，咱们的关系不在这些东西上（约12:46至13:04）。

甄嬛看出来的细节：这个孩子要的东西很小，而且是现成的。

## 3. 布局链条

目标：让淳儿把碎玉轩当成可以随时来的地方。

铺垫：
1. 槿汐在入宫当天就提过，东配殿的淳常在四日前入宫，晚些时候会来相见（第3集第48幕），所以甄嬛对这次拜访有预期。
2. 同一天她收到了华妃、皇上一波波送来的赏赐（第3集第51幕），知道自己的位置会让同批的新人心里有想法。

借谁的手：浣碧上茶、换牛乳茶、包点心；流朱拿点心。她自己负责问和听。

等什么时机：普洱端上来之后。她问的是合不合口，淳儿避开不答，只盯点心。她就在这一下读出了答案。

怎么收网：
1. 先问茶合不合口（让对方有机会说真话）。
2. 对方回避，她不追问，立刻让流朱添点心。
3. 通过年龄的小插曲，换上牛乳茶。
4. 抓住对方说晚饭没吃饱这个信息，问了一句为什么。
5. 对方说出想家，她给出一个具体的、可以长期兑现的承诺：晚饭没吃饱就来这里吃。
6. 对方恭维她得宠，她没有顺着接，转而主动分享宫花，把自己的好处匀出去。
7. 对方婉拒，她不再坚持，转头吩咐把点心包起来送过去。

留了什么后手：
- 第4集第82幕，浣碧说甄嬛生病后只有沈贵人、安答应和淳常在常来看望。淳儿后来真的成了常客。
- 第6集第107幕，淳儿深夜独自跑来求助，吓得发抖。甄嬛先让浣碧拿奶茶，让她慢慢说，然后让小允子先送她回去，答应第二天找眉庄商量再请皇后出面。她之前建立的那份安心感，此时成了对方遇事第一个想到的地方。

## 4. 关键话术

- 第3集第53幕 甄嬛：“怎么会，本来正打算过去看妹妹呢，谁知妹妹到先来了，坐。浣碧，上茶。”
  为什么管用：对方带着一点忐忑来，先把门打开，说明自己本来也打算去，不让对方觉得是在叨扰。

- 第3集第53幕 甄嬛（该行剧本未署名，按上下文判断是甄嬛）：“我今日备的是普洱，不知妹妹喝得惯吗？”
  为什么管用：问对方的口味，不问对方的意见，给对方留了真话的出口。博主观点是这一句不能当客套看，里面有真心照顾对方喜好的意思（BV1q2SEBqENg，约09:00至09:07）。

- 第3集第53幕 甄嬛：“请。流朱，再拿些点心来。”
  为什么管用：对方一盯着点心，她就加量，也不去评论对方是不是饿了。

- 第3集第53幕 甄嬛：“觉着妹妹不爱喝普洱。浣碧，换杯牛乳茶来。”
  为什么管用：把观察到的偏好直接变成动作，没有让对方说一句“我不喜欢”。

- 第3集第53幕 甄嬛：“好啊。你晚饭为何没吃饱啊？”
  为什么管用：先答应了叫淳儿这个称呼，再问一个关心的问题。博主观点是高情商聊天的法则是关注对方的需求，让他打开话匣子（约10:19至10:22）。

- 第3集第53幕 甄嬛：“以后晚饭没吃饱，就上姐姐这儿来吃。”
  为什么管用：对方说想家时，不说大道理，给一个小到马上能用的安排。

- 第3集第53幕 甄嬛：“我刚得了些时新宫花，样子挺奇巧，妹妹若喜欢，就挑两支去戴。”
  为什么管用：对方夸她得宠，她用分享来回应。博主观点是考虑到自己赏赐太多容易招嫉妒，分一些出去反而平衡关系（约12:32至12:44）。

- 第3集第53幕 甄嬛：“喜欢就多吃点。浣碧，挑些精致的点心包起来给淳常在送过去。”
  为什么管用：对方拒绝了她给的东西，她立刻换成对方说想要的东西，没有尴尬，也没有勉强。

## 5. 换到职场

### 场合一：和行业大佬建联（和同辈的行业新朋友第一次单独喝咖啡）

对应的局：展会上认识一位同龄的圈内人，对方主动来约，你想把关系做实，又不想显得功利。
打法：
1. 约的地点和饮品先问他的口味，不替他决定。
2. 看他的反应，不去听他的客套话，调整到他真正想要的。
3. 抓一个他随口带出来的信息问下去，别急着聊项目。
4. 他说出一点真实情绪时，给一个小而具体的、你能兑现的安排。
5. 他夸你，你不顺着接，把话头转回他。
一句能直接说出口的话：“这家咖啡我习惯点（某款），你要是不爱喝，我们换成（另一款）也行。对了，你今天是赶过来的吗，吃过东西了没有？”

### 场合二：面试（和未来同事的非正式午餐或咖啡聊天）

对应的局：终面之后，团队安排了一次午餐，几位同事在观察你怎么相处。
打法：
1. 先问对方的习惯，让他们来带节奏。
2. 他们提到团队的哪件事时语气有变化，就停在这里问。
3. 对方表达了真实感受时，不评价，只回应一个具体的善意。
4. 被夸时，用一句话把功劳回给团队。
一句能直接说出口的话：“我对这边不太熟，你们平时午休一般去哪里吃？刚才你提到（某件事）的时候好像挺有感触，能多讲讲吗？”

## 雷区

- 博主对淳儿“背后有嬷嬷指点”的推测（约11:19至12:26）没有剧本证据，不要拿它去判断一个真实的人是不是有人教。
- 后续的变化：陵容后来对甄嬛和淳儿的亲近心里不舒服，她对宝鹃说“淳常在说了，她俩出身差不多，所以亲近些，我算什么啊？”（第22集第366幕）。职场里对应：你对一个人特别体贴时，旁边的第三个人会看在眼里，并拿自己去对比。
- 甄嬛对邻居的好意是真实的，同时也是在为自己的位置铺垫。对方的反应也要看，淳儿婉拒宫花后她立刻收回，没有强推。职场里对应：被拒绝一次就换，不要连续推第二次。
- 这一局的前提是对方没有戒心、也没有利益冲突（同批新人、年龄小）。对有竞争关系的人，同样的方式要慎用。
