# 借浣碧通风报信，引华妃撞进闲月阁（第18至19集）

局面类型：被抢功陷害（身边人被收买，她反手设局） / 立威管人
对方：华妃（年世兰），后宫权势最大，急躁，多疑，最在意皇上的宠爱和协理六宫的权力；曹贵人（曹琴默），华妃身边的人，谨慎，做事不留把柄，与华妃在温宜公主的事上有了嫌隙（见第19集第322幕槿汐与甄嬛的推断，温宜公主一事的善后见第18集第296幕、第298幕）；浣碧，甄嬛的陪嫁丫鬟，心气高，想借华妃和曹贵人的势出头；皇帝，下过旨：不许任何人探视禁足的眉庄。
甄嬛的处境：对等偏弱。刚得宠，但华妃势大，眉庄已被禁足，身边又有内鬼，所有动作都在暗处，最后一幕是当着皇帝的面。
她的目的：让华妃自己违反圣旨闯进闲月阁，被皇帝当场撞见，丢掉协理六宫的机会；同时坐实浣碧是内鬼，摊牌后把人收回来，不让她继续往外传消息。

## 1. 人设和差异化

她对不同的人立了不同的人设：
- 对华妃和曹贵人：孤苦无依、想求垂怜的新人。（第18集第306幕）
- 对浣碧：照旧厚待，赏绸缎、赏珍珠项链，一点不露怀疑。（第18集第304幕）
- 对皇帝：本分，“不会自涉险境，也不愿违背皇上的旨意”（第19集第313幕）。
- 对敬嫔：并肩的同盟，两人在敬嫔宫里坐着，“咱们听听动静再说吧”（第18集第312幕）。

和别人比：眉庄被设局时是一个人硬扛，最后落得被禁足。甄嬛这次没有正面去挡华妃，借华妃自己的急性子，让对方一脚踩进违反圣旨的坑里。

为什么对上华妃、曹贵人的胃口：华妃最想抓的把柄，就是甄嬛违抗圣旨去探视眉庄。这个消息从身边最亲近的人嘴里漏出来，她不会怀疑。

## 2. 读人

浣碧：
- 看她的变化：日日对镜妆扮，艳丽，近日说话冒失。甄嬛当面提醒她“你近日说话怎么总是冒冒失失的”（第18集第300幕）。
- 受了皇帝一句俗气，哭着出门，被果郡王安慰了几句（第18集第303幕）。
- 甄嬛的判断：“这丫头，原本也是冤孽，只是她的心未免太高了，白白辜负了我对她的一番打算。”（第18集第304幕）
- 甄嬛先问她要木薯粉，她回答已经扔掉了（第18集第297幕）。剧本没有说明用意，我们自己的判断是一次试探，待核。

曹贵人：
- 甄嬛判断她从没用过名贵的香料，所以蜜合香她一定会收（第18集第307幕）。
- 博主观点：曹贵人跟浣碧交涉过很多次，稍一琢磨就知道甄嬛发现了端倪、在给华妃设陷阱，但她早就和华妃有嫌隙，所以顺势促成了华妃自投罗网（树懒小结界，BV1M1hwzJEzn，约03:47至04:11）。
- 博主观点：曹贵人一贯做事不留把柄，不亲自传递消息，把浣碧直接带到华妃面前，让华妃自己上当（约04:49至05:01）。
- 博主观点：史馆思答夫，BV1aevPzuErL，约05:46至05:53、约07:06至07:12、约07:49至07:52：假孕案当晚，茯苓被侍卫揪出后，曹贵人当场指认她是会贵人宫里的人，随后亲自上去翻包袱翻出血衣，博主认为曹贵人和华妃在这几个镜头里一看就是知情人。我们的对照：剧本第15集第271幕里指认和翻包袱确实都是曹贵人。这说明曹贵人之前是在华妃身边具体出面办事的人，和后来她在闲月阁这件事上让华妃自己撞进去形成对照。
- 博主观点：少女张六花，BV1L34y1d7ph，约19:59至20:23：曹贵人的计划里害人排在后面，上位和找靠山才是主线，华妃势弱时她会另寻靠山，华妃有机会复宠时又出力帮忙，惊鸿舞局就是为了引出楼东赋让华妃复宠。这一段中间有一句人名听不清，待核。我们的对照：剧本里甄嬛在第14集第253幕点破过惊鸿舞和楼东赋的关系。这条和树懒小结界说的曹贵人早有嫌隙、顺势促成华妃自投罗网可以互相印证，她站哪一边取决于哪一边对自己有利。
- 剧本里她事后对华妃说：“嫔妾只是一心记挂着娘娘……”（第19集第318幕）。

华妃：
- 多疑，疑心皇上因温宜公主的事疑她（第18集第305幕）。
- 一听到消息就亲自带人去，没有拿皇后手令（第19集第313幕）。

皇帝：旨意被违抗是最大的忌讳，所以华妃擅闯这一件事，足够让他翻脸。

敬嫔：低调，肯配合，在皇帝面前顺着华妃的话递了一句“不如去闲月阁查上一查”，把搜查的主动权交给皇帝（第19集第313幕）。

## 3. 布局链条

目标：华妃擅闯闲月阁被皇帝撞见，同时让浣碧的路走到头。

铺垫：
1. 先压住华妃复权。第18集第302幕，她劝皇帝暂缓恢复华妃协理六宫之权，理由是平物议、不损天威、等大节庆再加封。这一步博主在上一期讲，本期转写没有，不能引用博主观点。
2. 确认内鬼。第18集第304幕，她和槿汐一致认定浣碧是泄密的人。
3. 在曹贵人身上做记号。第18集第306幕，她带着肚兜、胭脂水粉去看温宜，再到内室送上皇帝所赐的一小盒蜜合香，请曹贵人在华妃面前美言。曹贵人收下了。那香气沾衣不退，之后谁进过曹贵人内室，闻一下就知道。
4. 放风。第18集第310幕，当着浣碧、流朱的面，说自己要穿浣碧的衣服，由槿汐带着去闲月阁，趁侍卫交班蒙混进去。流朱劝她，她说今晚皇上独宿，机会最好。
5. 同时布置自己的不在场。当晚她去敬嫔处坐着（第18集第312幕），槿汐带着人去闲月阁送东西，吸引华妃。

借谁的手：浣碧传话，曹贵人转给华妃，华妃上门；芳若拦住华妃；敬嫔派如意去通报皇帝（第18集第314幕）；苏培盛带人搜；皇帝裁决。

等什么时机：中元节夜。皇帝独宿（第18集第310幕）；这一天宫里放灯、祭鬼神，甄嬛还特意让浣碧出去烧祭品（第18集第300幕）。

怎么收网：
1. 华妃到闲月阁外，芳若拦着，槿汐说里面没有旁人。华妃说“在与不在本宫进去一看便知”（第18集第313幕）。
2. 皇帝赶到，问她有没有皇后的手令，华妃说急着赶来来不及求（第19集第313幕）。
3. 甄嬛和敬嫔从敬嫔宫里走出来。甄嬛说她陪敬嫔娘娘在里头说话。
4. 敬嫔和甄嬛先后请皇帝派人进去查，说是还沈答应清白。苏培盛带人搜过，里面除了沈答应和几个侍女，别无他人（第19集第313幕）。
5. 皇帝斥责华妃：协理六宫之权不复了，不许再见温宜公主。
6. 敬嫔趁势请求撤去一半守卫，皇帝同意（第19集第313幕）。

留了什么后手：
- 当晚摊牌浣碧（第19集第321幕）：先说“辛苦了”，再拿蜜合香的气味当证据，浣碧认下；甄嬛不责骂，讲她的前途和亲姐妹的情分，要求她以后小心。
- 同一幕里，甄嬛指出华妃现在恨浣碧入骨，还以为是主仆联手。博主观点：这一招反间计把浣碧的后路也断了（BV1M1hwzJEzn，约03:44至03:46）。
- 第19集第322幕，槿汐提出疑点：曹贵人谨慎，怎么让华妃来得这么快。甄嬛推断曹贵人是故意放了华妃过来，两人因温宜的事生了间隙。这一条留给后续。
- 小允子这一晚的行动路线很长：准备衣服、送甄嬛去敬嫔处、回碧桐书院盯着、跟着浣碧去曹贵人处、藏船、回来汇报（第19集第317幕）。博主观点：这种强逻辑思维和行动力很了不起（约02:33至02:52）。

## 4. 关键话术

- 第18集第306幕 甄嬛：“我独自在这宫中孤苦万分，如今沈答应又被禁足了，我更是孤零零一个了，还望姐姐垂怜。”
  为什么管用：先承认自己势弱，对方才有心理空间收下礼物，也愿意在华妃面前开口。

- 第18集第306幕 甄嬛：“这一小盒蜜合香是皇上所赐，听说是异域的贡品，统共就这么一小盒，还望姐姐不嫌弃。”
  为什么管用：这份礼的珍贵之处，是只有一盒，所以对方没法去分辨它从哪来，收下之后香气自然会留在她身上。

- 第18集第307幕 甄嬛：“她久在华妃之下，吃穿用度都恪守本分，连寝殿都这样简素，就知道她从未用过什么名贵的香料。”
  为什么管用：先读清对方的生活细节，再决定送什么，礼物才会被收下。

- 第18集第310幕 甄嬛：“我便自称是你，由槿汐带着去闲月阁送东西。那边我已经打点好了，只等入夜看守的侍卫交班时蒙混进去，自然是万无一失的。”
  为什么管用：当着嫌疑人说一条可以被转述的假消息，计划细节够具体，转述的人才有价值。这一步有欺骗成分，见雷区。

- 第19集第313幕 甄嬛：“沈答应身受囚禁之苦，若还背上违抗圣旨不尊皇上的罪名，臣妾也实在不忍心。还请皇上派人入闲月阁查一查，好还沈答应清白。”
  为什么管用：不替自己辩护，主动请上面查，查出来的结果就是清白，对方没有再追的余地。

- 第19集第313幕 敬嫔：“皇上，华妃娘娘一向行事果决，必然是有证据才来的，不如去闲月阁查上一查，一来娘娘不必白跑一趟，二来这事情也有个交代，皇上意下如何？”
  为什么管用：顺着对手的话把她推到台前，听起来是帮她，其实让她的错落到纸面上。

- 第19集第313幕 甄嬛：“臣妾不会自涉险境，也不愿违背皇上的旨意。”
  为什么管用：当场表态，皇帝一句“还好，没有牵连到你”之后就把这件事翻篇了。这句话与她当晚的实际行动不符，见雷区。

- 第19集第321幕 甄嬛：“外头进贡的一小盒蜜合香，皇上全给了我，我又全部转赠给了曹贵人，亲眼见她放入内室之中。若真如你所说对我并无异心，又怎会出入她的内室？你身上又怎会沾上蜜合香的气味呢？”
  为什么管用：用对方没法反驳的客观证据，不凭印象指责，逼她自己开口。

- 第19集第321幕 甄嬛：“不过我还是要谢谢你，若不是你去通风报信，我今日又怎能轻易扳倒华妃？只怕华妃现在会恨你入骨，还以为是咱们主仆联手呢。”
  为什么管用：先把她做的事挑明，再告诉她现在处境，让她明白已经没有别的靠山。

- 第19集第321幕 甄嬛：“你不说就是万幸。今日的事，华妃她们一定会嫉恨于你，你日后行事要格外小心。”
  为什么管用：摊牌结束时，给她一条退路，再提醒后果，防止她再被拉走。

## 5. 换到职场

### 场合一：老板 1on1（有人在老板面前说你违规，而你没有做）

对应的局：同事在老板面前暗示你越权或没按流程做事，你没有做。
打法：
1. 先问清楚对方指的是哪一件事，不要在对话里抢着自证。
2. 主动请老板或流程负责人核查，并把相关记录开放给他。
3. 点出对方有哪个流程没走完，比如没有书面依据，但只讲事实，不评价对方动机。
4. 查完之后，不追着对方说话，给彼此留余地。
一句能直接说出口的话：“这件事我希望您直接查，（相关记录）我都开放给您。需要我配合的我现在就配合，查清楚对大家都好。”

### 场合二：面试（行为面试题：同事把你的信息透给别人，你怎么处理）

对应的局：面试官问，如果发现团队里有人把你的计划外传，你会怎么处理。
打法：
1. 先说取证：不凭印象，找客观的、对方没法否认的依据。
2. 再说谈话：私下，先肯定他的付出，再摆证据，问他怎么回事。
3. 给出路：承认之后，说清楚前途和后果，要求他停止。
4. 最后收在流程：以后哪些信息给谁看，边界写清楚。
一句能直接说出口的话：“我会先私下找他，把我看到的记录摆出来，先听他怎么说。谈清楚之后，我会跟他说明后果，也给他一个改正的机会，同时把信息共享的边界定清楚。”

## 雷区

- 对曹贵人示弱，送一盒蜜合香当记号：这是拿礼物当追踪工具。职场里不要用礼物或资料做试探，一旦被识破，对方和旁人都会觉得你不可信。
- 当着浣碧的面放假消息，看谁传话：这是给身边人设假前提。职场里不要这样排查同事，容易误伤，也毁掉信任。
- 对皇帝说“不会自涉险境”，实际上当晚去了闲月阁（第19集第319幕）。职场里不要在老板面前说和事实相反的话，被发现就是信用归零。
- 流朱提醒过：万一被发现可是欺君的大罪（第18集第310幕）。这一局是在极大风险下完成的，职场里违反明确规定的事，不要因为眼前有机会就去做。
- 成败依赖对手曹贵人有自己的算盘。博主观点：如果曹贵人一眼看出并拦住华妃，甚至反杀甄嬛，整盘计划就泡汤了（BV1M1hwzJEzn，约04:14至04:20）。职场里对应：别把成败押在对方没看破上。
- 浣碧是被利用的人：她说曹贵人曾对她讲，皇上那么喜欢你，就算知道你有什么错处也不会深责于你（第19集第321幕）。职场里对应：有人用老板喜欢你这类话怂恿你冒险，需要识别。
- 甄嬛对华妃说：“容不容得下是娘娘的气度，能不能让娘娘容下是嫔妾的本事。”（第19集第313幕）对已经落败的对手说这样的话，会结下更深的仇，职场里不要这样收尾。
- 这一局只走通了一半：曹贵人和华妃的矛盾是意外之喜，并没有被甄嬛一人控制（第19集第322幕）。
