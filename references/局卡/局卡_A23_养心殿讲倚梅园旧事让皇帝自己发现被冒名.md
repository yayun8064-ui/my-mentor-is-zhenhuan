# 养心殿讲倚梅园旧事，让皇帝自己发现被冒名（第5至10集，主场景第10集第198幕）

局面类型：被抢功陷害（被冒名顶替） / 求人办事（请上位者出面处置）
对方：皇帝（雍正），权力最高，最在意被人欺骗和后宫争宠的阴毒之风，对除夕夜倚梅园那一晚一直有念想；余莺儿（余氏），原倚梅园宫女，靠冒认那一晚的人得封得宠，此时已因下药被废入冷宫；槿汐、苏培盛，一个先到御前打底，一个在皇帝身边递话办事。
甄嬛的处境：对等偏强。圣眷正好，下药案已经拿到人证物证，余氏被废；但冒名这件事她手里没有物证，只有自己亲历；私下，只有皇帝和她。
她的目的：让皇帝自己发现并认定余氏冒名，由他处置；自己不告状，不点余氏的名，不显得刻薄，同时让皇帝知道除夕夜那个人是她。

## 1. 人设和差异化

她在皇帝面前立的是无辜受害、自责、从不与人相争的人。

差异：
- 和余氏比：余氏主动攀附，靠一句诗、一身梅香、一口昆曲往皇帝跟前凑（第5集第97幕）；甄嬛五集之内从未主动说过倚梅园那个人是自己。
- 和陵容比：陵容后来亲自去冷宫逼问余氏，借苏培盛了断，还说“我要让姐姐知道，我这么做都是为了她”（第10集第202幕）。甄嬛不去现场，不动手，把处置权留给皇帝。
- 和槿汐比：槿汐的任务是先把事情说明白，说到皇帝动心爱怜（第10集第196幕苏培盛语）。甄嬛自己进殿后不陈述案情，只讲自己的感受和一段旧事。

为什么对上皇帝的胃口：皇帝对除夕夜的人念念不忘，第6集第113幕他对允礼说“也就这样，倒不如那一晚在倚梅园温婉动心了”，说明余氏和他心里那个人对不上。他缺的只是一个把两个人对上号的线索。

## 2. 读人

皇帝：
- 第6集第113幕那句话说明落差已经存在，他对余氏早就冷了，只是没想明白为什么。
- 第10集第198幕，甄嬛刚提到除夕夜祈福，他就追问“你在哪儿许的愿，许的什么愿？”，再追问“那你可曾遇到过什么人吗？”。他一听就在拼那一晚的画面，不需要她解释结论。
- 他对被骗的反应比对下毒大得多：下毒案他只是废了余氏、杖毙花穗和小印子，一听到冒名，立刻传旨“冷宫余氏欺君罔上毒害嫔妃，赐自尽”。
- 他嘴上说“君无戏言”，同时答应余氏尸首回本家，因为甄嬛求了情。他很吃肯替别人说一句软话的人。
- 博主观点：雾凇岛热饮，BV1Dio6BuEnZ，约08:30至08:51，皇帝在倚梅园只听到一句诗，还没见到人，就觉得宫女里有才学之辈，博主认为这是听声音就起了心思；约17:34至17:38，博主认为余氏要是长得丑一点，皇帝不会把她收进后宫。我们的分析：这两点能和上面的判断对上，皇帝对倚梅园那个人的兴趣，从一开始就连着具体的画面（雪夜、诗句、声音），所以甄嬛讲到雪夜许愿，他的反应会这么快。

余氏：
- 第5集第97幕她回话时说“风雪已停，比除夕之夜弄湿了鞋袜要好许多”，鞋袜湿了这个细节她是躲在旁边偷听到的（第5集第92幕“余莺儿目睹一切”）。所以鞋袜这个细节本身分不出真假，真正能分出来的是遇见陌生男子、谎称宫女脱身这件事。
- 她到冷宫才第一次知道真人是谁：“是她，竟然是她？”（第10集第202幕）。
- 博主观点：雾凇岛热饮，BV1Dio6BuEnZ，约19:26至19:33，博主认为余氏能留在皇帝身边，靠的是长得漂亮、人机灵、会唱昆曲，和甄嬛没有关系。剧本第5集第97幕里皇帝确实当场问了昆曲。我们的分析：这说明余氏手里有自己的筹码，不全靠冒名，皇帝处置时翻出来的只有冒名那一层。

甄嬛自己的判断：
- 第5集第98幕眉庄说倚梅园宫女得宠，她只回“是——倚梅园？”，没有追问，没有说破。第6至9集剧本里再没有人提这件事。我们的判断是她当时已经看出来，选择先不说。
- 博主观点：雾凇岛热饮，BV1Dio6BuEnZ，约20:50至21:02，博主盯的是甄嬛在眉庄面前评价余氏出身（第5集第98幕“她的出身搁在那儿，也越不过你去”），认为她嘴上讲人人平等，实际很看重出身。我们的分析：这一幕她谈的全是出身和位份，没有谈那个宫女是真是假，这也是我们判断她当时选择不说破的依据之一。
- 第10集第194幕槿汐说“小主可记得奴婢曾问过您，除夕夜里倚梅园是否有人鱼目混珠？”，槿汐当时问她的那一幕剧本里没有，待核。

## 3. 布局链条

目标：冒名这件事由皇帝亲口认定，余氏的欺君之罪成立。

铺垫：
1. 第5集第92幕，除夕夜她在倚梅园许愿，被皇帝听见，她谎称是园中宫女，说“我的鞋袜湿了，在换呢”，躲开。余氏全程在场。
2. 第5集第94、96、97幕，皇帝让苏培盛去找能对出“逆风如解意”下句的宫女，余氏对上了，封官女子。
   - 博主观点：雾凇岛热饮，BV1Dio6BuEnZ，约10:25至10:44，博主觉得找人的办法效率最低，直接让苏培盛查那晚宫女的值班记录就行，而且万一同时有四五个宫女对上，皇帝也没法办。我们的分析：皇帝选了靠一句诗认人，没有查记录，冒名才有空子可钻；后来他在养心殿也是靠甄嬛讲出的细节才认定，没有靠查证。
3. 第5集第98幕、第6集第113幕，她不说破，皇帝自己对余氏渐冷。
4. 第10集第192至194幕，下药案抓到小印子和花穗。槿汐点出药毒和诅咒还有活命的理由，欺君就是死罪（第10集第194幕）。

借谁的手：槿汐一早先到养心殿回禀（第10集第196幕，皇帝说“槿汐一早已经来回了朕与皇后”）；处置交给皇帝，执行是苏培盛的事。

等什么时机：余氏被废入冷宫之后（第10集第197幕）。这时候讲倚梅园，皇帝不会觉得是她为了报复，只会觉得是顺带。

怎么收网：
1. 皇帝说“从今往后你的药饮膳食朕都会叫人着意留心”，她先把责任揽到自己身上，说自己粗心。
2. 再说自己不与人相争，因无意得罪余氏牵连了许多人命，不配身受皇恩。眼泪和自责让话题回到她和皇帝的关系上。
3. 顺势提到除夕夜祈福，只说诗句，不说谁。皇帝自己追问地点、愿望、有没有遇见人。
4. 她只答事实：遇见一陌生男子，带病外出，男女授受不亲，谎称宫女脱身，并说臣妾不知是皇上，请他恕罪。
5. 皇帝自己说出“原来是你，竟然是你？朕还认错了旁人”，当场传旨赐死。
6. 她问“皇上怎么了，突然要赐死余氏？”，让皇帝自己讲出冒名的罪名。
7. 她为余氏求情，说只是仰慕皇上，皇帝因此让余氏尸首回本家。

留了什么后手：皇帝接着问她那天带了什么心爱的物件，她答“四郎若喜欢，嬛嬛再做一个便是”，把下一次相处的理由留下。

后续如实记录：余氏在冷宫不肯死，陵容赶去逼问，借苏培盛让小厦子用弓弦勒死（第10集第202幕）。甄嬛听完回报后问眉庄“这件事情是不是我太过分了？”（第10集第203幕）。

## 4. 关键话术

- 第10集第198幕 甄嬛：“也怪臣妾自己粗心，未曾发觉。”
  为什么管用：对方安慰你的时候，先把过错往自己身上收一点，对方反而更想护着你。

- 第10集第198幕 甄嬛：“嬛嬛向来不与人相争，只因无意得罪了余氏，才殃及了那么多人的性命，嬛嬛罪孽深重，不配身受皇恩。”
  为什么管用：把自己放在不争的位置，同时让皇帝看到她心里装着别人的性命。这句话没有指控任何人，却已经把余氏放在了起因的位置上。

- 第10集第198幕 甄嬛：“那夜雪地难行，嬛嬛还不小心弄湿了鞋袜。”
  为什么管用：只给一个细节，不给结论。这一句和除夕夜她对皇帝说过的话对得上，皇帝自己会往下想。

- 第10集第198幕 甄嬛：“四郎怎么知道？那夜嬛嬛在倚梅园中遇见一陌生男子，只因是带病外出，更是男女授受不亲，便只能谎称是园中宫女才得脱身。莫不是那夜的男子？”
  为什么管用：先反问皇帝一句，把主导权交回他，再把事实讲完。她说的是自己当时的处境，没有一个字是在贬别人。

- 第10集第198幕 皇帝：“原来是你，竟然是你？朕还认错了旁人。”
  为什么管用：结论由皇帝自己说出来，比任何人替他说都有分量，也就没有人能说她构陷。

- 第10集第198幕 甄嬛：“余氏千错万错，也只是仰慕皇上的缘故。”
  为什么管用：对方已经被判了，再为对方说一句软话，显得她没有赶尽杀绝。

- 第10集第198幕 甄嬛：“不过是女儿家喜欢的玩意儿罢了，四郎若喜欢，嬛嬛再做一个便是。”
  为什么管用：把话题从案子带回到两个人之间的小事上，案子翻篇，感情接上。

## 5. 换到职场

### 场合一：老板1on1（成果被别人说成是他的）

对应的局：你做的一块工作被同事在汇报里当成自己的，你没有当场吵，等到合适的时候和老板单独聊。
打法：
1. 先不告状，不点名。先聊你最近在做的事，把自己放在认真做事的位置。
2. 找一两个只有真正做这件事的人才知道的细节，自然带出来，比如当时的决定、客户说的一句话、一个版本的变化。
3. 让老板自己追问。老板问到哪里，你就答到哪里，只讲事实。
4. 老板自己得出结论之后，你不要加码，也不要落井下石，该说一句对方也有难处的话就说一句。
一句能直接说出口的话：“这个版本里（某个关键决定）是我当时定的，当时的记录我还留着。可能没有跟您单独汇报过，这是我的疏忽。”

### 场合二：面试（行为面试题：有人抢功你怎么处理）

对应的局：面试官问你有没有遇到过功劳被别人拿走的情况，怎么处理。
打法：
1. 先讲你做了什么留证据的动作，比如邮件、文档、会议记录。
2. 讲你选了什么时机、什么对象去说明，强调没有当众发难。
3. 讲结果由上级判断，你只负责把事实摆清楚。
4. 最后补一句你怎么对待那位同事，说明你没有记仇。
一句能直接说出口的话：“我当时没有在会上争，会后把（具体记录）整理出来，在和上级单独沟通的时候把过程讲清楚了。后来怎么判断是上级的事，我和那位同事之后合作也没有受影响。”

## 雷区

- 陵容在冷宫逼问余氏，再借苏培盛让她被勒死（第10集第202幕）。这是借别人的手去了结一个人，不要在职场里套用，也不要照学。看到有人用这套邀功，要保持距离。
- 余氏的做法：偷听别人的细节拿去冒名，拿别人的成果换自己的位置。职场里对应的是抢功和冒认，被识破的下场不由你决定。
- 甄嬛等了五集才开口，期间余氏借冒名得封、得宠，还有了下药的动力。职场里被冒名拖得越久，对方受益越多，还要小心对方已经把话说圆。
- 皇帝的反应超出她的预期：她问“皇上怎么了，突然要赐死余氏？”，听起来她没有想到会直接赐死。她事后对眉庄说“这件事情是不是我太过分了？”，也对陵容的做法有疑虑。职场里把事实交给上级之后，处置结果你控制不了，要想好自己能不能承受。
- 槿汐的打底是把话“说得让皇上动心爱怜”（第10集第196幕苏培盛语）。会说话没有问题，但内容必须是真的，不能为了让上级心软去编。
- 鞋袜这个细节余氏也知道，单凭它证明不了谁是真的。职场里自证身份的细节要选对方不容易知道的，选错了就是一句空话。
- 博主观点：雾凇岛热饮，BV1Dio6BuEnZ，约16:18至16:46，博主认为余氏本来就是倚梅园宫女，甄嬛倒借用了她的宫女身份，余氏能对上诗句符合苏培盛的赏格，余氏穿平底鞋在雪地站久了鞋袜湿很正常，所以博主认为甄嬛才是真正犯欺君之罪的人。其中余氏确实是倚梅园宫女、甄嬛确实对皇帝说过自己是倚梅园的宫女，与剧本第5集第92幕一致。博主的说法与剧本不一致的地方有两处：一是第5集第92幕写明鞋袜湿了这句话出自甄嬛之口，余莺儿目睹一切才离开，第97幕她再说鞋袜时是在复述所见；二是第10集第198幕皇帝认定的是余氏冒认那一晚的人，博主的结论在剧本里没有成立。这两处不采用博主的说法，以剧本为准。
- 博主观点：雾凇岛热饮，BV1Dio6BuEnZ，约04:57至05:09，博主觉得甄嬛许愿时突然提高音量，像是知道皇帝就在附近故意说给他听。博主的说法与剧本不一致：第5集第92幕写的是皇帝闻声发问，甄嬛急忙躲起，没有她事先知情的依据，本卡不采用。
- 我们的分析：博主能反过来说甄嬛欺君，是因为甄嬛自己确实说过谎，第10集第198幕她也亲口讲了谎称宫女这一段。职场里讲自己版本的时候，对方会拿你哪一句不太光彩的话反击，要先想到，该交代的自己先交代。
