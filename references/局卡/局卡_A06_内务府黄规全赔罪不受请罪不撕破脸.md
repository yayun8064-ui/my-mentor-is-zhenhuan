# 内务府总管黄规全赔罪，不受请罪、不撕破脸（第7集第142幕）

局面类型：认错善后（她是接受道歉的一方） / 立威管人
对方：黄规全，内务府总管，华妃的远亲，先前克扣碎玉轩，如今见她得宠转头赔罪。他最在意的是自己的饭碗和靠山，风向一变，他的态度就变。
甄嬛的处境：位置刚刚抬高（刚晋贵人，皇上正宠），但对方是华妃的人，背后势力比她大。场合是碎玉轩，流朱、槿汐等下人在场，当面。
她的目的：接下台阶，维持表面的和气，保证日后用度；同时把对方塞来的人控制住，不给华妃留下手脚。

## 1. 人设和差异化

她立的是大度、顾全大局、不记仇的主子，同时对人和事的防范一点没有松。

和旁边的人比：
- 流朱：当面说“黄公公的请罪我们可不敢受，没的背后又听见些不该听的，让人呛得慌！”（第7集第142幕）她的话是真的，但会把场面推向撕破脸。
- 黄规全：推责给手下小路子，当场踹了一脚，演一出请罪戏。
- 甄嬛：不接对方的表演，也不揭穿，只用一句话把事说小。

为什么对上黄规全的胃口：他来赔罪是被华妃点过的（第7集第139幕），要的是一个台阶，让他回去有话交代。甄嬛给了台阶，没有给他任何可以拿去报告的话柄。

## 2. 读人

黄规全：
- 之前的态度：碎玉轩份例被扣（第4集第85幕佩儿说连茶叶都没送来），眉庄想替她禀明皇后，她劝住了（第5集第87幕：“多一事不如少一事吧”）。这是她失势时的忍。
- 他在翊坤宫的表现：送月钱，说“份例归份例，咱们内务府上下依仗娘娘关照，自该多孝敬着点”（第7集第139幕），这是他两头的账。
- 华妃的点拨：华妃一边说“那位莞贵人一直默默无闻，想必是吃了你们内务府不少委屈吧”，一边说“皇上若是听了她的枕头风，本宫也帮不了你们”（第7集第139幕）。博主观点：华妃借内务府来送月例，顺便点拨他，是让他赶紧去补救（树懒小结界，BV1LV8MzrEjD，约08:52至09:57）。

华妃：这番话对谁有好处，看她的用词就清楚，说的全是内务府自己会怎样（我们的判断）。她在替自己的人避险，怕内务府得罪新贵人，日后在皇上面前出事。

甄嬛看出来的细节：这个人见风使舵，今天对你好是因为风向变了，风向再变他还会变。流朱后来说得对：“这黄规全见风使舵！”（第7集第142幕）甄嬛的回答是：“见风使舵的事宫中人人都会，不止他黄规全一个。”

## 3. 布局链条

目标：对内务府一个人，不结仇也不依赖。

铺垫：
1. 她失势时没有闹。眉庄要告状，她说：“我久病失势，难免他们不周到些，多一事不如少一事吧。况且你受宠，他们也不敢十分怠慢我。”（第5集第87幕）
2. 皇帝抱她回碎玉轩时，说要让内务府选几个老成的首领太监，她接了一半：首领太监先让小允子顶上，内务府新派人另说（第7集第135幕）。她在这时已经明确了自己的人要掌握关键位置。

借谁的手：皇上的话（内务府要派人）是黄规全上门的由头；槿汐接手教导新人，是她布置的第一道防线。

等什么时机：黄规全带着人和桌子进门、先开口请罪之后。

怎么收网：
1. 请起，让对方先安心。
2. 夸他挑的人必然是好的，同时提醒日后有事就找他一个人。
3. 吩咐槿汐把人带下去好好教导，当场把新人纳入自己手里。
4. 他请罪时，把事情说小：内务府千头万绪，底下一时疏忽也有。
5. 他送桌子，收下。
6. 客气送走。

留了什么后手：
- 对流朱：进殿以后单独训，说“你怎么言语上这样不谨慎”，解释撕破脸会让人说得势张狂，又说“你警醒他两句也好，让他有个忌惮”。她既管住了流朱，也肯定了流朱的方向。
- 对新人：“我会告诉槿汐和小允子，打起十二分的精神盯着，不许黄规全送来的人有什么手脚。另外，只派他们做粗活，我近身的事仍由你们伺候。”（第7集第142幕）
- 余波一：第10集第190至192幕，药被人动手脚，保管药罐的宫女花穗，原是余莺儿身边的人。第10集第190幕浣碧说“原本是我收着的，但是现在是由新来的宫女花穗保管着”，说明这条防线后来出了口子。博主观点：新安排的宫女里就有花穗，为后面下药埋下伏笔（BV1LV8MzrEjD，约13:36至13:39）。剧本第10集第192幕只写花穗是余氏被降位后被遣出来、后又被指到碎玉轩，没有写是不是黄规全这一批，待核。
- 余波二：第15集第282幕，眉庄失势时黄规全又送了不像样的花来，甄嬛说“这黄规全倒是越来越有出息了”。

## 4. 关键话术

- 第7集第142幕 甄嬛：“黄公公挑的人必然是好的，要不然以后有什么事，我便只找黄公公一个了。”
  为什么管用：前半句是夸，后半句把责任落到他身上。他要是在人里做手脚，是自己找死。

- 第7集第142幕 甄嬛：“公公言重了，其实内务府的事千头万绪人事相关，底下的人一时疏忽也是有的，公公何来请罪之说呢？”
  为什么管用：不接受请罪，也就不用认定之前的错，给了对方最大的体面，同时没有欠谁的。

- 第7集第142幕 甄嬛：“多谢公公心里还想着。小允子，收下吧。”
  为什么管用：东西可以收，收的是他的态度；让小允子去收，表示她自己不在这上面花心思。

- 第7集第142幕 甄嬛：“你自己心里明白，知道提防就行了，撕破脸传出去，只会叫别人说我们得势张狂。”
  为什么管用：教的是对内的规矩，提防留在心里，面上不动。

- 第7集第142幕 甄嬛：“你警醒他两句也好，让他有个忌惮。告诉底下人，不许他们生事。”
  为什么管用：对下属的情绪给出空间，可以敲打，但边界由她定。

- 第7集第142幕 甄嬛：“我知道，我会告诉槿汐和小允子，打起十二分的精神盯着，不许黄规全送来的人有什么手脚。另外，只派他们做粗活，我近身的事仍由你们伺候。”
  为什么管用：流朱提醒他是华妃的远亲，她早就知道，直接给出防范方案，限定新人只做粗活。

## 5. 换到职场

### 场合一：老板 1on1（先前卡你资源的部门负责人，在你被老板器重后来示好）

对应的局：之前拖着不给你配合的人，现在主动带着人和资源上门，还主动认错。
打法：
1. 不翻旧账，把对方的错说成流程里的疏漏。
2. 收下他的善意，但核心环节自己盯着，不全靠他。
3. 话里留一个责任的钩子，让他知道后面出问题找他。
4. 回头单独和你自己的人说清楚：面上和气，里面保持防备。
一句能直接说出口的话：“您太客气了，这类事各环节都有疏漏的时候。后面（这块资源）我们就直接对接您，排期有变动我随时跟您确认。”

### 场合二：和行业大佬建联（之前不回消息的平台或渠道负责人，在你数据起来之后主动联系）

对应的局：对方前后态度反差大，你知道他看的是风向。
打法：
1. 不质问为什么之前不回，当没发生过。
2. 把合作的约定落成具体事项和时间点，不停留在客套话上。
3. 内部把关键环节备份，不让整个项目依赖这一个人。
一句能直接说出口的话：“没事，之前大家都忙。现在这样挺好，（具体合作）我们就按（时间）推进，有变化您直接跟我说，我这边随时配合。”

## 雷区

- 流朱当面怼黄规全，被甄嬛训。职场里对应：同事替你出头的方式过了头，要在场外立刻纠正，同时承认她的出发点。
- 黄规全送来的人，后来出了问题。防范规定写得清楚，但执行中被突破。职场里对应：只靠一句话的规定不够，要有人定期查。
- 余莺儿安排花穗下药（第10集第192幕）是害人手段，这里只用来识别：对方送来的人和东西，可能带着目的。职场里不能套用这种做法。
- 博主观点中的华妃指点黄规全，是剧情背景，职场里没有可以直接对应的做法。我们要学的是看清对方转变背后有谁在推。
