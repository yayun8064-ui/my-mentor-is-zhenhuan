# 小产之后查欢宜香和罚跪的真相，先排除自己再取实物（第29至44集，第68集收尾）

局面类型：被暗算后追查真相（被抢功、冒名、暗算一类）
对方：表面上是协理六宫的华贵妃年世兰，她当众罚甄嬛跪（第29集第490幕）。往下数还有两层：欢宜香里的麝香是皇帝和太后定的（第36集第578幕）；甄嬛天天用的舒痕胶里也有麝香，来自安陵容（第44集第719幕、第68集第1076幕）。博主还认为皇后在背后安排了整个时机（见读人）。年世兰最在意皇帝的宠爱和脸面，皇帝和太后在意压住年家，陵容在意的是皇帝眼里自己只是只鸟（第68集第1076幕）。
甄嬛的处境：弱。孩子刚没，皇帝说她“性子太倔强”（第31集第508幕），她病了大半个月，皇帝也不愿去看（第32集第523幕），身边没有人替她撑腰。查事只能私下查，不能声张。
她的目的：先弄清孩子是怎么没的，有几层原因，每一层是谁。弄清之前不打草惊蛇，弄清之后让能定罪的人亲眼看到证据。

## 1. 人设和差异化

她在这个局里立的是失子后不吵不闹、一件一件往下排查的人。

和其他人比：
- 华贵妃出事后第一反应是推给别人：“一定是你们给她吃错了什么东西，还要赖在本宫头上！”（第30集第496幕）
- 眉庄当着皇帝的面说“莞嫔失子，并非天灾，而是人祸呀”（第30集第496幕），随后让温实初去查安胎药的药渣（第30集第497幕）。眉庄查的是药，是眼前的一环。
- 温实初一边自责“光顾着在太医院追逐名利”（第30集第497幕），一边劝甄嬛“您只记得是她们的错就是了，千万不可再因为此事而自责了呀”（第32集第520幕）。
- 甄嬛自己先自责了一阵：“我为何要得宠？我若是默默无闻，年妃就不会嫉恨我”（第30集第502幕）。后来她把自责换成排除，一项一项数：用的香、吃的药、自己以前服过的药。

为什么这个人设有用：她不急着给出一个有人要负责的结论，先拿到实物和旁证。到最后由皇帝自己叫太医验，没有人能说她是凭空指控。

## 2. 读人

年世兰：
- 罚跪那天她把用意讲得很明白：“要打压一个人，就要在她最得意的时候”，要让莞嫔知道“只许有侍奉皇上的人，不许有分得皇上宠爱的人”（第29集第487幕）。她要的是下马威。
- 甄嬛倒下、地上见血后，她先慌：“不是才半个时辰吗？怎么会有血？”（第29集第490幕）又说“当年本宫的孩子没了，地上也是那么一片血”（第30集第495幕）。我们自己的判断：她对这个孩子没有杀心，只是低估了后果。
- 后来她在冷宫里自己说得更直白：“我是让余氏下毒杀你，可是我没有想过要杀你的孩子！”（第42集第681幕）
- 博主观点（脖子细哔哔叨，BV1nTArz6ECh）：华妃出事后担心的只是自己受牵连，别人受伤害她不在乎（约03:22至03:34）。她从头到尾觉得自己照着太医的话做了，错不在自己，所以她自己并不觉得在诡辩，在她的认知里她就是冤枉的（约12:32至12:52）。

皇后和皇帝（罚跪之前）：
- 皇后把甄嬛叫去景仁宫，先讲齐妃的事“只能委屈你”，再说皇帝和她要去天坛祈雨，后宫交给华贵妃，“华贵妃的性子你也知道，能忍就忍着，等皇上和本宫回来为你做主”，最后问“你的伤疤怎么样了？”甄嬛答安常在送的舒痕胶很好用，皇后说：“既然是好东西你就多用，女孩子千万不要留下什么疤痕，要痊愈才好啊。”（第29集第481幕）
- 皇帝临走前也叮嘱她让着华妃，还加了一句：“为免纷扰，你怀着身孕，最好不要去翊坤宫。”（第29集第482幕）后来周宁海来请，搬出“违了皇上的圣意”，甄嬛想的是“皇上、皇后离宫时，一再要我多多忍让，我若不去，又不知道闹出多少是非来”（第29集第486幕、第488幕）。忍让的叮嘱，把她送进了翊坤宫。
- 博主观点（脖子细哔哔叨，BV1ztfmB1EAy）：这是皇后一环套一环的安排。夹竹桃事件之后稳住甄嬛，借旱灾祈福出宫，给自己造出不在场的条件，把锅留给华妃（约01:58至02:43）。让甄嬛别反抗，等华妃真的动手才好把锅甩到华妃身上（约03:14至03:20）。特意提舒痕胶，督促甄嬛多用（约03:55至04:06）。博主还认为，皇帝劝忍让是以为华妃本性不坏，皇后劝忍让是知道华妃会借机折腾甄嬛，两人目的不同（约07:32至07:57）。
- 博主观点：皇后当众提起纯元，是为了抬高皇帝对这个孩子的期待，好让华妃受更重的惩罚（BV1nTArz6ECh，约01:19至01:27）。博主说甄嬛小产、华妃被罚，对皇后皆大欢喜，皇后成了最大的赢家。博主认为导致小产的真凶另有其人，但华妃的跋扈本来就该受罚（约18:03至19:14）。
- 我们自己的判断：剧本里没有人当面认过皇后在这一次小产里的角色。第29集第481幕和第482幕里，皇后和皇帝的叮嘱，客观上都在把甄嬛往翊坤宫推。博主的整套安排是推断，只有舒痕胶那一环后来有剧本里的证据（第68集第1076幕）。

皇帝和太后（小产之后）：
- 皇帝自己有疑问：“莞嫔在翊坤宫跪了半个时辰孩子便没了，的确令人意外。”太后接话说“年妃宫里长年累月点着——”，话没说完就被皇帝打断：“皇额娘别说了，都是儿子的错。”（第30集第503幕）
- 太后随后把原因往别处引：“你再仔细想想，除了这条，还有没有别的？”皇帝想到余氏下毒，太后说“莞嫔本就中过毒，或许体弱难以保胎，所以你就更加无需自责了”（第30集第503幕）。我们自己的判断：两人都知道欢宜香里有麝香，当场把话题转到别的原因上。
- 同一场里章弥来请罪，说自己年过六十，要告老还乡（第30集第503幕）。博主推测（BV1ztfmB1EAy，约13:20至14:06）：章弥替甄嬛看安胎药，皇后可能让他在帝后出宫期间动手脚，并且特意带走温实初，防止药渣被发觉。我们自己的判断：章弥请辞是剧本里的事实，是否被授意没有对白证实。
- 第36集太后直接讲：“咱们独独赐给年妃的欢宜香，里头那味麝香早已伤了年妃的根本，不过连累了莞嫔，哀家和你都不想。”（第36集第578幕）所以欢宜香的麝香是皇帝和太后的主意，为了防年家，皇帝叮嘱别去翊坤宫也是因为这个。

端妃：
- 甄嬛去延庆殿探病，端妃的判断是：“年世兰不会那么蠢，要在她执掌后宫的时候让你出事，以她的性子，也就是想压压你立威而已，她要是知道你小产，恐怕比谁都害怕，这倒是弄巧成拙了。”（第32集第520幕）这段给了甄嬛一个旁证：年世兰的动机和后果对不上，说明还有别的原因。

安陵容：
- 甄嬛请她辨香，她很快认出当门子麝香，并说“久用此物不能受孕，即使有孕也多半是小产或死胎”。接着她把话引向“有心也好，无心也罢，千错万错都是年妃的错”，随后问“舒痕胶快用完了吧？”（第31集第506幕）。后来才知道舒痕胶里就有麝香（第44集第719幕）。我们自己的判断：你查事的时候，帮你分析的人既给了真信息，也把你的注意力引向某一个人，之后值得回头核对。
- 博主观点（BV1ztfmB1EAy）：舒痕胶是整个计划的关键一环，一盒一盒送，麝香含量会增加；做胶和送胶的都是陵容，皇后没有插手，事发后可以把责任推给陵容（约05:09至06:50）。

温实初：
- 他把脉发现麝香（第31集第504幕）。后来在碎玉轩，他提到眉庄的伤“还留下了一点淡淡的伤痕”，甄嬛问“姐姐没用舒痕胶吗？”，他答“……微臣还要到景仁宫去复命，先告退了”，临走又加一句“若是安小主有任何东西交予娘娘，还请娘娘务必让微臣过目之后再行使用”（第44集第719幕）。他知道有问题，但说不出口，是在等人逼问。

## 3. 布局链条

目标：弄清孩子是怎么没的，每一层原因是什么。

铺垫（按剧本顺序）：
1. 罚跪之前，她已经注意到翊坤宫的香：“她宫里也不知道熏的什么香，我闻着只觉得呛鼻。”（第29集第486幕）
2. 温实初把脉，发现她身上有麝香的痕迹，她第一反应是自检：“章太医说过本宫孕中禁用此物，本宫怎么会用呢？”再回想：“这些日子，本宫只在一处闻到过香料的气味。”（第31集第504幕）
3. 取实物，不凭印象：“流朱，明日你去内务府，想办法弄些年妃宫里的欢宜香来。”（第31集第504幕）香取回来之后，请最懂香的陵容鉴定（第31集第506幕）。
4. 自己算账，发现对不上：“这之前本宫每日在年世兰宫中不过三四个时辰，这药力之大竟至于如此吗？如今细细想来，本宫在去她宫中前几日便已有轻微的不适症状。”（第32集第520幕）她往前找第二个原因。
5. 逐项排除：“本宫的饮食皆用银器，自然不可能在饮食上出任何差错”，然后连自己信得过的人也问到：“当年本宫避宠，你给本宫服食的药物可会对身子有损？”（第32集第520幕）
6. 借探病找旁证：端妃说年世兰没那么蠢（第32集第520幕）。

借谁的手：
- 温实初：把脉、验药、验东西。
- 姜公公：替流朱从香药局取来欢宜香（第31集第506幕）。
- 端妃：提供旁证，后来在养心殿又提出“怎地跪了半个时辰就小产了？如今想来不觉得蹊跷吗？”（第68集第1076幕）
- 卫临：御前太医，由皇帝点名验舒痕胶（第68集第1076幕）。

等什么时机：
- 第一层真相（欢宜香）她很早就拿到了，没有对皇帝提。我们自己的判断：因为欢宜香是皇帝自己赐的。
- 第二层真相（舒痕胶）：温实初欲言又止，她追一句“大人说话吞吞吐吐的，岂非存心叫本宫不安？有什么话大人不妨直说”才问出来（第44集第719幕）。
- 她得知后只说：“这件事且不可让她知道，若此事真为安陵容所为，那决计是心机深重，本宫现下如此潦倒，眉姐姐更是势单力薄，千万要记得转告眉姐姐，千万不要得罪了皇后与安陵容，知道吗？”（第44集第719幕）当时自己势弱，不声张，让身边最近的人也先别动。
- 一直等到第68集：陵容因迷情香事发，甄嬛在养心殿提舒痕胶，端妃接着提当年的小产，皇帝叫卫临当场验，卫临说“此物中有极重的麝香，若每日取来匀面，不出三月便会小产”（第68集第1076幕）。这一段剧中她是借替陵容求情做引子。我们自己的判断：职场里能借用的只有让能裁决的人叫专业的人当场验这一点。

怎么收网：证据由皇帝亲眼和亲耳确认，甄嬛不替任何人下结论。皇帝当场判决陵容。

留了什么后手：
- 对年世兰：她在冷宫当面说出欢宜香里有麝香、是皇帝的旨意（第42集第681幕）。年世兰当场崩溃。后来她对端妃说：“我原以为我恨极了她，可如今她死了，我只觉得悲凉。”（第42集第682幕）
- 对皇帝：她始终没有在欢宜香这件事上质问过他，只在心里说“你要防她，岂知也伤了我们的孩子？”（第31集第506幕）
- 对皇后：剧本里这一次小产她没有对皇后摊牌。

## 4. 关键话术

- 第31集第504幕 甄嬛：“麝香？！章太医说过本宫孕中禁用此物，本宫怎么会用呢？”
  为什么管用：被人指出问题，先查自己有没有错，排除后再往外看，别人没法反咬她。

- 第31集第504幕 甄嬛：“这些日子，本宫只在一处闻到过香料的气味。流朱，明日你去内务府，想办法弄些年妃宫里的欢宜香来。”
  为什么管用：把怀疑缩到一个范围，马上去拿实物，不凭印象下结论。

- 第31集第506幕 甄嬛：“太医说我身上似有用过麝香的症状，而我自有身孕之后，便不再用过香料，所以奇怪。”
  为什么管用：向行家交代起疑的缘由，只讲事实：太医怎么说，自己做过什么。

- 第32集第520幕 甄嬛：“当年本宫避宠，你给本宫服食的药物可会对身子有损？会不会使身子虚弱容易滑胎？”
  为什么管用：连自己人也查，让后面的结论站得住。

- 第44集第719幕 甄嬛：“大人要本宫静心养胎不宜多思，可大人说话吞吞吐吐的，岂非存心叫本宫不安？有什么话大人不妨直说。”
  为什么管用：对方欲言又止，是在等人逼问。她把对方的理由（让我静心）倒过来用，逼他说实话。

- 第44集第719幕 甄嬛：“这件事且不可让她知道，若此事真为安陵容所为，那决计是心机深重，本宫现下如此潦倒，眉姐姐更是势单力薄，千万要记得转告眉姐姐，千万不要得罪了皇后与安陵容，知道吗？”
  为什么管用：自己势弱时，先稳住身边的人，宁可让他们不知道真相，也不让他们冲出去。

- 第68集第1076幕 皇帝：“你看看这个舒痕胶有没有什么不妥之处？”
  为什么管用：由有裁决权的人叫专业的人当场验，证据比谁说的话都硬。

## 5. 换到职场

### 场合一：职场（项目指标突然掉了，同事A说是渠道方压价，老板当场让你复盘）

对应的局：你负责的（某个活动）数据在（某周）突然下滑，同事A在会上说是渠道方调整了价格。老板让你周五前给结论，你觉得时间对不上。
打法：
1. 先查自己：这一周你自己改过什么（素材、出价、投放时段），先排除掉。
2. 拿实物，不拿转述：原始数据、后台操作记录、渠道方的调整通知。
3. 请懂行的人鉴定，同时留一个第二位复核的人。给你解释原因的人，也可能和结果有利害关系。
4. 看对不上的细节：下滑的日子和渠道调整的日子差几天，量级是否匹配。往前再找一层。
5. 查清之前不对同事声张，不对老板下定论。
6. 结论让有裁决权的人（老板，或财务、数据负责人）看原始数据，由他们叫专业的人确认。
一句能直接说出口的话：“（指标）开始掉是（某日），渠道方调整是（某日），两个时间对不上。我先把（原始数据）和（后台操作记录）调出来对一遍，再请（另一位同事）复核。查清之前我先不下结论，周五我把核对过程给您看。”

### 场合二：日常（合租，月底电费比平时多了一倍，房东和另一位室友都说是你用得多）

对应的局：三个人合租，电费账单突然翻倍，中介和另一位室友都怪你平时开空调多。你觉得没这么多。
打法：
1. 先查自己：你这个月比平时多用了什么，空调开了几天。
2. 拿账单和电表读数，不靠大家的印象，对比近三个月。
3. 请物业或供电局上门核一次电表，同时让另一位室友在场，别由一个人解释。
4. 对不上的地方再往前找：有没有人新添了电器，电表有没有出过问题。
5. 查清之前不在群里争对错。
一句能直接说出口的话：“这个月电费涨了一倍，我先把我这边的用电对了一遍，（具体读数）我发给你们。咱们三个人一起核一下（电表读数）和近三个月的账单，核完再说怎么分，行吗？”

## 雷区

- 甄嬛请陵容辨香、治疤，陵容后来被证明是下手的人（第31集第506幕、第68集第1076幕）。她当时把辨香和祛疤都交给同一个人，直到温实初临走前提醒一句“若是安小主有任何东西交予娘娘，还请娘娘务必让微臣过目之后再行使用”，她追问之下才查到舒痕胶（第44集第719幕）。职场里帮你分析原因的人，别让他同时是唯一的信息来源，重要的东西找第二个人复核。
