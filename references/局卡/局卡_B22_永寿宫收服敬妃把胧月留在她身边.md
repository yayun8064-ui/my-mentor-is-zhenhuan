# 永寿宫收服敬妃，把胧月留在她身边（第59至61集）

局面类型：认错善后（对方认错，由她来收尾）/ 谈条件
对方：敬妃，皇后掌权期间协助料理后宫多年的老资格嫔妃，胧月公主的养母。性子隐忍，一向自保。最在意胧月（安全感和余生的寄托），其次是自己从来没有被公平对待过。
甄嬛的处境：官面上强，实际上微妙。她即将晋熹贵妃接管六宫，位阶高于敬妃；但胧月是她的亲生女儿，感情却在敬妃那边，皇帝又说过会把胧月接回来（第61集第964幕）。私下，永寿宫，只有两人和心腹。
她的目的：把一个被皇后利用、刚害过自己的人拉回同盟，同时不丢掉与胧月的情分，不留一个随时可以被皇后再次点燃的隐患。

## 1. 人设和差异化

她在敬妃面前立的是不摆贵妃架子、讲道理也讲情分的姐姐。

和其他人比：
- 皇后用的是把柄加挑拨，让敬妃以为除了听她的没有别的选择。
- 皇帝手里有一句现成的话：“等胧月再长大些，朕就让她回来，不叫你们母女分离。”（第61集第964幕）甄嬛本可以顺水推舟要回孩子，她没有这么做。
- 敬妃自己的姿态是处处守礼，一口一个“贵妃娘娘”。

差异：甄嬛不接这个称呼，开口就问“看来真是要生分了”，用称呼的变化先把距离拉近。博主观点：甄嬛一直叫“姐姐”，说明她没有打算拿贵妃的身份压人，要给对方留足体面（树懒小结界，BV1UmqaBcEna，约12:23至12:30）。

为什么对上敬妃的胃口：敬妃要的是胧月，也要被当成一个有品德的人对待。甄嬛两样都给了。

## 2. 读人

敬妃：
- 守礼，隐忍。第61集第966幕她自己说“到底是尊卑有别”。
- 把贵妃之位看得很重，却从来没有想过自己能坐上去。博主观点：长期在华妃和皇后这种靠关系的掌权者手下，她从来没有想过自己的品德会被公平对待（BV1UmqaBcEna，约13:44至14:26）。
- 孤寂到数砖头：“我宫里一共有三百二十六块砖石”，其中三十一块已经有了裂纹（第61集第966幕）。这是她为胧月冒险的真正原因。
- 被皇后摆布：“无论是借你的手扳倒我，还是借我的手扳倒你，对于皇后而言都是有益无害的。”（第61集第966幕）

甄嬛读出的几件事：
- 缨络是敬妃看出的。甄嬛是这样推出来的：“槿汐与苏培盛一事，便是姐姐告诉皇后的，他们都是谨慎的人，唯一的破绽便是那枚柳叶合心的缨络曾被姐姐看出是槿汐的手艺，当日在场之人除了我，唯有你和眉庄，而那段时日姐姐曾出入景仁宫次数不少。”（第61集第966幕）
- 敬妃在第59集第943幕当众指出缨络从苏培盛袖口掉出，当时在场的就是她，与甄嬛的推断吻合。
- 博主观点：敬妃在揭发现场没有帮腔，在讨论如何处罚槿汐时也没有落井下石，产子后还曾想登门修复关系，所以甄嬛判断她值得原谅（BV1UmqaBcEna，约10:05至10:27）。这几处细节部分在剧本里难以逐条核到，待核。

## 3. 布局链条

目标：敬妃继续养着胧月，同时转到甄嬛这一边。

铺垫一，先判断值不值得原谅，也判断怎么原谅最划算。
博主观点：甄嬛这次出手是想自保，没有想害人的意思，所以敬妃值得原谅；从宫斗角度，把盟友推向对手那边得不偿失；从血缘角度，硬把孩子要回来感情不一定好；最优解是孩子继续留在敬妃身边，同时把敬妃拉回自己的阵营（BV1UmqaBcEna，约10:36至11:07）。

铺垫二，先让皇帝同意胧月留在敬妃处。
晋位之日皇帝对皇后说：“朕和熹贵妃商量过了，觉得胧月由敬妃抚养甚好，不必再挪动了”（第61集第968幕）。可见甄嬛事先已经与皇帝说通，这件事在她手里已经定了。

借谁的手：槿汐。
甄嬛让槿汐去请敬妃，槿汐说“贵妃娘娘说前几日没有得空，今日正赶上天气好，想要娘娘到永寿宫去一聚呢。”（第61集第965幕）博主观点：槿汐是被敬妃连累过的人，却言语客气、笑容真诚地来请，这是向敬妃公开传递“我已经原谅你”的态度（BV1UmqaBcEna，约09:30至09:53）。

等什么时机：册封礼之前，也就是她接管六宫之前。这时敬妃最怕她上位后清算，也最需要一个说法。

怎么收网（第61集第966幕）：
1. 先拉近距离，不接“娘娘”的称呼。
2. 敬妃把她捧到“实至名归”，她回一句“若论起品德资历来，难道姐姐就做不得贵妃吗？”用一个问句暗示：我掌权之后，公平的待遇你也有份。
3. 谈到皇帝对她念念不忘时，她轻轻带过，再把话题转到正题：既然明知皇上对我不薄，为什么与我作对。
4. 敬妃没有装傻，直接承认：“你已经知道了？”博主观点：敬妃的坦诚换来了甄嬛的开诚布公（BV1UmqaBcEna，约16:14至16:19）。
5. 甄嬛先替她把理由说出来：不争圣宠，只是想留住胧月。
6. 敬妃倾诉孤寂，甄嬛没有打断。
7. 甄嬛把皇后离间的手法点破，让敬妃明白自己和甄嬛是被同一个人算计的。
8. 然后才提安排：请姐姐替我抚育胧月，直至公主出嫁。再讲清楚理由：强行带回只会断了母女情分。
9. 收尾给敬妃一个体面的说法：她替我养胧月，就是在帮我保全这三个孩子。

留了什么后手：
- 同一天晚上，甄嬛在宴席上让皇帝去敬妃宫里陪胧月（第61集第969幕），把示好变成实际的福利。
- 敬妃后来在第63集第996幕为甄嬛站台，说祺贵人和熹贵妃素来积怨甚深，温太医去得勤是尽医家本分。

## 4. 关键话术

- 第61集第966幕 甄嬛：“姐姐如今都称我娘娘了，看来真是要生分了。”
  为什么管用：不批评对方守礼，只说出自己的感受，让对方自己决定要不要拉近。

- 第61集第966幕 甄嬛：“若论起品德资历来，难道姐姐就做不得贵妃吗？”
  为什么管用：用一个反问替对方说出了她从来没敢想的事，不写成承诺，对方自己会听出分量。

- 第61集第966幕 甄嬛：“姐姐一向慧智，又对世事洞若观火，既然明知皇上对我不薄，姐姐又为何要与我作对呢？”
  为什么管用：先夸对方聪明，再问她为什么做蠢事，对方很难再编借口，只能承认。

- 第61集第966幕 甄嬛：“姐姐不争圣宠，又甚少与人交恶，当年华妃独大时亦可忍辱保身，今日种种，不过是想留住胧月在身边。”
  为什么管用：替对方把动机讲成情有可原，把一件伤害性的事降级成一个母亲的无奈。

- 第61集第966幕 甄嬛：“姐姐可知，姐姐来往景仁宫之事，并非我自己探知，而是皇后故意透露此事？”
  为什么管用：让对方看到自己才是被利用的人，两人转为同一阵线。

- 第61集第966幕 甄嬛：“那么就请姐姐替我抚育胧月，直至公主出嫁。”
  为什么管用：用请求的语气，不当成赏赐，并且给出明确期限，给的是一颗定心丸。

- 第61集第966幕 甄嬛：“弘曕与灵犀已叫我自顾不暇，而胧月却视你为生母，我若强行把她养在身边，那才是真真断了我与她的母女情分。”
  为什么管用：把自己的让步讲成为孩子好的选择，对方没有觉得被施舍。

- 第61集第966幕 甄嬛：“姐姐能替我抚育胧月，等于在帮我保全这三个孩子。”
  为什么管用：把对方放在帮助者的位置，不让她停留在被宽恕者的位置。

## 5. 换到职场

### 场合一：老板 1on1（有同事曾在老板面前给你的项目挑刺，后续你要继续和他合作）

对应的局：跨部门的同事曾在评审里当着老板的面指出你项目的问题，你知道他的出发点是保护自己部门的资源。现在老板问你们的关系怎么样。
打法：
1. 先搞清楚他当时为什么这样做，他在担心什么。
2. 在老板面前不告状，也不装作没事，只讲你已经单独找过他，并且明白了他的顾虑。
3. 请老板确认一个对双方都有利的安排，让对方的核心担心得到保障。
4. 对那位同事，也用同样的方式表达：你把他放在帮你的位置上，别让他停在需要被原谅的位置上。
一句能直接说出口的话：“上次评审里（同事）提的那几点，我后来单独找他聊了，他主要担心的是（他的真实顾虑）。我们商量了一个办法：（具体安排），这样他那边也有保障。”

### 场合二：聊投资（老股东或早期投资人曾在关键节点反对过你，现在需要他继续支持）

对应的局：一位早期投资人在上一轮对你的方向表示过强烈保留，你发现他的真正担心是（他最在意的那一点），他现在还在观望。
打法：
1. 约一次不谈融资的沟通，不摆姿态，先把称呼和语气放平。
2. 说破：你当时提的反对意见我认真想过。你只讲自己想明白了什么，不去追究对方的动机。
3. 让他先讲，听完再替他把真实顾虑说出来。
4. 给他一颗定心丸：一个具体的、可以兑现的安排，比如信息同步的频率、关键事项的提前沟通。
一句能直接说出口的话：“您当时的保留我后来想了很久，我理解您担心的是（他的真实顾虑）。接下来我们会（具体安排），有变化第一时间同步给您，您看这样能让您放心一些吗？”

## 雷区

- 甄嬛能直接说破对方做过什么，是因为她有推理的证据，而且身份高于对方。职场里在对等关系中直接说破，对方不承认就变成正面冲突。先问问题，让对方自己说。
- 以德报怨在这里有明确的利益计算。博主观点：选择原谅属于理性决策，并没有圣母心的成分（BV1UmqaBcEna，约10:40至10:43）。职场里不要把计算讲成慈悲，对方一旦觉得自己被收买，会反感。
- 甄嬛让出的东西是真实的（胧月的抚养权）。职场里给对方的安全感必须是你真能兑现的，先许诺后收回，比不给更伤人。
- 暗示对方也有机会升这类话，甄嬛只用了反问，没有给承诺。职场里不要替上级或未批的事开空头支票。
- 皇后故意把消息递到甄嬛耳朵里，目的是让两人互相消耗。职场里消息来得太巧、对象恰好是你的盟友时，先想一想是谁在放消息。
- 敬妃后来答应皇后“只干这一次”，却发现没法脱身（第61集第966幕）。职场里被人拿住小把柄后，“就这一次”往往不会是最后一次。
