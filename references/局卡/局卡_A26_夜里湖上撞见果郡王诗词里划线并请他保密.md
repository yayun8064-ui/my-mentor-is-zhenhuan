# 夜里湖上撞见果郡王，诗词里划线并请他保密（第19集第320幕，前情见第19集第317至319幕）

局面类型：拒绝 / 求人办事（请对方保密）
对方：果郡王允礼，皇帝的十七弟，太后养大，闲云野鹤，王爷身份比甄嬛高很多；对她有好感，随身荷包里放着她的小像；另有巡逻侍卫一队，见王爷在就退。对方最在意的是被她理解、被她看见，也怕伤到她。
甄嬛的处境：弱。深夜出现在不该去的地方，刚探完被禁足的眉庄，身上穿着浣碧的衣服，被侍卫当场盘问就是欺君；私下；对方是亲王，帮不帮她全在他。
她的目的：平安回去，让这次碰面不进第三个人的耳朵；同时把对方的好感挡在安全线外，不接、不应邀，也不伤他的面子。

## 1. 人设和差异化

她在允礼面前立的是守本分、读书多、心里只有皇上的人。

和浣碧比：第18集第303幕浣碧在园中哭，被允礼说了一句“人好看穿什么都好看”，第19集第323幕她被流朱打趣惦记果郡王来不来宫里。甄嬛的回应方式相反：他说得越近，她越往远处说。

和一般的示好者比：允礼用诗词和比喻，没有一句直接表白。甄嬛也接诗词，但每一首都落回到她和皇上身上。

为什么对上他的胃口：他说“世人或叹西施，或骂吴王，却从无人责范蠡。贵人妙思，小王自叹不如”（第19集第320幕），被理解对他很重要。甄嬛用一段他没想到过的评论接住了，他心里舒服，也就愿意听她下面的话。

## 2. 读人

允礼：
- 他替她挡侍卫：“皇上留本王在宫中，这也要问吗？”（第19集第320幕）。说明他愿意帮她，而且很自然，不要求回报。
- 他随后说“我划船送你回去吧”，没有问她去了哪里。说明他不打算打听。
- 他的话一步一步靠近：荷花、杜若香、与西施共乘泛舟。这是在探她的反应，每一步都留了退路。
- 荷包掉落，里面是甄嬛的小像（第19集第320幕）。我们的判断是他情很深，这一步是有意还是失手，剧本写的是“一个站立不稳”，待核。
- 博主观点：史馆思答夫，BV1ww89z2ETR，约07:27至07:50、约09:46至09:57：惊鸿舞宴上敦亲王拿皇帝的妃嫔和自己府里的舞伎比，允礼马上出面解围，反复强调甄嬛的舞得自梅妃真传，博主认为他是在带节奏，帮甄嬛和纯元切割，同时也是在替皇兄说话；博主还认为皇帝这时是领了他的情。我们的对照：解围的话在第13集第252幕可以核对到，皇帝领情是博主对神态的判断，剧本里只有让他入座、罚酒的话。我们的判断是允礼早就习惯在公开场合替她挡话，今晚在湖上替她挡侍卫是同一路数。
- 我们的判断是他怕唐突。她一句“若非知晓王爷本意，我必然要生气”，他立刻接“怎么，贵人也同那些俗人一样以为西施是亡国祸水？”，顺着话题往后退，没有再追。

甄嬛自己的读法：
- 她闻出杜若的气味，问“难道王爷有意中人了？”。这一问把话题推到他的情感上，没有往她和他之间引。
- 她看到小像之后，一个字都没有评论小像，只说“王爷掉东西了”，递回去。这是不让对方有说破的机会。

侍卫：看到王爷就退，不会再盘问。

## 3. 布局链条

目标：这一晚没有被任何第三人知道，同时不伤到允礼。

铺垫：
1. 第19集第317、319幕，小允子安排好船停在荷丛深处，芳若调走了守卫，她完成了探视。
2. 她回程为了躲巡逻的侍卫，上了另一条船（第19集第320幕，舞台说明），遇到了允礼。这一局没有预谋，是临场应对。

借谁的手：王爷的身份挡住侍卫；诗词挡住直接示好。

等什么时机：侍卫离开、船已经动起来之后才开始说话。允礼先开口谈荷花，她跟着谈，把话放在安全的题目上。

怎么收网：
1. 先接他的善意：说“多谢王爷”，不问他为什么在这里。
2. 谈荷花时把“佛性、温和如慈母”放在前面，话题离开男女。
3. 他说西施，她当场划线：请他不要拿自己跟西施比。这是整段里最直接的一句。
4. 紧接着给出理由，用范蠡亲手把西施送去吴国的故事，说出她对薄情的看法。我们的判断是这也在表明她不愿意被当成筹码，同时顺手赢得了他的欣赏。
5. 他引《牡丹亭》的情不知所起，荷包掉出来。她捡起，看到小像，只递还。
6. 她把话收到“我与皇上朝夕相对，但愿也有此情”，并请他不要再把荷包示于人前。她没有收下他的心意，也没有当面拒绝，是替他把秘密收好。
7. 靠岸前她提出保密请求，理由用的是七夕夜宴那晚端妃替她解围的事，请他不要对人提起曾与她相遇，就如今晚一样。他答应“小王不会告诉第三个人”。
8. 他邀她去清凉台，她以“盛夏刚过，清凉台过于凉爽”推掉。他伸手扶，她不接。

留了什么后手：请求的措辞包括“就如今晚一样”，把这一晚也一并收了进去，同时没有告诉他今晚究竟发生了什么。

## 4. 关键话术

- 第19集第320幕 甄嬛：“世人皆赞荷花的清洁，我倒更喜欢荷花的佛性，温和如慈母。”
  为什么管用：对方想聊风雅的东西，她接了，但把重点放在慈母和佛性上，话题里没有男女的味道。

- 第19集第320幕 甄嬛：“若非知晓王爷本意，我必然要生气。请王爷不要拿我与西施相比。”
  为什么管用：先给对方一个台阶，说你是好意，我才不生气，再把界线划清楚。

- 第19集第320幕 甄嬛：“若说西施亡吴国，亡了越国的又是谁呢？”
  为什么管用：划线后马上给出一个对方没想到过的看法，对方的注意力被这个看法拉走，不会在被拒绝这件事上停留。

- 第19集第320幕 甄嬛：“世间情爱不知所起不知所终，王爷有幸可寻一往情深之人。我与皇上朝夕相对，但愿也有此情。”
  为什么管用：顺着对方的话说，把自己放在另一个人身边，不直接说你不要靠近。

- 第19集第320幕 甄嬛：“一枚荷包而已，王爷言重了。既是王爷心爱之物，那请不要再示于人前，免得徒惹是非无穷。”
  为什么管用：把对方的心意说成一件小事，再提醒他别再让人看到，是在替他保密，也是在替自己保密。

- 第19集第320幕 甄嬛：“七夕夜宴那晚我曾偶遇小小的麻烦，幸得端妃解围，所以无论王爷听说任何关于夜宴当晚之事，都不要对人说起曾与我相遇一事，就如今晚一样。王爷如应允，我亦感激不尽。”
  为什么管用：请对方保密时，说清范围、给一个理由、让对方知道这件事对你很重要，最后留一个由他决定的位置。

- 第19集第320幕 甄嬛：“盛夏刚过，清凉台过于凉爽，我就不前去打扰了。”
  为什么管用：邀约不用直接拒绝，用一个委婉但对方听得懂的理由，场面还保得住。

## 5. 换到职场

### 场合一：和行业大佬建联（大佬话里有拉近关系、私下约你的意思）

对应的局：私下遇到一位影响力很大的前辈，对方用比喻、玩笑把关系往近了拉，还约你私下聊，你想保持专业距离，同时不得罪。
打法：
1. 先接他的善意，不问他的动机。
2. 他的比喻过头时，当场轻轻划线，用一句给他台阶的话。
3. 把话题换到行业里的某个问题，让他的欣赏落在你的想法上。
4. 邀约用一个让对方挑不出毛病的理由推掉，同时给一个正式的出口。
一句能直接说出口的话：“您这个比方我受不起，我们还是聊聊（行业里的某个具体问题）吧。后面如果有合适的合作，我走正式流程再请教您。”

### 场合二：聊投资（私下接触，请对方暂时不要对外提）

对应的局：你正在和几位投资人做早期交流，希望对方对这次接触先不要外传。
打法：
1. 说清范围：这次聊的是哪一部分。
2. 给一个理由，让对方明白为什么需要。
3. 给一个时间点，到了就主动同步。
4. 不要求对方替你撒谎，只要求暂时不主动提起。
一句能直接说出口的话：“这次聊的（具体内容）我们目前还在和几方做交流，请您先不要对外提。等（某个时间点或节点）有结论，我们第一时间同步您。”

## 雷区

- 她请对方保密用的是另一件事（七夕夜宴）做理由，没有告诉对方今晚究竟是什么事。职场里请人保密，如果对方后来知道真实情况，容易觉得被利用。能讲清范围就讲清范围。
- 她收了对方的人情：他替她挡侍卫、送她回去、帮她保密，她只回了一句“多谢”。这是欠下的人情，后面怎么还没有交代，职场里要想好。
- 荷包里是她的小像，她假装没有看到，对方的感情被她留在了模糊里。职场里划线要让对方听得懂，不能靠对方自己领会，否则对方会越走越近。
- 诗词、《牡丹亭》、西施范蠡这套语言只适合他们两个人，职场里不要照搬暧昧的文雅语言，对方可能误会。
- 她这一晚本身属于欺君的冒险：换衣服、冒充浣碧、夜探被禁足的人。这些做法不可套用，这张卡只借被撞见之后怎么把话说完这一段。
