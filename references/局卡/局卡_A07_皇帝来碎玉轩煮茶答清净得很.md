# 皇帝来碎玉轩，岁寒三友一盏茶，答清净得很（第7集第143幕，前情见第7集第133至142幕）

局面类型：投其所好 / 被试探
对方：皇帝（雍正），权力最高。当天他刚在御花园为她处置了余莺儿、越级晋她为贵人。他最在意的是在后宫找到一个不拘束、不奉承、说真话的人。他自己说得很明白：怕了就拘束，拘束了就成了君臣（第7集第133幕）。
甄嬛的处境：正得宠，但君臣悬殊，身体状况半真半假（她在用药拖着病，第7集第141幕）。场合是碎玉轩，私下，只有皇帝和她。
她的目的：让皇帝继续觉得她与众不同、不争不显；不被看成恃宠而骄；把侍寝的节奏留在自己手里。

## 1. 人设和差异化

她立的是素净、家常、有情调、不索取的人。

和其他人比：
- 华妃：奢华、浓妆。博主观点：华妃最喜欢满头朱翠，甄嬛不屑以色侍人，偏要与众不同，做差异化竞争（树懒小结界，BV1LV8MzrEjD，约14:20至14:31）。
- 余莺儿：刚得势就拿位分压人，说“皇上宠谁，谁的位分就高”（第7集第133幕），当天被降为官女子。
- 甄嬛：接驾前，流朱劝她换身鲜亮的衣服，她说“就这身衣裳，挺好的”，又说“就是要这样家常的样子才好呢”（第7集第142幕）。

为什么对上皇帝的胃口：皇帝夸她的话是“清水出芙蓉，天然去雕饰”，这几个字就是他喜欢的标准（第7集第143幕）。她从穿着、茶、说话，每一个选择都落在同一个标准上。

## 2. 读人

皇帝：
- 他自己说过看重的是她的本性：“朕看重你也就是因为你的本性。如果你与她们并无两样，朕也不会如此重视与你的约定。”（第7集第133幕）
- 他怕对方一拘束，两个人的关系就变成君臣：“怕了就拘束，拘束了就成了君臣。”（第7集第133幕）
- 他问碎玉轩“住着还惯吗？朕瞧着偏远了些”。这是一道试探题，答案可以是抱怨、要求换宫，也可以是知足。博主观点：他听到清静的回答很满意，觉得她不多事，不会恃宠而骄（BV1LV8MzrEjD，约18:24至18:37）。
- 他喜欢用心的东西：“你亲手调的，这心意朕最喜欢。”（第7集第143幕）
- 博主观点：他赏赐上好的乐器，没有选俗气的首饰，这是对文艺女青年的精准投送（约02:23至02:36）。

槿汐：看得出皇帝喜欢甄嬛，也看得出甄嬛喜欢皇帝。她给甄嬛的要求是不求一心，但求用心（第7集第140幕）。

## 3. 布局链条

目标：这一次不求什么，只让皇帝觉得这里清静、舒服。

铺垫一，御花园当天（第7集第133幕）。
余莺儿被降位，甄嬛为她求情：“知错能改，善莫大焉”。皇帝要晋她为贵人，她先推辞：“臣妾一于社稷无功，二于龙脉无助，实在不敢领受皇上天恩。”这两件事已经把她放在了不争的位置上。

铺垫二，两个姐妹来道喜（第7集第137幕）。
陵容劝她不必怕，有皇上的恩宠。甄嬛回答：“就因为未曾侍寝而晋封，隆宠太盛，反而不妙。”眉庄、陵容都在劝她放心，只有她提醒自己。

铺垫三，当晚槿汐的开导（第7集第140幕）。
槿汐讲恩宠太过是六宫侧目，太少是人人可欺，还讲到前朝与后宫一体。甄嬛的回答是：“我只求保我甄家平安，求皇上对我真心。”她再讲到愿望：“第三愿：便得一心人，白头不相离。”槿汐说：“那就退而求其次，不求一心，但求用心。”

铺垫四，病情的节奏（第7集第141幕）。
她对温实初说：“那就请温大人治好嬛儿的病，但别太快治好了，一个月为期最佳。”

铺垫五，接驾前（第7集第142幕）。
小厦子通报皇上午后来，她没有换衣服，没有加妆。

借谁的手：槿汐（心态上的定力）、温实初（病情节奏）、小厦子（提前通报）。茶本身是她自己准备的，埋在梨树下的那两瓮水是她入宫前就备好的。

等什么时机：皇帝夸她“与众不同”之后。

怎么收网：
1. 谦：“皇上不嫌弃臣妾蒲柳之质罢了。”不顺着夸往上接。
2. 奉茶：一杯亲手调的茶，皇帝先猜，她再答。
3. 说明来历：松针、竹叶、梅花，荷叶上的露珠，名字叫岁寒三友。内容雅，但没有一句夸自己。
4. 把准备说成凑巧：“也是机缘凑巧……前两日才启出来的。”
5. 被问住得惯不惯：“臣妾觉得还好，清净得很。”
6. 被说远：“心近就好。”
7. 被问病：“原也不是什么大病……”把话说小，同时不拒绝皇上的关心。

留了什么后手：
- 病情的节奏仍然在她手里。皇帝刚说“朕瞧着你的气色好了不少，应该快大好了”，她就把话说成病不重，在福泽庇佑下好得更快，既没有说自己好了，也没有说自己不好。
- 之后第8集第145幕，皇帝赐汤泉宫沐浴，他们的关系往前走了一步。

## 4. 关键话术

- 第7集第142幕 甄嬛：“就是要这样家常的样子才好呢。”
  为什么管用：不盛装迎驾，让皇帝看到的是她平时的样子，也避免与华妃那种浓艳路线重叠。

- 第7集第143幕 甄嬛：“皇上不嫌弃臣妾蒲柳之质罢了。”
  为什么管用：皇帝夸她与众不同，她不承认，把评价的权力交回给他。

- 第7集第143幕 甄嬛：“皇上好灵的舌头。这道茶叫岁寒三友，是取松针、竹叶和梅花一起烹的，那水是夏日日出前荷叶上的露珠，才能有如此清新。”
  为什么管用：先夸对方猜中，再说内容，让对方有被看见的满足。茶的名字和用料本身就是她的人设。

- 第7集第143幕 甄嬛：“皇上过奖了。也是机缘凑巧，臣妾去岁收了两瓮舍不得喝，特意带了一瓮进宫，就埋在堂后的梨树下，前两日才启出来的。”
  为什么管用：把准备说成偶然，让对方觉得是自己赶上了，没有被安排的感觉。

- 第7集第143幕 甄嬛：“多谢皇上关怀，臣妾觉得还好，清净得很。”
  为什么管用：被问住处时，不抱怨，不要求，也不显得委屈。

- 第7集第143幕 甄嬛：“心近就好。”
  为什么管用：皇帝说偏远，她用这句话收住，把话题从地点抬到关系。

- 第7集第143幕 甄嬛：“原也不是什么大病，只是臣妾自己身子虚罢了，如今又有皇上的福泽庇佑，自然是好得更快些。”
  为什么管用：把病说小，让皇帝放心，同时把好转归给他。

## 5. 换到职场

### 场合一：老板 1on1（老板问：你现在这个位置做得怎么样，有没有想要的）

对应的局：老板主动问你近况，带着点试探，看你是抱怨、要东西，还是安于现状。
打法：
1. 不抱怨，不立刻开条件。
2. 用一句平实的话说现状，再带一个具体的小成果。
3. 对老板的关心表示感谢，把进展归因于他的支持。
4. 需要的东西留到有明确理由的时候再提。
一句能直接说出口的话：“我这边节奏挺稳的，（某一块）最近有个小进展想给您看看。资源上暂时够用，真有卡点我会提前跟您说。”

### 场合二：和行业大佬建联（第一次约饭或喝茶，你想让对方记住你）

对应的局：对方时间有限，你想留下一点与众不同的印象，又不想显得用力过猛。
打法：
1. 提前做功课，把准备变成一个小东西，比如一页整理好的观点，不要带一堆材料。
2. 当面把它说成顺手，不夸自己。
3. 对方夸你，你不顺杆往上爬，把话头还给对方。
4. 对方问你有没有需求，答还好，把具体的事留给后面。
一句能直接说出口的话：“您过奖了，正好前阵子看到您讲（某个观点），就顺手整理了一页，不一定对，您随便看看。”

## 雷区

- 刻意中的自然：茶、水、梨树下的两瓮，处处是预先准备，只是话说得轻。博主观点是皇帝其实看得出这类安排（见样卡B，BV1bJECzPEmC，约29:33至29:47）。职场里对应：准备可以做，但别以为对方看不穿，也别在被看穿时否认。
- 装病拖着：这条线在第7集第141幕布好，对皇帝说“原也不是什么大病”，是在掩护这个状态。职场里不要对上级装忙、装病，这一点不能套用。
- 余莺儿的反面：得势后拿位分压人，当天被降位（第7集第133幕）。职场里对应：刚被器重的当下，姿态比成果更容易让人记住。
- 接驾前不换衣服，这一步有风险，皇帝要是不喜欢素净，就会白白错过。她有把握，是因为之前在御花园已经见过皇帝对清新的偏好，并没有凭空去赌（第7集第133幕、第143幕）。
