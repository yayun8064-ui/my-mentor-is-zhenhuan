# 回宫当天，先夸香套话，再找人验证、问清风向（第56集第891至893幕）

局面类型：被试探 / 闲谈社交
对方：皇帝，亲自带她参观重修的永寿宫，正在兴头上，爱展示自己的用心；小允子，眉庄派回来的旧人，消息可靠；温实初，太医，专业上的自己人。最在意的是面子（皇帝）、甄嬛的安危（小允子、温实初）。
甄嬛的处境：表面强，实际弱。刚册封熹妃，有孕，皇帝宠着；但离宫三年，宫里谁是谁都不清楚，新指派的宫人也未必可靠。先是当着皇帝，后是私下关起门来。
她的目的：不拂皇帝的好意，顺势摸清永寿宫里的东西是谁安排的、有没有人暗算；再通过自己人查实、问风向。

## 1. 人设和差异化

她在皇帝面前立的是不敢受的熹妃。永寿宫的奢华她当场推辞：“皇上厚爱，臣妾不敢承受。”（第56集第892幕）、“永寿宫如此奢华，臣妾不敢擅居，还请皇上让臣妾别殿而居吧。”（第56集第892幕）我们自己的判断：她提前表明不愿意享受奢华，之后太后说她穿得简朴时，才能自洽地答“臣妾修行已久，不喜太过奢华”（第56集第899幕）。

和迎接时的人比：康常在好奇“听说熹妃就是以前的莞嫔？”，贞嫔站在一旁讽刺，陵容和敬妃说着场面话（第56集第891幕），都是围观。甄嬛对皇帝每一个安排都先谢再收，没有争辩、没有评价。

## 2. 读人

皇帝：
- 他对永寿宫的每一处布置都有话要说，莲花、椒墙、香。他要的是被看见用心。
- 他把责任分出去：“永寿宫的种种布置皆是朕的意思，皇后更着意添了许多，无人敢妄论。”（第56集第892幕）他知道皇后掺了手，自己不方便指出。博主观点：皇帝也明白皇后做这些的小心思，但她打着贤良的名号，他不好指责，只能任其发展（BV1MoKbzbEnm，约13:10至13:20）。
- 他提到陵容的香时，细节如数家珍：“配了数百种香料才配得此古方”，“朕有时不得安眠，闻得此香便能好受许多”（第56集第892幕）。博主观点：他提到陵容时表情十分享受（BV1MoKbzbEnm，约08:42至08:45）。

皇后：
- 甄嬛的推断：“我正想着她如何这般好心，原来是一边哄着皇上高兴博了贤良的名儿，一边只叫外头的人以为我狐媚惑主才引得皇上这般，更落实了我祸水之名。”（第56集第892幕）这是她在听了皇帝那句“皇后更着意添了许多”之后得出的。

陵容（香的制作人）：
- 博主观点：她送这道香有三层意思，向皇上卖好、让皇帝闻香想起自己并向甄嬛挑衅、以后在香上做手脚（BV1MoKbzbEnm，约08:47至09:10）。这是博主的推断，剧本里没有陵容这三句话。

小允子：
- 他回话抓重点，先说惠嫔好，再说皇帝久不去碎玉轩，然后讲外面大臣吵得凶，连恒亲王都上书（第56集第892幕）。博主观点：他的回答全是重点，也会哄人（BV1MoKbzbEnm，约12:12至12:40）。
- 甄嬛话问到一半就替他说了出来：“说本宫是废妃之身回宫，已是闻所未闻，又如此张扬奢靡，是祸乱后宫的妖孽祸水，是不是？”说明这些她早有预料，只是要对一下。

## 3. 布局链条

目标：搞清永寿宫的香是谁给的、有没有害；同时知道宫里的风向。

铺垫：
1. 她有被香害过的经历。博主观点：当年皇帝对华妃用欢宜香，陵容对她用色香导致她小产，所以她深知香料在后宫的可怕（BV1MoKbzbEnm，约07:37至07:46）。
2. 槿汐当天就提醒“要紧的是景仁宫”（第56集第892幕），两人对皇后动手的判断一致。

借谁的手：皇帝本人（报出香的来路）、温实初（验香）、小允子（宫内的消息）。

等什么时机：皇帝带她看寝殿，自己在兴头上介绍的时候，他最愿意讲来历。

怎么收网：
1. 先夸香气，引他开口：“此香的香气竟这般香甜。”
2. 抛出典故抬高这香的价值：周娥皇、南唐、失传，再问从何寻得。越是珍贵的东西，越容易让人说出来源。博主观点：引经据典是一边夸一边打探香的来路，推断是否有人要害自己（BV1MoKbzbEnm，约07:30至07:52）。
3. 皇帝说出陵容，她不接陵容这个话头，转到碎玉轩的梨香。皇帝顺着说出为什么用这个香，话头自然落到眉庄身上，随后他自己评价“论起对熹妃的贴心，莫若惠嫔”，并且安排小允子回来侍奉。
4. 皇帝一走，她先问眉庄好不好，再问宫里有无异动，最后立刻让槿汐请温实初来。
5. 温实初验香：无麝香一类伤胎的药，是安神之物。但他补一句不可与依兰花同放。

留了什么后手：
- 依兰花的提醒埋下伏笔，随后在第67集第1061幕，甄嬛追问“这依兰花有使人动情之效，如果碰上鹅梨帐中香会怎样？”可见她把这句话记住了。博主观点：这个伏笔之后会用上，玲蓉敢提纯少见的依兰花（BV1MoKbzbEnm，约13:30至13:53）。
- 她让槿汐请温实初的时候，没有当场责怪皇帝，也没有拒绝使用这香。香仍点着，只是她自己知道哪里不能碰。
- 温实初刚走，弘历就来求见（第56集第893幕），同一天的下一个局见局卡B04。

## 4. 关键话术

- 第56集第892幕 甄嬛：“皇上厚爱，臣妾不敢承受。”
  为什么管用：对皇帝大张旗鼓的好意，先退一步，显得她并不贪享，也给了她后面细看每一样东西的借口。

- 第56集第892幕 甄嬛：“此香的香气竟这般香甜。”
  为什么管用：从最普通的感受开口，对方听了会觉得被夸，然后主动讲来历。

- 第56集第892幕 甄嬛：“此香原是南唐国国后周娥皇所制，南唐国破后，此香已失传已久，不知皇上从何寻得这样的好香？”
  为什么管用：先显出自己懂行，再抛一个只有对方能回答的问题。这句同时是夸（珍贵）也是问（来路）。

- 第56集第892幕 甄嬛：“果真奇香，叫臣妾想起了碎玉轩的梨香满园了。”
  为什么管用：不评价制香的人，把话头带到自己亲近的人身上，让皇帝自己说出替代的缘由。

- 第56集第892幕 甄嬛：“惠嫔一向可好？”
  为什么管用：先问人，再问事。对方感觉到你记着她，她给你的消息会更详细。

- 第56集第892幕 甄嬛：“本宫回宫，宫中可有异动？”
  为什么管用：问法很宽，给对方足够的空间，由他挑最重要的说。

- 第56集第893幕 温实初：“娘娘请放心，此物里并没有麝香一类的伤胎之药，倒是梨香清甜，是上好的安神之物。”
  为什么管用：东西不只靠别人说好，请懂行的人当面验，专业判断才算数。

- 第56集第893幕 甄嬛：“本宫也是小心为上。”
  为什么管用：给验证一个让人不会不舒服的理由，自己谨慎，没有怀疑谁。

## 5. 换到职场

### 场合一：老板 1on1（刚调岗、刚回团队，老板热情地给你安排了位置和资源）

对应的局：老板大张旗鼓给你安排了一个位置、一批资源，你想搞清楚这些安排是谁提的、中间谁参与过，又不想拂了老板的好意。
打法：
1. 先谢，对过大的资源先轻推一下，说怕自己接不住。
2. 夸安排里一个具体的点，请老板讲来历。
3. 事后找一个懂行的同事核对关键的细节。
4. 再找一个旧同事问最近有什么动静，让他自己挑重点说。
一句能直接说出口的话：“这个安排很用心，（具体的资源或岗位）我想弄清楚来龙去脉，当时是谁提的，中间谁参与过？我好知道该向谁对接。”

### 场合二：大佬建联（对方正在展示自己的得意之作）

对应的局：行业前辈给你看他做的东西，你想知道背后的思路，又不想显得在探底。
打法：
1. 夸一个具体的点，不要笼统地说厉害。
2. 补一句你的理解，让他知道你懂行。
3. 抛一个只有他能回答的问题，比如当时试过哪些方案。
一句能直接说出口的话：“这个（具体的设计点）很少见，当时是怎么想到的？有没有试过别的做法？”

## 雷区

- 夸要有具体的点：甄嬛引的是周娥皇与南唐的典故，是真懂。空泛的夸容易被识破。
- 不要把对方的话当成唯一的来源：她听完皇帝，立刻请温实初验，再问小允子。职场里关键信息要找第二个来源。
- 替人说完他的话：她抢在小允子前面说出“祸水”那句，对下属可以，因为对方不敢纠正；对上级和平级用这种说法，容易显得压人。这是我们自己的判断。
- 皇帝的圆场：他知道皇后添了东西却不指责（博主观点，BV1MoKbzbEnm，约13:10至13:20）。职场里上级明知有人动手脚而不处理，不代表他站在你这边。
- 博主在这一期还讲了永寿宫匾额“德日新”的讽刺（约03:39至05:14）。剧本里没有找到这一情节，本卡不写。
