# 寿康宫训示，接下规劝皇帝的差事（第56集第899幕，兑现见第57集第915幕）

局面类型：投其所好 / 被试探（面试之后的训示）
对方：太后，卧病，最在意的是制衡后宫、守住皇后之位，同时让皇帝身边多几个懂事的人。眉庄仍在场，被太后催着生子。
甄嬛的处境：弱偏对等。面试刚过，叫起、赐座，人坐下了，身上的“狐媚”标签还没摘。私下，三个人，没有第四个人在场。
她的目的：把太后的训示全部接下，让太后觉得她可用、可管，同时不背上任何自己扛不起的承诺，不在太后面前表态站队。

## 1. 人设和差异化

她在太后面前立的是简朴、懂事、感恩、不争的人。

四个动作一起撑这个人设：
- 穿得素。太后说“如今你已在妃位，这样穿着太简朴了些”，甄嬛答“臣妾修行已久，不喜太过奢华”（第56集第899幕）。
- 送礼轻。前一天给皇后的是佛珠（第56集第894幕）。博主观点：她给人送礼都是佛经佛珠这类简朴的东西，内务府的料子只留一匹，转手送了人（BV1sWGwzZEA9，约17:37至17:49）。剧本里内务府来送料子、她让小允子把浅碧色那匹送给宁贵人，在第56集第896幕。
- 说话短。太后每说一件事，她只接一句。
- 不求任何东西。整场没有为自己、家人或孩子开口。

和华妃比：第20集第331幕华妃穿得素净去找太后卖惨，太后说“你如花似玉的年纪，位分又尊贵，打扮得这么素净做什么”，顺手赏了步摇。博主观点：太后那句是讽刺，华妃的素净处处是漏洞，甄嬛是真的低调，耳坠头饰都不值钱（约15:59至17:04）。

为什么对上太后的胃口：太后眼里的好嫔妃是不招摇、肯劝皇帝、不压皇后一头的人。甄嬛每一句都在往这个模子里靠。

## 2. 读人

太后：
- “不要怪哀家苛责，皇帝是哀家亲生的，哀家也怕再招进一个狐媚的”这句先摆立场，后面再给糖，博主称为恩威并施（约14:56至15:26）。我们自己的读法：她先说怕，是为了让后面的夸奖显得是特别开恩。
- 夸完简朴马上提旧恩：“你能这样懂事，也不枉哀家这些年疼你。”博主观点：先夸低调懂事，再提往日照顾，是让下属感恩戴德，便于管理（约18:02至18:16）。
- “既已回宫，以后就当没有甘露寺这回事”是替她洗履历，也是划线：别再提。博主观点：甘露寺是职业履历里的污点，所以皇后、安嫔、祺嫔才一直拿它说事（约20:28至21:12）。剧本里第56集第894幕皇后提过“又刚从甘露寺回来”，第57集第905幕祺嫔说“一点也瞧不出佛寺待过的样子”，两处都可核。
- 规劝皇帝这个差事，太后点名是她，没有交给皇后。博主观点：说明太后认可她的品德和能力（约22:24至22:36）。
- 太后专门叮嘱一定要尊重皇后。博主观点：太后既要借她压皇后，又怕她越过中宫（约22:39至22:54）。
- 太后向眉庄催生：“哀家一向看重你，可你却不肯把心思放在皇帝身上”。博主观点：太后担心自己走后没有人给眉庄撑腰（约23:19至23:28）。

甄嬛看出来的细节：太后话里只给了任务和边界，没有给任何实权。她接下的是一把能用的尚方宝剑，同时也是一道绳子。博主观点：回宫想活下去，只能从做棋子开始（约24:14至24:20）。

## 3. 布局链条

目标：让太后认可她是一枚好用的棋子，换来后宫里一份保护伞，不在这一场暴露自己的盘算。
铺垫：
1. 前一天在景仁宫请安送佛珠，这天又和眉庄同行，先把最容易出事的两个人（皇后、太后）摆在“她安分”的印象里（第56集第894幕、第898幕）。
2. 刚才五连问全部平稳通过（见局卡B11），太后气已经顺了。

借谁的手：眉庄。太后催生的火力转向眉庄，甄嬛只需要在一旁听着。眉庄的回答是“是，臣妾知道了”，太后接着说“光知道没用，要做到才行”。

等什么时机：等太后说完每一件事，她再接一句。尤其是“尊重皇后”这件事，太后说完她立刻答。

怎么收网：
1. 简朴一条，用“修行已久，不喜太过奢华”接。
2. 旧恩一条，用“没齿难忘”接。
3. 规劝皇帝一条，用“谨遵太后教诲”接。
4. 尊重皇后一条，用“皇后待臣妾很好，臣妾感激不已”接。博主观点：甄嬛假装不知道皇后害过自己，太后听着心里舒坦，面子上都过得去（约22:57至23:02）。

留了什么后手：
- 太后给的差事很快被兑现。第57集第915幕眉庄告诉她：“此事一出，后宫再没有妃嫔敢恃宠而骄，太后知道了很是欣慰，不住口地赞你。”她回答：“若不是拿祺嫔做样子，难免太后总对我心存疑虑，怕我狐媚惑主，现在动手张扬了，更有人把我恨成眼中钉了。”可见她明白这一课的目的，也知道代价。兑现的具体做法见局卡B13。
- 第58集第923幕太后又一次当着皇帝的面把惠嫔推出来伺候，我们自己的读法：太后既要用她，也在分她的权。

## 4. 关键话术

- 第56集第899幕 甄嬛：“臣妾修行已久，不喜太过奢华。”
  为什么管用：太后点出穿着太简朴，实际是夸；这一句把太后的话接成两人共同的价值观，没有顺势解释或要赏。

- 第56集第899幕 甄嬛：“臣妾在甘露寺时，幸亏有太后百般照拂，臣妾没齿难忘。”
  为什么管用：对方提到自己的恩情时，把恩情说成事实，而且具体到甘露寺这段难处。这时说感谢，比任何空话都更落实。

- 第56集第899幕 太后：“既已回宫，以后就当没有甘露寺这回事，这话哀家会盼咐旁人，你自己也要记得。”
  为什么管用：这是对方给你的保护。甄嬛没有追问细节，没有表示还想为甘露寺辩解，直接接受。

- 第56集第899幕 甄嬛：“臣妾谨遵太后教诲，必不忘妾妃之德。”
  为什么管用：用对方刚说过的词回答，句子短，不加自己的解释，也没有对规劝皇帝的具体内容许诺什么。

- 第56集第899幕 甄嬛：“皇后待臣妾很好，臣妾感激不已。”
  为什么管用：对方要的只是一个表态，并不需要真话。这一句不给太后再追问的口子，也不得罪皇后一系。

- 第57集第915幕 甄嬛：“若不是拿祺嫔做样子，难免太后总对我心存疑虑，怕我狐媚惑主，现在动手张扬了，更有人把我恨成眼中钉了。”
  为什么管用：这是她对眉庄说的私下话，说明她知道交差的方式会引来新的敌人，并没有被太后的夸奖冲昏头。

## 5. 换到职场

### 场合一：老板 1on1（老板交代一项任务，顺带敲打你几件事）

对应的局：老板在一次谈话里对你说“你要多带带新人，别和（某同事）起冲突，以前的事不要再提”，既交代任务也划边界。
打法：
1. 先听完，不打断，也不急着解释。
2. 对敲打的部分，直接接受，用他的话回答，不加辩解。
3. 对任务部分，复述一遍范围，确认他要的结果。
4. 不在这场谈话里提自己的诉求。
5. 过几天用一件小事兑现，让他知道你听进去了。
一句能直接说出口的话：“您说的三件事我记下了：（复述）。我先从（最先能落地的一项）做起，做完第一时间跟您汇报。”

### 场合二：大佬建联（前辈愿意提点你，顺便交代几句忌讳）

对应的局：行业前辈见你一面，说了一通圈子里的规矩和忌讳，其中有你不太认同的部分，也有对你过去经历的看法。
打法：
1. 提点的部分先谢，具体到某一句话。
2. 前辈说的忌讳，先记下，不当场辩论对错。
3. 提过去经历时，不解释，只说现在在做的事。
4. 下一次联系时，带着一个按他提点做出来的结果。
一句能直接说出口的话：“您上次提醒我的（具体一点），我照着做了，结果是（具体结果）。下一步（你的计划）想听听您的看法。”

## 雷区

- 对太后说“皇后待臣妾很好”是场面话，博主观点说她是假装不知道皇后害过自己（约22:57至23:02）。职场里对同事说场面话可以，但不要说成对方事后能核对出来的假话，也不要把场面话变成长期承诺。
- 博主观点：太后一贯主张“女子无才便是德”，所以喜欢眉庄、不喜欢甄嬛（约13:25至13:40）。我们自己核对剧本：第36集第590幕太后对甄嬛说的是“古语说女子无才便是德，哀家觉得不通”，下一句还夸“有才而知进退，福慧双修，这才难得”。这条博主论断与剧本有出入，别当作太后的固定偏好。
- 规劝皇帝这个差事的落地方式，是对祺嫔下手，见局卡B13。职场里领导交代的差事，兑现方式要自己负责，不能拿同事当样板。
- 太后用恩威并施管人。博主观点：先给大棒再给红枣（约15:23至15:26）。职场里对这种管法，越是甜的话越要看后面有没有条件。
- 提过往履历不能总是回避。太后说不要再提甘露寺，她就不提，但对手仍会拿来说。职场里被要求“不提”的经历，要备好一句自己能讲清楚的版本。
