# 回宫次日抢在早会前单独拜见皇后，先请罪再送佛珠（第56集第891至894幕）

局面类型：被试探 / 认错善后
对方：皇后（宜修），中宫，品级和权力都在甄嬛之上，背后是太后，是当年害她小产的幕后之人。最在意的是中宫的体面和对局面的掌控，以及自己的名声。
甄嬛的处境：官面上位高（熹妃，皇帝新宠，有孕），实际上根基未稳。前半段私下，景仁宫内室，皇后还没梳妆完；后半段当众，早会上所有嫔妃在场。
她的目的：不给皇后留任何失礼的把柄，不当场撕破脸；同时让皇后按她设计的方向理解她回宫的动机；还要为后面争取太后的支持留好余地。

## 1. 人设和差异化

她在皇后面前立的是恭敬到极致的熹妃：请罪、送礼、服侍簪花，都认。

和当年的人比：
- 博主观点：比起当年初入宫的晚贵人，她多了一丝王者的从容；比起当年同样直指中宫的华妃，她多了一丝智者的克制（树懒小结界，BV1G63WzYEqA，约00:51至00:58）。
- 博主观点：当年华妃迟到早退，被皇后用牡丹精准地气到，采取过激方式反抗（BV1G63WzYEqA，约07:22至07:44）。甄嬛不接这些刺激，每一句都顺着说。

和早会上的其他人比：安嫔陵容配合皇后说话，敬妃听到要把胧月送回去，嘴角微微抽动（博主观点，BV1G63WzYEqA，约12:29至12:40）。甄嬛什么都不争，回一句“谢娘娘”。

## 2. 读人

皇后：
- 开场：“今儿个也不是初一十五的大日子，熹妃这样早就来了。”（第56集第894幕）博主观点：明知故问，是在试探甄嬛这么殷勤想干什么（BV1G63WzYEqA，约02:40至02:50）。
- 她对甄嬛不再装贤惠，说的话都带刺。博主观点：两人早已知道对方当年怎么害人，再演就假了（BV1G63WzYEqA，约03:55至04:06）。
- 她提“刚从甘露寺回来”，博主观点是提黑历史，打击她的心态（BV1G63WzYEqA，约04:01至04:18）。
- 她让甄嬛簪花，博主观点是示威，暗示你永远是妾，也想借机气她，抓一个失礼的把柄（BV1G63WzYEqA，约07:03至07:16）。
- 她感叹“全不似本宫人老珠黄了”，博主观点是越强调什么越缺什么，皇后拿自己的中宫身份说事，恰恰说明她担心自己的后位不保（BV1G63WzYEqA，约07:25至07:34）。

太后（甄嬛读的第三个人）：
- 博主观点：太后同意迎她回宫，但绝不希望她超越中宫，所以要得到太后支持就必须尊重皇后（BV1G63WzYEqA，约08:56至09:03）。这个判断在当天下午应验了：太后在第56集第899幕说“既然说到妾妃之德，你一定要尊重皇后。”

## 3. 布局链条

目标：第一次碰面不输、不留把柄；让皇后判断她是有备而来的复仇者，不会把她当成碰巧回宫的人。

铺垫：
1. 回宫当天，众人面前她对皇帝皇后说的是“臣妾归来，恭祝皇上、皇后圣体康健、福泽万年。”皇后回应“皇上一告诉本宫你要回来，本宫开心得不得了啊。”她只答“多谢皇后娘娘关怀备至。”（第56集第891幕）一个字都没多说。
2. 她从皇帝的话里推断出皇后参与过永寿宫的装修（第56集第892幕，见局卡B03），知道今天要面对一个有备而来的皇后。槿汐提醒“要紧的是景仁宫”。
3. 佛珠早就备好。

借谁的手：不借人。借的是时间（早会之前）和礼数（请安、请罪、服侍簪花）。

等什么时机：回宫次日一早，赶在早会之前单独去。博主观点：这样她可以和皇后单独说话，不被当众比较，也先把礼数做足（BV1G63WzYEqA，约00:33至00:40）。

怎么收网：
1. 请安，把“没有昨天来”说成自己的过失：“本该昨日一回宫就来的，因而今日特来向娘娘请罪。”
2. 皇后提甘露寺和孕事，她不接，退一步说自己不敢放肆。
3. 送佛珠：一句话里同时有恩德、日日祝祷、有朝一日奉送，把时间线说成早有准备。
4. 皇后示威让她簪花，她照做：“服侍娘娘是应当的，臣妾不敢忘了规矩。”
5. 皇后叹老，她不接“人老珠黄”，转去夸牡丹和母仪天下。
6. 皇后回“牡丹又如何，凭它什么花都会有开有谢”，剪秋此时进来禀报嫔妃来请安，对话到此为止，甄嬛没有回嘴。

留了什么后手：
- 佛珠这句话的指向。博主观点：甄嬛明知这样说会暴露自己早有回宫计划，与她对皇帝的偶遇说法矛盾，这是故意的，她希望皇后相信她是先有回宫计划、再设法接近皇帝、再有孕回宫，因此皇后后来的策略是栽赃嫁祸，没有去查清双生子的来路（BV1G63WzYEqA，约05:46至06:38）。这是博主的推断，剧本中皇后的回话是“最要紧的是妹妹一番聪慧，知道终有一日还能与本宫相见”，可见皇后确实把这句话听成了有备而来。
- 早会上皇后挑拨敬妃和胧月，甄嬛什么都没说（第56集第894幕），之后在第56集第898幕她主动把孩子托付给敬妃，避免了皇后设的坑。
- 当天下午去寿康宫，太后果然要她尊重皇后，她答“皇后待臣妾很好，臣妾感激不已。”（第56集第899幕）

## 4. 关键话术

- 第56集第891幕 甄嬛：“多谢皇后娘娘关怀备至。”
  为什么管用：当众只答一句，不接对方的客气话，不给任何多余的信息。

- 第56集第894幕 甄嬛：“本该昨日一回宫就来的，因而今日特来向娘娘请罪。”
  为什么管用：对方挑礼数时，先把错揽到自己身上，对方没有再追问的理由。

- 第56集第894幕 甄嬛：“皇后关怀，臣妾也不敢太放肆。臣妾在外，不敢忘了皇后恩德，因此日日祝祷，奉了佛珠在佛前开光，希望有朝一日可以奉送给娘娘，保佑娘娘岁岁安康。”
  为什么管用：礼物轻，话却有分量。恭敬，同时给对方出了一个解读题。博主观点：礼物不必贵重，要符合自己修行节俭的人设，也要想想收礼的人是谁，对已是死敌的皇后，心意到了就够（BV1G63WzYEqA，约04:43至05:28）。

- 第56集第894幕 皇后：“熹妃有心。其实东西还是其次，最要紧的是妹妹一番聪慧，知道终有一日还能与本宫相见。”
  为什么管用：这是对方的反应，证明她把佛珠听成了甄嬛有计划。

- 第56集第894幕 甄嬛：“服侍娘娘是应当的，臣妾不敢忘了规矩。”
  为什么管用：被当面示威时顺着认下，对方出的招落了空。博主观点：一拳打在棉花上（BV1G63WzYEqA，约08:13）。

- 第56集第894幕 甄嬛：“皇后娘娘母仪天下，如这牡丹雍容华贵，不知娘娘为何出此伤感之语？”
  为什么管用：对方说软话想让她接，她把话换成夸对方的位置，不碰年龄和容貌。

- 第56集第899幕 甄嬛：“皇后待臣妾很好，臣妾感激不已。”
  为什么管用：在太后面前把对皇后的态度说死，对方的靠山听到的是同一个口径。

## 5. 换到职场

### 场合一：老板 1on1（向与你有过节的上级汇报）

对应的局：你调到新部门，直属上级的上级和你有过旧怨，你要第一次单独见他，他的开场会带刺。
打法：
1. 抢在大会之前单独拜访，不要当众被比较。
2. 先请罪，把没有早点来汇报说成自己的疏忽，小事上认得干脆。
3. 他用旧事刺你，不接茬，只说你愿意把工作做好。
4. 礼物或资料轻而有心，不要拿贵重的东西。
5. 他评价你有心时，说一句就停，不再追加解释。
一句能直接说出口的话：“这几天事情多，没能第一时间来向您汇报，今天特意补上。我这边（具体工作）的进展，想先听听您的意见再往下做。”

### 场合二：大佬建联（在行业活动上遇到曾对你不客气的前辈）

对应的局：你在活动上遇到一位对你不友好的前辈，当众不方便多谈，但你们以后还会合作。
打法：
1. 不要等别人介绍，主动过去打招呼，赶在他被别人围住之前。
2. 对他此前的批评，只承认事实部分，不辩解。
3. 他讲话带刺，你顺着他的位置夸他最看重的东西，不碰他的短处。
4. 不当场要承诺，留下下一次交流的理由。
一句能直接说出口的话：“您之前对（那件事）的提醒我一直记着，这次（做成了某件事）有您的一份启发。改天想专门向您请教一下，您看什么时候方便？”

## 雷区

- 暗藏指向的礼物：博主观点是她顺便阴阳皇后，暗示多年来害了不少孩子，今后别忘了行善（BV1G63WzYEqA，约05:27至05:34）。职场里不要借礼物或客套话暗讽，对方一旦听懂，就是新的矛盾。
- 对不同人讲不同版本：博主指出，她对皇后表示早有回宫的打算，与对皇帝的偶遇说法矛盾（BV1G63WzYEqA，约05:51至06:08）。职场里对不同的人讲不同的版本，两边一对就穿帮。
- 利用对方的误判：她希望皇后相信自己先有回宫计划，这是故意让对方判断错方向。职场里不要刻意制造误导，被识破后信用归零，这里只作识别别人套路时的参考。
- 皇后的试探手段：明知故问、翻旧账、让你当众服侍。职场里遇到上级用同样方法时，不接话、顺着认下礼数，通常比反驳安全。
- 她在早会上完全没有回应皇后的挑拨，也没有为敬妃说话（第56集第894幕）。职场里当众被人挑拨离间，沉默可以避免当场冲突，但要尽快私下补救，她当天下午就做了（第56集第898幕）。
