# 妹妹被皇帝看上，先抢在他开口前把婚事定给皇弟（第64集至第66集）

局面类型：拒绝（对上位者，不能直说不） / 求人办事 / 谈条件
对方：皇帝，最在意面子、不愿被人拒绝，也不愿在妻子面前显得是在抢人；玉娆，甄嬛的三妹，性子刚烈，不愿入宫也不愿为妾；慎贝勒允禧，皇帝的亲弟弟，母亲熙太嫔出身寒微，自称“最不起眼的贝勒”；浣碧（后来的玉隐），被甄嬛托了一件差事；太后，病危，是这件事的时间限制。
甄嬛的处境：官面上强（贵妃，皇帝宠她），实际上弱。她要拒绝的是皇帝亲自看上的人，当面说不会伤他的脸，说错一句还会连累玉娆和家人。私下和当众都有，场合一个接一个。
她的目的：在皇帝正式开口要人之前，让玉娆嫁给皇帝的亲弟弟，并且让皇帝自己点头、自己出嫁妆，事后不记恨。

## 1. 人设和差异化

她在这件事里立的是一个只想给妹妹找好归宿的姐姐，没有一次表现成防着皇帝的妃子。每一次开口，话头都落在妹妹的终身和妹妹自己的意思上。

和玉娆比：玉娆直接硬顶皇帝。皇帝赐名“玉婉”，玉娆当场回“这篇《永怀赋》乃是悼亡之作，臣女还活生生站在皇上眼前呢”（第66集第1023幕）。甄嬛补的是程序和台阶：问出处、追问含义、替皇帝收场。两人一刚一柔，皇帝没法同时对两个人发火。

和浣碧比：浣碧在这件事里是个能办事的人，却有自己的盘算（见读人）。甄嬛不让她做前台，只托她办后手。

为什么对上皇帝的胃口：皇帝既想要玉娆，又要显得自己宽厚，不愿让妻子伤心。甄嬛每次都给他一个“我成全”的位置，他最后真的把成全当成了自己的主意。

## 2. 读人

皇帝：
- 先是送东西试水。赏玉娆步摇、赐崔白的画（第64集第1009幕）。甄嬛当场替玉娆挡掉，说“她素日不爱这些金器，所以不曾戴上”。
- 当面拖延。甄嬛一提“以后要怎样一位妹夫才能管得住玉娆这张利嘴”，皇帝立刻接“再留两年，等慢慢地选个好的再说”（第65集第1015幕）。这句话的意思是：他不想让这件事现在定下来。
- 赐名想把玉娆改成“玉婉”，用的是张华的《永怀赋》（第66集第1023幕）。甄嬛听出来这是悼亡赋，是他在拿玉娆当纯元的影子。博主观点：改名是在试探甄嬛的底线，和之前说要封浣碧做常在是同一个目的，甄嬛不表态，玉娆的事就等于默认了一半（脖子细哔哔叨，BV1TYN76GEvm，约03:56至04:11）。
- 给了鸳鸯佩，说“过些日子再取回”（第66集第1024幕）。苏培盛一眼就看出来：“那个鸳鸯佩是纯元皇后的爱物啊”（第66集第1025幕）。皇帝自己说：“她有福气的日子在后头呢。”这是他已经打定主意的信号。博主观点：他把纯元的遗物放在玉娆手里，取回之日怕就是封玉娆为嫔妃之时（BV1TYN76GEvm，约10:09至10:17）。
- 软处：被人当面拆穿时，他退得很快。甄嬛一说“皇上，您不会是有以玉娆为妻之心吧”，他马上表态“妻者惟中宫皇后，朕无此心”（第66集第1023幕）。甄嬛一说出伤心的话，他马上说“可见是朕莽撞”。他怕在妻子面前显得失态。博主观点：他只否认了为妻，没有否认看上玉娆（BV1TYN76GEvm，约06:10至06:15）。

玉娆：
- 她和允禧是真心。第64集第1010幕两人路遇，聊元好问的词；第66集第1029幕她承认“允禧他和皇上不一样，他很好”。
- 她不愿做替身：“甄玉娆就是甄玉娆，只可独一无二，不能为人替身。”（第66集第1024幕）

允禧：身份尴尬，母亲出身寒微。他自己说“我什么都不要，就只要玉娆”，“我心匪石，不可转也”（第66集第1034幕）。皇帝想抢，要先从亲弟弟手里夺人，道义上不好看。这是甄嬛最大的一张牌。

浣碧（读人提示，不作打法）：甄嬛说“交给我来办”之后，浣碧去找的是果郡王府的旧人采蘋，让她进宫陪皇帝，说“咱们府不也就多了一重保障吗”（第66集第1030幕）。她的算盘有两层：替长姐分散皇帝的注意，同时给王府在宫里留一条路。甄嬛听到人选时一愣，说“怎么是她呢”（第66集第1035幕）。博主观点：浣碧一听就把目标定在采蘋身上，既替甄嬛解了难题，也除掉一个可能吸引王爷的人，因为她从清凉台时期就把采蘋当成对手（BV1TYN76GEvm，约16:25至16:38、18:19至18:34）。我们自己的判断：这是用一个无辜的人去换时间，不属于甄嬛的打法，只能当作一个提醒：身边人替你办事时，会按自己的利益改方案。

时间：太后病危，甄嬛说“太后一旦崩逝，你们还要守三年国丧，夜长梦多”（第66集第1035幕）。

## 3. 布局链条

目标：玉娆的婚事在皇帝开口之前定给允禧，由皇帝亲口批准。

铺垫：
1. 先替妹妹挡礼物。第64集第1009幕，皇帝赏步摇，甄嬛替玉娆推掉，顺带一句“臣妾也希望来日小妹成婚不要离臣妾太远”，第一次把成婚这件事放到皇帝面前。
2. 再当面提婚事。第65集第1015幕，园中遇见，甄嬛主动问“以后要怎样一位妹夫才能管得住玉娆这张利嘴”。皇帝拖延，反而顺口提起允禧：“允禧今日进宫来了，跟朕说天气好要去圆明园比箭”，等于自己把允禧和玉娆放到了同一个场合。
3. 赐名那一幕，把皇帝的心思逼到明处（第66集第1023幕）：先问“可有什么出处吗”；玉娆回敬；甄嬛再追一句“您不会是有以玉娆为妻之心吧”，让皇帝亲口说“朕无此心”；然后讲“玉娆性子高傲，必不能为人妾室”；最后说“你难道忍心看臣妾的姐妹都为人妾室吗”。皇帝退到“日后若有好人家，朕再好好为她留心”。这句口头承诺，后面用得上。博主观点：这一幕里，甄嬛没有直接反对改名，把问题抛回给皇帝；等皇帝说出他想纳妾的心思，再抓住妾室这一点，局面从改不改名变成了当不当妾（BV1TYN76GEvm，约04:11至04:46、06:28至07:38）。
4. 回永寿宫先问妹妹本人（第66集第1029幕）：“慎贝勒，是什么时候开始的事？”玉娆答“大约……我也不记得了”。确认她是真心之后，才定方案：“只有嫁给皇上的亲兄弟，才能彻底断了皇上的念头。”博主观点：皇帝再怎么样，也不能抢弟弟的妻子（BV1TYN76GEvm，约15:53至15:58）。
5. 确认对方的态度：允礼去问允禧“你对玉娆是否真心”，得到“我心匪石，不可转也”（第66集第1034幕）。
6. 对妹妹交底，不夸大把握：“我们虽然没有十足的把握，但都要尽力一试，不叫你和慎贝勒抱憾终身。”（第66集第1035幕）

借谁的手：允礼和允禧，兄弟之间去说；玉娆自己出面当面讲清楚；皇帝自己说出来的“日后若有好人家”。

等什么时机：皇帝刚好在园中看见两人在一起（第66集第1037幕）。甄嬛没有安排，也没有解释：“无需故意，这样的事天天都会有。”

怎么收网：
1. 园中让皇帝自己看到。甄嬛先说“何不成全了他们”；皇帝说“朕自有办法”；她回“即便皇上有办法，也得问问玉娆的意思，若不然勉强又有何益呢？慎贝勒又是您的亲弟弟”。这句话把“夺人”改写成“夺弟之爱”，皇帝沉脸离开。
2. 她明知皇帝生气，仍然这么做。槿汐担心迁怒，她答：“无论什么意思，我都得这么做。”（第66集第1040幕）
3. 皇帝亲自上永寿宫试探玉娆。玉娆把话讲死：“请皇上像喜欢小妹一样喜欢臣女吧。这是皇上交由臣女保管之物，臣女完璧归赵”（第66集第1041幕）。皇帝说：“这玉佩朕赐给你了。”
4. 皇帝自己下旨：“熹贵妃嫁妹，可按多罗格格出嫁之仪备办嫁妆……就当是为太后冲冲喜吧。”（第66集第1042幕）他还在养心殿问苏培盛“朕看上一个女子，想要纳她为妃她却不肯，你怎么看”，苏培盛劝他“能替纯元皇后伺候皇上高兴”才是福气，皇帝接着就吩咐备办嫁妆。
5. 车上他说：“有你，朕愿意成全玉娆。”（第66集第1045幕）

留了什么后手：
- 玉佩由皇帝亲口赐给玉娆，等于他自己给了这件事一个了结。
- 婚事按格格出嫁的规格办，皇帝出的规格，不容易反悔。
- 嫁的是亲弟弟，以后有风声，皇帝面对的是自己的弟弟，外人插不上手。

## 4. 关键话术

- 第65集第1015幕 甄嬛：“臣妾最怕的也是玉娆这张嘴，臣妾老在想，以后要怎样一位妹夫才能管得住玉娆这张利嘴？”
  为什么管用：用一句玩笑把妹妹该嫁人了这件事摆到皇帝面前，没有指名，也没有任何人被冒犯。

- 第66集第1023幕 甄嬛：“婉字也就罢了，可有什么出处吗？总不能说皇上赐名是随便捡了个字来送了三妹。”
  为什么管用：对赐名这种“恩典”不拒绝，只追问出处，让对方先亮出自己的用意。

- 第66集第1023幕 甄嬛：“张华的《永怀赋》乃是悼念亡妻，皇上，您不会是有以玉娆为妻之心吧？”
  为什么管用：把对方没说出口的心思问成一句让他无法承认的话。他只能当场撇清。

- 第66集第1023幕 甄嬛：“臣妾福薄无德，甘居妾妃之位侍奉皇上终身，而玉娆性子高傲，必不能为人妾室侍奉左右。”
  为什么管用：先把自己放低，再把妹妹的条件讲死。皇帝刚撇清了“为妻”，剩下的路只有“为妾”，被这句话堵上。

- 第66集第1023幕 甄嬛：“皇上，你难道忍心看臣妾的姐妹都为人妾室吗？”
  为什么管用：把拒绝换成姐姐的心疼。皇帝要是再坚持，就成了不心疼她。

- 第66集第1029幕 甄嬛：“慎贝勒，是什么时候开始的事？”
  为什么管用：替人拿主意之前先问本人。这样后面所有的“成全”都有了站得住的理由。

- 第66集第1037幕 甄嬛：“即便皇上有办法，也得问问玉娆的意思，若不然勉强又有何益呢？慎贝勒又是您的亲弟弟。”
  为什么管用：把皇帝最有力的手段（权力）和最难看的后果（夺弟弟的人）放在同一句话里。

## 5. 换到职场

### 场合一：职场（老板或大领导看中你团队里的核心成员，想直接调走）

对应的局：另一个部门的负责人或你的老板，开始频繁给你组里的核心成员派活、请吃饭、当面夸，你知道他下一步就是要人。直接说“不行”会得罪他，不说就等于默认。
打法：
1. 先问本人。这个人想不想走，想往哪个方向发展。他不想，你的话才站得住。
2. 在对方开口要人之前，先把这个人的下一步安排明白，最好是对方认可的方向。比如争取到转正、晋升或一个对方也看好的项目。
3. 对方开口时，不否认他的欣赏，只把话题转到这个人自己的发展上，让他自己说出不勉强。
4. 对方说出来的口头表态，当场记下，后面用它收尾。
5. 事后让对方在这件事上有面子，比如请他在公开场合肯定这个安排。
一句能直接说出口的话：“（姓名）这两年一直想往（方向）走，您看重他我们都知道。我想先问问他自己的意思，如果他愿意，（具体安排）对他的发展更合适，您看这样行吗？”

### 场合二：日常（替家人拿主意：亲戚或长辈想把你妹妹介绍给一个条件好、但你不放心的人）

对应的局：家里长辈或亲戚，热心要把你妹妹介绍给某个有钱有势的人，对方也已经表现出兴趣。你不放心，妹妹自己心里已经有人了。直接回绝，长辈觉得你不识抬举。
打法：
1. 先找妹妹单独问清楚：她心里有没有人，是不是真心，什么时候开始的。
2. 再去核对那个人靠不靠谱，找他身边的人问一句真话。
3. 对长辈不说她不愿意，把话落在妹妹的将来上，比如说她这个性子，进不了那样的人家。
4. 趁对方还没正式开口，让妹妹和意中人的事先有个明路，比如先让两家大人见一面。
5. 约好妹妹：事情没定之前不要私下出去见面，免得落人话柄。
一句能直接说出口的话：“（叔叔），您想着她，我们全家都记着。她性子倔，我想先问问她自己的意思，也跟她说好了，有了合适的人，一定先让您帮着看。”

## 雷区

- 采蘋的安排。浣碧的办法是送一个王府里的旧人进宫去吸引皇帝，换时间。这个办法让一个无辜的人被推进宫里，甄嬛当场也说了“怎么是她呢”。职场里对应：别把一个无关的人推出去替你挡事，对方一旦发现，会把账算在你头上，被推出去的人也会记恨。
- 先斩后奏的风险。甄嬛在园中让皇帝看到两人，等于当面表明了态度，皇帝沉脸离去（第66集第1037幕）。槿汐也担心“皇上真的生气了，会迁怒了娘娘”（第66集第1040幕）。这一步成功，靠的是此前已经让皇帝亲口说过“朕无此心”和“日后若有好人家”。没有这两句铺垫，不要去做这一步。
- 玉娆太刚。她敢在皇帝面前说“甄玉娆就是甄玉娆”，是因为姐姐在旁边接着。职场里，性子直的人当面顶上级之前，要先有人在旁边负责收场。
- 允礼提醒过允禧：“咱们怎么争也争不过皇上。”（第66集第1034幕）没有胜算时硬争，结果最差。甄嬛也没有让他们去争，她让皇帝自己点头。
- 皇帝赐的鸳鸯佩如果收下，就是一个让他一直有借口的信物。玉娆第一时间想退（第66集第1024幕），甄嬛没有让她急着还，等到玉娆亲自见皇帝时当面交还（第66集第1041幕）。职场里对应：上级私下给的、不明含义的东西，先别当场拒绝让他难堪，也别留着不处理。
