# 景仁宫被告发，先拆证人（第62至63集第996幕）

局面类型：被当众发难
对方：祺贵人（瓜尔佳文鸳）带来的证人玢儿、斐雯，幕后是皇后宜修，后宫众人和皇帝稍后到场。对方最在意的是把私通的罪名坐实，皇后还要保住“公正的法官”这个体面。
甄嬛的处境：官面上位高（熹贵妃），实际上弱。罪名一旦成立就是死罪，当众，人证已经摆上，而且她自己也有真正怕被查出来的另一件事（博主观点，BV1PFPLzVE9R，约03:00至03:23）。
她的目的：不去证明“我没有”，转去拆掉最关键的证人斐雯，让皇后的证据链断掉一环。

## 1. 人设和差异化

她在这场里立的是受了冤屈但不乱、讲分寸的贵妃。

和其他人比：
- 温实初一进门就慌，自己编了一个“喝茶卷袖口”的故事（第62集第996幕），越解释越被人抓住。
- 祺贵人发毒誓、骂人（第63集第996幕“甄嬛生性淫贱”），情绪压过了证据。
- 甄嬛的做法是对已经成立的事实不反驳，对说不清的事不自证，只去动证人的可信度。

为什么对上现场人的胃口：皇后需要一个“中立法官”的样子，不能阻止当事人发问；皇帝在乎的是不丢脸和查清楚。甄嬛按规矩开口要审问权，把自己放在“请求查明”的位置。

## 2. 读人

- 斐雯：博主观点是口齿伶俐，心理素质过关，吓唬两句不会露馅，像是被辅导过（BV1PFPLzVE9R，约09:41至10:08）。所以普通质问行不通，甄嬛才设计了需要具体答案的问题。
- 皇后：要扮演公正，不方便直接偏袒证人。博主观点：甄嬛先客客气气讨要审问权，皇后只好保持微笑同意（约10:13至10:27）。剧本里甄嬛的原话是“容臣妾问她几句话”（第63集第996幕）。
- 祺贵人：沉不住气，容易被激得说出更难听的话（博主观点，约18:55至19:06）。
- 温实初：关心则乱，越描越黑（博主观点，约05:17至05:19）。他后来还搬出“浣碧和槿汐二位姑姑替微臣作证”，被祺贵人一句“谁不知道槿汐和浣碧是熹贵妃的心腹，她们的证词怎么可以作数”顶回去，反而引出重刑拷打（第63集第996幕）。
- 玢儿的证词是真事（选秀前温实初提过亲），甄嬛没有反驳。博主观点：反驳只会暴露更多破绽（约08:10至08:12）。
- 斐雯说的“拉手”“对视”无法证明，博主观点是一旦对质就陷入自证逻辑，所以甄嬛绕开具体内容，转去否定证人信誉（约08:21至08:55）。

## 3. 布局链条

目标：打掉斐雯这个证人，让指控失去最硬的一环。

铺垫：
1. 玢儿的话属实，不争。
2. 斐雯说的“拉手”只有她一个人看见，无法对质，不碰。
3. 同伴各自补一刀：敬妃指出温太医袖口花纹“也不是一日两日的了”（第62集第996幕），后来又说“这丫头讲的话不能相信，恐怕后面还有更大的阴谋”（第63集第996幕）。端妃问“怎么斐雯回回都能瞧得见”。

借谁的手：
- 皇后的法官身份，被甄嬛借来当程序依据。
- 槿汐配合，当场纠正斐雯。
- 敬妃、端妃、欣贵人、贞嫔先后从不同角度补问，把斐雯和祺贵人绑在一起。

等什么时机：斐雯说完“只能对皇上一人尽忠”之后。甄嬛立即反扣“你对皇上尽忠也算得罪本宫的话，岂非要置本宫于不忠不义之地了？”（第63集第996幕）这一下堵住了对方预备好的话。

怎么收网：
1. 先要审问权：“容臣妾问她几句话。”
2. 诱导表态：“斐雯，无论今日之事结局如何，你都不能再回永寿宫再伺候本宫了。”斐雯答“只要是在宫里伺候，无论服侍哪位小主，奴婢都会赴汤蹈火在所不辞”。立住了我很认真负责的人设。
3. 抛一个对方必须回答的具体问题，问桌上的琉璃花樽擦了没有（桌上本来没有）。斐雯说“已经擦了”。
4. 槿汐补一刀，说那分明是青玉的。斐雯改口“是奴婢记错了，是青玉花樽”。
5. 甄嬛揭底：正殿紫檀桌上从未放过什么琉璃花樽。斐雯连日常差事都记不清，却能记住袖口花纹，供词不可信。
6. 补一句质问动机：“如此居心实在可疑。”

留了什么后手：
- 斐雯的反应是“日夜心里只牵挂着这件大事，哪里还留心得了别的事情”（第63集第996幕），等于自己承认了盯梢。后面接着被端妃、敬妃、欣贵人从不同方向追问。
- 皇帝到场后先打了祺贵人一巴掌，再答应传静白。这一局没有赢到最后（后续的静白作证在下一个局），但至少断了斐雯这一环。

## 4. 关键话术

- 第63集第996幕 甄嬛：“斐雯，你在宫里这些日子，本宫倒没瞧出你有这份心胸。”
  为什么管用：开口先点出对方的反常，用一句看似夸奖的话暗指她背后有人。

- 第63集第996幕 甄嬛：“你对皇上尽忠也算得罪本宫的话，岂非要置本宫于不忠不义之地了？”
  为什么管用：对方拿出一个冠冕堂皇的理由时，把这个理由推到最极端，让她自己收回。

- 第63集第996幕 甄嬛：“容臣妾问她几句话。”
  为什么管用：按程序要发问权，拿到问话的主动。

- 第63集第996幕 甄嬛：“斐雯，无论今日之事结局如何，你都不能再回永寿宫再伺候本宫了。”
  为什么管用：先让对方表态，给后面的问题定一个你已经想好离开的前提。

- 第63集第996幕 甄嬛：“正殿紫檀桌上从未放过什么琉璃花樽，你伺候本宫，不把心思放在正经事上，倒日日留心哪位太医的手搭了本宫的手，翻出来的袖口上绣了什么花样，这些情景若是放了旁人，是看都不敢看，为何你连枝叶末节都这般留意？如此居心实在可疑。”
  为什么管用：用对方自己前后的记忆反差，指出她在选择性地记，把质疑从“我做没做”换成她为什么盯着我。

- 第63集第996幕 槿汐：“胡言乱语，娘娘的紫檀桌上何曾有琉璃花樽，那分明是青玉的。”
  为什么管用：同伴不替她辩护，只补一个只有熟悉的人才知道的细节。

- 第62集第996幕 敬妃：“臣妾以为温太医袖口上的花纹也不是一日两日的了，但凡是个有心人都会留意看见的，这也说明不了什么呀。”
  为什么管用：把对方的“独家证据”降成公共信息。

## 5. 换到职场

### 场合一：面试（压力面，面试官抓住简历一处细节质疑）

对应的局：面试官说“这个项目你好像只是参与，不是主导吧”，或者怀疑你夸大了成果，其他面试官在旁边看。
打法：
1. 属实的部分先认，不辩解。认得越干脆，后面的话越可信。
2. 不在你说得清说不清的点上自证。直接拆分：哪一块是我做的，哪一块是团队做的。
3. 想反问时先要发问权，问一个可以核对的具体问题，让对方也说出他的判断标准。
一句能直接说出口的话：“您说得对，这个项目整体是团队做的，我负责的是（具体一块），产出是（数字或结果）。您想深挖哪一块，我可以展开讲。”

### 场合二：聊投资（投资人当面拿一个数据点或口径质疑你）

对应的局：路演问答，投资人说“你这个增长是不是靠投放堆的”，或者怀疑某个口径。
打法：
1. 先问清对方指的是哪个口径，避免被带去别的战场。
2. 对已经成立的事实不躲，说这部分确实如此。
3. 把话题拉回他需要判断的核心问题，比如您真正关心的是留存还是成本。
4. 对方在口径上说不清的地方，用一句话请对方给出他的参照。
一句能直接说出口的话：“这一点我先确认口径，您说的增长是指（某指标）对吗？如果是，这部分确实有投放的贡献，我们把自然增长和投放增长拆开给您看。”

## 雷区

- 温实初：被指控时为没发生的事编故事解释，越编越多，被抓住。博主观点（BV1PFPLzVE9R，约04:43至05:07）。职场里对应：被问没做过的事，直接说没做过，不要编细节来圆。
- 温实初：搬出自己人作证，被对方一句“谁不知道槿汐和浣碧是熹贵妃的心腹，她们的证词怎么可以作数”顶回去。职场里对应：用自己人做证人的说服力很弱。
- 斐雯：同一个细节三次说法不同（琉璃、青玉、记不住），说“日夜心里只牵挂着这件大事，哪里还留心得了别的事情”，等于自己承认了动机（第63集第996幕）。职场里对应：被追问时前后改口，信用当场归零。
- 祺贵人：拿毒誓、骂人代替证据，情绪越高越容易被人抓住。
- 甄嬛设假前提再追问的做法：要有同伴当场纠正，对方必须是在说谎。拿到职场里，别设假前提去套同事，一次被识破，对方和旁观的人都会觉得你不可信。
- 陵容：用“念佛的人心肠都好”把甄嬛抬到圣洁的位置，再暗示她在甘露寺不检点（博主观点，约17:55至18:12）。这是害人的话术，职场里需要识别：有人夸你的同时在埋你的坑。
