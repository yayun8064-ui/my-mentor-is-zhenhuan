# 离宫前给女儿取名绾绾，托敬妃抚养胧月，体面告别（第45至46集）

局面类型：谈条件 / 求人办事（兼告别）
对方：皇帝（雍正）是主要对手，敬妃是接手人。皇帝刚发完火又舍不得，最在意的是面子和权威，不能接受被人当面抛弃；敬妃最在意的是自己没有孩子可以依靠，以及在宫里站稳。
甄嬛的处境：弱。刚早产生下公主，家族被流放，父亲病危，皇帝在碎玉轩当着敬妃和下人的面劝她“想明白”。她手里没有任何筹码，只有开口的顺序和措辞。
她的目的：自己决定离开，不求恩，不翻脸，同时给女儿争到三样东西：自己取的名字、可靠的养母、不被皇帝迁怒。

## 1. 人设和差异化

她在这场里立的是认下自己不适合留在宫里这个结论，并且一件一件把后事安排清楚的人。

和其他人比：
- 皇帝先递了封妃的台阶，又说“朕待你还和从前一样”，以为自己在施恩（第45集第741幕）。博主观点：皇上从来没觉得自己在伤害甄嬛，在他心里已经从轻处置，对方应当感恩（BV1hoR7BzEU9，约03:46至04:12）。
- 敬妃只说了一句“妹妹，你何苦呢？”（第45集第741幕），是旁观者的心疼。
- 眉庄在离宫前说“你走了，我一个人还有什么意思”（第46集第743幕），是情绪。
- 甄嬛从头到尾没有哭诉，没有控诉皇帝，也没有说“你会后悔”。她先接下皇帝的气话，再顺着气话提要求，每一句要求都放在孩子身上。

为什么对上皇帝的胃口：皇帝要的结局是他自己下令“去佛堂静静心”（第45集第741幕），这样他是发令的人，没有被人抛下。甄嬛把离开说成“臣妾不详之身，不敢扰了宫中平安”，让他保住了赶人的体面，他才肯一路答应下去。

## 2. 读人

皇帝：
- 被她一句“从前？皇上以为还能回到从前吗？”（第45集第741幕）顶回去之后，当场脸色一变，说“实在是不适合留在宫中”。这是被拒绝后的气话。博主观点：皇上说她不适合留在宫中，其实舍不得她走，是气话，也是想逼她服软（约07:54至08:06）。
- 听到名字，第一反应是“菀菀？”（第45集第741幕）。纯元是他最放不下的人，名字同音会戳到他的执念。甄嬛立刻把话讲明白，不给他自己联想的空间。
- 他看重的是自己给过机会这个姿态。后面提宝华殿，是给自己找台阶，让她别走得太难看。
- 博主观点：绾绾与纯元小字同音，皇上每次见到公主会想起纯元，可能因此多照顾公主；“长发绾君心”也是在表明对他仍有感情（约09:28至10:19）。我们自己的判断：剧本没有写甄嬛是否有意借同音，这一层是博主的推测，只能当作可能性。

敬妃：
- 甄嬛失宠失子时，宫里只有敬妃、眉庄和敦亲王福晋来看过她（第42集第689幕）。
- 敬妃在甄嬛生产当天劝眉庄先别去，让皇帝自己去听莞嫔怎么拼命生孩子（第45集第737幕），可见她会算，也站在甄嬛这一边。
- 她没有亲生孩子。交接胧月时，敬妃自己说出“是你体恤我没有孩子可以依靠”（第46集第742幕）。
- 博主观点：敬妃心善、位分不低，眉庄位分低、自顾不暇，交给敬妃就是两个人疼公主（约11:17至11:42）。

先例：温宜公主交给端妃，是甄嬛自己在第42集第682幕提议的（“我愿意为娘娘尽力一试”）。所以皇帝在第45集第741幕说“端妃已经收养了温宜，敬妃还可托付”，用的是现成的做法，不需要甄嬛说服。

## 3. 布局链条

目标：离宫前把女儿安置好，自己体面地走。

铺垫：
1. 不接封妃：“臣妾失德，不敢忝居妃位。”（第45集第741幕）这一步是把“留下”这个选项关掉。
2. 回绝“还和从前一样”：“从前？皇上以为还能回到从前吗？”皇帝翻脸，说出“去佛堂静静心吧，不用住在这儿了”，离开由他开口，她没有提出请求。
3. 接下这句命令：“多谢皇上。”把赶人的体面还给他。

借谁的手：皇帝自己的先例。她还没说完理由，皇帝已经先提起端妃养温宜这件事，抚养的理由由皇帝补全。

等什么时机：皇帝说完“去佛堂”之后。她说“公主只会因为臣妾而备受苦楚”，把取名字说成母亲能给女儿的最后一件东西，趁他心里有愧时开口，他答了一个“好”。

怎么收网：
1. 取名。绾绾，讲明来由，同时把纯元摘出去。
2. 宝华殿是皇帝给的台阶，她回绝，理由是自己不吉。
3. 提抚养人，只报敬妃娘娘这一个名字，不贬低别人。皇帝自己补上“端妃已经收养了温宜，敬妃还可托付”，再赐封号“胧月”。
4. 对恩典当场道谢：“胧月一出生就能得此殊荣，臣妾多谢皇上垂爱。”
5. 留诀别诗，三叩首。皇帝留下一句承诺：“胧月，朕自会和敬妃好好抚养。”

后手（离宫前的最后一天，第46集第742至743幕）：
- 当面把孩子交给敬妃，同时免掉她“视如己出”的负担。
- 安排身边人的去处，愿意留的留，愿意跟的跟。
- 皇帝赏的东西一件不带，全部锁上等内务府清点。
- 把眉庄托给温实初和敬妃，叮嘱眉庄不要为她使意气。

## 4. 关键话术

- 第45集第741幕 甄嬛：“臣妾失德，不敢忝居妃位。”
  为什么管用：皇帝递来的是台阶，接下来就要重新进入从前的关系。用“失德”两个字把自己放在被处分的位置，对方没法再往下劝。

- 第45集第741幕 甄嬛：“从前？皇上以为还能回到从前吗？”
  为什么管用：只复述对方那个词，用问号退回去，没有指责，也没有解释。皇帝自己接了气话，离开的决定因此落在他嘴里。

- 第45集第741幕 甄嬛：“不错，臣妾是不用住在这里了，公主若有臣妾这样的母亲，有这样落魄的家族，公主只会因为臣妾而备受苦楚。臣妾既想离开，孩儿的姓名就允许臣妾来取吧，请皇上成全。”
  为什么管用：先认下他的话，再把自己的处境说成“对孩子不利”，提的要求只涉及一个名字，成本小，皇帝容易答应。

- 第45集第741幕 甄嬛：“臣妾怎敢让公主沿用先皇后的小字这样大不敬”
  为什么管用：对方听到同音字已经皱眉，她抢在他开口前把冒犯的可能性自己说出来，并且摆明立场。

- 第45集第741幕 甄嬛：“不，臣妾不详之身，不敢扰了宫中平安。”
  为什么管用：皇帝给了一个留在宫里的台阶，她拒绝，理由只讲自己，不拿皇后或旁人当借口。

- 第45集第741幕 甄嬛：“臣妾出宫后，希望能由敬妃娘娘来抚育公主，若能如此，臣妾再无遗憾。”
  为什么管用：只报人选，不比较别人，也不解释为什么选她。皇帝想起端妃的先例，自己把理由补全。

- 第45集第741幕 甄嬛：“公主都是满月那日才能赐予封号，胧月一出生就能得此殊荣，臣妾多谢皇上垂爱。”
  为什么管用：对方给了额外的恩典，她点出这件事不寻常，让他觉得自己被看见。这一步是为孩子换一份将来的体面。

- 第45集第741幕 甄嬛：“朱弦断，明镜缺，朝露晞，芳时歇。白头吟，伤离别，努力加餐勿念妾，锦水汤汤，与君长诀。”
  为什么管用：用诗把话说完，语气里没有威胁也没有怨，皇帝说“朕亦无话可说”，没有留下可以反驳的地方。博主观点：诀别诗既没把话说得太狠，也明确表达了自己的态度（约12:43至12:50）。

- 第46集第742幕 甄嬛：“我在这宫里多待一天，公主只会多一分危险。从今往后，姐姐便是公主的额娘了。”
  为什么管用：直接告诉接手人你为什么必须走，并且在交接的一刻明确名分，不让对方做“代养”的角色。

- 第46集第742幕 甄嬛：“胧月是姐姐的孩子，何来视如己出这一说呢？我相信姐姐会照顾好公主的。”
  为什么管用：敬妃说“视如己出”，等于承认这是别人的孩子。甄嬛主动把这层说法拿掉，换成信任。

- 第46集第742幕 甄嬛：“什么都不用，带一些寻常衣物即可。把长相思带上吧。”
  为什么管用：赏赐一件不带，免得离开之后还有人拿带走皇上赏赐这件事做文章，只留一件私人的琴。

- 第46集第743幕 甄嬛：“姐姐在宫中一日，就千万要留意安陵容和皇后，不要为我使意气，安心保重自己要紧。”
  为什么管用：最后一次见面，对最可能替她出头的人提醒的是对手名单，叮嘱对方先保自己。

## 5. 换到职场

### 场合一：职场（决定离职，走之前要把团队和项目安排好）

对应的局：你已经决定离开，老板先抛出涨薪、升职之类的挽留。你仍然放不下手下的人和还没做完的项目，想在走之前把去向定下来。
打法：
1. 老板的挽留先接住，再回绝。理由只讲自己，一句话讲完，不翻旧账。
2. 回绝之后紧跟一个很小的请求：交接安排。请求放在对方心里有愧或有台阶的时刻，不要和别的诉求打包。
3. 提接手人只说名字和一条理由，不比较别人，让老板自己补出他想到的先例。
4. 当面说谢谢，谢的是具体的一件事。
5. 离开前把资料、账号和未完成事项逐项清点，写成交接清单，交给接手人，不要只留给老板。
一句能直接说出口的话：“谢谢您愿意留我，这个位置我先不接。我已经决定（日期）离开。走之前想把（项目）交给（同事），他（一条具体理由）。您看这样安排可不可以？”

### 场合二：日常（家人，因工作或搬家要离开，需要把照顾长辈的事托付给亲戚）

对应的局：你要去外地工作，一直是你在照顾奶奶，想拜托姑姑接手，又担心姑姑觉得被硬塞一个负担。
打法：
1. 先说你为什么必须走，讲你的处境，不指责任何人。
2. 把你能留下的那一份说清楚，比如每月的药费、复诊陪同的时间，让对方知道自己接手有人分担。
3. 请对方接手的是最需要她的那一块，其余留给原来的分工，避免对方变成接手全部的人。
4. 把名分说平：不用对方做“你的替身”，把话说成这是奶奶的事，大家一起照顾。
5. 交接完对方的亲戚也要提醒一句，比如谁容易挑拨，不要多讲别人坏话。
一句能直接说出口的话：“我下个月要去（城市）工作，奶奶这边我会把（药费、复诊、每月回来几天）安排好。想拜托您多费心（一件具体的事），其余的事我们一起分。奶奶最信您，我才开这个口。”

## 雷区

- 皇帝：以为封妃是足够大的恩典，听不懂她要的是他的真心（博主观点，BV1hoR7BzEU9，约06:10至06:32）。职场里对应：老板以为加薪能留人，你的真实原因他不一定想听。回绝时把理由压到一句，别展开讲细节，细节一多就成了谈判条件。
- 名字与纯元小字同音，皇帝第一反应是“菀菀？”（第45集第741幕）。如果甄嬛没有立刻澄清，这个名字会被当作冒犯。职场里对应：你给项目、产品或文档起的名字，如果和老板的忌讳撞上，先说来源，不要等他自己联想。
- 博主观点：甄嬛为了公主的周全，还得对皇上虚与委蛇（约12:11至12:15）。我们自己的判断：这是她的离场策略，只适合在离开之前的最后一次谈话里用。职场里如果还要继续共事，不能靠敷衍对方来换交接。
- 皇帝说“宫中也留不得了”是气话（第45集第741幕）。职场里对应：老板在气头上说“你不用来了”，不要当作正式通知，也不要当场同意，等正式书面。
- 托付是一次性的信任，无法永久担保。敬妃日后被皇后利用，害过甄嬛（见局卡B22）。职场里对应：交接给同事的事项要写成清单，留存证据，别以为一次托付就万无一失。
- 诀别诗里的“努力加餐勿念妾”，没有任何威胁的成分。职场里对应：离职信不要夹带“你们会后悔”这类句子，对方记住的永远是最后一句话。
