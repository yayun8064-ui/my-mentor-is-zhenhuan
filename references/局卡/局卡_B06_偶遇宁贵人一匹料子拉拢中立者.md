# 偶遇宁贵人，一匹料子拉拢中立者（第56集第894至896幕）

局面类型：投其所好 / 闲谈社交
对方：宁贵人（叶澜依），皇帝新宠，性子孤傲，不受宫规驯化，和皇后一方不对付，太后不待见她。最在意的是自己不被当作皇帝的附属品，情绪上对落花这类东西特别敏感。
甄嬛的处境：强。妃位远高于贵人，皇帝宠着，有孕。私下，御花园偶遇，随后在永寿宫当着眉庄的面处理这匹料子。
她的目的：不得罪、不立敌，给这位还没摸清底细的中立者留下好印象，为日后拉拢打底；同时把这件事做成皇帝看得见的体贴与节俭。

## 1. 人设和差异化

她在宁贵人面前立的是没有架子的熹妃：被顶了也不恼，关心她的身体，夸她的心意，事后送一匹料子又告诉她不用来谢恩。

和旁人比：
- 浣碧：“她怎么这样无礼？不过是仗着皇上喜欢她罢了，怪不得别人都说她孤僻桀骜。”（第56集第895幕）浣碧在乎的是对方对主子的态度。
- 眉庄：“不必对她太好，太后就头一个不待见她了，她的性子又孤傲，合宫里没有和她处得来的。”（第56集第896幕）眉庄看的是风险。
- 甄嬛看的是这个人的性格值不值得结盟。博主观点：她判断一个人，只看性格特质和是否值得结盟，从来不把注意力放在对方对她的态度上（树懒小结界，BV1G63WzYEqA，约18:25至18:33）。

## 2. 读人

宁贵人：
- 第一次交锋很不客气：甄嬛问“那你如何知晓本宫是熹妃？”她回“娘娘这样大的阵仗进宫，有谁不知道？”（第56集第895幕）
- 自我介绍只说“嫔妾是贵人叶氏”，没提皇帝赐的封号。博主观点：说明她从来没有忘记自己是谁，没有把自己视为皇帝的附属品（BV1G63WzYEqA，约16:54至17:00）。
- 被问到摘花瓣的原因时，她的态度软下来：“太医说嫔妾病着，需拿合欢花入药，所以就来收了些，左不过这落花白白入泥也是可惜了。”（第56集第895幕）博主观点：被问及最隐秘的情感，她一改嚣张，有些慌了（BV1G63WzYEqA，约17:41至17:46）。
- 她对落花的态度，和甄嬛刚才说“留得住一时也留不住一世，即便做成香囊，到底还是要枯萎的，不如随它去吧”（第56集第895幕）形成对照。博主观点：甄嬛因此产生共情，感到一丝温暖（BV1G63WzYEqA，约22:22至22:32）。
- 她的颜色偏好：甄嬛判断“大约喜欢绿色”（第56集第896幕）。博主观点：她从头到脚都是绿色（BV1G63WzYEqA，约20:59至21:05），剧本里这一视觉细节本卡未核对。

皇后一方：
- 早会上皇后特意问“对了，宁贵人呢？为什么今日没来呢？”陵容替她请病假（第56集第894幕）。博主观点：皇后和陵容唱双簧，目的是演给甄嬛看，也怕甄嬛过早看清关系而拉拢宁贵人（BV1G63WzYEqA，约13:26至13:55）。这是博主的推测。

## 3. 布局链条

目标：给还没摸清的中立者留下好印象，为拉拢铺路。

铺垫：
1. 早会上听到皇后点名，她知道这个人和皇后一方关系不好。
2. 离开景仁宫，在御花园听槿汐提议把合欢花做成香囊，她的回答是不如随它去，说明她当时心里有人和事放不下。几分钟后就遇到了摘落花的宁贵人，这份共情是真实的，后面的好意才不显得刻意。

借谁的手：内务府总管梁多瑞带来皇帝赏的料子，她先挑；小允子送料子、传话。

等什么时机：梁多瑞带着皇帝赏的料子来，请她先挑。这个机会是皇帝给的，送出去的东西来路正当。眉庄恰好在场，送料子是当面做的，没有避人。

怎么收网：
1. 御花园：被顶了也不恼，换一个关心身体的角度，把对方的无礼接成一句“等下日头毒了越发要难受了”。
2. 追问摘花瓣的原因，并夸“妹妹怜香惜玉之情，本宫自愧不如”。
3. 对方告辞，她不追不拦。
4. 回永寿宫，梁多瑞说皇帝让她先挑蜀锦和苏缎。她只让小允子把浅碧色的锦缎送去给宁贵人，理由是“大约喜欢绿色，那颜色也衬得起她”。
5. 浣碧不满，她解释：“我只是想着什么人穿什么样的衣服合适”。
6. 补一句让小允子告诉宁贵人，大热天的不必来谢恩。

留了什么后手：
- 不要对方谢恩，也不要对方回应，这份善意没有设条件。
- 博主观点：这样做有三层目的，做给皇帝看她体贴识大体，拉拢中立角色，呼应自己节俭的人设（BV1G63WzYEqA，约21:44至22:36）。
- 博主观点：她没有把料子送给敬妃、端妃，因为皇帝没给她们，转赠不合适，这点布料也收买不了她们；新人里她只遇到了宁贵人，对其他人还不了解（BV1G63WzYEqA，约22:03至22:25）。
- 眉庄劝她不必太好，她回“论起来总是皇上喜欢的人，有些场面不得不过。”这句把事说成场面，没有暴露真实的结盟想法（第56集第896幕）。

## 4. 关键话术

- 第56集第895幕 甄嬛：“听闻妹妹今日身子不适，怎么不在宫里好好歇息？等下日头毒了越发要难受了。”
  为什么管用：对方态度冷淡，不理会，转去关心身体，没有给对方一个可以对抗的目标。

- 第56集第895幕 甄嬛：“贵人为何摘了那么多花瓣呢？”
  为什么管用：问的是对方做的事，没有碰对方的身份，让对方说出自己在意的东西。博主观点：对宁贵人又称妹妹又称贵人，尊敬示好，不留痕迹（BV1G63WzYEqA，约17:34至17:41）。

- 第56集第895幕 甄嬛：“妹妹怜香惜玉之情，本宫自愧不如。”
  为什么管用：夸的是对方刚才说出来的真心，她会觉得被看懂。

- 第56集第896幕 甄嬛：“小允子过来，那匹浅碧色的锦缎给宁贵人送去，本宫看她大约喜欢绿色，那颜色也衬得起她。”
  为什么管用：送礼看对方的喜好，不看自己的。颜色这类小细节，说明你观察过她。

- 第56集第896幕 甄嬛：“我只是想着什么人穿什么样的衣服合适，这颜色适合她，我才让小允子给送过去，你和她刚见过一面，怎么就弄得跟冤家似的呢？”
  为什么管用：对自己人的情绪先接住再引导，同时把送礼的理由说得简单，不让别人往拉拢上想。

- 第56集第896幕 甄嬛：“怎么那么多话，不过一匹料子而已。小允子，你去告诉宁贵人，大热天的不必来谢恩了。”
  为什么管用：把礼物说小，免掉回礼的负担。

- 第56集第896幕 甄嬛：“论起来总是皇上喜欢的人，有些场面不得不过。”
  为什么管用：对担心风险的人，给一个对方能接受的说法，不把真实打算说出来。

## 5. 换到职场

### 场合一：面试（面试官态度冷淡甚至有点傲慢）

对应的局：面试官一直冷着脸，回答简短，甚至有些顶撞，同事私下说他不好相处。
打法：
1. 不被态度带着走，把注意力放在他的性格和关心的事上。
2. 他一旦在某个话题上松动，就顺着他说话，问他做过的具体事。
3. 夸他刚才说出来的真话，不要夸职位。
4. 面试结束不要求他给承诺，留下一个不需要他马上答复的跟进方式。
一句能直接说出口的话：“您刚才说团队现在最缺的是（对方提到的难点），我之前遇到过类似的情况，当时我是这样处理的（一句话）。不知道对您有没有参考价值？”

### 场合二：大佬建联（给还不熟的圈内人一个轻量的善意）

对应的局：你在活动中认识了一位性格独特、圈内口碑两极的人，你想留个好印象，但直接送礼或请吃饭会显得刻意。
打法：
1. 先观察他在意的东西，比如他提过的书、他发过的观点。
2. 送的东西要小，只对他的偏好，不对你的需要。
3. 明确说不必回复，也不必感谢。
4. 之后不要追着要回应。
一句能直接说出口的话：“上次听您提到（具体的那本书或那件事），我正好看到一篇相关的内容，发您参考。不用回复。”

## 雷区

- 浣碧：替主子计较对方的态度，拿情绪当判断。职场里别人对你冷淡，先看这个人的性格和位置，不要先生气（博主观点，BV1G63WzYEqA，约18:25至18:33）。
- 眉庄的提醒有道理：太后不待见的人，走得太近会被连累。这是风险。甄嬛的做法是把善意控制在一匹料子和一句关心上，职场里对圈内争议大的人，也只做小事，不公开站队。
- 做给皇帝看：博主观点这是三层目的之一（BV1G63WzYEqA，约21:44至21:56）。我们自己的判断：善意被说成刻意讨好，会减分，所以她用免谢恩把痕迹降到最小。
- 送礼前先想收礼的人是谁：博主观点是对静安师太这类人送金银等于骂她拜金（BV1G63WzYEqA，约05:16至05:21）。职场里同样要挑对方在意的东西，不要用价格代替心意。
- 小礼物没有交换条件。她料到对方不会感恩戴德，只图一个好印象（博主观点，BV1G63WzYEqA，约22:47至22:56）。职场里别指望一次善意换回对等的回应。
