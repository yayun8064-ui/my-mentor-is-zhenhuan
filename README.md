# 我的mentor是甄嬛

> 召唤甄嬛，当你的职场 mentor。


> 面试被追问、老板不松口、会上被当众质疑、饭局上不知道怎么开口……
> 把这个局说给她听。她会用自己的口吻帮你看透对面那个人，出一招，再递你一句明天就能说出口的话。

这是一个 AI Agent Skill（Claude Code 等支持 Skill 的工具都能用）。它从《甄嬛传》76 集剧本和 B 站 30 期深度解读里，蒸馏出甄嬛看人、布局、说话的方式，再一一对应到现代职场。召唤之后，你就是在和甄嬛本人聊天。

## 先看效果

> **你**：明天要找老板谈加薪。上次绩效面谈他说今年预算紧，我怕一开口就被堵回来。
>
> **甄嬛**：妹妹先别慌。他上回提预算紧，说明心里早料到你会开口，那句话是提前堵门呢。你明天若一上来就报数，正好撞在他备好的那句话上。
>
> 本宫看这位老板，在意的是两样：钱的口子不能由他先松，在他上头面前也得有个交代。所以你先别谈钱，先把这半年扛下来的事摆出来，让他自己说出“你确实辛苦了”。
>
> 到时候你就这么说：“这半年（具体项目）是我在推，结果是（具体数字）。我知道今年预算紧，想先听听您的看法：照这个表现，我接下来往哪个方向使劲，能在（时间点）调整到（目标）？”
>
> 他要是还拿预算挡，你也别硬顶，退一步，要一个时间点就好。当年本宫想接父母进宫，又请皇上重查旧案，两回都被挡了回来，本宫只回了一句可以等，不吵也不逼，让他记住这件事还在。
>
> 只有一样千万别做：拿别家的 offer 去压他。这一招，留到你真打算走的那天再用。

没有固定格式，你说一句，她接一句。信息不够，她会像宫里那样随口问你；你说“陪我练练”，她就扮成你的老板或面试官，跟你对戏。

## 她能陪你过哪些局

- **四个常见场合**：面试、聊投资（路演和投资人问答）、老板 1on1（要资源、谈晋升、推掉不合理的活）、和行业大佬建联（展会、饭局、加微信后的第一次聊天）。
- **四类通用难题**：被当众发难、处境不利、投其所好制造契机、small talk。
- **陪练**：她扮演对方出难题，你现场接话，接完她点评，再给你一版更好的说法。

## 和普通的“高情商话术”有什么不同

1. **蒸馏的单位是一盘局，一句台词只是其中一环。** 甄嬛厉害的地方在于：在皇帝面前立了一个和别人不一样的人设，把每个人看透，再用一连串前因后果把局做成。每个局都拆成五层：人设和差异化、读人、布局链条、关键话术、换到职场。
2. **先读人，再出招。** 她会从你给的细节里，读出对方在意什么、怕什么、软肋在哪，所有建议都落在你这个具体的局上，不说放之四海皆准的道理。
3. **只教体面的打法。** 剧里下毒、栽赃、设假前提钓鱼、利用感情换好处这些手段，只拿来帮你识别别人的套路，绝不当成你的打法。

## 甄嬛的 8 条底层逻辑

1. 把自己的诉求，说成对方自己的利益
2. 底牌不先亮，让对方先开口
3. 示弱是一种策略，但有边界
4. 先稳住，再等时机
5. 先给情绪价值，再谈实际的事
6. 借力，自己少露面
7. 给对方留余地
8. 先守住自己的可信度，再去动对方的证人

出现次数最多的几招：情绪价值先行、判断风险再开口、底牌不先亮、借第三方出手、让对方主动开口、给台阶。每一招在 `references/招式库.md` 里都配了一场完整还原的戏、换到职场的具体场面，以及它会失灵的情况。

## 安装

**Claude Code**

```bash
git clone https://github.com/yayun8064-ui/my-mentor-is-zhenhuan.git ~/.claude/skills/my-mentor-is-zhenhuan
```

重启 Claude Code 后，说“我的mentor是甄嬛”“召唤甄嬛”或“问问甄嬛”就能用。

**其他支持 Skill 或知识库的 AI 工具**

把 `SKILL.md` 当作系统指令或技能说明，把 `references/` 整个文件夹作为知识库一起上传。`SKILL.md` 靠 `references/` 里的局卡和招式来支招，两者要放在一起。

## 怎么用

- **触发词**：我的mentor是甄嬛、召唤甄嬛、问问甄嬛、甄嬛怎么办、甄嬛军师。
- **把局说清楚，她能看得更准**：你要面对的人是谁、和你什么关系，发生了什么（当众还是私下），你想要什么结果。
- **想练就说“陪我练练”**，她会扮成那个人出题。
- 她给你的话里，涉及数字、项目、经历的地方会用括号空着，要你自己填真实的内容。她不会替你编。
