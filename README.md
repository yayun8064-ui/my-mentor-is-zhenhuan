# 我的mentor是甄嬛

> 召唤甄嬛，当你的职场 mentor。
>
> 面试被追问、老板不松口、会上被当众质疑、饭局上不知道怎么开口……
> 把这个局说给她听。她会用自己的口吻帮你看透对面那个人，出一招，再递你一句明天就能说出口的话。

这是一个 AI Agent Skill（Claude Code 等支持 Skill 的工具都能用）。它从《甄嬛传》76 集剧本和全网的剧集解读里，蒸馏出甄嬛看人、布局、说话的方式，再一一对应到现代职场。召唤之后，你就是在和甄嬛本人聊天。

## 两种答法

| 你怎么问 | 她怎么答 |
|---|---|
| **闲聊、问一句、“帮我回一下这条”** | 几句体己话，点破要害，直接给你一条能复制发出去的回复 |
| **摊开一个复杂的局**：几个人、前因后果、要做决定或要去谈 | 进入**军师模式**：先查剧里最像的局，再按“局势先判 → 三套话术 → 预判对方进攻路线 → 底层心法”完整拆解 |

### 简单问答

> **你**：明天要找老板谈加薪。上次绩效面谈他说今年预算紧，我怕一开口就被堵回来。
>
> **甄嬛**：妹妹先别慌。他上回提预算紧，说明心里早料到你会开口，那句话是提前堵门呢。你先别谈钱，先把这半年扛下来的事摆出来，让他自己说出“你确实辛苦了”。
>
> 到时候你就这么说：“这半年（具体项目）是我在推，结果是（具体数字）。我知道今年预算紧，想先听听您的看法：照这个表现，我接下来往哪个方向使劲，能在（时间点）调整到（目标）？”
>
> 他要是还拿预算挡，你也别硬顶，退一步要一个时间点就好。当年本宫请皇上重查旧案被挡了回来，本宫只回了一句可以等，不吵也不逼，让他记住这件事还在。只有一样千万别做：拿别家的 offer 去压他。

### 军师模式（节选，虚构案例）

> **你**：明天事故复盘会，产品部门要把上线事故的锅甩给我们技术团队。真实原因是他们上线前两天临时改需求，测试被压到一天，我在群里提醒过风险，他回了一句“先上，有问题再修”。VP 主持，产品负责人跟 VP 关系很好。我不想背锅，也不想跟产品部门撕破脸。

> **【甄嬛军师 · 局势先判】**
> 妹妹，先别急着委屈。明天那间会议室里，谁先动气谁就输了一半。
>
> **过往伏笔**：你在群里提醒过风险，他回了“先上，有问题再修”。**这句话就是明天最硬的那张牌。**
> **对方真正图的**：把事故定性成技术问题，产品部门就不用改流程，以后照样可以临时改需求。
> ✅ **你的核心目标**：让事故原因按时间线落地，责任按事实分清；不点名攻击任何人，会后两个部门还能坐在一张桌上。
>
> 🔹 **版本一｜温婉持重版**（首选）
> “这次事故，技术侧确实有要改进的地方：（属实的一两点），这些我们已经在补。另外我想把时间线完整对一遍，方便大家判断根因：需求是（日期）调整的，测试从三天压到了一天，当时我在群里提过风险，记录都在。我建议这次复盘一起看看需求变更的流程，后面两边都好做。”
>
> ⚠️ **最高危的一问**：“你的意思是责任全在产品？”
> 你回：“我没有要分谁多谁少，我只想把时间线放在桌上。结论请您来定。”
>
> **本宫的底层心法**：本宫当年在景仁宫被人当众告发，属实的那件旧事认了，先请皇上准本宫问几句话，一问就把作证的人问出了破绽。你明天也一样，先守住自己的可信度，再去动对方的证据。

完整的三个示范在 [`examples/`](examples)：[事故复盘会被甩锅](examples/示例一_事故复盘会被甩锅.md)、[空降总监拆走项目](examples/示例二_空降总监拆走项目.md)、[投资人当面压价](examples/示例三_投资人当面压价.md)。

## 她怎么出主意

军师模式下，她不会凭空发挥，每次都先查卡：

1. **路由**：`tools/route.py` 按信号词判断这是什么场合、什么局面（被当众发难、被抢功陷害、拒绝、谈条件……），对面是什么位置的人，再从 16 大类、93 个职场和日常场景里挑出最像的两三行，连同对应的局卡、招式、底层逻辑和雷区一起交给她。场景表里没有现成情形时，也会按局面类型把同类的局卡找出来。
2. **心里先盘六件事**：盘人、读伏笔、识真意、守本心、算后手、留余地。
3. **落到你身上**：在局卡的基础上，结合你给的细节写诊断、话术和预判。缺关键信息时，她只问你一句。

**不接大模型也能跑**：`python3 tools/route.py "你的情况"` 会直接给出匹配的剧中局、可用的招、局卡里的现成说法和雷区，当一个离线的锦囊检索器用。实测 16 个职场和日常场景，第一候选基本都能对上；读人、把话改到你的具体情况上，还是要交给大模型。

## 她能陪你过哪些局

职场和日常里人和人之间的局，她都接：刚到新地方怎么立足、被长辈或领导盘问、当众被挑刺、功劳被抢、想拒绝又不想撕破脸、求人帮忙、闺蜜和伴侣之间的那些事……一共 16 类。

挑几个最有意思的：

| 你遇到的 | 甄嬛当年 |
|---|---|
| 男朋友当着你的面夸你闺蜜好看 | 皇帝当着她的面夸浣碧，她用皇帝自己说过的话，把话题轻轻挡了回去 |
| 婆婆突然特别客气，说过年不用回去了 | 皇后称病不陪驾，把露脸的机会“让”给了她 |
| 过年被七大姑八大姨轮番盘问 | 回宫第二天，被太后一口气连问五个问题 |
| 刚入职，老员工热情请你吃饭，顺便打听你跟谁熟 | 入宫第一天，华妃派人送来一份厚礼 |
| 饭局上两位领导当众互呛，全场僵住 | 清音阁看戏，华妃拿出身刺皇后，她点了一出《南柯记》把话转开 |
| offer 谈得差不多了，还想再比一比 | 华妃的厚礼收下了，登记入库，一件没戴 |
| 发现对象爱你，只因为你像他的前任 | 读到那句“莞莞类卿” |

想练的时候说一声“陪我练练”，她就扮成你的老板、面试官或者那位难缠的亲戚，跟你对戏，接完再点评。

## 和普通的“高情商话术”有什么不同

1. **蒸馏的单位是一盘局，一句台词只是其中一环。** 甄嬛厉害的地方在于：在皇帝面前立了一个和别人不一样的人设，把每个人看透，再用一连串前因后果把局做成。每个局都拆成五层：人设和差异化、读人、布局链条、关键话术、换到职场。
2. **先读人，再出招。** 她会从你给的细节里，读出对方在意什么、怕什么、软肋在哪，所有建议都落在你这个具体的局上，不说放之四海皆准的道理。
3. **只教体面的打法。** 剧里下毒、栽赃、设假前提钓鱼、利用感情换好处这些手段，只拿来帮你识别别人的套路，绝不当成你的打法。

## 甄嬛的 8 条底层逻辑

1. 把自己的诉求，说成对方自己的利益
2. 底牌不先亮，让对方先开口
3. 示弱是一种策略，但有边界
4. 先稳住，再等时机
5. 先给情绪价值，再谈实际的事
6. 借力，自己少露面
7. 给对方留余地
8. 先守住自己的可信度，再去动对方的证人

出现次数最多的几招：情绪价值先行、判断风险再开口、底牌不先亮、借第三方出手、让对方主动开口、给台阶。每一招在 `references/招式库.md` 里都配了一场完整还原的戏、换到职场的具体场面，以及它会失灵的情况。

## 安装

**Claude Code**

```bash
git clone https://github.com/yayun8064-ui/my-mentor-is-zhenhuan.git ~/.claude/skills/my-mentor-is-zhenhuan
```

重启 Claude Code 后，说“我的mentor是甄嬛”“召唤甄嬛”或“问问甄嬛”就能用。

**其他支持 Skill 或知识库的 AI 工具**

把 `SKILL.md` 当作系统指令或技能说明，把 `references/` 整个文件夹作为知识库一起上传。`SKILL.md` 靠 `references/` 里的局卡和招式来支招，两者要放在一起。运行不了脚本的平台也没关系，她会改用 `references/场景映射.md` 末尾的局面类型速查表来查卡。

## 怎么用

- **触发词**：我的mentor是甄嬛、召唤甄嬛、问问甄嬛、甄嬛怎么办、甄嬛军师。
- **把局说清楚，她能看得更准**：你要面对的人是谁、和你什么关系，发生了什么（当众还是私下），你想要什么结果。
- **想练就说“陪我练练”**，她会扮成那个人出题。
- 她给你的话里，涉及数字、项目、经历的地方会用括号空着，要你自己填真实的内容。她不会替你编。
